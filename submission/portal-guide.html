二、登录步骤（发布者本人，约 1 分钟）

1
在右侧可见浏览器面板操作
面板当前已停在 platform.openai.com/login。若显示 Cloudflare 验证框，点击勾选即可（自动脚本可能过不了，人工点一下通常秒过）。
2
选择登录方式
Google / Apple / Microsoft / 手机号 / 邮箱，任选你 codex 已登录的同一个 OpenAI 账号。完成验证码/OTP。
3
登录后告知助手
说一句「登录好了」，助手会立刻继续：核验权限 → 身份验证状态 → 填 URL → 确认政策声明。

四、登录后的逐项核验路径

#核验项在哪里看 / 怎么做判定
1Apps Management Write 权限Platform 左侧 Settings → Organization → Members/Roles；或进入 Apps/Plugins 提交入口，看是否出现「提交/发布」按钮而非只读提示能进入提交表单并保存草稿 = 有权限；提示需要权限 = 需组织 Owner 在 Roles 里授予
2身份验证（Identity Verification）Settings → General/Account 或提交表单内的 Verification 环节显示 Verified = 通过；显示待验证 = 按表单提交材料（须发布者本人完成）
3网站/支持/隐私/条款 URL提交表单对应字段，按上文映射逐项粘贴保存草稿成功
4政策声明确认提交表单底部的数据/隐私/安全/政策复选框，逐项勾选全部勾选后「提交审核」按钮亮起
5发行地区表单发行地区选择按需选择
6提交审核点击「提交审核」（Submit for Review）进入审核状态；审核通过后由发布者主动点击发布

五、常见卡点

卡点处理
Cloudflare 验证框反复出现在可见面板里人工点击勾选；自动脚本可能无法通过
提示无 Apps Management Write需组织 Owner（可能就是你自己）在 Settings → Roles 授予该权限后重试
身份验证要求证件/企业材料必须发布者本人完成，助手不代提交；完成后再继续
表单没有出现 URL 字段该字段为「如被要求」项——未被要求时跳过，四项 URL 保持就绪即可
审核通过后未上架需发布者本人主动点击「发布」；发布后公共详情页可被普通用户安装才算完成
