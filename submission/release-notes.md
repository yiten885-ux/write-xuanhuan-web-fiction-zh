# Release notes

## 1.2.0

- 新增逐章节奏二十项硬锁，覆盖有效节拍、主角能动性、反派压迫、能力记忆点、信息载体、开闭钩、回报、对白、释谜、战斗、配角、战力、感官、心理、修炼、支线、悬念、章间衔接与名词锚定。
- 二十项与既有 v1/v2、01–10、九项留存、连续性和去模板化合同并列累积；示例不进入通用门禁，单一 POV、因果链和设定稀缺性继续优先。
- 默认逐章净正文窗口统一为 2000–3200，并保持逐章独立验收、禁止跨章补偿和非正文补字。
- 加固正文防火墙：二十项规则名、公式、IF/THEN、自检报告、重写标记及其 Markdown、HTML、Unicode 变形不得进入正文或参与字数。
- 扩展章卡与故事圣经的滚动证据账；机械审计仍不冒充节奏语义、文学质量、读者留存或商业结果证明。

## 1.1.0

- 新增长篇防跳脱状态事务，累积执行事实、人物、世界、主线、视角、知情、时间与空间等连续性锁，不替换旧版开篇与留存合同。
- 新增独立 `.state.json` 模板与验证器，检查最终正文原始哈希、来源锚、关键帧、事务绑定、相邻版本链、知情来源与硬冲突。
- 强化读者正文防火墙，状态卡、JSON/YAML、Markdown/HTML 表格、约束标签与审计填充不得进入正文或补足 2000–3000 净字数。
- 增加去模板化风格卡、候选扫描与定向改写闭环；候选词命中不冒充 AI 作者身份判断。
- 全量回归扩展至 117 项，并补充结构化状态污染、混淆文本和跨章补字的对抗用例。

## 1.0.1

- 同步最新版 `write-xuanhuan-web-fiction-zh`，将前三万字留存合同由六项扩展为九项，并保持既有规则累积生效。
- 新增核心外挂稀缺性、滚动六章情绪峰值配比和章尾安全区禁令，减少能力同质化、连续算计疲劳与弱钩子收尾。
- 加固正文污染审计，覆盖更多 Markdown、HTML、Unicode、隐藏内容和跨章凑字绕过，同时避免常见小说语句误伤。
- 保持逐章 2000–3000 个净正文有效字符门禁；内部规则 ID、自检标签和 QA 控制文字不得进入读者正文。
- QA JSON 默认只记录源文件名与 SHA-256，不暴露使用者本机绝对路径。

## 1.0.0

- 首次以 skills-only Codex Plugin 形式封装 `write-xuanhuan-web-fiction-zh`。
- 市场展示名定为“玄章天工｜Xuanhuan Storyforge”，保持原 Skill 技术 ID 兼容。
- 汇总中文玄幻网文规划、前三章、续写、重写、人物与世界观、节奏与连续性工作流。
- 强化读者可见正文隔离，避免内部约束标签、自检块和 QA 元数据混入小说正文。
- 默认逐章检查 2000–3000 个净正文有效字符，防止跨章凑字和隐藏内容补字。
- QA JSON 仅记录源文件名与 SHA-256，不再暴露使用者本机绝对路径。
