# 公开页面内容草案

这些内容需要由发布者放到公开 HTTPS 页面后，再把真实 URL 填入 OpenAI 提交门户。当前仓库是私有仓库，因此仓库内文件本身不能替代公开 URL。

## 隐私说明草案

玄章天工是一个 skills-only Codex Plugin，不包含远程 MCP 服务，不自行建立用户账户，不要求第三方 API Key，也不向开发者控制的服务器发送正文或设定。它在 Codex 会话中处理用户主动提供的文本；相关数据处理同时受用户所使用的 OpenAI 产品条款与隐私政策约束。

本地审计工具只读取用户指定的正文和随插件提供的规则文件。只有在用户或代理显式传入 `--json-out` 时，它才会另写本地 QA 报告；报告记录源文件名和内容 SHA-256，不记录绝对路径。

## 服务条款草案

玄章天工提供写作辅助、结构建议和机械检查，不保证作品获得签约、流量、收入、出版或任何特定市场结果。用户应自行确认其输入材料、生成内容和发行行为符合适用法律、平台规则与第三方权利。机械校验通过不等于文学质量、事实准确性或商业成功。
