# Report 16 规则蒸馏

## 报告主题
章末钩子全解：钩子的定义与八种类型、产品层钩/结构层大钩、创作硬规则（K01-K14）、八套公式、钩子在小说结构中的嵌套位置与黄金三章钩排布。

## 硬规则

### 定义与类型
- R16-01 钩子只做一件事：让手指去点下一屏。钩子=未完成动作+绑定主角命运的疑问+下章必须落地；三件缺一就是空钩。
- R16-02 钩子不是伏笔（伏笔当时可以看不见），不是悬念本身（悬念可以撑一个单元）；钩子必须这章看见、下章接住。
- R16-03 章末八型：1动作截断（刀在喉、手在门把，下章先完成这个动作）、2危机突袭（刚赢，更大的眼在暗处，番茄容错最高，下章新压迫源进场）、3半揭（物证亮了、称呼被打断，用于掉马、隐藏层，下章把那一声喊完）、4反转揭秘（最后一行推翻整章预判，用于内鬼、真凶，下章余震+改局面且必须有齿）、5倒计时（香还剩一寸、三日婚期，下章抢时限）、6新债（更高层看见了，打脸后，下章上报后果）、7机遇/灰行（系统亮两字、秘境开门，下章试用或踩坑）、8信息遮断（他知道了但不能说，悬疑、少用于纯爽，下章代价先落地再给真相）。
- R16-04 番茄男频默认多用1/2/3/5/6（动作截断/危机突袭/半揭/倒计时/新债）；4不能空降；8用多了像谜语人。
- R16-05 章首钩（接上一章）不是新开，是把上章刀接住：第1句接动作，不接心情、不接"一夜无话"。
- R16-06 章中钩（可选，防中途划走）：打脸刚完、场景要切时丢一个微钩（灰行闪一下、门外脚步、名册缺一行）；立刻接着写，不准在这里断章。
- R16-07 产品层钩：书名钩的是"点开"（身份反差+金手指+结果）；简介末句钩的是"点第1章"（下一件具体事，禁"踏上巅峰"）；章标题钩的是"点进该章"（冲突或结果预告，不要"第X章"空名）。
- R16-08 结构层大钩：黄金三章末=更高层点名；打脸单元末=换标的或换图齿（带向下一单元）；卷末=本图Boss死后的上游债（带向新地图规则）；起点付费卡点=动作截断+身份齿，付费后第1章立刻兑现。

### 创作硬规则 K01-K14
- R16-09 K01 断在动作，不断在总结："他不知道更大的风暴"=作者剧透不是钩；门开了、香按进炉、茶杯放下，才是钩。
- R16-10 K02 必须绑定主角命运：配角接神秘电话、天边流星、路人说城东闹过鬼，跟主角桌上的标的无关=谜语人，骗两次读者就不信。
- R16-11 K03 本章先给爽，再留钩：钩子不能代替兑现；整章只吊不给，完读掉；结构是加压→释放→钩子。
- R16-12 K04 下章前200字必须接住：不准另开修炼、回忆、日常；答案可以拆，动作必须接。
- R16-13 K05 轮换防疲劳：禁止连续3章同一型；强钩（截断/半揭/反转）每2-3章一发，中间用倒计时、新债、灰行这种小钩；连续5章架刀，读者会麻。
- R16-14 K06 最后100-200字才是钩的位置：前面铺画面，最后一句落地；字写太长，钩被冲淡。
- R16-15 K07 断在天然断层：情节转换、场景切换、情绪刚到顶；不要在解释设定的句子中间切。
- R16-16 K08 反转钩必须有齿：章末"师父才是真凶"前文没3齿=空降，读者骂作者。
- R16-17 K09 一条钩只问一个问题：禁止最后三句连丢身份+秘境+天劫；读者不知道追哪条，等于没钩。
- R16-18 K10 钩要带本书指纹："且看下回分解""接下来会发生什么"放到哪本书都能用=空钩；婚书、名册、供奉令、灰行……才抄不走。
- R16-19 K11 主线章强钩，过渡章小钩：不是每章都要喉上架刀；过渡章用"名册缺一行"就够。
- R16-20 K12 钩链3-5环，不准一次揭完：接钩时只解当前动作，同时咬出下一环；下章开头马上把全部答案倒完，钩就死了。
- R16-21 K13 番茄要画面，起点才允内心：番茄=可视化（门、香、令、血）；起点=可以"他忽然想起那枚印"；晋江=欲言又止；别混用。
- R16-22 K14 卷末钩必须换规则，不能只换一个更骂人的反派。

## 公式与结构模板
- 公式1 钩子卡（每章必填）：本章主钩类型（八选一）；未完成动作（最后看见什么）；绑定主角的疑问（一句）；下章第1句怎么接；本环解开后咬出的下一环；是否与上两章类型重复（必须否）；指纹物（婚书/名册/令/灰行/香）。
- 公式2 最后120字结构：余波40字（收获入账或观众改口，证明本章已兑现）+断层40字（场景切/有人来/时限提示）+钩40字（一个未完成动作、一句疑问、打住）；禁止在钩后面再写一句解释。
- 公式3 八型造句：1截断="刀锋抵到喉结。他手腕一翻——"；2危机="护体刚裂。回廊暗处，第二双眼睛睁开。"；3半揭="青令放下。来人开口：见过——"门在这时撞开。"；4反转="名册最后一行，执事自己的名字被勾掉了。"；5倒计时="执事把香按进炉。'一炷香。'"；6新债="茶杯放下的人站了起来。他看的不是令，是袖口那道灰印。"；7机遇="面板灰行亮了两个字：未授权。"；8遮断="婚书背面的印，他认得。这句话不能在这个堂上说。"
- 公式4 接钩（下章开头）：第1句=上章最后那个动作的下一帧；第2-3句=当场代价或见证；然后再开本章新加压；禁止一夜无话、回房修炼、突然换人。
- 公式5 钩链（3环起）：环1章末"门开了（谁）"→环2解开谁、咬出他手里的令（什么）→环3令亮了、咬出令上不是本宗的印（哪来的）→环4印对上婚书灰烬（因果账）；每环只解一个疑问，同时制造一个更贵的疑问。
- 公式6 强弱配比：强钩（截断/半揭/反转）=第3、5、10、30章以及单元末、卷末；中钩（危机/倒计时/新债）=其余主线章；小钩（灰行闪/名册缺字）=过渡章；禁止第4、6、7、8、9章连续强钩。
- 公式7 产品钩：书名="谁被怎样，他用什么把结果反过来"；简介末句="三日后她另嫁内门第一人。聘礼单还在执事手里。"；章标题="《名册上那一笔》《一炷香》《见过——》"；章标题钩的是本章，不要剧透下一章。
- 公式8 自检三问：1.我会不会立刻点下一章？2.点是因为必须知道，还是随便翻翻？3.把人名换掉，这钩是不是哪本书都能用？第3问为是=空钩，重写。
- 结构落点细则：书名=卖点钩12-22字、第1章兑现一半；简介最后一句=具体事件钩1句、第1章；第1句正文=冲突钩（不是悬念谜语）1句、当章；黄金三章每章末=强钩、第3章钩必须指向更高层、下章/第4章兑现；每章章首=接钩前200字；每章章中=微钩可选1句不切章、当章后半兑现；每章章末=主钩八型轮换、最后100-200字、下章前200字接；第5、10、30、50章=强钩+隐藏层齿（半揭）；单元末=新债或换标的、强于普通章、下单元第1章兑现；卷末=规则级钩带下图齿、可半揭身份、下卷第1-3章用冲突教规则；起点上架章=动作截断+物证卡在喉上、付费章立刻接并给小兑。
- 黄金三章的钩怎么排：Ch1末=倒计时或灰行（明日来杀/权限未授权）；Ch2末=危机或新债（新天才进场/名额被夺）；Ch3末=半揭或更高层（"见过——"/长老要见他）。第1章不要用大反转钩（读者还没有错误信念可折）；第3章不要用纯机遇钩（该把场子抬高了）。
- 一章内部坐标（2000-2500字）：0-200接上章钩（上钩的兑现口）；200-1000加压（可在切场处丢微钩）；1000-1800释放（打脸/升级）——这里不要断章；1800-2200余波入账；2200-2500主钩。最常见的写崩：在1500字打脸最高点断章（读者爽完了不一定翻）；把余波写完，再在"更高层站起来"处断，翻页率更高；打脸是兑现，站起来的人才是钩。
- 和埋伏的位置差：钩=章末、看见、下章接；微回应=章中或余波里、证明长伏还活着、不断章；埋伏齿=爽点刚过的缝里、当时可忽略。三者可以叠在同一物上：婚书是埋伏，章末"灰烬里那道印发光"是钩，下章印烫手是接钩，第30章对印是回收；不要三件事写成三件道具。

## 禁忌与反例
- 写崩对照（病→改法）：空钩（"且看下回""接下来会发生什么"）→换成带指纹的动作；谜语钩（流星、神秘电话）→绑回名册/婚书/令；总结钩（风暴即将来临）→门开了；不接钩（下章修炼）→第1句接动作；以钩代爽（整章只吊）→先兑现再钩；同型连发（五章都刀在喉）→2-3章一发强钩；钩三问（身份+天劫+秘境）→只留一个动作；打脸点断章（护体裂完就切）→裂完写余波，再让更高层站起来；上帝钩（"他不知道……"）→删掉，写看见什么；空降反转钩（章末师父是凶手，前文0齿）→改危机/半揭，齿够了再用4。
- 锁死段（可贴System Prompt）：钩子=未完成动作+绑定主角命运的一个疑问+下章前200字必须接住；每章先兑现再留钩；钩在最后100-200字，断在动作，禁止总结和上帝旁白；八型轮换，禁止连续3章同型；强钩每2-3章一发；一条钩只问一个问题，必须带本书指纹物；下章第1句接上一帧，禁止一夜无话；接钩只解一环同时咬出下一环，链长3-5；黄金三章：Ch1倒计时或灰行、Ch2危机或新债、Ch3半揭或更高层；打脸不要断在最高点，断在更高层看见之处；卷末钩必须带下图规则齿；空钩/谜语钩/不接钩视为废章，重写。
