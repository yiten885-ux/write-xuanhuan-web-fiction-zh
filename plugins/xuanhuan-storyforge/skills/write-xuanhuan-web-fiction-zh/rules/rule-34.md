# Report 34 规则蒸馏

## 报告主题
入门/入宗考核合同（第七轮补充规则 43-48）：三关递进结构、反套路差异化、作弊/黑幕机制、主角破局差异化、考核结果多重出口、考核后置收益清单——六大可量化硬规则，专治考核写成流水账（内容平庸/只有主角在动/结果无悬念/对后续无推动）。

## 硬规则

### 考1｜三关递进结构（防单一无层次）
- R34-01 完整入门考核必须三关递进，每关考核不同维度：第一关·门槛关（基础资质/硬指标：测灵根/骨龄/灵力下限，字数占比 10-15%）；第二关·筛选关（实战/应变/心性：猎杀妖兽/闯迷宫/心魔幻境，40-50%）；第三关·决胜关（对决/终极考验：擂台赛/夺旗战/最后试炼，35-45%）。
- R34-02 递进逻辑：淘汰率逐级递增——第一关 50-70%（刷杂鱼）、第二关 60-80%（刷平庸者）、第三关 30-50%（留精英）。
- R34-03 禁止考核只有「测灵力→打擂台」两关，或三关内容同质化（全是打架）。
- 公式：考核结构强度 S = 关卡数(3) × 维度差异化(D)；任两关维度重复则强制替换内容。

### 考2｜反套路差异化（防读者看吐）
- R34-04 三关内容必须按替换规则避开经典套路：测灵根（摸水晶球）→ 测「道心」（幻境坚持时长）/「气运」（随机抽取试炼场）/「特殊体质」（血滴石台看反应）；猎杀妖兽（杀怪数数量）→ 猎特定目标（兽核/灵草）/护送任务/解谜任务（破阵/找线索）；擂台赛（一对一）→ 混战淘汰赛/夺旗战/守关战（挡波次攻击）；心魔幻境（看幻象）→ 问心石（拷问灵魂）/因果镜（看见未来可能）/血誓台（代价性誓言）。
- R34-05 禁止同一部小说连续两次考核用完全相同的关卡形式。
- 公式：新鲜度 N = 1 − (经典套路使用次数/总关卡数)；N < 0.5（超一半是套路）触发套路预警，强制替换 ≥2 关。

### 考3｜作弊/黑幕机制（防考核太平）
- R34-06 考核中必须存在至少一处不公正因素，五类可选：考官偏袒（放水/透题，主角被压分刁难）；世家联手（围剿散修，主角被孤立针对）；买通关系（妖兽被削/关卡透题，不公平竞争）；规则倾斜（世家子弟初始多一分，主角劣势开局）；暗杀干预（借考核行暗杀，威胁超出考核范围）。
- R34-07 禁止考核全程公平公正毫无波澜。
- R34-08 作弊/黑幕的揭露必须与主角的反转/打脸在同一考核周期内完成。
- 公式：考核压迫感 P = 作弊存在(0/1) × 影响程度(1-5)；P = 0 判「考核太平」，强制插入不公正因素。

### 考4｜破局差异化（防主角莽夫化）
- R34-09 主角通过三关的方式不得全是硬实力碾压，至少一关用非武力破局，五类可选：智谋破局（识破阵法规律/话术绕过心魔）；奇遇破局（古碑/熔炉异动获临时加成）；人性破局（拉拢盟友/挑拨内讧）；代价破局（精血/寿命/宝物换临时突破）；规则破局（发现规则漏洞反向操作，如「没说不能合作」）。
- R34-10 分布比例：武力破局 ≤1 关；非武力破局 ≥2 关。
- 公式：破局多样性 V = 武力(≤1) + 非武力(≥2)；不合格判定「主角变莽夫」，强制至少一关改非武力破局。

### 考5｜多重出口（防只有过/不过）
- R34-11 考核最终结果至少三种可能：甲等通过（三关卓越/惊人表现→直接内门/亲传）；乙等通过（中等偏上→外门+后续任务）；丙等通过（某关极差但其他极亮→破格录取+附加条件如一年内突破否则逐出）；被针对通过（黑幕压分但表现优异→后续自证/闹翻另投）；未通过但有收获（获得关键物品/信息→另一条成长线）；主动弃权（发现考核背后阴谋→提前触发主线）。
- R34-12 禁止考核结束只有「你通过了/你没通过」一句话交代。主角为甲等时，同场景至少提一句其他选手的不同结果。
- 公式：出口丰富度 E = 结果选项数 ≥3；E < 3 判「结局单一」，强制增加 1-2 种。

### 考6｜后置收益清单（防考核白写）
- R34-13 考核结束后主角必须获得至少三项可量化收益并逐一列出，六类可选：身份收益（内门令牌/藏经阁权限）；资源收益（凝气丹×3/黄阶功法）；信息收益（父亲陨落的神秘标记/长老与身世有关）；人脉收益（长老注意/天才结盟）；能力收益（突破瓶颈/新法术）；悬念收益（考核场地古碑纹路暗示更大秘密）。
- R34-14 禁止考核结束只有「主角成功入门」而无任何具体收益；收益清单必须在考核结束后 200 字内呈现，不可拖到下一章。
- 公式：考核价值 V = 收益项数 ≥3；V < 3 判「考核白写」，强制补充至少 2 项。输出格式：「1. 身份收益：…2. 资源收益：…3. 信息收益：…」
