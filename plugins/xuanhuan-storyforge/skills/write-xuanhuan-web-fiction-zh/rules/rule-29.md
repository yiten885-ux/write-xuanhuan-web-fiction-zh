# Report 29 规则蒸馏

## 报告主题
爆款语言合同（番茄玄幻爽文）：白·短·冲·有物的语言总标准、语1-语15 十五条语言硬规则、语言指纹病表、禁用词/慎用词表、八个语言公式与五刀自检——专治模型默认写「工整、抒情、总结、排比」的作文腔。

## 硬规则

### 一、句子与节奏
- R29-01 一句一事：一句里禁止又羞辱又回忆又报境界，拆开。
- R29-02 叙述句默认不超过二十字；超过必须是对话或规则原文。
- R29-03 动词开头或人名开头；禁止「在这充满压迫的气氛中」。
- R29-04 每 200 字必须出现一件物或一个数字（婚书、令、香、榜、境界、灵石）；没有物的 200 字当水删。
- R29-09 同一段禁止三句同结构（他……他……他……）；改成动作/对话/别人的反应。
- R29-12 标点：句号、问号为主；感叹号每章不超过五个；禁止「……」当高潮，省略号留给半揭被打断。

### 二、对话与心理
- R29-05 对话占比不少于四成，且对话要办事：羞辱、报价、宣律、喊名、点破一句；禁止用对话讲体系课。
- R29-06 心理不超过两成，单次不超过三句；能改动作必须改动作。
- R29-13 称呼和口吻锁死：遮住名字还能听出谁在说话；主角不解释、不喊口号；反派羞辱必须落到身份加资源，禁止空骂废物连发。
- R29-14 系统面板可以短、可以贱，角色嘴里禁止系统腔。

### 三、总结与比喻
- R29-07 禁止作者总结：「他不知道」「这意味着」「正是此时」「命运开始」。章末尤其禁。
- R29-10 比喻每章最多一处，且必须落到物上（「像被按进炉里的香」可以；「如同一把利剑刺入心脏」删）。
- R29-15 去翻译腔：禁止「他感到一种……」「一种名为……的情绪」「他意识到他必须」。

### 四、词汇纪律
- R29-08 禁用词出现即替换（当章作废级，见禁用词表）。
- R29-11 四字格密度：连续两个四字成语就改口语；反派可偶用四字装逼，主角少用。

## 公式与结构模板

### 总标准
能看见手和物 > 能听见谁在说话 > 能感到情绪。禁止作者替读者总结该怎么爽。

### 公式A：白描替换
情绪词 → 手 + 物 + 一下：「愤怒」→ 他把两半婚书叠齐，压回石桌；「紧张」→ 香灰掉在他袖口上，他没弹；「震惊」（别人）→「他是炼气？」

### 公式B：句长谱（一段四到六句）
短（≤8字）。短。中（15~25字，放入物或数字）。对话。短。例：执事收走聘礼单。苏绾笑。「炼气三层，也配写进苏家谱？」陆沉把两半叠好。「今晚送，还是我去取。」

### 公式C：信息从嘴里出，规则从手上出
羞辱、报价、点名 → 对话；盖印、抽令、裂护体 → 叙述动作一句一个动词；体系、历史禁止专段，最多借执法之口宣一句律。

### 公式D：三人三嘴
主角：短，问手续，不解释；对手：长，具体羞辱（身份+资源+时限）；旁观：一句数字或一句「他是……？」。三人同腔=废对话。

### 公式E：打戏语言
报数字 → 一招（一个动词+碰到哪）→ 对照物碎（护体纹、剑、榜）→ 一句改口。禁止招式名连喊、禁止内力在经脉里跑八百字。

### 公式F：章首章末
章首第一句：动作下一帧，禁天气。章末最后一句：未完成动作，禁总结。

### 公式G：去 AI 味五刀（写完扫一遍）
1. 删所有「不禁、仿佛、这意味着、在这一刻」；2. 连续排比改留一句；3. 心理改手；4. 每 200 字补一个物或数字；5. 章末若像预告片旁白，改成门、香、印、剑。

### 公式H：对照改写
作文腔「在这充满嘲讽的议事堂中……空气仿佛凝固了」→ 爆款腔「婚书两半落在青石上。苏绾：『炼气三层，也配写进苏家谱？』陆沉把两半叠好，放回桌上。『聘礼单。今晚送，还是我去取。』」——同一场，字少、物在、嘴在、怒在动作里。

## 禁忌与反例（语言指纹病表，出现就改）

| 病 | 样子 | 改成 |
|---|---|---|
| 排比三连 | 他不哭，不辩，不求 | 只留一个动作 |
| 情绪标签 | 心中一凛、微微一怔、不禁 | 手碰到什么 |
| 空气文学 | 空气仿佛凝固、时光静止 | 茶盏放下、全场没人出声 |
| 总结句 | 这意味着更大的风暴 | 删，写门开了谁进来 |
| 对仗工整 | 不是废物，而是王者 | 令放下。有人喊见过 |
| 成语串 | 趾高气扬、目中无人 | 一句具体羞辱 |
| 全员一书 | 长老也说「不过如此」 | 分人口吻 |
| 心理大会 | 连续内心超过三句 | 改成看、拿、放 |
| 副词堆 | 缓缓、微微、深深 | 删副词，留动词 |
| 翻译腔 | 他意识到他必须 | 他按住印 |

## 禁用词 / 慎用词

- 禁用（出现就改）：不禁、微微、缓缓、一丝、仿佛、宛如、如同、心中一凛、眼神一凝、空气凝固、时光静止、与此同时、这意味着、不仅仅、而是、正是、在这一刻、命运、齿轮、篇章、画上句点、深深地、令人、显得、进行、开始感到、他意识到、不由得、嘴角微扬、目瞪口呆、倒吸一口凉气（每章最多一次）、暴风雨前的宁静、更大的风暴还在后面。
- 慎用（每章各最多一次）：冷哼、淡淡道、不屑、嗤笑、目光如炬、杀意、霸气、傲然。
- 主角禁口号：天不生我、问剑、我命由我、不过如此（他自己说）、你们都得死（空喊）。杀伐用动作：收聘礼单、把香按进炉、一招、走。

## 稳定产出方法
单靠「写得像爽文」无效。要样例 + 禁用表 + 句长谱 + 写完五刀。System 里锁：白短冲、一句一事、对话四成、禁用表、章首章末。用户消息里塞 50-100 字本章口吻样例（模仿句长用词，不模仿情节）。输出顺序：先章纲再正文；正文后强制跑公式G五刀，有禁用词改完再交。抽检指令：「遮住人名三人说话能否分开」「任意连续 200 字有没有物或数字」。润色方向写死：只删不添，只改动作，不升格比喻。
