# Report 23 规则蒸馏

## 报告主题
爽点货盘：男频玄幻默认 12 种爽点货（打脸/装逼/掉马/升级/得宝/规则反套/真香/复仇/离场/新用法/越级/解释权）各自的爽核、硬规则、四拍公式与组合排货法。

## 硬规则

### 一、总纲
- R23-01 爽点是读者欲望被当场结算的那一下：桌上那件东西易手、全场改口、数字跳了、仇账兑了一笔；不是「主角赢了」。
- R23-02 总公式：爽=压力积累×释放满足×反差程度。类型只决定释放的货；货要轮换，压和债的结构不变。
- R23-03 完整小闭环（推荐默认）：装逼/挑衅→打脸→余震改口→收获。没有收获的打脸，爽感会虚；收获不等于升级，改回名册一行也算。
- R23-04 女频常加：甜宠、护短、误会解开；男频番茄默认关或降成「资源包」。都市常加：刷卡、打赏、身份打脸；结构一样，物换成卡和姓。

### 二、总硬规则 S01-S12（所有货都吃这一套）
- R23-05 (S01) 先压后弹。无落地损失的弹是闹剧。
- R23-06 (S02) 必须当众。没观众就没有余震。
- R23-07 (S03) 弹要短：核心释放 ≤200 字。
- R23-08 (S04) 必须改局面：名分/资源/阶层/解释权至少动一项。
- R23-09 (S05) 收获可视化：数字、令、名册、境界。禁「他变强了」。
- R23-10 (S06) 只 +1 级。杂役章发仙帝=通胀。
- R23-11 (S07) 同货不应期：连续 3 章禁止同一类型。
- R23-12 (S08) 人设不跟着爽：杀伐不圣母，装废不话痨报身份。
- R23-13 (S09) 弹完欠债：更高层看见。
- R23-14 (S10) 一章一个主爽点，最多一个辅（通常辅=收获或离场）。
- R23-15 (S11) 读者方向猜对、幅度猜小。不要把主高潮写成惨败。
- R23-16 (S12) 删掉这货，桌子上什么都没变=假爽点。

### 三、分类型硬规则（12 货）
- R23-17 打脸：爽核=对方按错误信念作死，被结果打回原形。硬规则：反派主动挑衅且有真实好处；羞辱 ≥3 句落到身份+资源；损失先落地；主角不解释；四拍走完。禁止对骂、禁止演讲三观、禁止换沙包复读同一句「废物」。原句必须可奉还；打的是信念，不是血量。
- R23-18 装逼（扮猪吃虎）：爽核=信息差（读者≥主角>场上）。硬规则：先让读者看见齿，再让场上踩；装废必须有收益（燃料不暴露），否则是犯贱；自己报「其实我很强」是最弱装逼；大人物来接、令、一声称呼，才是装。装逼必须接打脸或掉马，单独吹牛不是爽点。
- R23-19 掉马：爽核=身份跨至少两级，物证先于口。硬规则：别人先喊；只 +1 级，留齿；当众；不复合。禁止身世 800 字；半揭优于全揭。和钩子「半揭」是同一刀，章中兑现、章末可再半揭加码。
- R23-20 升级：爽核=付出可见、回馈立刻、对照物在。硬规则：升级必须换阶层或换用法，不能只加数字；有门槛、有失败可能；升级章也要有冲突，禁止闭关专章；可视化：炼气三层→四层，写明能打谁。升级不实战=面板游戏，读者不认。
- R23-21 得宝：爽核=更贵的东西到手，且刚被抢走过同类。硬规则：宝要能当章用；禁止开箱鉴定会；得宝是打脸的辅货，很少当主货；通胀锁：本图最高只发本图能用的。例：聘礼单抽回来、令压上公证空位；不是「获得神秘古玉，回房研究」。
- R23-22 规则反套（卷高潮首选）：爽核=打的是地图，不只是人。硬规则：先用冲突撞规则（失败）；再亮适用条件/公证权例外；当场套到对手头上；观众被迫按规则改口。例：「杂役不可还口」→名册上他才是被除名的。
- R23-23 真香：爽核=当初那张嘴来求，主角不接。硬规则：分级滴灌、禁止第 3 章跪完；主角反应锁死：原句奉还+走、不教育、不复合、不收她当女主；每次真香对方必须再丢一样真资源。真香是后悔药，不是感情线。
- R23-24 复仇：爽核=讨债票兑付。硬规则：债必须具名、有原句、损失已落地；本卷见血或废，禁止「先变强十年」；兑付=原物或 +1 级剥夺；禁止虐仇人十章无结果。复仇是债务账的结算，不是新开一条虐线。
- R23-25 离场：爽核=解释权已经不需要了，场留给他们自己崩。硬规则：必须先兑现一角再走，纯走是怂；走的动作要具体：喝茶尽、扫帚靠墙、收聘礼单；禁止回头补刀演讲。章末钩交给更高层，不交给主角嘴；离场常当辅爽，主货仍是打脸/掉马。
- R23-26 金手指新用法：爽核=旧玩具玩出新动词。硬规则：旧法先失败；亮灯当章实战；新代价必须付；禁止讲座；只亮一层；灰行原词可进面板，不准进长老的嘴。这是隐藏层节点的专属货，禁止每章「又发现新功能」。
- R23-27 越级：爽核=数字对不上的反差。硬规则：必须有对照：护体裂、一口血、旁人喊境界；越一级，禁止越五级；越完立刻有更高层看见（否则下图没有压）。无对照的「轻松打败」是假越级。
- R23-28 解释权：爽核=谁有权定义刚才发生了什么（退婚、替婚、名册、谣言的主货）。硬规则：摊开三件：文件名字、当场的人、谁先开口定义；人输给文件；主角不靠解释赢，靠手续赢。解释权常与规则反套叠用，一章只标一个主货。

## 公式与结构模板
- 打脸公式：挑衅（标的被夺）→隐忍（反常动作）→反转 ≤200 字→余震近→远→权威。
- 装逼公式：前置齿→全场按 X 羞辱→主角做无关的事→别人开口把 X 打成 Y。
- 掉马公式：物证上桌→他人喊到关键词→打断或余震→局面改名分/公证。
- 升级公式：撞墙（旧法不够）→付代价→数字/权限跳一档→立刻实战打一个刚压过他的人。
- 得宝公式：先被夺/先缺→当众拿到（或从对方手里抢）→立刻改变本场手续。
- 规则反套公式：对手引用规则 R 压你→不辩 R 对不对→亮 R 的条件权→R 套回去→解释权易手。
- 真香公式（分级滴灌）：级1 跟班→级2 本人私下→级3 父母带利益→级4 新对象翻脸→级5 场子易手。
- 复仇公式：欠条（谁/场合/拿走什么原句）→同一或更高场合→物证+短爆发→奉还原句→离场。
- 离场公式：短爆发已改局面→做一个日常动作→把原句或物放下→走。
- 新用法公式：旧用法不够用→灰行亮新词→当章改手续→付新代价（被更高层看见/过热）。
- 越级公式：公布双方数字→一招→对照物碎→观众改口喊数字。
- 解释权公式：对方先定义（你是废物/婚书作废）→物证上桌→公证/名册令改口→对方的定义作废。
- 公式A 章默认套餐：主货 1 个+辅货 1 个（收获或离场）；加压用虐/冲突，弹用主货，余波用辅货，钩用新债。例：主打脸+辅得宝（抽回聘礼单）+钩新债（茶杯放下）。
- 公式B 单元升级（5-8 章）：章1 打脸（面子）→章2 装逼/越级（实力对照）→章3 掉马齿或得宝→章4 真香一级（跟班）→章5 离场（跟班）→章末 规则反套或解释权（中爽）；标的升档：面子→资源→归属→规则。
- 公式C 不应期：打脸后下一章=升级或得宝，禁止再打同一人同一句；掉马后=真香或新债，禁止紧接着再掉更大的马；真香后=换图或规则，禁止连续求饶；新用法后=至少隔一个单元才下一层。
- 公式D 可视化验收：打脸=护体裂/名册改；掉马=令、称呼；升级=境界数字+能打谁；得宝=物易手（写进 debt_ledger）；规则=对方被同一条律套住；真香=对方丢失新资源；复仇=原句当场还回去。写完看不到画面，这货没发出去。
- 公式E 爽点卡（每章必填）：本章主货（12 选 1）/辅货（收获/离场/无）/压的落地损失/反差（从 X 到 Y，只跨 1-2 级）/当众谁在看/≤200 字释放动作/可视化收获/欠的新债/与近 3 章是否同型（必须否）。
- 层级接法：微爽=离场一句、系统入账、路人改口；小爽=打脸、得宝、升级实战；中爽=掉马齿、规则反套、真香升级、新用法、越级；大爽=破本图规则、Boss 结算、复仇卷兑、L3 亮灯换图。番茄：每章必有小爽；5-8 章一个中爽；3-5 万字一个大爽。
- Prompt 锁死段（爽点合同）：每章只选 12 货之一做主爽：打脸｜装逼｜掉马｜升级｜得宝｜规则反套｜真香｜复仇｜离场｜新用法｜越级｜解释权；辅货最多 1 个，优先收获或离场；先压后弹，弹 ≤200 字，必须当众、必须可视化改局面、只 +1 级、弹完欠更高层的债；连续 3 章禁止同型；打脸走四拍；掉马物证先于口；真香分级且不复合；升级必须当章实战；规则反套先撞墙再反套；新用法先失败再亮灯；删掉该货桌子不变=假爽，重写。

## 禁忌与反例（假爽对照）
- 无观众对骂（两人互喷）→ 打脸：拉到堂上。
- 自我介绍掉马（「其实我是战神」）→ 掉马：别人喊。
- 闭关升级（回房突破一章）→ 升级：撞墙后当章实战。
- 开箱不打（鉴定古玉 800 字）→ 得宝：当场改手续。
- 第 3 章跪求（退婚女哭着复合）→ 真香：推迟到级 2，且不接。
- 十年后报仇（师父死了 200 章）→ 复仇：本卷见血。
- 每章其实我很强（同货通胀）→ 换升级、得宝、规则。
- 讲课解锁（系统说明书）→ 新用法：旧法失败再亮。
- 一句话：先让他们把东西当众拿走，再用一种货短短夺回来，夺回来的必须能看见，并且比他们以为的只高一档；下一章换货，别再打同一张脸。
