# Report 36 规则蒸馏

## 报告主题
小人物 NPD 反射模块（第九轮补充规则 54-58）：侧写反射三类型（认知失调/前后反差/代价感知）、触发门槛三级、旁观者叠加（核心+环境共震≥2）、视角权重（主角≥20字/小人物心理≤20字）、后续涟漪（传播/拉拢/告密/追随）——通过小人物视角把主角的强「反射」给读者，快、不铺陈、一个眼神一句闲话就让读者爽到。

## 硬规则

### 反1｜侧写反射三类型（防只会震惊脸）
- R36-01 三种反射类型必须轮换，禁止连续三章同一种：①认知失调型（30-50 字，小人物对主角的认知被现实击碎——把他当软柿子的家伙一指震碎了他跟了十年的护身玉）；②前后反差型（40-60 字，态度前倨后恭/前漠后惊——一刻钟前还用鼻孔看人，此刻双手捧令牌脊背弯得比草低，「您……您请上座。」）；③代价感知型（50-80 字，切身感受差点死了/倾家荡产/万劫不复——护甲碎成七块，残留剑意嗡嗡作响，若那一剑偏了三寸……冷汗湿透里衣）。
- R36-02 反射丰富度 R = 本章类型数 × 与上章差异权重（同型 0.3/异型 1.0）；连续 3 章同类型 ≥2 次触发「反射疲劳」，强制轮换。

### 反2｜触发门槛三级（防无因恐惧）
- R36-03 反射必须由可被感官捕捉的事触发，三级：一级触发（接酒杯/抖水珠→低反射：多看一眼/停顿一秒）；二级触发（随手挡攻击/轻松开禁制→中反射：面色微变/动作迟疑）；三级触发（越阶反杀/破解高阶阵法→高反射：失态/尖叫/瘫软）。
- R36-04 禁止无触发事件直接写「小人物吓得发抖」（无因恐惧）；比例建议一级 50%/二级 35%/三级 15%。
- 公式：反射可信度 C = 触发动作等级(1/2/3) + 反射强度(小/中/大)；反射强度 ≥ 触发等级+1 判「过激」，需补充原因。反射段前 30 字内必须有可被感官捕捉的主角动作。

### 反3｜旁观者叠加（防爽感不够烈）
- R36-05 关键反射场景必须「核心反应者（1人）+ 环境共震者（≥2人）」叠加，远距涟漪者（≥1 人，帘后/楼上/暗处）可选：核心反应者提供最强情绪（执事张着嘴忘了合上）；环境共震者放大群体震惊（两个随从面面相觑，登记簿啪地掉地）；远距涟漪强化传播性（二楼雅间帘子掀开一角：「下面怎么回事？」）。
- 公式：反射烈度 I = 1(核心)×2 + 环境共震人数×0.8 + 远距涟漪(0/1)×0.5；I < 3.0 判「反射太淡」，强制追加 ≥2 个环境共震者。

### 反4｜视角权重（防小人物抢戏）
- R36-06 反射场景按权重分配：主角动作/表情/一句话（第一优先级，≥20 字）；小人物感知结果（第二优先级，30-50 字）；小人物心理/回忆（第三优先级，≤20 字，禁止长内心戏）；环境共震者反应（第四优先级，10-30 字/人）。
- R36-07 禁止小人物心理活动超 50 字；禁止反射场景超 300 字（超=抢戏）。
- 公式：主角存在感 P = 主角动作字数(≥20) + 小人物心理字数(≤20)；小人物心理 > 主角动作 → 判「视角失衡」，压缩心理扩写主角动作。先写主角在做什么，再写小人物看见了什么、感受到了什么。

### 反5｜后续涟漪（防浪费爽感素材）
- R36-08 反射发生后，小人物在同一章或下一章内必须有后续动作：传播者（把所见传出去引发更多关注——杂役跑回后院念叨「太强了」，半个时辰后整个外门在传）；拉拢者（讨好/贿赂/攀附——端上最好的灵果弓腰「师兄您尝尝」）；告密者（因恐惧/讨好主动提供情报——「您要小心后山那批人，他们今晚要设局」）；追随者（主动跟随混好处——第二天一早门口蹲着三个杂役「师兄，我们跟您干」）。
- 公式：爽感持久度 D = 反射段落(基准1) + 后续涟漪(0/1)；有后续动作 D×2.0 爽感翻倍。无后续 → 强制在合理位置插入 ≥50 字后续动作。

## 公式与结构模板

### AI 调用示例（入门考核破阵）
主角动作（叩指）→ 触发二级（九宫锁阵寸寸龟裂）→ 核心反应者（执事记录笔停了）→ 环境共震者 ×2（记录员笔落地、围观弟子倒吸凉气后退半步）→ 小人物感知结果（把内门专供闭卷题用手指头敲开了）→ 小人物心理 ≤20 字（坏了，我刚才让他排最后了）→ 远距涟漪（二楼青色衣角一闪）→ 后续涟漪（次日门口三份早饭两瓶灵液一张纸条：「今晚有人要动你，看完即焚」）。

### 与全局规则关联
规则一（反射段≤300 字不拖节奏）；规则八（反射是「情绪收益」的极简形式）；规则四十（旁观者反应是反射的放大协议）；规则四十九-五十三（小人物推剧情 vs 本轮反射镜功能）。

## 自检清单 54-58（章末追加）
54. [反射类型] 三类型轮换？连续 3 章未重复超 2 次？ 55. [触发门槛] 反射前有可被感官捕捉的触发动作？ 56. [旁观者叠加] 核心反应者 + ≥2 环境共震者？ 57. [视角权重] 主角动作≥20 字？小人物心理≤20 字？ 58. [后续涟漪] 小人物有后续动作（传播/拉拢/告密/追随）？
