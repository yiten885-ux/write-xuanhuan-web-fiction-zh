# Report 15 规则蒸馏

## 报告主题
钩子、悬念、埋伏三分类拆解：三类各自的回收期限与被看见要求、分类型硬规则（钩子H01-H04、悬念S01-S05、埋伏F01-F10、金手指灰行G01-G03）、十套公式、埋伏时机表与平台时机对照。

## 硬规则

### 总则
- R15-01 必须把钩子、悬念、埋伏三样拆开用：钩子（读者问"然后呢"）下章必接、埋的时候必须看见；悬念（"会怎样"）3-8章一个单元、必须看见；埋伏伏笔（"原来如此"）一卷内回收、番茄还要中途点头、最好当时不当真。
- R15-02 番茄免费读者记不住"三十章前那枚戒指"，长线必须微回应，否则等于没埋。
- R15-03 钩子留人，悬念拉单元，埋伏让反转合法。

### 钩子硬规则 H01-H04
- R15-04 H01 钩子每章必有，断在未完成动作；禁止总结、禁止"他不知道风暴来了"。
- R15-05 H02 下章前200字必须接住，不准另开日常。
- R15-06 H03 钩子类型（危机/半揭/反转/机遇/新债/倒计时）轮换，禁止连续3章同一型。
- R15-07 H04 钩子不能代替本章爽点：整章只吊不给，完读掉。

### 悬念硬规则 S01-S05（读者必须意识到"有事"）
- R15-08 S01 悬念=未结算的硬标的，不是气氛；桌上要有名额、婚书、刀、灰行。
- R15-09 S02 信息差悬念：读者≥主角>场上；禁止长期读者什么都不知道（那是悬疑）。
- R15-10 S03 一个单元只主吊1个悬念，章钩子是它的牙齿，不是新开5条线。
- R15-11 S04 3-8章必须兑一次；番茄拖过10章，读者会当作者忘了。
- R15-12 S05 兑的时候改局面（名分/资源/阶层/解释权），不准只"揭晓"不改桌子。

### 埋伏硬规则 F01-F10（当时可以不当真）
- R15-13 F01 埋时给"忽略理由"：穷、不识货、正在挨打、来不及看；没有理由=预告。
- R15-14 F02 至少3齿，分散在冲突缝里；禁止专段"意味深长"。
- R15-15 F03 只可"不完整"，不可"写反"：写过确无后台，后面就不能变供奉。
- R15-16 F04 一条埋伏兑一个悬念；禁止一枚戒指串三层身世。
- R15-17 F05 回收靠触发动作，不靠嘴：戒指烫手、印对上灰烬，不是"原来这是封印"。
- R15-18 F06 番茄：超过5章必须微回应（发热一下、灰行闪一下、有人多看一眼）；没有点头=没埋。
- R15-19 F07 飞卢即埋即爆：身份梗3章埋，5章内揭；爽在"我就知道"。
- R15-20 F08 起点才能"一百章后收"；把起点长线直接搬番茄，等于没写。
- R15-21 F09 忘回收=烂尾，比不埋更毒；建表，埋一条记一条。
- R15-22 F10 埋伏不是钩子：角色对伏笔大惊小怪，读者就会死盯，后面加码全废。

### 金手指灰行硬规则 G01-G03（隐藏层的埋伏形态）
- R15-23 G01 L1当场能用，灰行只露"还有层"。
- R15-24 G02 揭层必须：旧法失败→亮灯→当章实战→新代价；禁止讲座解锁。
- R15-25 G03 L4/L5禁止在前30章。

## 公式与结构模板
- 公式1 三时钟（开书就锁）：短钩=每章章末、下章接；中悬=每单元1个、5-8章兑；长伏=每卷2-4条、中途每5章微回应、卷内或卷末兑；跨卷=最多1条（L5/上游棋盘）、每卷点头一次。
- 公式2 章末钩子六选一：危机（铜铃响了，名册最后一行不是他的名字）；半揭（"见过——"门开了）；反转（最后一行物证和全章暗示相反）；机遇（灰行亮出两个字，还没解释）；新债（回廊里茶杯放下的人站了起来）；倒计时（"一炷香。"执事把香按进炉里）。接钩公式：下章第1句接动作，不接心情。
- 公式3 埋伏三件套：忽略理由+齿（物件/句/数字/反应）+触发动作。例：挨打时戒指滚进排水沟（忽略）→有人来捡被他踩住（齿）→第10章对印时烫手（触发）。
- 公式4 3齿分布：齿1埋在冲突高潮刚过（读者在爽，不会细抠）；齿2埋在另一条线的闲笔（别人的一句、名册一个号）；齿3埋在回收前1-2章、半揭（让部分读者提前喊出来）；炸=压力最高、话最满、观众最齐。
- 公式5 微回应（番茄专用）：不揭内容，只证明"这东西还活着"——戒指发热/灰行闪一下/配角欲言又止被打断/数字再出现一次；频率=长伏每5章一次，否则当死线。
- 公式6 信息差悬念：读者已知齿="他不简单"；场上信念="他是杂役"；悬念问句="何时当众折断"；兑=物证+别人开口≤200字；加码=折断后再留一齿（印比令大）。
- 公式7 身份埋伏：先定Y，再写X；X的每个正面场留一个矛盾（快半拍、避话题、护某物）；回收时矛盾全部变成证据；禁止事后补"他其实一直……"的回忆段。
- 公式8 语言埋伏：闲话一句+表情不对或有人岔开（小异常=第二齿）；回收≤10章（语言线读者忘得最快）。
- 公式9 因果账埋伏（接虐点讨债票）：埋=谁、场合、拿走什么、原句（写进手续里）；活=中间用物件提醒（半张婚书还在）；兑=同一或更高场合、原句奉还、+1级剥夺。
- 公式10 一条埋伏一张卡：编号；类型（钩子/中悬/物件/身份/语言/数字/灰行/因果）；忽略理由；齿1章/齿2章/齿3章；微回应章；计划回收章；触发动作；兑哪一个悬念（只准一个）；回收后新债；状态（已埋/已点头/已兑/作废）。

## 禁忌与反例
- 埋伏时机：该埋的窗口——1.爽点刚过（最佳：打脸余震里随手一笔，读者在爽齿进潜意识，金手指掉落、对方护体碎屑、地上多一枚印都放这里）；2.冲突缝不是专段（挨打、逃、抢名册的动作里带出来，禁止停下来写"他注意到"）；3.开局损失落地时（退婚撕书、除名、废丹，把长伏贴在物证上：婚书灰烬里的印、名册编号07，损失场景读者记得最牢）；4.换图前2章（旧图结算时留一件带不走的东西/一句带得走的话作下图规则的齿）；5.回收前1-2章半揭（让一部分读者猜到30%，猜中的人会更追"怎么炸"）；6.隐藏层节点前先让旧法失败（L2/L3亮灯前必须有一次"按旧用法不够用"，失败本身就是埋伏的触发器）。
- 不该埋的窗口：第1句世界观谜语（冲突还没立住，悬念是空的）；专章回忆/梦境/讲座（预告不是埋伏）；连续纯虐0兑现时（读者在掉，埋了等于白埋）；刚揭完一层立刻把下层讲完（透支L4）；章末用上帝旁白（"他不知道这枚戒指……"=作者剧透）；同一段里埋3条长伏（全变成预告）；收线后再补齿（读者能看出来是圆谎）。
- 平台时机对照：番茄=短钩每章、中悬兑5-8章、长伏点头每5章、长伏回收本卷最多跨1卷；飞卢=每章更密、中悬兑3-5章、几乎不玩长伏、即埋即爆；起点=可隔章、15-20章也能撑、可疏、可跨很多章。番茄口诀：即埋即点头，卷内必有炸；跨卷最多一条，还得每卷露齿。
- 黄金三章埋什么：Ch1=短钩（明日来杀/灰行）+一条贴在婚书/名册上的长伏齿；Ch2=中悬立住（大比/新婚期/名额）+身份或内鬼的齿1；Ch3=单元小炸（当众最小兑现）+长伏微回应+更高层新债钩子；禁止前3章把身世、系统起源、上游棋盘讲完。
- 写崩对照（病→改法）：钩子当伏笔（章末谜题下章不接去修炼）→下章第1句接动作；伏笔当预告（角色对戒指大惊小怪）→给忽略理由；埋了不点头（番茄20章后突然戒指封神）→每5章发热一下；一物三用（戒指=身份=系统=爱情）→拆成三条卡；忘回收（开局黑印再也没有）→列表写到卷末清一次；谜语开书（先问这是谁的天下）→先退婚，印藏在灰里；上帝钩（他不知道风暴）→门开了，人站起来。
- 锁死段（可贴System Prompt）：三时钟：章钩每章必有且下章前200字接住；中悬5-8章兑一次；长伏每5章微回应、卷内必炸。钩子断在未完成动作，六型轮换，禁止连续3章同型，禁止上帝旁白。埋伏三件套：忽略理由+齿+触发动作；至少3齿，只可不完整不可写反。一条埋伏只兑一个悬念；回收靠动作不靠嘴。番茄禁止无点头的超长伏；飞卢身份梗5章内揭。黄金三章只埋齿和中悬，禁止揭L4/L5和系统起源。每埋一条必须填卡：类型/齿章节/点头章节/回收章节/触发动作/状态。忘回收视为烂尾，卷末强制清表。
