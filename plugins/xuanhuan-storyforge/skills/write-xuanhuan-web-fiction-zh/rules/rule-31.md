# Report 31 规则蒸馏

## 报告主题
反转专精模块（第五轮补充规则 31-35）：反转类型轮换、三段式结构、前置线索密度、后置收益验证、情绪曲线锚定——五条可量化硬规则 + 自检清单 31-35 + AI 执行示例，补齐反转设计从「有反转」到「反转有效」的执行层。

## 硬规则

### 转1｜反转四种类型协议（防同质化）
- R31-01 剧情反转必须从四种经典类型中选择：①底牌反转（隐藏实力/手段揭露）；②身份反转（真实身份出乎意料）；③资源反转（废物变宝藏）；④理解反转（因果判断被颠覆，如「原来被追杀是考验」）。
- R31-02 不得连续两章使用同一反转类型；禁止连续三章仅用「底牌反转」，需轮换。
- 公式：反转类型池 = [底牌, 身份, 资源, 理解]；本章反转类型 ≠ 上一章反转类型（强制轮换）。

### 转2｜反转三段式结构（防突然开挂）
- R31-03 任何反转必须三段式，缺一不可：①铺垫（反转前 200-500 字，建立读者默认预期——他人评价/主角自我怀疑/环境暗示）；②触发（50-100 字，突发事件/一句话/一个物品打破预期）；③揭示（100-300 字，真相展开 + 附带「为什么之前没发现」的合理解释，如「他一直在隐藏气息」「那件东西被下了三层禁制」）。
- R31-04 禁止反转「直接说出答案」而缺失「为什么之前被隐瞒」的闭环。
- 公式：反转效果 R = 默认预期强度 P × 触发冲击力 T × 揭示合理性 E。P 低则反转无效；E 弱则反转崩塌。
- 缺揭示+解释环节时，在揭示段后追加一句解释性复盘（如「难怪他刚才一直在护着左手袖口」）。

### 转3｜前置线索密度（防凭空开挂）
- R31-05 反转所需关键线索必须在反转发生前至少提前 500 字埋入正文。
- R31-06 埋入比例：显性线索（直接描写，如「他左手始终藏在袖中」）1 处以上；隐性线索（间接暗示，如「别人提起左手伤势时他神色微变」）2 处以上；显性:隐性 = 1:2。
- R31-07 禁止反转前零线索、反转后倒推解释（事后补丁）。
- 公式：线索埋设密度 D = 显性×1 + 隐性×0.5；D < 2.0（即至少 1 显性 + 2 隐性未达标）判定铺垫不足，反转扣分，强制在反转前插入至少 1 条隐性线索。

### 转4｜后置收益验证（防反转完就没了）
- R31-08 反转揭示后必须在同一章内展示至少一项明确收益，三选一：①局势逆转（必败/必死局面翻转）；②地位/资源跃升（获得此前无法触及的资源/权限/信息）；③情绪碾压（反派的轻视得到加倍返还）。
- R31-09 禁止反转揭示后以「待后续分解」或「主角也懵了」草草收场；收益必须同章兑现。
- 公式：反转收益 I = 反转前劣势 × 反转后优势差值；差值 < 3 收益不足，追加展示。反转后 200 字内主角仍被动/困惑或局势未变 = 收益悬空，强制插入「反转即时效果」（对手色变、众人惊呼、主角反制）。

### 转5｜情绪曲线锚定（防平淡如水）
- R31-10 反转触发段落必须达成读者预期从低谷到峰值的跳变：反转前情绪基线=被压制/被误解/被低估/绝境的负向状态；触发瞬间至少一个情绪爆点词（「不可能」「他竟然是……」「原来如此」）；反转后锚点=旁观者视角的震惊/恐惧/崇拜/懊悔（至少两个角色的反应）。
- R31-11 禁止反转前后情绪无显著波动（「哦，这样啊」级）；需触发瞳孔放大/倒吸凉气/拍案叫爽级反应。
- 公式：反转情绪强度 E = (反转前压抑时长 × 1.2) + (触发震惊值 × 1.5) + (旁观者反应数 × 0.8)；E < 5.0 判定平淡，加强前段压抑或后段反应。反转前被动/受害/被轻视描写 ≥3 句为合格；反转后旁观者/敌人震惊反应 ≥2 句为合格；任一不合格强制补写。

## 公式与结构模板

### 自检清单 31-35（追加到章末自检）
31. [反转类型] 本章反转类型与上一章不同？属[底牌/身份/资源/理解]四类之一？
32. [反转结构] 反转含三段式（铺垫-触发-揭示+解释）？
33. [前置线索] 反转前 500 字内 ≥1 显性 + ≥2 隐性线索？
34. [后置收益] 反转后同章内展示明确收益（局势/资源/情绪）？
35. [情绪曲线] 反转前 ≥3 句压抑描写？反转后 ≥2 个旁观者震惊反应？

### 合格/不合格对照示例
- ❌ 不合格（无铺垫、无结构、无收益）：「够了。」陆沉突然抬头，眼中血光一闪，「我已突破凝元境。」一掌拍出，所有人倒飞。
- ✅ 合格（三段式+线索+收益+情绪曲线）：铺垫段（陆英羞辱「三年前灵海碎裂这辈子别想翻身」+围观窃语+左手袖口一丝极淡红光一闪而没）→ 触发（陆英踩头，一脚踩空）→ 揭示（气息节节攀升至凝元境；「灵海碎裂？那是我自己碎的。不碎，怎么骗得过你们主家派来的探子？」）→ 收益兑现（陆英笑容僵住瞳孔骤缩；围观弟子长剑落地；沈砚——陆沉拂去肩上泥土踏一步，演武场石板龟裂）。

### 与既有体系的嵌入关系
规则八（情绪收益/打脸五步闭环）管整体爽感结构；规则十八（悬念轮换）管章末钩；本模块（31-35）是反转本身的专项执行层。爽感模块 = 规则八 + 31 类型轮换 + 32 三段式 + 33 线索密度 D≥2.0 + 34 收益即时兑现 + 35 情绪曲线 E≥5.0。

## System 锁死段（可直接贴进提示词）

```text
【反转专精模块】
每章剧情反转必须遵守：
1. 类型轮换：从[底牌/身份/资源/理解]中选一，不得与上一章重复。
2. 三段结构：①铺垫（建立默认预期）→②触发（打破预期）→③揭示+解释（为什么之前没发现）。
3. 线索前置：反转前500字内至少埋 1 条显性线索 + 2 条隐性线索。
4. 收益即时：揭示后同一章内展示局势逆转/地位跃升/情绪碾压之一。
5. 情绪曲线：反转前至少3句压抑描写，反转后至少2个旁观者震惊反应。
若任一指标不满足，标注【反转无效】并重写该段落。
反转情绪强度 E = (压抑时长×1.2) + (震惊值×1.5) + (旁观者反应数×0.8)；E<5.0 为平淡反转，加强前段压抑或后段反应。
```

## 禁忌与反例
- 禁：连续同型反转、零线索反转、反转后懵圈收场、「哦这样啊」级平淡。
- 禁：事后补丁（反转后倒推解释线索）。
