# Report 13 规则蒸馏

## 报告主题
爽文反转与悬疑反转的区别：反转的三分类、四拍节拍、八种可复用反转类型、写作硬规则（F01-F14）与十套创作公式，以及假反转对照表。

## 硬规则

### 反转类型学
- R13-01 必须先分清三种反转：信息差反转（场上的人被骗，读者感受"我就等这下"，是主力，用于扮猪吃虎、退婚现场）、加码反转（骗读者幅度，感受"比我想的还狠"，是每场打脸的第二刀）、认知反转（骗读者事实，感受"原来不是那样"，少用，用于隐藏层、内鬼、更大棋盘）。
- R13-02 番茄爽文反转配比必须遵循：信息差60%、加码30%、认知10%（认知反转一卷最多一次大的）。
- R13-03 认知反转用多了读者不敢期待，追读会掉；读者需要"等打脸"的确定性。
- R13-04 反转必须有观众，否则没有余震。

### 底层节拍
- R13-05 爽文反转必须走通用四拍：信息前置→压制→拉扯→反击（和硬冲突、打脸是同一套骨头）。前置=让读者先知道底牌一角，建立"等着吧"；压制=对手按错误信念作死，读者憋；拉扯=对手再加码、主角不解释，更憋更确定要炸；反击=短爆发，揭的是结果不是说明书。
- R13-06 信息前置是爽文反转的命门：读者不知道底牌，压制段就是纯受虐；读者知道一点，压制段就变成期待。前置只露齿（身份一句、面板一行灰、信物一个印），禁止把反转内容讲完。
- R13-07 揭开时机必须是压力最高、对手话最满、观众最齐的那一秒；最佳落点是对手那句羞辱说完、动作还没收回。不要回房再揭，不要章末用旁白揭。

### 八种反转类型的使用约束
- R13-08 一次只用一种主反转，辅反转最多加码一刀。
- R13-09 身份反转（掉马）：场上以为是X其实是Y，Y必须比X高至少两级（X=废物/赘婿/杂役→Y=战神/供奉/真传私生子）。揭法只能靠别人来接、令牌、一声称呼，不靠自己报家门。共享底层动机：装废是为了躲因果/完成托付，不是为了挨骂，否则读者觉得主角犯贱。
- R13-10 实力反转：境界数字对不上（炼气打筑基），必须有可见对照：护体裂、一口血、旁人喊境界。
- R13-11 规则反转：对方拿来压你的规矩，当场砸到他自己脸上（"杂役不可还口"→点名册上他才是被除名的那个；"退婚需长老公证"→公证权在主角手里）。这是卷高潮最硬的一种，因为它打的是地图，不只是人。
- R13-12 因果反转（将计就计）：对手设的套，是主角要的燃料（"他们要当众废你→你要的就是当众→金手指只在观众面前计价"；读者已知"装逼值看见证者境界"，对手把长老请来，等于自己把燃料送到嘴边）。
- R13-13 对象反转：骂的人、抢的人、退婚的人，打的不是他们以为的那个（当众羞辱杂役，回廊里放下茶杯的才是他要见的人；替婚女不是庶女，婚书上的印是皇女）。
- R13-14 立场反转：友变敌、敌变债，爽文里友变敌比洗白更有用，洗白容易圣母。硬规则：底层动机开局就要有一条；纯两肋插刀的兄弟后期背刺=人设崩，不是反转。
- R13-15 金手指隐藏层反转：旧用法失败→新动词亮灯。这是认知反转的合法配额，必须按隐藏层节点出，不随便加。
- R13-16 态度反转（反套路）：读者以为要打脸，主角不接、先走、先退婚、把场子留给对方自己崩（对方等他解释→他问"聘礼今晚送还是我去取"→离场；打脸发生在下一章，由对方的新对象/父母完成）。这一型用来打破"每章必对线"的疲劳，但一单元最多一次，否则读者会觉得主角不还手。

### 写作硬规则 F01-F14
- R13-17 F01 方向不骗读者，幅度可以骗：爽文承诺"他会翻"，可以让翻的方式、对象、代价出乎意料，禁止让主角突然惨死当主高潮（那是虐文）。
- R13-18 F02 读者要先站在正确一边：信息差反转必须读者≥主角>场上；加码反转必须读者=主角<真相幅度；禁止长期读者<全场（那是悬疑，番茄爽文会掉完读）。
- R13-19 F03 揭的是结果，不是说明书：亮令牌、裂护体、改名册、一声"见过供奉"；禁止当场讲身世三分钟。
- R13-20 F04 必须当众：反转没有观众，就只是情节变化，不是打脸。
- R13-21 F05 必须短：核心翻转≤200字；余震给别人喊，不给主角说。
- R13-22 F06 伏笔至少3齿，且不与真相打架：齿=重复动作、灰色面板、看不懂的印、对某类人反常手软。误导只能"不完整"，不能"写反"——写过"他真的是凡人、确无后台"，后面就不能变战神。
- R13-23 F07 人设不反转：杀伐不会因为反转变圣母；装废不会因为揭身份变话痨。反转改的是场上认知，不是主角性格。
- R13-24 F08 反转必须改局面：删掉这句揭晓剧情还能走=假反转；必须当场改名分、资源、阶层或解释权。
- R13-25 F09 反转后立刻欠新债：更高层看见、规则反噬、身份齿被登记；空窗一章，钩子断。
- R13-26 F10 类型轮换：禁止连续3章都是"其实我很强"；下一章换规则/对象/因果。
- R13-27 F11 认知大反转一卷一次：假死、梦境、全员卧底，全书各限一次；用第二次，读者开始不信死亡。
- R13-28 F12 时机：话最满的时候打。对手的"你也配"说完再打；提前揭=浪费压制；拖到回房揭=浪费观众。
- R13-29 F13 加码遵循+1级：你以为校董→其实城西商会会长（+1）；禁止一揭就是仙帝，后面没有层。
- R13-30 F14 反派因错误信念获益：他嚣张是因为信息差对他有利，不是作者让他作死；反转才能打在"他算错了"上。

## 公式与结构模板
- 总公式（P1 标题级）：反转爽感=错误信念的硬度×揭开速度×反差级数×当众程度。必须有观众，否则没有余震。
- 公式1 反转卡（每场必填，填不完不准写爆发段）：主类型（信息差/加码/认知八选一细分）；场上错误信念（一句话）；读者已知多少（齿）；对手靠这个信念要抢的标的；观众（含一个更高层）；揭开物证（令牌/名册/数字/一声称呼）；揭开动作（≤200字）；局面改了什么（名分/资源/阶层/解释权）；新债；下一场禁止再用的类型。
- 公式2 信息差主循环（章级默认）：前置（读者看到齿：面板灰行/来接的人在门外）→压制（对手当众按X羞辱）→拉扯（主角不解释，对手加码：倒计时、再夺一样东西）→反击（用物证把X打成Y）→余震（近→远→权威）→新债（权威把这件事上报）。
- 公式3 加码公式：读者预期的反转结果=N，实际揭开=N+1（高一级身份/多一个标的/多一个见证者）；禁止N+5（一次揭完）。例：预期"他有内门后台"→加码"来接的人喊供奉，后台是宗门那尊不露面的"→再留齿"供奉看了一眼他手腕上的印，没出声"。
- 公式4 掉马三件套：1.物证先于口；2.别人先开口（来接的人、系统、长老）；3.主角仍不解释，做无关的事（喝茶、扫地、收聘礼单）。自己报"其实我是战神"是最弱掉马。
- 公式5 规则反转：对手引用规则R压主角→主角不辩R对不对→亮出R的适用条件/公证权/例外条款→R当场套到对手头上→观众被迫按R改口。
- 公式6 将计就计：对手的杀招=金手指的燃料→读者已知燃料公式→对手越把场面做大，反击越便宜→打完点一句燃料入账，不要解说策略。
- 公式7 关系反转（慎用）：开局给一条共享动机（家族/任务/活命）→中期3齿（重复动作、反常护短、一句当时不像反话的话）→揭晓卡在"刚为他拼命"之后→揭晓后不准立刻和解，先变成债。友变敌：爽在被骗后的清算。敌变友：爽文里很弱，除非对方立刻献上硬资源，且主角不心软。
- 公式8 章末反转钩子：反转可以打在章中爆发，也可以打在最后100字。章末只用半揭：全揭=本章释放下章写余震和债；半揭=物证亮了、称呼被打断（"见过——"门开了）。番茄更吃半揭当钩子，但本章必须已经有一次小兑现，不能整章只压不给。
- 公式9 三步埋线（认知反转专用，卷级）：第一步齿：提前8-20章塞3处，读者不当真；第二步误导：用配角观点帮读者建错误第一印象（不写反事实）；第三步命题句：反转前一章末放一句可回看的话。例："这枚印，和退婚那天婚书上的灰烬是同一个。"揭晓靠关键事件强迫切换，不靠回忆杀讲课。番茄不要"提前50章"，免费读者记不住。
- 公式10 反转密度：每章1次微反转（小打脸/小加码）；每5-8章1次单元反转（身份齿或规则）；每卷1次认知大反转（隐藏层或内棋盘）；禁止每章都"你不知道的是"。
- 衔接·和前面三套系统怎么接（P10）：硬冲突提供「桌上那件不可让的东西」；退婚/替婚提供开局现成的错误信念（他配不上）；金手指隐藏层提供加码和认知反转的弹药；反转是把错误信念当众折断的那一刀。所以反转不是第三套剧情，是冲突的释放段写法。退婚场：场上信念=他配不上，反转=婚书/聘礼/供奉令把「配不上」折断；隐藏层：场上信念=金手指只会掉垃圾，反转=这回掉的是规则本身。

## 禁忌与反例
- 假反转对照（病→改法）：无前置（"其实我是你哥"硬跳）→至少3齿且不写反；自己报身份（演讲掉马）→别人来接、物证先开口；揭开太长（身世800字）→砍到200字，余震给观众；无观众（夜里告诉仇人）→改到宴席点名台；不改局面（大家吃惊，名额还是没了）→当场改名册/婚书/规则；人设跟着转（揭完变圣母）→只转认知不转态度；幅度一次揭完（杂役直接仙帝）→+1级留齿；连续同型（三章都是"其实我很强"）→轮换规则对象因果；假死二次（读者不信死亡）→全书一次，先铺解药条件；洗白无齿（反派突然被迫）→开局就给共享动机，否则别洗；虐向主高潮（反转后主角惨败当爽点）→方向必须逆境→顺境，失败只能当加压，不当释放。
- 一段对照：软（假反转）="被骂废物他忍着，回房后作者写没人知道他是隐世家族少主，下一章出门把人打了"；硬（信息差+加码）="议事堂里苏绾说完'炼气三层也配'，陆沉不接话把婚书叠好，门开了进来的人没看苏绾，把一枚青令放在石桌上只喊了一声供奉；护体裂的是她跟班；回廊里茶杯放下的人站起来——加码还没说完，那人看的不是令，是陆沉袖口一道灰印"。读者已知：他不简单；场上刚知：供奉；读者新知（齿）：印比供奉更大；局面改了：婚书还在桌上，解释权已经不在苏绾嘴里；新债：站起来的人会上报。
- 锁死段（可贴System Prompt）：爽文反转默认信息差（读者已知≥主角>场上），加码为辅，认知大反转每卷≤1；方向不骗（逆境转顺境），只骗幅度和方式；每场先填反转卡（错误信念、读者已知齿、物证、≤200字揭开动作、局面改什么、新债）；揭开靠物证和别人开口，禁止主角演讲报身份；必须当众；必须改名分/资源/阶层/解释权之一；人设不随反转改变；连续3章禁止同一反转类型；伏笔至少3齿，只可"不完整"不可"写反"；假死/梦境/全员卧底全书各限1次。
