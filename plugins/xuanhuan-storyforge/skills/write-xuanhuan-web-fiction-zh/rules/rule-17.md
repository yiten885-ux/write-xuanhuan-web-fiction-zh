# Report 17 规则蒸馏

## 报告主题
钩子链：同一笔债、同一件物、同一个错误信念拆成3-5环接力的系统设计（主问句+指纹物+欠债升级路径+解一咬一），含设计七步、六套公式、一条完整样链与全书结构挂接、专治链的硬规则（L01-L12）。

## 硬规则

### 链的定义与总纲
- R17-01 钩子链不是章末各丢一个悬念，是同一笔债、同一件物、同一个错误信念拆成3-5环接力；每环解开一个疑问，同时咬出更贵的下一问；读者追的不是"又有事了"，是"那一笔还没结"。
- R17-02 钩链=主问句+指纹物+3~5环（解一咬一）+结算改局面+新链齿，一条链只准有这些元件：主问句（整条链追什么）、指纹物（环与环之间的钉子）、欠债人（每一环都还指向他或他的上层）、环（一章或两章一口）、结算（必须改桌子上的标的：名册、公证权、规则）。
- R17-03 章末八型是环的嘴巴形状（截断/半揭/倒计时…），不是链本身；没有指纹物的八型轮换，只是互不相关的惊吓。
- R17-04 同时进行的链：主链1条（本章必须咬）+暗链1条（长伏，每5章点头，不跟主链抢章末）；禁止3条以上章末同时开口；暗链用微回应，不要用强钩，否则读者不知道追哪条。
- R17-05 一环的内部结构是同一套四拍，只是问句在升级：接上环动作→解开口（只答上一问）→当章兑现一角（防纯吊）→咬下一问（更贵：人更高/物更真/规则更硬）→断在未完成动作。
- R17-06 升级必须吃掉上一环，不能换沙包：四档脊柱=谁→他拿着什么→这东西按哪条规则生效→谁在写这条规则；跳档（第1环直接"谁在写规则"）=第3章揭完L5。

### 设计步骤（开写前做完）
- R17-07 第1步写主问句（读者能转述）：坏例"他还有秘密吗"；好例"退婚当众生效之后，谁还能在这张堂上定义他"。
- R17-08 第2步选指纹物（能被撕、烫、对、喊出来）：婚书、名册、令、灰行、香；物必须在第1环就已经在桌上。
- R17-09 第3步列4档升级（先写完再切成章）：环1谁（门开了，来的是谁）→环2什么（他放下的是令，不是请帖）→环3哪条规则（令在本堂有公证权）→环4谁写的规则（令上的印=婚书灰烬里那道）→可选环5（上游还要这枚印干什么）。
- R17-10 第4步给每环选嘴巴形状（八型轮换）：环1动作截断或半揭；环2关键信息凸显（令）；环3规则/倒计时（公证来不及了）；环4新债或半揭（印对上，更高层站起来）；环5危机或机遇（灰行亮：未授权）。
- R17-11 第5步标兑现：每环必须有当章最小兑，否则链=纯吊；整条链的总兑=改一个硬标的（名分/公证权/名额）。
- R17-12 第6步切章：一环通常=一章章末；环3、环4可以占单元末；不要一章咬两环。
- R17-13 第7步写下章第1句：现在就写，不要等到写下一章再想；接的是动作下一帧。

### 硬规则 L01-L12
- R17-14 L01 先写主问句和指纹物，再写八型；没有物，不要排章末。
- R17-15 L02 解一咬一：答案必须成为下一问的主语。
- R17-16 L03 一章只咬一环：一章末既"谁"又"哪条律"=透支。
- R17-17 L04 每环当章有最小兑：纯吊2章，链断。
- R17-18 L05 下章第1句现在就写。
- R17-19 L06 欠债人升级，不换路人。
- R17-20 L07 暗链不准抢章末最后一句。
- R17-21 L08 结算必须改标的：只揭晓、名册不变=假链。
- R17-22 L09 结算必留齿，开下一条，禁止空窗章。
- R17-23 L10 环数3-5：2环太短像单钩；6环以上番茄读者会忘主问。
- R17-24 L11 嘴巴轮换：五章全"门又开了"是疲劳，不是链。
- R17-25 L12 主问句中途不许换题：发现写跑了，把新问题并进暗链，不要另开章末。
- R17-26 一卷建议：主链2条（先后，不并行抢嘴）+暗链1条（金手指灰行或上游印），每条3-5环；黄金三章不要开第二条主链，第二条等第4章用"跟我走"自然长出来。

## 公式与结构模板
- 公式1 解一咬一：上一问的答案=下一问的主语；谁来了→来的人放下令→令按哪条律生效→律上的印是谁的；主语咬着走，读者不会丢。
- 公式2 每一环+1贵：贵=见证者更高或标的更硬或代价更大；只加一档，禁止+3。
- 公式3 链卡（一条链一张）：链名；主问句；指纹物（第几章上桌）；欠债人升级路径；环1问/型/章末动作/当章兑/下章第1句；环2…；环3…；环4…；结算（改了哪个标的）；暗链点头（哪几章、用何物）；新链齿（结算时留下的下一物）；状态（进行中/已结算/并入暗链）。
- 公式4 接钩句：下章第1句=上章最后动作的下一帧；第2句=见证或代价；第3句起=本章新加压（仍挂在同一物上）；解开本环后到章末才咬下一环；禁止开头把后面三环一起说完。
- 公式5 双链不抢嘴：章末强钩只给主链；章中或余波=暗链点头（发热、灰行闪、多看一眼）；单元末=主链结算，暗链可以跟着露一齿，但仍不准抢最后一句。
- 公式6 结算即开新链：本链结算时必须留下一件"带不走的东西"，这件东西=下一条链的指纹物；例：公证权拿下了，令上那道印还烫——新链问：印要带他去哪张图。
- 完整样链（退婚开局，前5章）：主问句="婚书撕了之后，谁有权在堂上定义陆沉"；指纹物=两半婚书+灰烬里的印；欠债升级=苏绾→跟班执事→来接的人→回廊长老。环1（Ch1，倒计时）：章末"执事把香按进炉。'一炷香。婚书作废。'陆沉把两半叠好，灰烬里有道印在亮"，下章第1句"香还没燃尽。他拇指按住那道印"，当章兑=跟班护体裂；环2（Ch2，半揭）：章末"门开。来人没看苏绾，把一枚青令放在石桌上：见过——"，下章第1句"'见过供奉。'令面朝上，堂上没人敢先出声"，当章兑=聘礼单被他抽回来；环3（Ch3，规则）：章末"第三长老的押位是空的。青令压上去，空位自己烫出印。苏绾的退婚少了一押"，下章第1句"公证未成。退婚在律上还没生效"，当章兑=当众最小掉马（供奉令）；环4（Ch4，新债）：章末"回廊里放下茶杯的人走下来。他看的不是令，是陆沉袖口和婚书灰烬同一道印"，下章第1句"那人开口要的不是解释，是'跟我走'"；当章兑=苏绾当场失语，解释权易手；环5（Ch5，灰行/危机）：章末"跟走可以。面板灰行亮了：未授权。门外校场，内门第一人陈青已经在等三日婚期"，下章第1句"灰行没解释。陈青的剑先到"，当章兑=L1挡下一剑，L2齿留下。结算（环3-4）=退婚在律上卡住，定义权暂时不在苏绾嘴里；新链齿=印+陈青的三日婚期+灰行未授权；暗链=印从Ch1灰烬就在，Ch1/3/4点头，Ch30才问"谁在写这条律"。读者五章追的是同一张婚书，不是五件奇闻。
- 挂到全书结构上：书名/简介=主问句的广告（"三日另嫁，聘礼还在执事手里"）；黄金三章=环1-3，必须完成第一次"律上卡住"；第4-8章=环4-5，单元结算：解释权易手；第10章=暗链第一次真点头（隐藏层40%）；第30章=主链升到"谁写规则"并换图；卷末=本链结清+留下下图指纹物。

## 禁忌与反例
- 链的病（病→改法）：散钩（章末各吓一跳、物不同）→钉死一件指纹物；跳档（Ch1就问谁在写天道）→按谁→物→规则→写规则；倒答案（下章开头把三环说完）→只接一帧，章末再咬；双嘴（章末印亮了又天劫又内鬼）→天劫改章中点头；无兑（五章全是门开了）→每环给回一样东西；换债主（苏绾消失，换无关魔教）→魔教必须接印或接婚书；忘主问（写着写着去秘境捡宝）→秘境里也要出现那道印；结算空（大家吃惊，退婚仍生效）→当场卡住公证或改名册。
- 锁死段（可贴System Prompt）：先锁主问句+指纹物+欠债升级路径，再选章末八型；一条主链3-5环，一章一环，解一咬一（上一问的答案=下一问的主语）；每环：接下帧→当章最小兑→咬更贵一档→断在动作；下章第1句在写本章时就定；同时只允许1条主链占章末，暗链只准章中点头；结算必须改标的，并留下下一链的指纹物；禁止跳档、倒答案、一章咬两环、连续同型、无物散钩；黄金三章只跑主链环1-3。
