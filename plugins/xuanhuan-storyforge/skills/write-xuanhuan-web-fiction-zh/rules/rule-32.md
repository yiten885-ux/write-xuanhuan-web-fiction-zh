# Report 32 规则蒸馏

## 报告主题
情绪合理性专精模块（第六轮补充规则 36-40）：情绪锚定清单、烈度场景匹配、生理本能优先、宣泄与克制节奏、旁观者共鸣放大——五条可量化硬规则，专治 AI 写「面瘫主角」导致读者无法共情。

## 硬规则

### 情1｜主角情绪锚定清单（防面瘫主角）
- R32-01 九种经典爽文场景主角必须触发标配情绪反应（至少三选一，且必须包含外化动作），不得弱化、合理化或跳过：
  1. 当众被羞辱/退婚/废黜 → 愤怒（脸涨红/双拳攥出血/牙关咬碎）+ 羞辱（浑身发抖/低头避目）+ 杀意暗涌（眼底寒光一闪）。
  2. 被背叛/戴绿帽 → 暴怒（摔杯掀桌/指节发白）+ 心冷如刀（笑容消失/眼神空洞一瞬）+ 决绝转身（从此恩断义绝）。
  3. 亲人/恩人被杀害 → 悲痛欲绝（泪流满面/嘶吼）+ 滔天恨意（发誓复仇）+ 极端冷静（暴风雨前的死寂）。
  4. 被踩脸/踩手/踩尊严 → 屈辱（嘴角渗血/浑身僵硬）+ 隐忍中的杀意（这一脚我记下了）+ 后发制人的决心。
  5. 辛苦所得被夺 → 不甘（指节攥白/牙关紧咬）+ 愤怒质问（凭什么）+ 暗下决心夺回。
  6. 被嘲讽废物/垃圾 → 冷笑反击（嘴角一勾）+ 内心火山爆发（表面平静）+ 实力打脸伏笔。
  7. 爱人受伤/受辱 → 暴怒失控（灵力爆发/周围物品碎裂）+ 不顾一切冲上去 + 事后冷静复盘。
  8. 长年积怨一朝爆发 → 酣畅淋漓（仰天长笑）+ 如释重负（浑身轻松）+ 旧怨清算（一一数回）。
  9. 真相大白/误会解除 → 释然（长出一口气）+ 羞愧（低头握拳）+ 重新站起的坚定。
- R32-02 禁止标配场景出现「他面无表情」「他毫无波澜」「他淡然一笑」「他只是静静地看着」等冷漠化表达——除非主角人设是「天生无情」且前三章内明确，否则判定「情绪缺位」，强制重写。
- 公式：情绪合理性 R = 场景类型 ∈ 锚定清单 → 强制触发标配情绪；E=冷漠/平淡/忽略 → 强制重写。情绪词 <3 个或全为平静/淡然 = 情绪缺位。

### 情2｜情绪烈度场景匹配（防情绪扁平）
- R32-03 三级烈度表：高烈度（9-10 分：父母被杀/当众踩脸/挚爱背叛/苦修被废）→ ≥100 字篇幅 + ≥3 个外化动作（怒吼/砸物/灵力爆发/吐血）+ ≥2 个感官描写（手抖/牙颤/眼前发黑/耳鸣）；中烈度（5-8 分：当众嘲讽/所得被夺/冤枉禁闭/好友重伤）→ ≥50 字 + ≥2 个外化动作 + ≥1 个感官；低烈度（1-4 分：日常小亏/路人轻视/小失败）→ ≥20 字 + ≥1 个外化动作。
- R32-04 红线：高烈度事件不得用低烈度表达（父亲被杀只写「他握了握拳」=违规）；中烈度不得无烈度处理（被当众退婚只写「他走了」=违规）。
- 公式：烈度匹配度 M = 事件严重度 S − 表达烈度 E；|M| > 3 判定情绪错位，强制调整。

### 情3｜生理本能优先（防阅读理解式情绪）
- R32-05 任何情绪表达必须先写生理本能反应，再写心理活动，最后写语言/动作，顺序不可颠倒。
- R32-06 生理本能反应库（按情绪分类，至少二选一）：愤怒（太阳穴突突跳动/牙关咯咯响/指节发白/颈侧青筋暴起/胸口起伏/体温骤升）；羞辱（脸烧发烫/耳根红透/浑身僵硬/冷汗浸背/喉咙发紧）；悲痛（眼眶酸胀/喉头哽咽/胸口闷痛/眼前发黑/指尖冰凉/身体发抖）；恐惧（瞳孔骤缩/心跳漏拍/后背发凉/呼吸停滞/本能后退/汗毛倒竖）；狂喜（心跳加速/面色潮红/浑身颤抖/咧嘴/双手无措）；杀意（血液倒流的冰冷/瞳孔缩如针/呼吸极轻极慢/身体如弓绷紧）。
- R32-07 禁止跳过生理本能直接写心理（「他心想：我好愤怒」）；必须从「太阳穴跳了跳」「指节攥白了」开始。
- 公式：情绪真实度 T = 生理本能 0.4 + 心理 0.2 + 外化动作/语言 0.4；生理本能为 0 则 T≤0.6 判「假情绪」，强制插入生理描写。情绪段第一句是「他心想/他觉得自己」→ 生理描写强制前移。

### 情4｜宣泄与克制节奏（防读者憋屈）
- R32-08 隐忍蓄力期连续最多不超过 2 章；第 3 章若仍隐忍，必须出现一次「克制的释放」（冷笑放狠话/暗中动手脚/眼神让对方不寒而栗）。
- R32-09 宣泄爆发必须有实际后果（打脸成功/杀掉仇人/夺回资源），不得爆发完什么都没变。
- R32-10 禁止受极端羞辱（退婚/杀亲/踩脸）后超过 3 章仍隐忍不发而无实质反击。
- 黄金比例：隐忍:宣泄 = 6:4。憋屈指数 F = 隐忍章数×1.5 − 宣泄章数×1；F > 3.0 触发读者憋屈警告，强制安排宣泄。本章前连续隐忍 ≥3 章 → 本章必须低烈度宣泄。

### 情5｜旁观者共鸣放大器（防情绪独角戏）
- R32-11 高烈度场景（烈度≥8 分）必须加入至少 2 个旁观者反应：同情/不忍（「有人倒吸一口凉气」）、嘲讽/幸灾乐祸（「活该」）、震惊/畏惧（「满场哗然」）三型。
- R32-12 旁观者功能：验证主角情绪合理性、放大读者共情、为反转积累社会性势能（当时嘲笑的人越多，打脸时越爽）。
- R32-13 禁止高烈度场景只有主角一人有情绪、周围人像 NPC。
- 公式：共鸣强度 A = 旁观者人数×0.6 + 反应强度（轻/中/重=1/2/3）；A < 2.0 判共情不足，强制插入旁观者描写。

## 公式与结构模板

### 自检清单 36-40（章末追加）
36. [情绪锚定] 命中锚定清单？情绪匹配标配？(是/否/不适用)
37. [情绪烈度] 事件严重度与表达烈度匹配？(是/否)
38. [生理本能] 情绪段先写生理反应再写心理？(是/否)
39. [宣泄节奏] 连续隐忍≤2章？超 3 章是否有释放？(是/否/不适用)
40. [旁观者共鸣] 高烈度场景 ≥2 个旁观者反应？(是/否/不适用)

### AI 执行优先序（生成任何情绪触发场景前）
1. 场景是否命中锚定清单 → 是则调用标配情绪模板。
2. 严重度对应烈度等级 → 匹配表达强度。
3. 情绪表达是否生理本能为开端 → 否则强制插入。
4. 主角是否已隐忍多章 → 是则强制宣泄。
5. 旁观者是否足够 → 不足强制插入。

## 合格/不合格对照示例
- ❌ 被当众退婚：「陆沉面无表情地看着她，转身离开了人群。」（情绪缺位）
- ✅ 合格：生理本能（浑身一僵、脸烧发烫、耳根红透、指节攥白、胸口闷痛）→ 心理≤50字+外化（想冷笑嘴角只抽动一下）→ 旁观者（哗然/嗤笑/女弟子偏头不忍看）→ 宣泄种子（捡婚书缓缓折好，目光掠过锦衣男子：「这婚约，我接了。三年后，我会让你亲手拿回去。」）
- ❌ 被戴绿帽：「他沉默片刻，转身轻轻关上了门。」（过度隐忍）
- ✅ 合格：瞳孔骤缩血冻住又烧成岩浆 → 太阳穴狂跳/牙关咯咯/青筋暴起/眼前发黑 → 按剑指节咯咯响/灵力撞门轰然巨响/温度骤降 → 低烈度宣泄一句（「你们……活腻了。」沙哑如铁片摩擦）→ 旁观者（丫鬟瘫软尖叫引家家丁，无人敢上前）。

## 与既有体系的嵌入关系
规则二（能动性）管决策频率；规则八（情绪收益）管爽感结构；规则十五（心理外化）管篇幅；36-40 管「情绪表达的标准和底线」。作为**前置协议**在所有情节生成前优先执行。

## System 锁死段（可直接贴进提示词）

```text
【情绪合理性模块】
主角情绪表达必须遵守：
1. 锚定强制：命中[退婚/背叛/杀亲/踩脸/夺宝/嘲讽/爱伤/积怨/真相]九类场景时，触发标配情绪（愤怒/羞辱/暴怒/悲痛/不甘），禁止面无表情或淡然。
2. 烈度匹配：高烈度（≥8分）≥100字+≥3动作+≥2感官；中烈度（5-7分）≥50字+≥2动作+≥1感官；低烈度（1-4分）≥20字+≥1动作。
3. 生理优先：先生理本能（脸烧/手抖/牙咬/瞳孔缩/心跳/青筋），再心理，最后语言/动作。
4. 隐忍上限：连续隐忍≤2章，第3章必须有释放（放狠话/小反击/暗中布局），禁止憋屈超3章。
5. 旁观者放大：高烈度场景插入≥2个旁观者反应（同情/嘲讽/震惊），作为情绪外部验证。
若任一指标不满足，标注【情绪失效】并强制改写。
```

## 禁忌与反例
- 禁：标配场景面无表情/毫无波澜/淡然一笑/静静看着（人设例外须前三章明确）。
- 禁：高烈度低表达（父亲被杀只握握拳）。
- 禁：跳过生理直接写心理。
- 禁：爆发完什么都没变。
- 禁：高烈度场景全员 NPC。
