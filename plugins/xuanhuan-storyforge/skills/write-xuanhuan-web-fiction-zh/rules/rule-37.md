# Report 37 规则蒸馏

## 报告主题
资质测试+全宗震荡+抢人大战模块（第十轮补充规则 59-65）：历史对比锚定、测试感官烈度三叠加、高层反应层层失控（五级）、抢人大战规格、五重收益清单、快节奏延续、多宗派竞抢规格——七条硬规则打造「资质测试引发全宗震荡」的顶级爽感名场面。

## 硬规则

### 测1｜历史对比锚定（防读者不知道主角资质多高）
- R37-01 测试前必须三层对比锚定：①宗门历史最高（前 300-500 字内，30-50 字：「三百年来最高纪录是第九代老祖七尺三寸赤光冲天，此后百年无人破六尺」）；②当代天骄基准（前 200-400 字内，20-40 字：「陆天都上月六尺九寸紫气东来，掌教赞百年一遇」）；③历代平均线（前 100-300 字内，15-30 字：「三尺合格，五尺天才，六尺三十年一遇」）。
- R37-02 主角成绩必须至少超过宗门历史最高纪录，否则不算「震惊全宗」。
- 公式：震撼度 S = 主角成绩 / 宗门历史最高纪录；S ≤ 1.0 不够震撼，强制提升至 ≥1.2 倍。测试前强制输出三句铺垫。

### 测2｜测试感官烈度三叠加（防画面干瘪）
- R37-03 测试过程三阶段感官：①测试触发（1-3 秒，物理接触，20-40 字：冰凉触感从掌心蔓延）；②异象爆发（3-10 秒，视觉/听觉/威压/触觉四维叠加，80-120 字：石碑轰震、赤色光柱冲天、耳中嗡鸣、石板龟裂、焦灼雷火之气）；③结果呈现（定格，20-40 字：一行金纹浮现「九尺九寸，万丈金光」）。
- R37-04 禁止只写「石碑亮了显示××」，必须有视觉+听觉+环境反馈叠加。
- 公式：画面饱满度 P = 视觉词 + 听觉词 + 环境反馈词；任一维度为零判「画面干瘪」，强制补缺。

### 测3｜高层反应层层失控（防长老点点头）
- R37-05 测试结果引发宗门高层逐级失控，从底层到顶层反应递增：第一层执事/导师（物品掉落/面色剧变/失声惊呼，30-50 字）→ 第二层普通长老（霍然起身/茶杯粉碎/交换震惊眼神，40-60 字）→ 第三层核心长老/副宗主（灵识全开/灵力失控震碎物件/传音询问，50-80 字）→ 第四层宗主/掌教（从座位站起/打断事务/亲临现场，60-100 字）→ 第五层太上长老/老祖（闭关被惊动/神念横跨千里/声音从天穹落下，80-120 字）。
- R37-06 禁止跳过中间层级直接写「宗主收徒」；红线标志：必须至少一人「坐不住站了起来」或「说话被打断」。
- 公式：失控强度 U = 反应层级数(1-5) × 烈度词数；层级数 < 3 判「震撼不足」，强制追加高层反应。

### 测4｜抢人大战规格（防不烈）
- R37-07 抢着收徒的最低规格：①最低规格（合格线）：≥3 位长老同时开口争抢，互相瞪眼/拍桌/打断（老夫愿收！/老夫先看到的！/你一个炼丹长老抢什么武修弟子？）；②标准规格（推荐）：≥5 位含核心长老/副宗主，互相揭短/身份施压/当场开条件（你去年废了三个弟子也好意思抢？/老夫愿将珍藏三十年的九转淬体经赠予此子）；③顶级规格（爆款）：≥7 位含宗主/太上长老，灵压对撞/桌案碎裂/宗主出面调停（两道凝元巅峰灵压对撞桌案四碎，宗主起身「本座亲自收徒」）。
- R37-08 禁止只有 1-2 位长老「表示欣赏」就结束。
- 公式：争抢烈度 B = 参抢人数(≥3) + 争执台词数(≥5) + 开价条件数(≥3)；任一维度不达标强制追加。

### 测5｜五重收益清单（防空头支票）
- R37-09 主角被抢收为亲传/圣子后必须立刻兑现至少 5 项可量化收益：身份收益（封圣子/进出藏经阁/内门最高权限）；功法收益（地阶功法/镇宗心法承诺）；资源收益（圣子洞府/灵石供奉翻百倍/护身法器）；人脉收益（太上长老记名/宗主亲传令牌/隐世高人示好）；信息收益（宗门秘史/父亲陨落真相/秘境入口）；地位收益（轻视者当场跪认错/天骄主动示好）。
- R37-10 禁止只有「你以后就是我徒弟了」一句而无具体收益条目。
- 公式：收益价值 V = 收益项数 ≥5；V < 5 判「收徒像空头支票」，强制追加 ≥2 项。输出【圣子/亲传收益清单】。

### 测6｜快节奏延续（防节奏塌方）
- R37-11 测试+抢人后，同一章或下一章内必须衔接新的前进指令，3 段内开启新事件：新任务下达（最优先：三日后随队前往万兽秘境）；新冲突引入（次优先：被抢了弟子的长老黑脸「我不服，要挑战他」）；新信息解锁（次优先：宗主无意透露身世线索「你父亲曾是天命碑前另一道异象的主人」）；新场地解锁（第三优先：圣子洞府深处藏着意想不到的东西）。
- R37-12 禁止测试完后「尘埃落定、主角回房休息」。
- 公式：节奏延续性 C = 测试后新事件距离 ≤3 段；>3 段判「节奏塌方」，强制插入新事件。

### 测7｜多宗派竞抢规格（如适用）
- R37-13 若剧情为多宗派同时收徒竞抢：参抢宗派 ≥3（顶级 ≥5 含超级宗门）；每宗至少 1 次宣示、1 项具体条件；宗派间至少 1 次直接争执（顶级：差点动手/宗主调停/天穹异象被打断）；主角必须做出选择且选择要震惊全场（选最弱的宗派/选超级宗门但附条件）。
- R37-14 禁止多宗派竞抢变成「几大宗门代表看了看就走」。
- 公式：竞抢规格 Q = 参抢宗派(≥3) × 台词(≥3) × 筹码(≥3)；任一维度不达标强制追加。输出【竞抢清单】：①参抢宗派及代表；②每宗条件（≥3 项）；③争执/加码描写（≥5 句对话）；④最终选择及理由。

## 公式与结构模板

### 六步执行流程
Step1 三层对比锚定（历史最高/当代天骄/平均线）→ Step2 测试感官三叠加（触发/异象爆发/结果定格）→ Step3 高层五级失控（执事→长老→核心长老→宗主→太上）→ Step4 抢人大战（人数/台词/开价三大件）→ Step5 收益清单（≥5 项）→ Step6 快节奏延续（3 段内新事件）。

### 与全局规则关联
金手指规则四/二十五（测试触发金手指异动）；规则八（资质测试=顶级情绪收益展示）；规则五/二十二（宗门历史设定挂载于事件载体）；规则四十（高层失控中的旁观者放大）；规则三十一-三十五（主角资质超高=底牌反转）；规则四十三-四十八（资质测试可作入门考核第一关的反套路替代）；规则五十四-五十八（长老反应=高阶版小人物反射）。
