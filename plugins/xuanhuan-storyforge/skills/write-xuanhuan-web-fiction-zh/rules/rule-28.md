# Report 28 规则蒸馏

## 报告主题
智商与武力配比合同（番茄玄幻）：结算方式配比 7:2:1 锁、十二条智武硬规则、八个创作公式，专治模型爱写「智商戏」导致追读掉的问题。

## 硬规则

### 一、结算定义与配额
- R28-01 本章爽点验收只认画面：护体碎、吐血、榜改名、令烫印、名册改字、丹成、兽改口、数字跳；只有嘴赢、对方「恍然大悟」=不算兑现。
- R28-02 结算方式配比必须锁 7:2:1：每 10 章 7~8 章主糖是武力/修为碾压（打、越级、护体碎、榜、令、丹），1~2 章主糖是信息差点破（一句拆穿+立刻动手或立刻改手续），最多 1 章真布局。
- R28-03 每章内部篇幅：动手/验功/物证烫印 ≥50%；对话里的「拆局」≤15%，且拆完 200 字内必须见结果；内心推演 ≤3 句。
- R28-04 单元高潮（五到八章里那次中爽）必须武力或规则落地，禁止用「揭穿阴谋」当唯一高潮；揭穿只能当辅——揭完一招或揭完令烫上。
- R28-05 起点偏慢的玄幻可放武力 60%、信息差 25%、布局 15%；权谋玄幻才反过来；番茄打脸按 7:2:1 锁。

### 二、先打后说
- R28-06 先打后说，或只打不说：禁止先讲三章计再动手；允许一句话点破 → 两百字内动手/改手续。
- R28-07 点破不超过一句（≤20 字），点在物上：「这印不是本宗的。」后面立刻烫、裂、抽令；禁止把点破展开成破案课。
- R28-08 内心推演不超过三句；禁止「若他如此，我便如彼」的树状图；要算，用手上的物去碰，碰出结果。
- R28-09 禁止事后解释：「其实我从第一章就……」删；读者靠信息差已经知道，再说是作者邀功。

### 三、真布局约束
- R28-10 真布局配额：连续三章禁止「还在布局、本场不打」；十章最多一场真布局，且当场必须废一个人或改一条手续。
- R28-11 真布局必须短网：布局只允许同一场、同一桌、同一炷香内收网，不准跨三章才收；网底必须是刀、律、印，不是对方认输道歉。
- R28-12 高潮章禁用纯智商：单元高潮、卷高潮的主货必须是打脸、越级、规则反套、掉马物证；规则反套也要烫印/改名册，不是辩论赛。

### 四、修为与对手底线
- R28-13 智商不能代替修为：炼气可以靠信息差打过筑基的嘴，但不能靠嘴让筑基护体自己裂；护体裂仍要有一招、一丹、一令、一反噬。
- R28-14 反派可以蠢，但不能蠢得没好处：对方上当是因为贪名额、贪婚、贪灭口，不是因为智商为零陪主角演戏。
- R28-15 越级仍要报数字：信息差再强，场上也要喊境界、碎对照物；否则不得用「他看破了」跳过打。
- R28-16 对话不讲计：对白只羞辱、只报价、只宣律、只喊境界；计在动作里。
- R28-17 金手指不是诸葛锦囊：系统给的是权限、反噬、灰行两字，不是「宿主请按甲乙丙方案」。
- R28-18 反派行动优先于主角心计：先写反派要抢的好处和下的手；主角反应是挡、抽、烫、裂；反派自己要来，主角只在桌上结算。

## 公式与结构模板

### 公式A：章结算标签（写正文前必填）
本章主结算三选一：武力修为 / 信息差点破 / 真布局。若选后两者，必须同时填写「两百字内的武力或手续结果」。禁止主结算=真布局且本章无护体/名册/令/数字变化。近三章若已有一次信息差点破或真布局，本章强制选武力修为。

### 公式B：7:2:1 发放排程
每 10 章中第 1、2、4、5、7、8、10 章武力修为主结算；第 3、6 章信息差点破（一句）+立刻动手；第 9 章可真布局但章末必须废现场刀或改手续；下一轮十章换掉第 9 章位置，禁止连着布局。黄金三章：第一、二章武力最小弹，第三章可以半揭（信息差）但必须一招或令上桌；禁止第三章靠揭穿身世当高潮。

### 公式C：点破句模具
一句（≤20 字）点在物上 → 两百字内抽令/一招/烫印/改榜 → 观众改口喊的是数字或身份，不是「好深的心机」。对例：他放下令，「缺一押。」空位烫印。错例：他分析退婚律十五条，对方被说哭。

### 公式D：真布局短网
同一场、同一桌、同一炷香内收网；网底必须是刀、律、印。合法真布局例：宴上让对方先宣连坐 → 证据在对方袖里亮出 → 当场按同一条律废对方名籍（三拍一场）。

### 公式E：打戏最低配置（防跳过）
报双方境界或公开身份 → 一招或一物（令、丹、反噬）→ 对照物碎 → 旁人改口 → 更高层看见。缺对照物碎，本章武力结算无效，重写打；不准改成「他识破了所以对方不敢动手」。

### 公式F：篇幅闸门
推演、拆局、回忆算计合计超过本章 15% = 废段改成动手；单段对话拆局超过 200 字 = 腰斩留一句点破；出现「计策、布局、棋、算到、早知、不过如此」等词超过 2 次 = 改动作句。

### 公式G：反派先行
先写反派要抢的好处和下的手；主角反应挡、抽、烫、裂；不写主角设计让反派来抢。信息差还在（读者等打脸），但戏是武力。

### 公式H：自检三问（有一个答错就改）
1. 读者截图发群的是「裂了/榜变了/令烫了」，还是「他真聪明」？必须是前者。
2. 把所有分析对话删掉，打脸还成立吗？不成立=智商戏替了武力，补一招。
3. 本章若改成纯开打，是否会更爽？会=分析是水，删。

## 禁忌与反例
- 合规样板：苏绾当众撕婚书，跟班动手，护体裂，他放下令「缺一押」，空位烫印，回廊人盯袖口的印——智商只占五个字，结算是裂和烫。
- 一句话总纲：七成用打和修为把桌子改掉，两成用一句话把刀指对，一成才允许同一场内收一个短局；模型每想写「他算到了」，就改成护体裂或令烫上。
