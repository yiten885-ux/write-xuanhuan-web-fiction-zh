# Report 35 规则蒸馏

## 报告主题
小人物推动剧情模块（第八轮补充规则 49-53）：五类推动模式（消息传送者/冲突点燃者/人性对照者/规则解锁者/命运映射者）、硬/软触发、人性逻辑一致性、主线关联度（8-15%）、事件闭环——让小人物的每次出现都推动主角向前。

## 硬规则

### 小1｜五类剧情引擎分类（防工具人单一化）
- R35-01 小人物（地位低/实力弱/活不过三章的路人）有五种核心推动模式，按剧情需要轮换，禁止反复同一种：①消息传送者（无意说漏/偷听/被审问→提供行动目标，「听说后山禁地昨晚有光」）；②冲突点燃者（嘴贱挑衅/偷东西/抢资源→拖入新对抗，「你就是那个废物？」）；③人性对照者（被折磨/被踩→唤醒共情/愤怒/觉悟）；④规则解锁者（递话/善意提醒/反面教材→规避风险获捷径，「想活就别走正门」）；⑤命运映射者（同地同路不同结局→紧迫感/感恩/战斗欲，他死在距终点三步处，主角亲眼目睹）。
- R35-02 类型丰富度 R = 本章小人物类型数(≥1)；同一类型连续 3 章内出现 ≥2 次触发「工具人警告」，强制轮换。

### 小2｜硬触发与软触发（防机械降神）
- R35-03 硬触发（占 60%）：小人物因自身欲望/利益/求生本能主动做事影响主角（嘴贱路人挑衅→触发熔炉反击震碎其兵器）。
- R35-04 软触发（占 40%）：主角出于目的主动找小人物问出/观察出关键事（花三块灵石从醉散修口中套出「今晚演武场截杀外门弟子」）。
- R35-05 禁止「突然有人喊了一句」「人群中有人低声道」式凭空触发；必须有合理解释——他为什么在这里/说这句话/有什么动机。
- 公式：触发合理性 R = 硬触发动机强度(1-5) + 软触发主角主动系数(1-5)；R < 4.0 判「硬塞」，强制在事件前 150 字内插入动机描写。

### 小3｜人性逻辑一致性（防 NPC 化）
- R35-06 小人物行为必须符合小人物生存逻辑——实力低微者通常不无理由挑衅强者，除非有动机：被利益驱动（赏钱/灵石/出头机会，最常见）；被恐惧驱动（不做就被杀/废/驱逐，最常见）；被无知驱动（不知主角多强）；被欲望驱动（酒色财气上头）；被身份绑架（「我是某某的人」必须做姿态）。
- R35-07 禁止「为了坏而坏」或「无代价倒向主角」。
- 公式：人性可信度 H = 行为动机 ∈ 五类动机库；无匹配动机判 NPC 行为，强制追加动机描写。行为比动机更激烈（怕死却攻击主角而非逃跑）→ 强制调整行为强度或补动机。

### 小4｜主线关联度（防水字数）
- R35-08 每个小人物事件必须链接主线下一步——读完事件，读者应知道主角接下来去哪/找谁/防什么。
- 关联度：事件导致主角下一步行动变化 = 1.0 合格；仅氛围/世界观填充、行动未变 = 0.3 不合格（水字数）。
- R35-09 黄金比例：小人物事件占本章总字数 8-15%；<8% 推动力不足（强制追加消息传送者类事件），>15% 喧宾夺主（移入配角区或压缩）；事件后主角行动无变化 → 强制改为与下一步行动直接相关。
- 公式：主线推进效率 E = (事件字数/本章字数) ∈ [8%, 15%] 且 事件后行动状态有变化。

### 小5｜事件闭环（防烂尾 NPC）
- R35-10 发挥关键作用的小人物，事件结束后 3 章内必须有收尾交代，三选一：后续交代（最常见，通风报信的店小二拿了赏钱连夜离开青阳城）；悲剧收场（强化情绪，通风报信被反派发现，次日尸体挂在城门口→主角愤怒升级）；反转变数（最高级，看似卑微的乞丐是长老的道童，递话有意为之）。
- R35-11 禁止「说完话就消失再无下文」，哪怕一句话交代结局也行。
- 公式：闭环率 C = 已收尾数/关键小人物总数；C < 80% 判「烂尾 NPC」，强制插入收尾语句。建立本章关键小人物清单逐个检查。

## 公式与结构模板

### AI 调用示例
硬触发（利益驱动）：尖嘴弟子凑上来收「安顿费」→ 动机描写（榨三块灵石是他今晚喝酒的指望）→ 主线关联（主角捕捉到外门例钱与打点规则，计划改为找更狠的靠山）→ 闭环（三个月后那人远远绕道走）。
软触发（主角主动）：蹲三天等采药老人 → 两枚灵石放石块上 → 老人指点暗道与认罪书位置 → 闭环（老人消失，传言是内门长老暗桩）。

### 与全局规则的关联
规则一（节奏：反射段≤300字不拖节奏）；规则五/二十二（小人物口中的设定必须锚定）；规则十二（小人物与配角区分——小人物核心功能就是推剧情，不求深度塑造）；规则四十（人性对照/悲剧收尾是共情放大器）。

## 自检清单 49-53（章末追加）
49. [小人物类型] 连续 3 章内类型是否轮换？ 50. [触发机制] 硬/软触发是否有动机解释？ 51. [人性逻辑] 行为是否匹配五类动机库？ 52. [主线关联] 字数占比 8%-15%？事件后主角行动有变化？ 53. [事件闭环] 3 章内关键小人物是否有收尾交代？

## System 锁死段（可直接贴进提示词）

```text
【小人物推动剧情模块】
「小人物」作为剧情推动者必须遵守：
1. 类型轮换：从[消息传送者/冲突点燃者/人性对照者/规则解锁者/命运映射者]五类中选，连续3章内不得同一类型用2次以上。
2. 触发有因：硬触发（小人物主动）必须有动机（利益/恐惧/无知/欲望/身份）；软触发（主角主动）必须有主角为何找上他的解释。
3. 人性可信：小人物行为必须匹配底层生存逻辑，禁止「毫无理由地坏」或「无代价倒戈」。
4. 主线关联：小人物事件字数占本章8-15%，且事件后主角的下一步行动必须发生变化。
5. 事件闭环：关键小人物在事件结束后3章内必须有收尾（离开/死亡/转场/身份揭露）。
若任一指标不满足，标注【小人物事件无效】并强制修正。
小人物事件价值公式：V = 主线推进效率(E) × 事件闭环率(C)；E=事件后主角行动变化(1/0)，C=收尾交代是否存在(1/0)；V=0 判「NPC凑字数」，强制重写。
```
