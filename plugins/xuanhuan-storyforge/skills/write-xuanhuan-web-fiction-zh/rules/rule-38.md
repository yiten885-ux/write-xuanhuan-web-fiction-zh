# Report 38 规则蒸馏

## 报告主题
爽点大全（第八轮补充）：玄幻男频爽文八大类三十九个爽点的完整目录——每个爽点含定义、心理机制、创作公式、硬规则，另附 3 条全局硬规则（爽点间距/可感知锚定/类型轮换）。与前 12 爽货货盘（S 系列）互补：S 系列管货的分类与分货公式，本目录管 39 个具体爽点的逐点操作手册。

## 硬规则

### 全局三条
- R38-01 爽点间距：连续两个高烈度爽点（如越阶反杀+当众打脸）之间至少间隔 500 字或一个场景过渡，避免爽感疲劳。
- R38-02 爽点锚定：每个爽点必须有可感知的结果（见血/碎物/跪地/变色/惊呼），不能让读者「猜」主角赢了。
- R38-03 爽点类型轮换：连续三章内至少使用 3 种不同类型的爽点，避免「只会打脸」的单一模式。输出爽点段落时附类型标注。
- R38-04 八大类体系：尊严型（01-05）/实力型（06-10）/资源型（11-15）/关系型（16-20）/智谋型（21-25）/命运型（26-30）/群体反应型（31-35）/爆发突破型（36-39），共 39 点，逐点公式见 references/satisfaction-catalog.md。

### 逐点硬规则精要（每点 3-4 条，全文见目录文件）
- 爽点01 当众打脸：羞辱场合公开（≥5 见证者）；反转前有压制性台词或沉默蓄势；反派失态至少一处；结果可感知（见血/碎物/倒地/跪地）。
- 爽点02 杀人诛心：先打服再诛心；诛心点=反派前三章展示过的引以为傲之物；必须有旁观者印证；反派必须活着退场（死亡剥夺持续爽感）。
- 爽点03 身份碾压：反派必须完全不知情；身份亮出须第三方证实；嚣张→恐惧可感知（膝软/嗓哑/手抖）。
- 爽点04 天骄踩踏：天骄战前被 ≥3 旁观者认证最强；获胜方式出乎意料；战后有地位交接仪式感（剑被拿走/称号继承）。
- 爽点05 旧人追悔：至少一次今昔对比；旧人必须主动亲眼目睹；追悔表情至少一次；主角回应最好是无视（无视比嘲讽更诛心）。
- 爽点06 越阶反杀：≥2 项前置条件+明确代价；反杀逻辑说得通（轻敌/要害/属性克制）；反杀后有价值兑现（储物袋/灵核/情报）。
- 爽点07 秒杀：秒杀前 ≥100 字对手全力展示；主角动作轻描淡写（≤20 字）；秒杀后 ≥2 人震惊校准强度。
- 爽点08 以少胜多：人数比 ≥1:5；明确写应对围攻方式（不能写成 1v1）；至少一个标志性瞬间（一拳打飞三人）。
- 爽点09 一力降十会：对手招式写得精巧复杂；主角力量纯粹（就一拳）；碾压后有认知颠覆描写（练三十年的剑法被一拳粉碎）。
- 爽点10 压制全场：由近及远的递进反应；实体化威压（石板裂/空气凝/烛火灭）；压制持续到本章结束。
- 爽点11 杀人夺宝：宝物与反派人设相关；价值锚定（坊市五百灵石/黄阶上品好三倍）；过程≤300 字。
- 爽点12 捡漏奇遇：捡漏必须合乎逻辑（凭特长发现）；价值超常人认知；捡漏后有对比描写（摊主不知卖了什么）。
- 爽点13 传承/灌顶：传承必须有代价（寿命/古碑暗淡/虚弱）；过程有身体感受（经脉撕裂/太阳穴胀）；结果即时验证（一掌新法术）。
- 爽点14 奖励夺魁：奖励有具体内容（名称+品阶+功能）；发放时 ≥1 个羡慕嫉妒恨旁观者；奖励匹配当前需求。
- 爽点15 无中生有：技能须前文埋线；制成品有鉴别过程（老丹师/验宝台）；品级肉眼可见高于同类（丹晕三圈 vs 两圈）。
- 爽点16 美人倒追：前期高冷 ≥200 字铺垫；态度变化循序渐进；主动行为具体可感知；主角回应不太在意保持低位差。
- 爽点17 叛徒跪地：叛徒必须是认识的人；求饶含具体开价；主角处置比死亡更诛心（「我不杀你，让你活着看着今日的我」）。
- 爽点18 知遇之恩：前期帮助小而具体（一碗饭/一句话）；危机与主角崛起直接相关；出手后有恩人感慨（当年那小子……）。
- 爽点19 万人臣服：有第一个跪下的人作视觉锚点；由近及远蔓延；齐声高喊 ≤8 字（拜见圣子）；主角位置在高处俯瞰。
- 爽点20 天骄追随：前期足够高傲；折服有具体事件；追随理由合理（想成为像你这样的人，非图好处）。
- 爽点21 设局反杀：设局提前埋线；规模与威胁等级匹配；揭示后有解释性台词（那条路上的枯草是我故意踩的）。
- 爽点22 利用规则：规则前文明确提及；漏洞合理不耍赖；成功后有无法反驳的验证（裁判确认符合规则）。
- 爽点23 借刀杀人：A 与 B 矛盾真实存在；操作隐晦（随口一句/匿名纸条）；不留把柄。
- 爽点24 信息差碾压：来源合理（前世记忆/金手指/遗物）；第 2 章之前铺垫；收益即时兑现。
- 爽点25 扮猪吃虎：藏拙有合理理由；被欺凌程度足够深（被打到跪/当众羞辱）；展露后 ≥3 旁观者震惊。
- 爽点26 天命认证：认证前有无人能触发的铺垫；异象比历史最高宏大；认证后有官方仪式（封圣子/神子）。
- 爽点27 血脉觉醒：前期铺垫一句（血液与旁人不同）；觉醒能力有代价（消耗寿命/特殊灵石维持）；来历分阶段揭示。
- 爽点28 气运通天：事件完全随机（非主角操控）；概率足够低（万分之一/千年一遇）；事后至少一个质疑者被打脸。
- 爽点29 旧日真相：分三章释放（现象→线索→核心）；真相改变主角下一步行动；揭示后有即时外化反应（捏碎茶杯/拳攥出血）。
- 爽点30 命运逆转：逆转前 ≥200 字绝境描写；逆转方式意料之外；逆转后预言者反应（我的占卜从未出错……）。
- 爽点31 万众瞩目：目光由近及远 ≥3 个节点；主角反应淡然（得意是反派）；被看后推进下一步行动。
- 爽点32 鸦雀无声：寂静前有吵闹铺垫；寂静持续可感知（三息）；打破时有一个具体声音（茶杯落地/一声咳嗽）。
- 爽点33 倒吸凉气：多人同时（数十人）；紧接一个具体人的质疑/确认（揉眼睛/低声问是真的吗）。
- 爽点34 谣言风暴：传播有路径（外门→内门→长老）；版本比原始夸张（打退筑基传成凝元）；主角听到传闻有内心活动（摸摸鼻子）。
- 爽点35 官方认可：书面感表达（掌教手谕/宗谱添名/金匾）；改变实际权利（A 地进 B 地/领更多灵石）；后有对比反应（撇嘴/恭贺）。
- 爽点36 当场突破：突破前有瓶颈感描写；突破有代价（灵石耗空/极度虚弱）；突破后立即验证（一掌/威压/感知扩大）。
- 爽点37 功力暴涨：暴涨有来源（传承/丹药/吞噬）；过程有身体感受（≥2 感官）；暴涨后有外界认证（探测术震惊/威压逼退）。
- 爽点38 反败为胜：破绽是故意露的且前文埋伏笔；逆转一击精准（刺要害/攻破绽）；后有解释性台词或回忆闪回。
- 爽点39 一路畅通：期间至少 1 个略有威胁的对手被举重若轻化解；不超过 1.5 章（防平推流）；之后必须有转折（真大敌/招来嫉妒）。

## 公式与结构模板

39 个爽点各配「心理机制+创作公式」，完整逐点公式见 references/satisfaction-catalog.md（如：当众打脸 = 公开羞辱(≥10人) + 先踩至最低点 + 反转揭露 + 全场寂静音效反差 + 反派脸色红→白→青 + 一句回敬台词）。

## 禁忌与反例
- 禁：爽点结果不可感知（嘴上赢了）、高烈度低间距（疲劳）、连续同类（单一模式）、秒杀无铺垫、传承无代价、捡漏无逻辑、气运可被操控、真相一次性倒完、一路畅通超 1.5 章。
