# Report 33 规则蒸馏

## 报告主题
玄幻命名规则协议（世界构建层）：丹药/功法/兵器法器三大类的命名公式+词库+品阶映射规则，加规则四十一（名字即线索）与规则四十二（品阶与字数暗示）两条辅助协议——好名字让读者秒懂品阶属性功能，烂名字让人瞬间出戏。

## 硬规则

### 命1｜丹药命名公式
- R33-01 丹药名 = [前缀(品阶/数量)] + [核心词(功效/原料/属性)] + [后缀(形态/品阶)]。前缀词库：一~九/十/百/千/万 + 玄紫金玉龙凤麒麟太乙混元无极；核心词库：还魂续命筑基破障洗髓淬体凝元化神融灵焚天镇魂归元易筋换骨通脉开窍孕婴合道；后缀词库：丹丸散膏液露精华玉灵元珠珀晶髓。
- 品阶映射：≤3 阶名长≤4 字（凝气丹）；4-6 阶 4-6 字（筑基洗髓丹）；7-9 阶前缀含数词（一转/三转/六合/九转，如九转洗髓丹）；≥10 阶前缀含玄/紫/金/玉/龙/凤（九幽续命膏）；≥13 阶前缀含太乙/混元/无极/九幽/涅槃（九转太乙还魂丹）。

### 命2｜功法命名公式
- R33-02 功法名 = [前缀(属性/品阶)] + [核心动作词/核心名词] + [后缀(类别/形态)]。三种经典句式：①动词+名词（翻天印、劈山掌、碎星拳、断岳刀）；②名词+名词（九幽玄功、太虚剑典、紫霄雷诀、混元真经）；③动词+名词+名词（焚天诀、镇魂经、破虚剑、凝元功）。
- 前缀词库：九幽太虚紫霄混元无极玄天赤阳寒冰太乙归元万象苍冥混沌造化；核心动词：翻劈碎断焚镇破凝化引聚炼融吞噬裂斩灭封镇；后缀词库：印掌拳刀剑诀经典功法录鉴要纲谱图阵符。
- 品阶映射：凡阶无前缀（铁砂掌/奔雷拳）；黄阶双字属性+单字动作（赤火掌/寒冰诀）；玄阶三四字属性（九幽玄冰掌/紫霄雷霆诀/混元归真经）；地阶传说前缀（太虚破天剑/无极镇魂印）；天阶极致前缀+四字组合（混沌开天造化功/万象归元镇魔典）。

### 命3｜兵器/法器命名公式
- R33-03 兵器名 = [前缀(材质/品阶/属性)] + [核心名(本体/功能)] + [后缀(形态/类别)]。前缀词库：玄铁寒铁赤铜紫金玄冰赤炎九幽太虚无极七星九环断岳裂天镇海焚山；核心词库：龙吟凤鸣虎啸镇魂斩妖诛魔破虚裂空焚天碎星断江崩山锁魂封脉；后缀词库：剑刀枪戟斧锤鞭锏钩叉伞镜钟鼎塔印旗幡轮环尺杖棍。
- 类型风格表：剑=雅致飘逸（青霜剑/太阿剑/寒月秋水）；刀=刚猛霸道（屠龙刀/破军刀/裂天战刀）；枪戟=凌厉大气（破阵枪/霸王破阵枪/九幽穿云戟）；锤斧=沉重碾压（碎星锤/开山斧/九幽震岳锤）；鼎塔印=厚重镇压（镇魔塔/封天鼎/九幽镇魂印）；伞镜幡=玄奇防御（遮天伞/照妖镜/万魂幡）；鞭锏尺=灵活审判（打神鞭/量天尺）。
- 品阶映射：凡兵单材质+形态（铁剑）；黄阶材质+意象+形态（玄铁剑）；玄阶属性+意象（寒月剑/紫电枪）；地阶功能前缀（斩妖剑/诛魔刀）；天阶四字复合（九霄凤鸣剑/七星龙渊刀）；神阶传说四字（混沌开天斧/鸿蒙量天尺/太初镇世塔）。字数校验：凡兵≤4 字、黄阶 4-6、玄阶 4-8、地阶 6-10、天阶 8-12。

### 命4｜名字即线索（规则四十一）
- R33-04 丹药/功法/兵器的名字必须与实际功能存在至少一个词的直接关联：「九转还魂丹」必有效果=还魂/续命；「焚天诀」必有属性=火系/高温；「斩妖剑」必有功能=对妖加成。禁止名字与功能完全无关（如「九转还魂丹」实际是加力量）——违者判定「命名欺诈」。
- 执行：提取命名核心词（还魂/焚天/斩妖）对照实际功能描述；无重合语义则强制改名或改功能。

### 命5｜品阶与字数暗示（规则四十二）
- R33-05 字数越短品阶越低、字数越长品阶越高（铁剑<玄铁剑<九霄凤鸣剑）。映射表：凡品 2-4 字、黄品 4-6、玄品 4-8、地品 6-10、天品 8-12、神品 10+。
- 例外：极短名配极高品阶（翻天印地阶 3 字、诛仙剑天阶 3 字）可制造反差压迫感，但**每部小说最多使用 3 次**，否则削弱效果。
- 执行：命名后检查字数是否落在品阶建议区间；不符合且非「极简神兵」例外（≤3 次）则强制调整。

## 公式与结构模板

### AI 命名执行步骤
丹药：定品阶 → 选 1-2 个功效词 → ≥玄品加数词前缀 → ≥地品加属性前缀 → ≥天品加传说前缀 → 后缀统一丹/丸/散/膏/液/露/玉/髓。
功法：定品阶 → 选句式 → 抽属性前缀 → 抽核心动词 → 抽类别后缀 → 检查通顺与含义重复。
兵器：定品阶与类型 → 抽 1-2 个材质/属性/功能前缀 → 抽本体意象词 → 后缀统一为类型名 → 检查读音顺口与字数。

### 命名自检清单（嵌入 Skill）
丹药类：名字匹配品阶（字数/前缀特征）？含数词+动词+名词结构或变形？品阶与功效匹配（九转配还魂而非止血）？
功法类：名字匹配品阶？属三种句式之一？属性前缀与动作核心逻辑自洽（寒冰配凝而非焚）？
兵器类：名字匹配品阶？前缀与核心意象搭配（九幽配镇魂而非凤鸣）？后缀与类型一致（剑不后缀印、鼎不后缀剑）？

## 禁忌与反例
- 禁：命名欺诈（九转还魂丹实际加力量）。
- 禁：品阶字数错位且非刻意例外（凡品丹叫九转太乙还魂丹）。
- 禁：属性矛盾（寒冰诀配焚天效果、九幽前缀配凤鸣意象）。
- 禁：后缀与类型错位（剑后缀印、鼎后缀剑）。
- 禁：例外滥用（极简神兵超 3 次）。
