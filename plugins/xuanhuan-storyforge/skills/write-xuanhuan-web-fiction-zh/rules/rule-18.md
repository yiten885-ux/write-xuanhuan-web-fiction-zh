# Report 18 规则蒸馏

## 报告主题
章末八型详解：八种钩子"嘴巴形状"总表、逐型拆解（何时用/公式/下章怎么接/什么算写废）、同一场退婚的八张嘴对照、选用规则与废钩速查表。

## 硬规则

### 总表与总纲
- R18-01 章末八型是钩子的嘴巴形状：同一条链上的债，用不同方式卡住；八型轮换针对的是嘴巴，指纹物和主问句不变；连续三章同一张嘴，读者会麻。
- R18-02 八型总表：1动作截断（卡住"动作没做完"，读者要下一帧，优先级高）；2危机突袭（卡住"刚赢又来更大的"，读者要新压迫落地，优先级最高）；3半揭（卡住"物证亮了定义没喊完"，读者要那一声喊完，优先级高）；4反转揭秘（卡住"整章预判被最后一行翻掉"，读者要余震+桌子怎么改，优先级中，必须有齿）；5倒计时（卡住"时限被按下去"，读者要抢不抢得及，优先级高）；6新债（卡住"更高层看见了"，读者要上报的后果，优先级高，打脸后首选）；7机遇/灰行（卡住"新权限/新门开了一缝"，读者要用还是踩坑，优先级中）；8信息遮断（卡住"他知道了不能说"，读者要代价是什么，优先级低，纯爽少用）。
- R18-03 一章只准一张嘴：半揭完又天劫又灰行，读者不知道追哪条。
- R18-04 钩在最后100-200字，钩后不准再解释。
- R18-05 遮断整卷≤1次，插在"印认得但不能说"。
- R18-06 链上推荐顺序（黄金三章+单元）：Ch1倒计时、Ch2危机或截断、Ch3半揭、Ch4新债、Ch5灰行（压力下的选择）、单元末反转（齿够了才准用）。

### 逐型硬规则
- R18-07 动作截断：何时用=打、抢、推门、画押（本章兑现已经给过一角，或本就是"抢"的章，主线强钩）；公式=动作进行到不可逆的前一帧+感官具体（刀锋/门把/笔尖）+破折号或句号打住；禁止补心理"他心中一凛"；下章第1句=笔尖下一帧（墨渗开/被另一只手按住/名册被抽走）；废法=切在"于是他决定去抢名册"（这是计划不是动作）、切完再写三句气氛。
- R18-08 危机突袭：何时用=打脸单元中段、刚小赢、需要把场子抬高；不要用在第1章开场（开场该当众落地，不是赢完）；公式=本章兑现收口（一句话）+新压迫进画面（眼、剑、人、铃）+新压迫必须比刚解决的高一档；下章第1句=剑到、挡、或名册被第三只手按住，新压迫必须真出手，不能只"看着"；废法=天边打雷、莫名心悸、配角说"有大事"（新压迫必须有脸、有标的）。
- R18-09 半揭：何时用=掉马章、L2/L3亮齿、黄金第3章（读者已有错误信念可折）；公式=物证先于口（令/印/名册）+别人开口喊到关键词+被门/剑/铃打断；主角自己报身份=最弱半揭；下章第1句=把称呼喊完，或撞门的人把称呼抢了（加码：来的比供奉更大）；废法="他的身份即将揭晓"（没有物证的半揭是预告）、一口气把供奉+私生子+仙帝揭完（是全揭，透支链）。
- R18-10 反转揭秘：何时用=内鬼、真凶、名册其实勾的是执事自己、婚书背面才是真契约；前文至少3齿；一卷里这种强嘴不要超过2次；公式=本章按信念A走完+最后一行物证=B+B必须改桌子上的标的；没有齿=不准用这一型；下章第1句=余震（谁改的、堂上怎么乱、陆沉仍不解释）+立刻改局面（除名作废/公证反套）；废法="原来师父是仇人"前文0齿、反转后名册不变只是大家吃惊。
- R18-11 倒计时：何时用=第1章、抢资格、退婚、大比前夜；和动作截断很配，但倒计时的钩是钟本身不是刀；公式=具体时限（一炷香/三日/开钟）+手续动作（按香、敲铃、贴告示）+时限到了会丢的标的已写明；下章第1句=香还在燃，他做了什么（按印、抢笔、把门反锁），必须看见时限还在走；废法="时间不多了"（无手续无数字）、连续三章都"还剩最后一天"却不缩短（钟是假的）。
- R18-12 新债：何时用=打脸章首选；护体裂了不要断，余波写完让更高的人站起来再断；也是钩链"欠债人升级"的标准嘴；公式=本章释放已入账+见证者等级>被打者+他看见的是物证（印/令）不是惨状+他有动作（放下茶、站起、开口要人）；下章第1句=他开口要的不是解释，是"跟我走"/"把名籍拿来"；废法="此事惊动了高层"（无脸）、断在跟班倒地（那是兑现点不是钩）、更高层看完夸一句走了（债没欠上）。
- R18-13 机遇/灰行：何时用=隐藏层节点前、小赢之后需要齿、过渡章的中小钩；黄金第1章可用（权限未授权）；不要当单元末唯一的强钩；公式=可见的新缝（灰行两字/门缝/碎片）+不解释规则+立刻有使用压力（不用会亏，用了有代价）；禁止"恭喜宿主解锁隐藏功能"+说明书；下章第1句=剑到，灰行仍不解释，他按还是不按必须当章选；废法=灰行亮了然后回房研究一章（机遇没有倒计时压力=软钩）、把L3规则写完（是揭层不是钩）。
- R18-14 信息遮断：何时用=悬疑、权谋、婚书背面的印他认得；纯打脸爽文少用；用了必须跟着代价（说出会死/会暴露/会让公证崩）；公式=他得到信息（看见印、听见一句）+明确不能说的理由绑定命运+不写信息内容；下章第1句=先落地"不说"的代价（有人逼问、公证要他开口、灰行警告），不要下章第一句就把印的含义讲完；废法="他终于知道了真相"（真相跟命运无关）、下一章开头把真相倒完、连续用这一型（像作者在装神）。

### 选用与轮换
- R18-15 选用规则（写章末前判一次）：本章刚打完脸→6新债（不要断在倒地）；正在抢/打/画押→1截断；刚小赢需要抬场→2危机；要掉马只露齿→3半揭；时限是标的的一部分→5倒计时；隐藏层该亮缝→7灰行；3齿已齐且要改名册→4反转；知道了说出会毁公证→8遮断；以上都不像→检查本章有没有硬标的，没有就先补冲突，不要硬安钩。
- R18-16 轮换规则：连续3章禁止同型；强嘴（1/3/4）每2-3章一发；过渡章用5或7。

## 公式与结构模板
- 对照：同一场退婚，八张嘴（指纹物都是婚书，主问：谁有权定义他）——1截断="他把两半婚书按回原缝，执事抢笔的手已经抓住他的腕"；2危机="跟班护体裂了。门槛外，陈青的剑穗扫过青石。"；3半揭="青令放下。见过——"门撞开。"；4反转="名册转过来。勾掉的是执事自己的名字。"；5倒计时="香按进炉。'一炷香。燃尽作废。'"；6新债="茶杯放下的人站起来，盯着袖口那道印。"；7灰行="灰行亮：未授权。香还在燃。"；8遮断="灰烬里的印他认得。堂上这句话不能说。"
- 可贴Prompt的短表：章末八型=1截断/2危机/3半揭/4反转/5倒计时/6新债/7灰行/8遮断；选用=打脸后用6、抢着用1、小赢抬场用2、掉马用3、时限用5、隐藏层用7、3齿齐才用4、说出会毁局才用8；一章一张嘴；连续3章禁止同型；钩在最后100-200字，断在动作，下章第1句接下一帧；4必须有齿；6不要断在倒地；7禁止说明书；8整卷≤1。

## 禁忌与反例
- 废钩速查（病→哪一型最容易犯→改法）：计划当动作（1）→写成手已经碰到；无脸危机（2）→给名字、给剑、给标的；自己报身份（3）→物证+别人开口+打断；0齿反转（4）→改2或6，齿齐再用；假钟（5）→手续+数字，下章必须看见在走；断在倒地（6）→余波写完，更高层站起来；说明书（7）→只亮两字，当章逼他选；装神（8）→绑代价，下章先付代价再揭。
- 锁死段（可贴System Prompt）：嘴巴可以换，桌上的婚书不能换。选哪一张嘴，看本章停在动作、钟、物证、更高层，还是一句不能说的话；下一章第一句只接这一帧。
