# Report 39 规则蒸馏

## 报告主题
女频玄幻爽点大全（第九轮补充）：女频与男频爽点底层逻辑对照、通用三段式公式（压抑+蓄势+释放）与打脸四拍、七类 16 个女频爽点（废柴逆袭/马甲掉马/打脸虐渣/情感/身份反转/团宠/实力碾压）逐点公式与硬规则、全局规则 66-69（类型轮换/打脸体面三不/情感占比 6:4/压抑-释放周期）。

## 硬规则

### 女1｜女频爽点类型轮换（规则六十六）
- R39-01 连续 3 章内不得使用同一种女频爽点类型超过 2 次（废柴逆袭/马甲掉马/打脸虐渣/情感爽点/身份反转/团宠/实力碾压七类轮换）；连续 3 章同类型 ≥2 次触发「爽点疲劳」，强制轮换。

### 女2｜女频打脸体面三不（规则六十七）
- R39-02 女频打脸必须满足三不：不脏手（女主亲自出手但姿态优雅，禁止泼妇骂街）；不掉价（不打低级的脸）；不解气不罢休（打完要让读者长出一口气，对方必须「彻底社死」而非「有点尴尬」）。
- R39-03 禁止打脸后没有旁观者反应。

### 女3｜女频情感占比（规则六十八）
- R39-04 女频玄幻中实力爽点与情感爽点比例 = 6:4（实力线六成，情感线四成）。
- R39-05 每 3 章内必须至少出现一次情感类爽点（被偏爱/修罗场/双向奔赴），否则判定「感情线缺失」。
- 注：与男频智武配比 7:2:1（R28-02）分频适用——男频走 7:2:1，女频走 6:4。

### 女4｜压抑-释放周期（规则六十九）
- R39-06 番茄/快节奏女频：压抑 1-2 章内必须释放；起点/长线女频：可铺 3-5 章再释放。
- R39-07 无论哪种，压抑必须有具体的不公/嘲讽/危机，越具体释放越爽。

### 女5-女20｜七类 16 爽点逐点规则（要点精要，全文见 references/female-frequency-satisfaction.md）

- 女5 废柴觉醒（爽点1）：嘲讽必须公开（宗门大会/家族宴/演武场）；觉醒有感官化异象（光柱冲天/古碑碎裂，不只是境界提升）；嘲讽者有打脸台词回收（你说谁是废物）。
- 女6 被夺逆塑（爽点2）：被夺过程写生理痛感（灵根抽离剧痛/经脉灼烧）；重塑有代价；回归时让夺她之人亲手感受「我夺走的东西变得更强了」的绝望。
- 女7 层层掉马（爽点3）：马甲至少三层（身份伪装/技能隐藏/终极身份）；每次掉马前有信息差（读者知道剧中人不知道）；掉马有震惊反应链（≥3 个不同角色：路人→配角→大人物）。
- 女8 她就是背景（爽点4）：前期女主主动不解释（沉默是金）；揭露时有物证（令牌/信物/大佬当众行礼）。
- 女9 揭穿白莲（爽点5）：诬陷必须具体；反杀有铁证（留影石/书信/证人）；打脸体面——姿态优雅不骂街。
- 女10 渣男回头（爽点6）：回头必须有具体利益动机（女主变强/有新靠山）；拒绝公开（在渣男最在乎的场合）；拒绝台词扎心（当初配不上现在更配不上）。
- 女11 退婚逆袭（爽点7）：退婚场景公开+羞辱（婚书被扔/休书宣读）；逆袭后有前未婚夫视角的后悔描写（指甲掐进掌心）；拒绝后新追求者登场对比碾压。
- 女12 独一份偏爱（爽点8）：偏爱有具体行动（挡刀/公开宣言/放弃利益）；偏爱独一份（对别人冷漠只对她特殊）；偏爱场景有旁观者（从不低头的男人为她跪下）。
- 女13 修罗场（爽点9）：竞争男性各有特色（高冷/温柔/霸道/忠犬）；不喧宾夺主（女主核心男人是配菜）；女主被追求但未回应的克制。
- 女14 双向救赎（爽点10）：男主真香有过程（不能一章爱上）；动心标志动作有反差（高冷者做低姿态事）；必须有男主视角内心活动（读者知道女主不知道）。
- 女15 身世曝光（爽点11）：曝光有物证（胎记/信物/血脉异象）；有当初欺负她的人的反应特写（她居然是……我当初还打过她）；曝光后女主态度淡然（从不需要身份证明自己）。
- 女16 穿书改命（爽点12）：明确写出原本命运（原书怎么死/被虐）；改变有蝴蝶效应（小事连锁反应）；有一场与原著剧情的对决（避开原情节，原恶人自己踩坑）。
- 女17 全员团宠（爽点13）：团宠有层级（哥哥→父亲→爷爷→全族→全宗）；宠法各不同（资源/撑腰/陪伴）；有外人视角（不理解为什么都宠她，然后发现她值得）。
- 女18 大佬收徒（爽点14）：收徒有理由（女主做了让大佬欣赏的事）；场景有旁观者震惊（≥3 个）；收徒后有资源兑现（功法/法宝/令牌）。
- 女19 越级反杀（爽点15）：越级有合理解释（提前布局/利用弱点/消耗宝物）；反杀后付出代价（受伤/消耗）；有旁观者分析（她提前布置了三天）。
- 女20 拿下第一（爽点16）：不看好有具体表现（赔率/赌局/公开嘲讽）；夺冠有反转（先落后再反超或一路碾压）；夺冠后有押她输的人的反应（输灵石/输面子）。

## 公式与结构模板

### 通用三段式（所有女频爽点共用）
爽点 = 压抑（把不公/嘲讽/危机写具体）+ 蓄势（隐忍/布局/觉醒）+ 释放（打脸/翻盘/碾压）。
打脸四拍（释放阶段标准结构）：①嘲讽（反派越嚣张越好）→②沉默（主角不辩解淡淡出手）→③碾压（实力/真相/反转一击致命）→④围观（旁观者震惊反应——最容易被忽略但最爽）。
爽点升级铁律：同一爽点不能原地重复，必须升级对象/规模/方式：打脸同窗→打脸长辈→打脸宗门→打脸天才→打脸大势力→打脸天道。

### 男频 vs 女频底层逻辑对照
| 维度 | 男频 | 女频 |
|---|---|---|
| 底层爽点 | 实力升级/打脸/地位攀升 | 情感拉扯+独一份偏爱+自我成长+仇人报应 |
| 代入方式 | 成为强者（向上） | 被珍视/掌控全局（向内或俯视） |
| 主线 | 世界线推进（弱小→登顶） | 人际关系线（CP 磨合/误会反转/双向奔赴） |
| 金手指 | 硬外挂（系统/功法/空间） | 软外挂（身份/重生/读心/空间） |
| 打脸风格 | 实力碾压/越级挑战 | 让瞧不起我的人后悔/体面解气/不掉价 |
| 结局诉求 | 站上巅峰 | 圆满的爱+体面的赢 |

女频铁律：情感线是主菜，实力线是配菜；「被偏爱」和「掌控感」是核心爽点；打脸要体面、解气、不掉价。

### 爽点烈度公式
S = 压抑具体度(1-5) × 蓄势时长(1-3) × 释放围观人数(1-5)；S < 15 判「爽感不足」，加强压抑描写或追加围观反应。

## 禁忌与反例
- 禁：女频打脸像泼妇骂街、打完没旁观者、打脸太轻（对方只是尴尬）。
- 禁：偏爱只有甜言蜜语没有具体行动。
- 禁：男主真香一章速成、无反差标志动作。
- 禁：团宠无层级无差别宠法。
- 禁：越级反杀零代价零解释。
- 禁：压抑不具体（空喊被欺负）。
