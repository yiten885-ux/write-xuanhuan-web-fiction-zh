# Report 30 规则蒸馏

## 报告主题
拍卖合同（番茄玄幻爽文拍卖场）：拍卖不是「比谁钱多」，是当众用一件物把身份、财力、来历三根轴一起折断。拍1-拍14 十四条硬规则、四种主糖、七拍套餐与八个公式——T091 拍卖套餐的完整操作化。

## 硬规则

### 一、拍卖场四件事与主糖
- R30-01 一场拍卖只办四件事：①先按穷/假/没资格把他踩到席外；②拍品必须是硬标的（令、残谱、婚书、器胚、地契、仇家赃物）；③当众易手（认主飞来、一口价、主权亮出），数字或物可视化；④更高层进场（金主、刑堂、原物主、灭门令签发者）。缺第 1 场=炫富不打脸；缺第 3 场=嘴赢拍卖师没改口；缺第 4 场=拍完就散没有下一章。
- R30-12 一场拍卖一个主糖：穷样打脸 / 赝品变真 / 仇人拍到自家赃 / 认主，四选一当主，其余当辅，不要一场全做完。真香级（父母来加价求让）只能放余波。

### 二、流程与篇幅
- R30-02 必须当众，必须有拍卖师改口；私下成交不算拍卖戏。
- R30-03 先辱后拍：开场就要请出席、限资、当赝品、当杂役没号牌；羞辱落到资格和钱，不少于三句。
- R30-04 拍品绑定主线指纹物：他家的、仇人赃、灭门遗、能开本图门、能证身份；禁止拍无关灵药凑热闹。
- R30-05 穷要写实：破席、空牌、被搜身、灵石不够最低价；禁止开场掏仙帝卡；财力只升一档。
- R30-06 结算是物易手，不是报价演讲：认主、抽令、血契、拍卖锤落下改名；数字跳要看见（牌、榜、账）。
- R30-07 出价过程短：加价来回不超过三轮，第四轮起删，改成一口价或认主飞出；禁止二十轮报价注水。
- R30-08 男主少说话：一句出价或一声不吭亮物；禁止介绍拍品年代功用八百字（鉴宝课另场，拍卖场只验当场能验的一处）。
- R30-09 仇人必须有真好处才进来抢：要这件去办婚、去镇族、去灭口；不是来陪主角演戏。
- R30-10 通胀锁：本图拍卖只出本图能用的最高，禁止拍出仙帝本源。
- R30-13 智商配额：拍卖不是布局戏；点破最多一句（≤20 字，「这是陆家的印。」），两百字内锤落下或物飞到他手里；禁止心中计算全场谁在托价。
- R30-14 篇幅：番茄一场拍卖压进一章两千五，或两章（前章入席被辱+拍品亮相，本章易手+新债）；禁止三章围观。

### 三、武力与新债
- R30-11 禁止用钱解决武力：可以一口价压场，但若有人抢、有人灭口，仍要一招或一令，对照物碎；钱赢嘴，打赢抢。
- R30-10b 拍完必有新债：金主、刑堂、被拍破产的后台、拍品认主暴露的血脉；断在有人站起来要人/要物，不断在「他买到了」。

## 公式与结构模板

### 四种主糖
| 主糖 | 场上轴 | 折轴 | 可视化 |
|---|---|---|---|
| 穷样一口价 | 没资格、没钱 | 报一口或亮欠条/令抵价 | 账改、锤落 |
| 赝品变真 | 当假货赶人 | 当场一处对照（纹、年款、内印） | 拍卖师改鉴定 |
| 认主飞来 | 他不配碰 | 拍品自己飞、烫、认血 | 物在他手，抢的人空 |
| 仇人拍到自家赃 | 仇人出风头 | 物证来历对上灭门/盗案 | 仇人牌碎，刑堂起身 |

### 公式A：开场三辱
资格辱（没号牌/杂役席/请出去）、财力辱（最低价都没有/限资）、物辱（这件跟你这种人无关）；三辱都要碰到具体手续：撕号牌、拦门、当众宣读资产。

### 公式B：拍品卡（先填再写）
物的名字 / 它跟男主的关系（家物/血契/钥匙/赃）/ 仇人要它来干什么（婚、镇族、灭口）/ 当场能验的一处（印、纹、认主）/ 拍到谁手里会改哪条标的 / 拍完谁必须站起来。填不出「跟男主的关系」，换拍品。

### 公式C：七拍套餐（可压进一章）
①入席被拦或被请到穷席；②拍品亮相，仇人举牌装逼；③当众判他没资格/判假/限价；④他出手：一口价或亮主权或血滴认主（≤200字）；⑤拍卖师改口/锤落/物飞到他手；⑥仇人加价失败或拍到自家赃，牌碎；⑦金主或刑堂起身（钩，八型用新债或半揭）。第 4 拍是爆发，第 6 是余波，第 7 不断在倒地的仇人。

### 公式D：三轮加价封顶
轮1 仇人开价+羞辱 → 轮2 托儿或天才再压 → 轮3 男主一口价/认主/「这件不卖，是我的」；禁止轮4。一口价要有来源：令抵、欠条、真正物主权、本图能解释的一笔钱；禁止无底洞灵石。

### 公式E：认主写法
先被禁止碰 → 物自己动（飞、烫、鸣）→ 抢的人出手 → 短挡（一招或物反噬）→ 对照：抢的人护体/手套裂 → 拍卖师改「成交」为「归主」。认主不是温馨，是当众打资格的脸。

### 公式F：赃物反噬
仇人高价志在必得 → 锤将落 → 男主一句点破 ≤20 字（「印是陆家祠堂的。」）→ 全场验印 → 仇人不是买到了，是当众承认赃 → 刑堂/金主起身。点破后两百字内必须验印，不准开鉴定会。

### 公式G：章内比例（2000-2500 字）
前 40%：入席、三辱、拍品、仇人装逼（加压）；中 40%：三轮内易手（释放）；后 20%：改口、牌碎、更高层看见（余波+钩）。

### 公式H：和前后剧情咬合
上一场损失（婚书、令、矿契被夺）→ 本场拍品必须是那件或那件的钥匙；本场新债主语（金主/刑堂/原物主）→ 下一场对手；财力只 +1 档：杂役能亮一枚令，不能买下宗门。

## 禁忌与反例（写崩表）

| 病 | 改 |

| 二十轮报价 | 三轮封顶 |
| 拍无关神药 | 换指纹物 |
| 开场掏黑卡 | 先限资、先请出 |
| 鉴宝课 | 只验当场一处 |
| 钱解决一切打架 | 抢夺仍要对照物碎 |
| 拍完回房数宝 | 更高层起身 |
| 一场四主糖 | 只留一个主折轴 |

## 语言提示
对：号牌被撕。「杂役席没有出价权。」锤要落。陆沉把袖口那道印按上托盘。托盘自己烫了。拍卖师嗓子卡住。
错：在这金碧辉煌的拍卖行中，陆沉感到一种被轻视的怒火在胸中燃烧……
报价格只用短数字，不要写「整整三百万上品灵石啊」。数字出现一次，锤落一次。
