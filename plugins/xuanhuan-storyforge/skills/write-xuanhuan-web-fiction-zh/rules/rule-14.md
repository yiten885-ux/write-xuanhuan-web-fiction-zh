# Report 14 规则蒸馏

## 报告主题
爽文虐点：虐不是产品是燃料，虐点的三要素定性、12种常用虐点清单（分三档）、写作硬规则（N01-N14）与九套公式，以及假虐/毒虐对照表。

## 硬规则

### 定性
- R14-01 爽文虐点=已落地的不可逆损失+明确欠债人+可执行的讨债票，三件缺一不可：缺损失落地=软虐加压不够；缺欠债人=虐命运虐作者、读者恨书；缺讨债票=白挨、虐文或弃书。
- R14-02 爽文里的虐必须把刀抽出来砍到该还债的人身上：写完一场虐，必须能指出哪一章、砍谁、拿回什么；指不出来就是写成虐文了。
- R14-03 虐点不是独立剧情，是硬冲突的加压段存货（爽=压力积累×释放满足×反差程度；虐负责压力，反转打脸负责释放，金手指负责讨债手段）。

### 虐点清单（按"好换成爽"排序，男频番茄默认前6种当主力）
- R14-04 第一档（当场能兑，开局/每章都可用）：1.当众羞辱——面子被踩观众还在（退婚、点名、宴席骂废物），兑=同一批观众改口；2.剥夺——名额、丹药、婚书、房子、宗门籍，必须已经拿走不是威胁，兑=当众拿回来或拿走更贵的；3.规则不公——"杂役不可还口""庶女不入谱"，地图本身在打人，兑=规则反转套到对方头上；4.倒计时绝望——日落前滚、三日改嫁、开钟除名，兑=时限内反杀，最好提前当众完成。
- R14-05 第二档（能撑一个打脸单元5-8章）：5.退婚/替婚——归属+面子+资源一起掀，兑=后悔药分级、不复合；6.背叛——兄弟交情报、师兄抢机缘、未婚妻带路，硬条件：开局给过共享动机，否则像作者变脸，兑=清算不当场和解；7.努力作废——闭关成果被废丹、积分被改、功劳记在别人名下，兑=物证翻案+对方当众丢人；8.功为他人做嫁衣——主角挡灾/炼丹/破阵好处归天才，兑=下次让对方自己上当场翻车，或把契约锁回去。
- R14-06 第三档（一卷一把，慎用，兑得必须更狠）：9.亲情偏心——家族养嫡废庶、父母把主角当聘礼，男频不要写成哭戏，兑=断供、除名、把资源从家里搬空，主角不回头跪；10.牺牲不被看见——挡刀没人信、背锅洗不白，兑=解释权易手，靠结果不是靠哭诉；11.关键人物重伤/死——师父、引路人、唯一善待他的人，这是最险的刀，兑=仇必须具名、必须在本卷内第一次见血、禁止"先变强十年再报仇"；12.身份当货物——替嫁、联姻、炉鼎、祭品，人被标价，兑=婚书/契约/祭名单改写、定价的人破产。
- R14-07 男频默认删掉的三种：13误解虐（他不解释她误会，男频杀伐文里这是假冲突）、14虐恋拉扯（爱而不得）、15洗白虐（让读者心疼反派，男频会把打脸写软）。男频要用13，只能虐场上误解、读者已知，读者跟主角一起憋，不能跟主角一起傻。

### 写作硬规则 N01-N14
- R14-08 N01 先开讨债票，再下刀：写虐前必须能填欠债人、兑付章、拿回什么；填不出就不要虐。
- R14-09 N02 损失必须落地："小心我废了你"不是虐；丹砸了、籍除了、婚书撕了、人倒下了，才是虐。
- R14-10 N03 虐完当章至少兑一角：番茄=本章虐、本章最小翻盘（挡下致命、拿回信物、金手指亮齿）；禁止连续2章纯虐0兑。
- R14-11 N04 读者希望不能虐死：可以虐处境，禁止虐金手指报废、虐主角永久降智、虐到读者觉得"这书没盼头"；信息前置那颗齿必须留着。
- R14-12 N05 不虐主角智商：能躲不躲、能说死不解释还导致误伤无辜、明知是局还送人头——读者虐的是作者。
- R14-13 N06 不虐主角人设：杀伐被虐完变跪舔，装逼被虐完变哭包；虐的是局面，不是性格。
- R14-14 N07 欠债人必须具名、必须有脸：虐天道、虐命运、虐"大环境"，读者无处出气；刀要砍在具体人/具体规则上。
- R14-15 N08 亲情刀在男频兑成断，不兑成跪：父母偏心→主角断供离开、把账算清；禁止哭回家族、禁止"他们是我爸妈"。
- R14-16 N09 死人刀必须本卷见血：师父死于第8章，仇人最晚第30章必须付出不可逆代价（废、死、夺权）；拖过一卷，刀就臭了。
- R14-17 N10 一把刀只砍一次完整形状：同一句废物、同一套退婚羞辱、同一个哥哥抢功，最多一个单元；下一刀升级标的。
- R14-18 N11 虐的观众比对手高：没更高见证者，余震和上报都没有，这刀兑不干净。
- R14-19 N12 禁止用虐拖字数：内伤描写、夜哭、回忆童年，单段≤200字；情绪用动作：手、停顿、把东西放下。
- R14-20 N13 比例锁：章内加压≤60%，必须留30%给兑现；单元（5-8章）虐:兑≈1:1，不是5:1；卷可以有一次第三档大刀，但必须配一次破规则级释放。
- R14-21 N14 刀口对准"他以为自己赢了"：最好的虐是对方得手的那一瞬（名额改了、婚书撕了、丹碎了）；读者恨的是那张脸，不是天气。

## 公式与结构模板
- 公式1 虐点总公式：虐=落地损失×当众×倒计时×欠债人清晰度；兑=同一观众+原句奉还或加一级剥夺+新债；虐完不兑，分母是0。
- 公式2 虐点卡（下刀前填）：这刀类型（1-12选）；落地损失（已经发生）；欠债人（姓名/身份/他图什么）；观众（含更高层）；倒计时；主角态度动作（不解释、不跪）；当章最小兑（哪一角）；单元兑（第几章、拿回什么）；卷兑（如需）；下一刀禁止重复的形状。
- 公式3 先虐后爽四拍（章级）：拍1得手（对方把标的拿走，虐落地）→拍2加码（再当众踩一脚/倒计时缩短）→拍3齿（金手指或身份露一角，读者有盼）→拍4兑一角（挡致命/改回一个数字/跟班裂开）；章末=新债（更高层看见或对方新婚期）。拍3不能省——没有齿的纯虐，免费读者第二轮就不跟了。
- 公式4 讨债票：欠条=【谁】在【场合】拿走了【什么】，说了【原句】；兑付=在【同一或更高场合】用【物证/一招/规则】让他失去【原物或+1级】；奉还=把原句还回去，然后离场；禁止教育、原谅、把东西还他以德报怨。
- 公式5 虐点升级（防复读）：同一仇链往上走，不要换沙包：跟班羞辱→执事剥夺→真传退婚→长老动规则→家族除名；损失：面子→名额→归属→本图资格→血脉/供奉；每一级的兑，必须让上一层的人看见自己算错。
- 公式6 死人刀（第三档）：死者必须给过主角不可替代的一样东西（名额、功法齿、一句人话）；死因必须是具名仇人的选择，不是天灾；主角反应短、动作化（收遗物、把灯吹了、去排队），禁止哭章；第一次讨债本卷内必须见血或废；余债可以留到下图，但本卷不能0兑。
- 公式7 亲情刀（男频）：偏心必须有账本（钱、丹、名额、婚约，写成数字）；主角不辩论谁亲；当章动作=把账本合上/把钥匙放下/把宗门籍自己划掉；兑=资源搬空或关系断干净；禁止年夜饭感化、临终和解当高潮。
- 公式7b 背叛刀：开局一条共享动机（家族/活命/任务）；3齿（反常的手、晚到的援、一句当时不像反话）；揭晓卡在"刚为他拼命"之后；兑=清算资源与解释权，不听理由；理由可以有，给读者看，不给主角改决定。
- 公式8 密度：每章1个第一档虐（羞辱/剥夺）+当章最小兑；每5-8章1个第二档虐单元闭环；每卷最多1个第三档大刀且必须配破规则释放；禁止连续2章0兑现；禁止开局10章只虐不亮金手指。番茄读者忍虐的窗口很短，飞卢更短，起点可以多压几章但爆发必须更狠。
- 公式9 虐的写法（怎么写惨又不写成哭戏）：只写物件和手续（婚书两半、名册一笔墨、丹粉在地上、灯灭）；羞辱台词≥3句，具体到身份和资源；主角写手、走位、把东西放回桌上；内心OS≤3行；旁人反应1-2个，留一个更高层给余震；惨在手续里，不在形容词里。

## 禁忌与反例
- 假虐/毒虐对照（病→改法）：软虐（只威胁不落地）→先撕婚书、先划名册；无债主（天灾、病、命运）→换成具体人的选择；白挨（虐完修炼一章）→当章最小兑；虐智商（主角犯贱送人头）→隐忍必须有收益（燃料/不暴露）；虐人设（杀伐变跪舔）→只虐局面；哭章（回忆童年800字）→砍到物件手续；亲情跪（打完回家认爹）→断、搬空；刀臭（师父死了200章才报仇）→本卷见血；复读（每章同一句废物）→升级标的；虐读者希望（金手指被废死）→齿必须留下；女频刀硬塞男频（误会不解释、虐恋）→改成当众剥夺。
- 一段对照：软虐="未婚妻瞧不起他，他很受伤，夜里失眠，想起童年被骂废物，发誓要变强"；硬虐（可兑）="婚书两半落在青石上；聘礼单被执事卷走；苏绾说'炼气三层也配写进苏家谱'，三日后另嫁内门第一人；名分当场没了。陆沉把两半对上、叠好、放回去，问聘礼今晚送还是他去取；跟班护体应声裂开——最小兑；回廊茶杯放下——讨债票已经开给更高层"。虐在：婚书、聘礼、三日、原句；兑在：裂开的护体；债在：放下的茶杯；没有失眠，没有童年。
- 锁死段（可贴System Prompt）：爽文虐=落地损失+具名欠债人+讨债票，缺一不准下刀；本章虐必须本章最小兑，禁止连续2章纯虐；不虐主角智商、不虐人设、不虐金手指报废，读者希望必须留齿；亲情刀兑成断不兑成跪；死人刀本卷见血；背叛开局就要有共享动机；虐写物件和手续，不写哭和回忆；羞辱≥3句，OS≤3行；一把刀只砍一次完整形状，下一刀升级标的；每卷第二档大刀<1必须配破规则级释放。
