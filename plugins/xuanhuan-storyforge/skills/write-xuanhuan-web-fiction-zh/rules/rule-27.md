# Report 27 规则蒸馏

## 报告主题
96 套路全文（T001-T096）：每条的硬规则 + 写作公式 + 验收标准，分九批（开局/打脸/身份/资源/关系/复仇/规则/金手指/场面套餐），并附通用前置、总约束与套餐硬规则。

## 硬规则（全局/跨套路）
- R27-01 必须当众：每个套路的核心事件必须有观众，没有观众就没有余震。
- R27-02 损失先落地：主角的损失/羞辱必须先写出可观察结果，再谈反击。
- R27-03 爆发不超过两百字；必须带对照物（护体裂、榜改字、印烫上、数字跳）。
- R27-04 收获必须能看见：名册、令、数字、护体碎等可视化结果。
- R27-05 只比场上预期高一档；多出的那一档只露齿，不一次揭完。
- R27-06 主角不解释、不圣母、不复合；用手续和物证说话，不演讲。
- R27-07 本章改完桌子（标的易手），章末把更高层送进画面；下章第一句接这一帧。
- R27-08 救美、双修、收徒、真香一律不得改成主线感情戏。
- R27-09 灭门、除名、退婚必须写成画过押的手续（划谱、点火、收令），不许只写心情。
- R27-10 羞辱落到身份和资源，至少三句具体的。
- R27-11 一章最多两个套路（PRIMARY_T + 可选 SUB_T），禁止超过两个；禁止一次吞 96 条。
- R27-12 撞 BAN 或全局 S/F/V = 废章重写（S/F/V 语义原文未给出，待补）。
- R27-13 先填套路卡再写正文；禁止跳过套路卡直接写正文。
- R27-14 T001 救美锁死为辅线：可发生、只作证人物证；禁止当主糖、禁止性过程。
- R27-15 T002 退婚开局：婚书、聘礼、三日期限三件必须上桌；羞辱不少于三句；禁止第三章对方跪完复合。
- R27-16 T051 真香必须对得上退婚原句，分级（跟班→本人→父母→新靠山→解释权易手），一级一次，禁止一天五级。
- R27-17 套餐（T089-T096）按顺序拍，不许打乱成流水账；每一拍都有物在桌上；全程不超过一单元五到八章（番茄可压进三到五章）。

## 公式与结构模板
- 套路通用公式：当众 → 损失先落地 → 爆发≤200字（对照物碎）→ 收获可视化 → 高一档露齿 → 章末更高层进场。
- 验收标准：每条套路必须写清可核验的验收点（如 T002 验收：婚约在律上是否真废，必须留下缺口——缺押、未公证）。

## 禁忌与反例
- 禁止写性过程（双修/炉鼎/洞房一律功法/手续化）。
- 禁止复合、禁止圣母、禁止为了感情线放过主仇。
- 禁止回房慢慢养伤/翻译/鉴定十章（当章必须用出一招或改一寸）。
- 禁止无对照物的越级（越一级、不越五级；无对照则重写）。
- 禁止把 96 条全文一次塞进上下文（必须最小加载）。
