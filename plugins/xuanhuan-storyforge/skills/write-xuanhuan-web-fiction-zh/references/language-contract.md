# 爆款语言合同（白 · 短 · 冲 · 有物）

> 来源：pasted_text_20260827-063637（report 29）。配套溯源：rules/rule-29.md。本文件是番茄玄幻爽文的写作语言合同，写任何正文前/后都要过一遍；与 references/language 指纹病表配套使用。

## 适用范围

写、改、审玄幻爽文正文时的语言层闸门。爆款语言不是文笔好，是**滑得动**：短、白、硬、有物、有嘴。模型默认会写成「工整、抒情、总结、排比」——那是作文，不是番茄。

## 总标准

```text
能看见手和物 > 能听见谁在说话 > 能感到情绪
禁止：作者替读者总结该怎么爽
```

爆款语言五字诀：
- **白。** 常用词，少成语堆、少比喻。婚书、香、令、护体纹、青石，不写「命运的齿轮」。
- **短。** 一句一事，句号密；怒打、抢、验用短句，只有规则宣读才允许稍长。
- **冲。** 动词领头：撕、按、抽、烫、裂、放下。少「进行、开始、显得、令人」。
- **硬。** 具体：炼气三层、一炷香、末押、护体纹裂到喉；不写「极强的压迫感」。
- **分人。** 遮住名字还能听出谁在说话：杀伐主角短；反派羞辱密而具体；系统可以贱。

节奏感：短短短。一句稍长把物放上桌。再短。对话顶上来。爆款读感像刀，不像散文。

## 硬规则总表（语1-语15，R29 全量）

- 语1 一句一事：一句里禁止又羞辱又回忆又报境界，拆开。
- 语2 叙述句默认不超过二十字；超过必须是对话或规则原文。
- 语3 动词开头或人名开头；禁止「在这充满压迫的气氛中」。
- 语4 每 200 字必须出现一件物或一个数字；没有物的 200 字当水删。
- 语5 对话占比不少于四成，对话要办事（羞辱、报价、宣律、喊名、点破一句）；禁止用对话讲体系课。
- 语6 心理不超过两成，单次不超过三句；能改动作必须改动作。
- 语7 禁止作者总结（「他不知道」「这意味着」「正是此时」「命运开始」），章末尤其禁。
- 语8 禁用词出现即替换，当章作废级（见禁用词表）。
- 语9 同一段禁止三句同结构；改成动作/对话/别人的反应。
- 语10 比喻每章最多一处且必须落到物上。
- 语11 连续两个四字成语就改口语；反派可偶用四字装逼，主角少用。
- 语12 句号问号为主，感叹号每章≤5；省略号只留给半揭被打断。
- 语13 称呼口吻锁死：主角不解释、不喊口号；反派羞辱落到身份+资源，禁止空骂废物连发。
- 语14 系统面板可以短、可以贱，角色嘴里禁止系统腔。
- 语15 去翻译腔：禁止「他感到一种……」「一种名为……的情绪」「他意识到他必须」。

## 语言指纹病表（出现就改）

| 病 | 样子 | 改成 |
|---|---|---|
| 排比三连 | 他不哭，不辩，不求 | 只留一个动作 |
| 情绪标签 | 心中一凛、微微一怔、不禁 | 手碰到什么 |
| 空气文学 | 空气仿佛凝固、时光静止 | 茶盏放下、全场没人出声 |
| 总结句 | 这意味着更大的风暴 | 删，写门开了谁进来 |
| 对仗工整 | 不是废物，而是王者 | 令放下。有人喊见过 |
| 成语串 | 趾高气扬、目中无人 | 一句具体羞辱 |
| 全员一书 | 长老也说「不过如此」 | 分人口吻 |
| 心理大会 | 连续内心超过三句 | 改成看、拿、放 |
| 副词堆 | 缓缓、微微、深深 | 删副词，留动词 |
| 翻译腔 | 他意识到他必须 | 他按住印 |

## 禁用词 / 慎用词（直接贴进提示词）

**禁用（出现就改）：** 不禁、微微、缓缓、一丝、仿佛、宛如、如同、心中一凛、眼神一凝、空气凝固、时光静止、与此同时、这意味着、不仅仅、而是、正是、在这一刻、命运、齿轮、篇章、画上句点、深深地、令人、显得、进行、开始感到、他意识到、不由得、嘴角微扬、目瞪口呆、倒吸一口凉气（每章最多一次）、暴风雨前的宁静、更大的风暴还在后面。

**慎用（每章各最多一次）：** 冷哼、淡淡道、不屑、嗤笑、目光如炬、杀意、霸气、傲然。

**主角禁口号：** 天不生我、问剑、我命由我、不过如此（他自己说）、你们都得死（空喊）。杀伐用动作：收聘礼单、把香按进炉、一招、走。

## 语言公式（A-H）

- **公式A 白描替换**：情绪词 → 手 + 物 + 一下。「愤怒」→ 他把两半婚书叠齐，压回石桌；「紧张」→ 香灰掉在他袖口上，他没弹；「震惊」（别人）→「他是炼气？」
- **公式B 句长谱**（一段四到六句）：短（≤8字）。短。中（15~25字，放入物或数字）。对话。短。例：执事收走聘礼单。苏绾笑。「炼气三层，也配写进苏家谱？」陆沉把两半叠好。「今晚送，还是我去取。」
- **公式C 信息从嘴里出，规则从手上出**：羞辱、报价、点名 → 对话；盖印、抽令、裂护体 → 叙述动作；体系、历史禁止专段。
- **公式D 三人三嘴**：主角短、问手续、不解释；对手长、具体羞辱（身份+资源+时限）；旁观一句数字或「他是……？」。三人同腔=废对话。
- **公式E 打戏语言**：报数字 → 一招（一个动词+碰到哪）→ 对照物碎 → 一句改口。禁止招式名连喊、内力跑八百字。
- **公式F 章首章末**：章首第一句动作下一帧，禁天气；章末最后一句未完成动作，禁总结。
- **公式G 去 AI 味五刀**：①删「不禁、仿佛、这意味着、在这一刻」；②连续排比留一句；③心理改手；④每 200 字补物或数字；⑤章末像预告片旁白 → 改成门、香、印、剑。
- **公式H 对照改写**：「在这充满嘲讽的议事堂中……空气仿佛凝固了」→「婚书两半落在青石上。苏绾：『炼气三层，也配写进苏家谱？』陆沉把两半叠好，放回桌上。『聘礼单。今晚送，还是我去取。』」

## 稳定产出方法

单靠「写得像爽文」无效。要**样例 + 禁用表 + 句长谱 + 写完五刀**：System 里锁白短冲、一句一事、对话四成、禁用表、章首章末；用户消息塞 50-100 字本章口吻样例（模仿句长用词，不模仿情节）；输出顺序先章纲再正文；正文后强制跑公式G五刀，有禁用词改完再交。抽检指令：「遮住人名，三人说话能否分开」「任意连续 200 字有没有物或数字」。润色方向写死：**只删不添，只改动作，不升格比喻。**

## System 锁死段（可直接贴进提示词）

```text
语言合同（番茄玄幻爽文）：
白、短、冲、有物。一句一事。叙述句默认不超过二十字。每两百字必须出现物或数字。对话不少于四成，对话只办事：羞辱、报价、宣律、喊名、一句点破。心理≤两成，单次≤三句，能改动作必须改动作。
动词领头。禁止作者总结、禁止空气凝固、禁止命运齿轮、禁止事后「这意味着」。章首第一句接动作，章末最后一句未完成动作。
禁用：不禁、微微、缓缓、一丝、仿佛、宛如、心中一凛、眼神一凝、与此同时、不仅仅、而是、在这一刻、令人、显得、他意识到、更大的风暴。出现即替换后再交稿。
一段内禁止三句同结构。比喻每章最多一处且必须落到物。感叹号每章≤5。主角不喊口号，杀伐用收、按、抽、烫、走。
三人三嘴：主角短、对手羞辱具体、旁观喊数字。系统腔只进面板，不进角色嘴。
写完五刀：删禁用词；砍排比；心理改手；补物；章末改成门香印剑。
润色只准更短更硬，不准更美。
```

一句话总纲：**让读者看见手上的婚书和裂开的护体，听见三句不一样的嘴；句子短，物在场，怒不写出来。模型每想写「仿佛、不禁、这意味着」，就改成一个动词碰到一件东西。**
