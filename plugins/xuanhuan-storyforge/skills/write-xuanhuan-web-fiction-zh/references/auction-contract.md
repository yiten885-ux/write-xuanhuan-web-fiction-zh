# 拍卖合同（当众折断三根轴）

> 来源：pasted_text_20260827-064805（report 30）。配套溯源：rules/rule-30.md。本文件是 T091 拍卖套餐的完整操作化，写拍卖场戏前必读。

## 适用范围

写拍卖会、坊市竞拍、宗门大比发榜前的物品竞逐等「当众以物易主」场景时必读。核心：拍卖在爽文里不是「比谁钱多」，是**当众用一件物把身份、财力、来历三根轴一起折断**。穷样是场上轴，认主或一口价是折轴，拍品来历是钩。

## 一场拍卖只办四件事

1. 先按穷 / 假 / 没资格把他踩到席外
2. 拍品必须是硬标的（令、残谱、婚书、器胚、地契、仇家赃物）
3. 当众易手（认主飞来、一口价、主权亮出），数字或物可视化
4. 更高层进场：金主、刑堂、原物主、灭门令的签发者

缺第 1 场：炫富，不打脸。缺第 3 场：嘴赢，拍卖师没改口。缺第 4 场：拍完就散，没有下一章。

## 硬规则总表（拍1-拍14，R30 全量）

- 拍1 必须当众，必须有拍卖师改口；私下成交不算拍卖戏。【R30-02】
- 拍2 先辱后拍：请出席、限资、当赝品、当杂役没号牌；羞辱落到资格和钱，不少于三句。【R30-03】
- 拍3 拍品绑定主线指纹物：他家的、仇人赃、灭门遗、能开本图门、能证身份；禁止拍无关灵药。【R30-04】
- 拍4 穷要写实：破席、空牌、被搜身、灵石不够最低价；禁止开场掏仙帝卡；财力只升一档。【R30-05】
- 拍5 结算是物易手，不是报价演讲：认主、抽令、血契、锤落改名；数字跳要看见。【R30-06】
- 拍6 加价来回不超过三轮，第四轮起删；禁止二十轮报价注水。【R30-07】
- 拍7 男主少说话：一句出价或一声不吭亮物；禁止鉴宝课八百字。【R30-08】
- 拍8 仇人必须有真好处才进来抢（办婚、镇族、灭口），不是陪主角演戏。【R30-09】
- 拍9 通胀锁：本图拍卖只出本图能用的最高，禁止拍出仙帝本源。【R30-10】
- 拍10 拍完必有新债：金主、刑堂、后台、认主暴露的血脉；断在有人站起来要人/要物。【R30-10b】
- 拍11 禁止用钱解决武力：有人抢、有人灭口，仍要一招或一令，对照物碎；钱赢嘴，打赢抢。【R30-11】
- 拍12 一场拍卖一个主糖：穷样打脸 / 赝品变真 / 仇人拍到自家赃 / 认主，四选一；真香级只能放余波。【R30-12】
- 拍13 智商配额：点破最多一句 ≤20 字，两百字内锤落或物到手；禁止心中算托价。【R30-13】
- 拍14 篇幅：一场压进一章两千五，或两章；禁止三章围观。【R30-14】

## 四种主糖（先选一种）

| 主糖 | 场上轴 | 折轴 | 可视化 |
|---|---|---|---|
| **穷样一口价** | 没资格、没钱 | 报一口或亮欠条/令抵价 | 账改、锤落 |
| **赝品变真** | 当假货赶人 | 当场一处对照（纹、年款、内印） | 拍卖师改鉴定 |
| **认主飞来** | 他不配碰 | 拍品自己飞、烫、认血 | 物在他手，抢的人空 |
| **仇人拍到自家赃** | 仇人出风头 | 物证来历对上灭门/盗案 | 仇人牌碎，刑堂起身 |

真香级（父母来加价求他让）只能放余波，不能当主糖。

## 七拍套餐（公式C，可压进一章）

1. 入席被拦或被请到穷席
2. 拍品亮相，仇人举牌装逼
3. 当众判他没资格 / 判假 / 限价
4. 他出手：一口价 或 亮主权 或 血滴认主（≤200字）
5. 拍卖师改口 / 锤落 / 物飞到他手
6. 仇人加价失败或拍到自家赃，牌碎
7. 金主或刑堂起身（钩，八型用新债或半揭）

第 4 拍是爆发。第 6 是余波。第 7 不断在倒地的仇人。

## 关键写法公式

- **公式A 开场三辱**：资格辱（没号牌/杂役席/请出去）、财力辱（最低价都没有/限资）、物辱（这件跟你这种人无关）；三辱都要碰到具体手续。
- **公式B 拍品卡**（先填再写）：物的名字 / 跟男主的关系 / 仇人要它来干什么 / 当场能验的一处 / 拍到谁手里改哪条标的 / 拍完谁必须站起来。填不出关系，换拍品。
- **公式D 三轮加价封顶**：轮1 仇人开价+羞辱 → 轮2 托儿再压 → 轮3 男主一口价/认主；禁止轮4。一口价要有来源：令抵、欠条、物主权。
- **公式E 认主写法**：先被禁止碰 → 物自己动（飞、烫、鸣）→ 抢的人出手 → 短挡 → 抢的人护体裂 → 拍卖师改「成交」为「归主」。认主不是温馨，是当众打资格的脸。
- **公式F 赃物反噬**：仇人志在必得 → 锤将落 → 一句点破 ≤20 字（「印是陆家祠堂的。」）→ 全场验印 → 仇人当众承认赃 → 刑堂起身。点破后两百字内必须验印，不准开鉴定会。
- **公式G 章内比例**（2000-2500 字）：前 40% 加压（入席、三辱、拍品、装逼）；中 40% 三轮内易手（释放）；后 20% 改口、牌碎、更高层看见（余波+钩）。
- **公式H 剧情咬合**：上一场被夺物 → 本场拍品必须是那件或其钥匙；本场新债主语 → 下一场对手；财力只 +1 档。

## 写崩对照表（出现就改）

| 病 | 改 |
|---|---|
| 二十轮报价 | 三轮封顶 |
| 拍无关神药 | 换指纹物 |
| 开场掏黑卡 | 先限资、先请出 |
| 鉴宝课 | 只验当场一处 |
| 钱解决一切打架 | 抢夺仍要对照物碎 |
| 拍完回房数宝 | 更高层起身 |
| 一场四主糖 | 只留一个主折轴 |
| 心中算全场托价 | 删，留一句点破 |

## 语言提示

对：号牌被撕。「杂役席没有出价权。」锤要落。陆沉把袖口那道印按上托盘。托盘自己烫了。拍卖师嗓子卡住。
错：在这金碧辉煌的拍卖行中，陆沉感到一种被轻视的怒火在胸中燃烧……
报价格只用短数字。数字出现一次，锤落一次。

## Prompt 锁死段（可直接贴进提示词）

```text
拍卖合同：
一场拍卖只办：先辱资格财力、拍品必须是主线指纹物、当众易手、更高层进场。
先选一个主糖：穷样一口价 / 赝品变真 / 认主飞来 / 仇人拍到自家赃。
加价最多三轮，第四轮删。爆发≤200字。一口价必须有来源（令、欠条、物主权），禁止无底洞灵石。
男主少说话。点破≤一句≤20字，200字内锤落或物到手。禁止鉴定课、禁止布局推演。
结算验收：拍卖师改口、物在谁手里、数字或印可视化。恍然大悟不算。
拍完断在金主或刑堂起身，不断在「他买到了」。本图禁止拍出仙帝级。抢夺时仍须报数字、对照物碎。
```

一句话总纲：**先被请出穷席，再让拍品自己认人或者一口价把锤按死；拍的必须是你家的印或仇家的赃；锤落后不要数钱，让金主站起来。**
