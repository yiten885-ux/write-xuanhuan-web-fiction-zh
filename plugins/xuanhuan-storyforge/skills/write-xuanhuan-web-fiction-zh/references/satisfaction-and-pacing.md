# 爽点与节奏（爽点货盘 / 铺压弹债 / 波形规则）

> 本文档由 4 份规则蒸馏合并而成：report 03（爽点货盘，总硬规则 S01-S12）、report 06（爽点节奏 R01-R10，四级爽点/最小循环/波形）、report 20（爽点节奏 R01-R10，铺压弹债/黄金三章/波形规则）、report 23（12 种爽货货盘，各货爽核/硬规则/公式）。合并=并集：同义条目已合并并标注全部来源编号；冲突并列保留；任何一条规则未丢失。4 份输入未发现互相冲突的规则；个别措辞差异（如 S01「无落地损失的弹是闹剧」与 R01「无压的弹是闹剧」）按同义合并、原文措辞并列保留；OCR 存疑处（公式B、公式4）两种读法均保留并标注。

## 适用范围（什么时候读这份文档）

- 写男频玄幻爽文（番茄默认）时读这份文档：它管「这一章读者为什么爽、下一章为什么不划走」。

- 开书前三章读「黄金三章」；开一卷读「一卷/一张地图」；开全书读「全书骨架」（均见第五节）。

- 本主题范围（report 06/20 主题）：节奏不是写得快，是奖励发放的频率和升级方式；结构管的是多重压、何时弹、弹完欠什么；冲突、虐、反转、钩子都是这根骨头上的零件。爽点分级、铺→压→弹→债最小循环、一章/打脸单元/黄金三章/一卷/全书的节奏结构与奖励发放时间表（report 20 主题）。

## 硬规则总表（按主题分组；每条保留原始编号如 S01/R01，同义合并标注多来源，冲突并列保留）

### 一、总纲：爽点定义、总公式、节奏定义

- **R23-01 爽点定义**：爽点是读者欲望被当场结算的那一下：桌上那件东西易手、全场改口、数字跳了、仇账兑了一笔；必须不是「主角赢了」。（同义：report 03 主题「爽点是读者欲望被当场结算的那一下（桌上那件东西易手、全场改口、数字跳了、仇账兑了一笔）」）
- **总公式与节奏定义（R03 公式·总公式 / R06 公式·总公式 / R20-01 / R20-02 / R23-02）**：爽=压力积累×释放满足×反差程度；类型只决定释放的货，货要轮换，压和债的结构不变；节奏=压和弹的间隔+弹的升级+弹完立刻欠新债；节奏管的是多重压、何时弹、弹完欠什么；冲突、虐、反转、钩子都是这根骨头上的零件。

### 二、总硬规则 S01-S12（所有货都吃这一套）

- **S01 先压后弹（R03-01 / R23-05；同义：波形规则 R01，R06-01 / R20-35）**：必须先压后弹；弹的幅度必须≤压的积累；无落地损失（无压）的弹是闹剧，禁止写。
- **S02 必须当众（R03-02 / R23-06）**：必须当众；没观众就没有余震。
- **S03 弹要短（R03-03 / R23-07；同义：波形规则 R07，R06-07 / R20-41）**：核心释放必须≤200 字（一招≤200 字）；过程越长，宣泄越低。
- **S04 必须改局面（R03-04 / R23-08）**：名分/资源/阶层/解释权至少动一项。
- **S05 收获可视化（R03-05 / R23-09；同义：波形规则 R08，R06-08 / R20-42）**：必须用数字、令、名册、境界写收获；禁止「他变强了」。
- **S06 只+1 级（R03-06 / R23-10）**：只能+1 级；杂役章发仙帝=通胀，禁止。
- **S07 同货不应期（R03-07 / R23-11；同义：类型轮换 R06-12 / R20-06）**：连续 3 章禁止同一类型；连续 3 章同一货，读者会麻；打脸章的下一章必须用升级或得宝，禁止再骂同一个废物。
- **R04 同型不应期（R06-04 / R20-38）**：打脸后至少隔 1 章才能换升级/得宝/真香。
- **S08 人设不跟着爽（R03-08 / R23-12）**：杀伐必须不圣母，装废必须不话痨报身份。
- **S09 弹完欠债（R03-09 / R23-13；同义：波形规则 R02，R06-02 / R20-36）**：弹完必须立刻欠债；债的等级必须>刚被打的人；更高层必须看见。
- **S10 一章一个主爽点（R03-10 / R23-14）**：一章只能一个主爽点，最多一个辅（通常辅=收获或离场）。
- **S11 读者方向猜对、幅度猜小（R03-11 / R23-15）**：必须让读者方向猜对、幅度猜小；禁止把主高潮写成惨败。
- **S12 删掉这货，桌子上什么都没变=假爽点（R03-12 / R23-16）**：必须删掉重写。

### 三、波形规则 R01-R10（report 06 与 report 20 同源合并）

- **R01 先压后弹（R06-01 / R20-35）**：弹的幅度必须≤压的积累；无压的弹是闹剧。（同义并入 S01，见上）
- **R02 弹完立刻欠债（R06-02 / R20-36）**：债的等级必须>刚被打的人。（同义并入 S09，见上）
- **R03 下一弹必须+1 档（R06-03 / R20-37）**：面子→资源→规则；同档复读是假节奏。
- **R04 同型不应期（R06-04 / R20-38）**：打脸后至少隔 1 章换升级/得宝/真香。（见「总硬规则」）
- **R05 大爽前可以连压，但微爽不能断（R06-05 / R20-39）**：铺大高潮必须≤2 章纯压；缝里仍要微入账。
- **R06 信息前置（R06-06 / R20-40）**：必须信息前置；读者已知齿，压才是期待不是受虐。
- **R07 释放要短（R06-07 / R20-41）**：一招必须≤200 字；过程越长，宣泄越低。（同义并入 S03）
- **R08 收获可视化（R06-08 / R20-42）**：必须用数字、名册、令、境界；禁止「他变强了」。（同义并入 S05）
- **R09 日常/修炼不是节奏（R06-09 / R20-43）**：要写只能塞进余波 200 字，禁止开专章。
- **R10 换图是大爽的一种，不是休息（R06-10 / R20-44）**：新图第 1 章必须用冲突教新规则。

### 四、四级爽点与密度

- **四级爽点（R06-11 / R20-03 / R20-04 / R20-05）**：必须先定货再排班——微爽（嘴角动一下：一句怼、一个数字、系统入账、路人改口）每章必须≥1，可 2-3；小爽（这章没白看：当众小打脸、挡下致命、名册改回一行）每章必须 1 个主小爽；中爽（想催更：掉马一齿、越级、规则反套、后悔药升一级）每 1 万字/5-8 章必须 1 个；大爽（想截图：破本图规则、Boss 结算、换图、隐藏层+1）每 3-5 万字/每卷必须 1 个。微爽维持不划走，小爽维持完读，中爽维持追读，大爽维持换图不掉。禁止用微爽冒充大爽（每章都「其实我很强」）=通胀，后面加不动。（详细表见第四节）
- **层级接法（R03-31 / R23 公式·层级接法）**：微爽=离场一句、系统入账、路人改口；小爽=打脸、得宝、升级实战；中爽=掉马齿、规则反套、真香升级、新用法、越级；大爽=破本图规则、Boss 结算、复仇卷兑、L3 亮灯换图。番茄：每章必有小爽；5-8 章一个中爽；3-5 万字一个大爽。
- **番茄口诀（R06-23 / R20-34）**：每章必小爽；每 5-8 章必中爽；每卷必大爽；连续 2 章无兑现=死；连续 3 章同货=通胀。
- **平台密度对照（R06-22 / R20-33）**：飞卢每 2000 字小爽、每 3 万字中爽、每 30 万大高潮（闭环更碎、一天多爽）；番茄每 3000 字/每章 1 小爽、每 1 万字中爽、每 3-5 万大高潮（一章 2000-2500 字）；七猫近番茄、可插日常、可略松；起点每 1 万字小高潮、每 5 万中爽、每 20-30 万大高潮（铺更长，弹必须更狠）。

### 五、最小循环：铺→压→弹→债

- **最小循环四拍（R06-13 / R20-07 / R20-08；同义：R06 公式·最小循环）**：所有层级都是这四拍的放大——铺（信息前置，让读者有盼：金手指齿、身份齿）→压（标的被当众拿走，损失落地）→弹（短释放，改桌子）→债（更高层看见/灰行/倒计时=下一循环的压）。没有铺的压=纯虐；没有压的弹=无根装逼；没有债的弹=空窗，追读断。
- **宣泄公式（R06-14 / R20-09）**：宣泄强度=(前段压抑值×释放速度)/逻辑合理度。番茄操作：至少 3 句具体羞辱+1 个落地损失，换≤200 字爆发。

### 六、一章结构（2000-2500 字，番茄）

- **一章结构（R06-15 / R20-10 / R20-11 / R20-12 / R20-13 / R20-14；同义：R06 公式·一章结构比例）**：0-200 必须接上章钩（动作下一帧，不算爽，是信用）；200-1000 加压 40%（虐冲突落地）；1000-1800 释放 40%（本章主小爽，可叠 1 个微爽）；1800-2200 余波入账（数字、改口、收获可视化）；2200-2500 钩子 20%（未完成动作，八型轮换）。
- **硬比例与断点（R06-16 / R20-15 / R20-16）**：加压必须≤60%，必须留≥30% 给兑现；连续 2 章 0 兑现=废；禁止断在打脸最高点——余波必须写完，让更高层站起来再断（兑现是弹，站起来的人是债）。
- **章内情绪曲线（R06-17 / R20-17）**：必须按 接钩（短稳）→压爬升→小平台（反派再踩）→俯冲弹→余波平→钩再抬 走；像一小节过山车，禁止一条斜线爽到底。

### 七、打脸单元（5-8 章，中爽）

- **打脸单元（R06-18 / R20-18 / R20-19 / R20-20 / R20-21）**：必须按 Chn 挑衅+损失落地+最小兑+钩；Chn+1 加码（新对象/倒计时缩短）；Chn+2 蓄力可见（憋招，不是纯挨）；Chn+3 反转炸场（中爽）；Chn+4 余震分级（跟班→本人→父母）；Chn+5 新债抬到更高层/换标的=下一单元入口。飞卢必须把这套压进 3 章；起点可拉到 15-20 章，但炸必须更猛。单元升级脊柱（标的必须升一档）：面子→名额→归属/婚约→本图规则→谁有权写规则。换沙包复读「废物」不是新单元，是通胀。

### 八、黄金三章（全书节奏的第一发）

- **黄金三章（R06-19 / R20-22 / R20-23 / R20-24 / R20-25 / R20-26）**：Ch1 必须压 60/弹 30/钩 10（当众冲突+金手指最小亮+小爽挡致命或改一个数字，钩=倒计时或灰行）；Ch2 必须压 50/弹 30/再压 20（跟班上门，小打脸，新天才进场，钩=危机或新债）；Ch3 必须弹 50/收获 30/大钩 20（当众展示，一招制敌，收获可视化，钩=半揭或更高层要见他）。前 300 字必须有冲突；第 1 章必须有最小弹；第 3 章必须把场子抬到「这书后面能炸」。禁止：10 章只虐不亮金手指；第 3 章就把仙帝身份揭完。

### 九、一卷/一张地图（大爽）

- **一卷/一张地图（R06-20 / R20-27 / R20-28 / R20-29）**：一卷必须=一张图+一条本图规则+一个必须结算的 Boss+一个带向下图的债。卷内波形（番茄约 3-5 万字/15-25 章）：开图 1-3 章必须用冲突教规则（先撞墙）→前中一个打脸单元中爽（打赢本图层的人）→中 规则反压（人不够了，地图本身出手）→后 隐藏层或规则反套大爽（Boss 结算：打废/夺权/当众认）→卷末 换图齿，禁止空窗修炼章。Boss 打跑不算结算——大爽必须改规则或换图，不能只多打一个长老。

### 十、全书骨架（男频玄幻番茄）

- **全书骨架（R06-21 / R20-30 / R20-31 / R20-32）**：书名/简介必须卖点钩（冲突+金手指+下一件具体事）；黄金三章第 1 发小闭环，决定完读；10 章第 1 个中爽（掉马齿或越级）；30 章第 1 个大爽或换图（隐藏层约 40%）；每 3-5 万字一个大高潮；每卷一张图一个 Boss；L1→L5 必须按隐藏层表发弹药，禁止一次揭完；同时只跑 1 条主爽链+1 条暗齿——主链占章末兑现，暗齿章中点头。

### 十一、情绪守恒

- **情绪守恒（R06-24 / R20-45）**：憋屈时长必须∝需要的释放强度；长虐短兑=读者恨作者；短压超大弹=莫名其妙。

### 十二、12 种货分类型硬规则（完整版见第三节，此处保留编号映射与提要）

- **打脸（R03-13 / R23-17）**：反派必须主动挑衅且有真实好处；羞辱必须≥3 句落到身份+资源；损失必须先落地；主角必须不解释；四拍必须走完。禁止对骂、禁止演讲三观、禁止换沙包复读同一句「废物」；原句必须可奉还；打的是信念，不是血量。爽核：对方按错误信念作死，被结果打回原形。
- **装逼/扮猪吃虎（R03-14 / R23-18）**：必须先让读者看见齿，再让场上踩；装废必须有收益（燃料不暴露），否则是犯贱；自己报「其实我很强」是最弱装逼；大人物来接、令、一声称呼，才是装。装逼必须接打脸或掉马，单独吹牛不是爽点。爽核：信息差（读者≥主角>场上）。
- **掉马（R03-15 / R23-19）**：身份必须跨至少两级，物证必须先于口；别人必须先喊；只+1 级，留齿；必须当众；不复合。禁止身世 800 字；半揭必须优于全揭。和钩子「半揭」是同一刀，章中兑现、章末可再半揭加码。爽核：身份跨至少两级，物证先于口。
- **升级（R03-16 / R23-20）**：升级必须换阶层或换用法，不能只加数字；必须有门槛、有失败可能；升级章也要有冲突，禁止闭关专章；必须可视化：炼气三层→四层，写明能打谁。升级不实战=面板游戏，读者不认。爽核：付出可见、回馈立刻、对照物在。
- **得宝（R03-17 / R23-21）**：宝必须能当章用；禁止开箱鉴定会；得宝是打脸的辅货，很少当主货；通胀锁：本图最高只发本图能用的；必须先被夺/先缺→当众拿到（或从对方手里抢）→立刻改变本场手续（例：聘礼单抽回来、令压上公证空位）；禁止写「获得神秘古玉，回房研究」。爽核：更贵的东西到手，且刚被抢走过同类。
- **规则反套（卷高潮首选）（R03-18 / R23-22）**：必须先用冲突撞规则（失败）；再亮适用条件/公证权例外；必须当场套到对手头上；观众必须被迫按 R 改口；不辩 R 对不对。例「杂役不可还口」→名册上他才是被除名的；退婚需契押→末押在主角令上。爽核：打的是地图，不只是人。
- **真香（R03-19 / R23-23）**：必须分级滴灌（级 1 跟班→级 2 本人私下→级 3 父母带利益→级 4 新对象翻脸→级 5 场子易手）；禁止第 3 章跪完；主角反应锁死：原句奉还+走、不教育、不复合、不收她当女主；每次真香对方必须再丢一样真资源。真香是后悔药，不是感情线。爽核：当初那张嘴来求，主角不接。
- **复仇（R03-20 / R23-24）**：债必须具名、有原句、损失已落地；本卷见血或废，禁止「先变强十年」；兑付=原物或+1 级剥夺；禁止虐仇人十章无结果。复仇是债务账的结算，不是新开一条虐线。爽核：讨债票兑付。
- **离场（R03-21 / R23-25）**：必须先兑现一角再走，纯走是怂；走的动作要具体（喝茶尽、扫帚靠墙、收聘礼单）；禁止回头补刀演讲；章末钩交给更高层，不交给主角嘴；离场常当辅爽，主货仍是打脸/掉马。爽核：解释权已经不需要了，场留给他们自己崩。

### 各货详解（爽核 / 硬规则 / 公式 / 示例）

**1. 打脸**
- 爽核（R23-17）：对方按错误信念作死，被结果打回原形。
- 硬规则（R03-13 / R23-17）：反派必须主动挑衅且有真实好处；羞辱必须≥3 句落到身份+资源；损失必须先落地；主角必须不解释；四拍必须走完。禁止对骂、禁止演讲三观、禁止换沙包复读同一句「废物」；原句必须可奉还；打的是信念，不是血量。
- 公式（R03/R23 各货公式）：挑衅（标的被夺）→隐忍（反常动作）→反转≤200 字→余震近→远→权威。
- 示例：验收=护体裂/名册改（公式D）；无观众对骂→改法=拉到堂上（假爽对照）；开局、每单元（货盘总表）。

**2. 装逼（扮猪吃虎）**
- 爽核（R23-18）：信息差（读者≥主角>场上）。
- 硬规则（R03-14 / R23-18）：必须先让读者看见齿，再让场上踩；装废必须有收益（燃料不暴露），否则是犯贱；自己报「其实我很强」是最弱装逼；大人物来接、令、一声称呼，才是装。装逼必须接打脸或掉马，单独吹牛不是爽点。
- 公式：前置齿→全场按 X 羞辱→主角做无关的事→别人开口把 X 打成 Y。
- 示例：信息差章（货盘总表）；自我介绍「其实我是战神」=假装逼→改法=别人喊（假爽对照）。

**3. 掉马**
- 爽核（R23-19）：身份跨至少两级，物证先于口。
- 硬规则（R03-15 / R23-19）：别人必须先喊；只+1 级，留齿；必须当众；不复合。禁止身世 800 字；半揭必须优于全揭。和钩子「半揭」是同一刀，章中兑现、章末可再半揭加码。
- 公式：物证上桌→他人喊到关键词→打断或余震→局面改名分/公证。
- 示例：第 3/10 章齿（货盘总表）；验收=令、称呼（公式D）；自我介绍掉马=假掉马→改法=别人喊（假爽对照）。

**4. 升级**
- 爽核（R23-20）：付出可见、回馈立刻、对照物在。
- 硬规则（R03-16 / R23-20）：升级必须换阶层或换用法，不能只加数字；必须有门槛、有失败可能；升级章也要有冲突，禁止闭关专章；必须可视化：炼气三层→四层，写明能打谁。升级不实战=面板游戏，读者不认。
- 公式：撞墙（旧法不够）→付代价→数字/权限跳一档→立刻实战打一个刚压过他的人。
- 示例：隔章、勿连打脸（货盘总表）；闭关升级=假升级→改法=撞墙后当章实战（假爽对照）；验收=境界数字+能打谁（公式D）。

**5. 得宝**
- 爽核（R23-21）：更贵的东西到手，且刚被抢走过同类。
- 硬规则（R03-17 / R23-21）：宝必须能当章用；禁止开箱鉴定会；得宝是打脸的辅货，很少当主货；通胀锁：本图最高只发本图能用的；必须先被夺/先缺→当众拿到（或从对方手里抢）→立刻改变本场手续（例：聘礼单抽回来、令压上公证空位）；禁止写「获得神秘古玉，回房研究」。
- 公式：先被夺/先缺→当众拿到（或从对方手里抢）→立刻改变本场手续。
- 示例：打脸后的收获段（货盘总表）；开箱不打（鉴定古玉 800 字）=假得宝→改法=当场改手续（假爽对照）；验收=物易手（写进 debt_ledger）（公式D）。

**6. 规则反套（卷高潮首选）**
- 爽核（R23-22）：打的是地图，不只是人。
- 硬规则（R03-18 / R23-22）：必须先用冲突撞规则（失败）；再亮适用条件/公证权例外；必须当场套到对手头上；观众必须被迫按 R 改口；不辩 R 对不对。例「杂役不可还口」→名册上他才是被除名的；退婚需契押→末押在主角令上。
- 公式：对手引用规则 R 压你→不辩 R 对不对→亮 R 的条件权→R 套回去→解释权易手。
- 示例：单元末、卷高潮（货盘总表）；验收=对方被同一条律套住（公式D）。

**7. 真香**
- 爽核（R23-23）：当初那张嘴来求，主角不接。
- 硬规则（R03-19 / R23-23）：必须分级滴灌（级 1 跟班→级 2 本人私下→级 3 父母带利益→级 4 新对象翻脸→级 5 场子易手）；禁止第 3 章跪完；主角反应锁死：原句奉还+走、不教育、不复合、不收她当女主；每次真香对方必须再丢一样真资源。真香是后悔药，不是感情线。
- 公式（分级滴灌）：级1 跟班→级2 本人私下→级3 父母带利益→级4 新对象翻脸→级5 场子易手。
- 示例：后悔药 2-4 级（货盘总表）；第 3 章跪求=假真香→改法=推迟到级 2，且不接（假爽对照）；验收=对方丢失新资源（公式D）。

**8. 复仇**
- 爽核（R23-24）：讨债票兑付。

- 示例：打脸拍 4（货盘总表）；微爽=离场一句（层级接法）。
