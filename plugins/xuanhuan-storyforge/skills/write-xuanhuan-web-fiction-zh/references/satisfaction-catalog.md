# 爽点大全（八大类 39 爽点 + 用户增补 40 号·逐点操作手册）

> 来源：pasted_text_20260827-080119（report 38）。配套溯源：rules/rule-38.md。本文件是玄幻男频爽文的「情绪弹药库」目录——39 个爽点按八大类组织，每个爽点含定义、心理机制、创作公式与硬规则。与 satisfaction-and-pacing.md（12 爽货货盘 S 系列）互补：S 系列管货的分类与分货节奏，本目录管每个爽点的逐点操作。

## 适用范围

写任何爽点/打脸/收获/突破场景前查阅对应条目；每章选型时用「全局三条」控制间距与轮换。

## 全局三条（R38-01~03）+ 用户增补第四条

1. **爽点间距**：连续两个高烈度爽点之间至少间隔 500 字或一个场景过渡，避免爽感疲劳。
2. **爽点锚定**：每个爽点必须有可感知的结果（见血/碎物/跪地/变色/惊呼），不能让读者「猜」主角赢了。
3. **类型轮换**：连续三章内至少使用 3 种不同类型的爽点；输出爽点段落时附类型标注【本章爽点：当众打脸（01）+身份碾压（03）】。
4. **同型升级铁律（2026-08-31 用户增补，对齐女频规则六十六）**：同型爽点第二次出现必须升级对象、规模或方式之一；同型主爽连续 3 章禁。

## 逐点硬规则精要

### 尊严型（代入感最强的底层爽感：践踏→反转→加倍奉还）

- **01 当众打脸**：公式=公开羞辱(≥10人)+先踩至最低点(对方说最狠的话)+反转瞬间揭露+全场寂静音效反差+反派脸色红→白→青+一句回敬（「刚才谁说要废了我来着？」）。硬规则：场合公开 ≥5 见证者；反转前有压制性台词或沉默蓄势；反派失态至少一处；结果可感知（见血/碎物/倒地/跪地）。
- **02 杀人诛心**：公式=物理压制+精神打击(点破对方最在乎的东西)+崩溃瞬间(哭/跪/失态)+主角飘然离去(不补刀更诛心)。硬规则：先打服再诛心；诛心点=前三章展示过的引以为傲之物；旁观者印证；反派活着退场。
- **03 身份碾压**：公式=欺辱(建立不知情)+关键信物亮出+权威第三方证实(当场跪下)+反派煞白发抖+轻描淡写「现在，还要我的命吗？」。硬规则：反派完全不知情；须第三方证实；转变可感知（膝软/嗓哑/手抖）。
- **04 天骄踩踏**：公式=铺垫天骄威名(≥200字)+天骄挑衅/被迫应战+以越阶方式获胜+全场震惊+地位交接仪式。硬规则：天骄被 ≥3 人认证最强；获胜方式出乎意料；战后地位交接（剑被拿走/称号继承）。
- **05 旧人追悔**：公式=回忆闪回+今非昔比+旧人亲眼目睹辉煌+追悔表情(嘴唇颤抖/欲言又止)+主角目不斜视走过。硬规则：今昔对比一次；旧人主动看到；追悔表情一次；回应是无视（无视比嘲讽更诛心）。

### 实力型（直观感受主角很强且越看越强）

- **06 越阶反杀**：公式=对手境界明确更高(≥1 大境界)+碾压压制 3-5 句+金手指/底牌/代价释放+精准打击要害+死前不可置信。硬规则：≥2 项前置条件+明确代价；反杀逻辑说得通；价值兑现（储物袋/灵核/情报）。
- **07 秒杀**：公式=对手全力展示(≥100字)+随手一击(≤20字)+被秒结果+≥2 人「这不可能」+轻描淡写评价（「就这？」）。硬规则：先全力展示；动作轻描淡写；他人震惊校准强度。
- **08 以少胜多**：公式=明确人数比(如1vs10)+多人围攻+游刃有余身法+逐个击破/群伤+最后一人跪逃。硬规则：人数比 ≥1:5；明确围攻应对方式（不能写成 1v1）；标志性瞬间（一拳打飞三人/一剑扫断五兵）。
- **09 一力降十会**：公式=对手精巧招式(≥100字)+主角无视技巧纯力量轰出+招式正面粉碎+对手愣住/恐惧。硬规则：对手招式必须精巧；主角力量纯粹；碾压后有认知颠覆（练三十年的剑法被一拳粉碎）。
- **10 压制全场**：公式=主角入场/释放气息+威压实体化(石板裂/烛火灭/空气凝)+众人由近及远递进反应+全场寂静+有人嘴唇颤抖不敢说话。硬规则：由近及远递进；威压实体化；效果持续到本章结束。

### 资源型（拥有感）

- **11 杀人夺宝**：公式=击杀+翻找(制造期待)+意外之宝(与人设关联)+主角惊讶+价值描述(≥100字让读者觉得赚大了)。硬规则：宝物与人设相关（丹师→丹药）；价值锚定（坊市五百灵石/黄阶上品好三倍）；过程 ≤300 字。
- **12 捡漏奇遇**：公式=常规情境+因特长注意到被忽略之物+低价/零代价获得+事后揭示真实价值。硬规则：捡漏合乎逻辑（金手指/观察力/体质）；价值超常人认知；有对比描写（摊主不知卖了什么）。
- **13 传承/灌顶**：公式=触发(古碑/秘境/封印)+传承过程(能量涌入/身体改造)+变化(突破/新技能/记忆)+来源背景(≥2句)。硬规则：传承有代价；过程有身体感受（经脉撕裂/胀感）；结果即时验证（一掌新法术）。
- **14 奖励夺魁**：公式=竞赛背景+表现超预期+延迟公布结果+奖励揭晓(超预期)+羡慕嫉妒目光。硬规则：奖励具体（名称+品阶+功能）；≥1 个嫉妒旁观者；奖励匹配当前需求（缺功法给功法）。
- **15 无中生有**：公式=展示特殊技能+制成品超预期(新手炼出极品)+旁人质疑被证据征服+价值锚定（市面三千灵石）。硬规则：技能前文埋线；鉴别过程（老丹师/验宝台）；品级肉眼可见高于同类（丹晕三圈 vs 两圈）。

### 关系型（人际碾压与收获）

- **16 美人倒追**：公式=前期冷淡(≥200字)+主角展示实力/价值+态度微妙变化(多看/多问/多留)+主动示好/脸红+主角淡然给台阶。硬规则：前期高冷铺垫；变化循序渐进；主动行为具体；主角不太在意保持低位差。
- **17 叛徒跪地**：公式=背叛闪回+主角今日强大+叛徒找上门/偶遇+跪地磕头哭求开价+主角处置(「滚」/沉默无视)+拖走/吓瘫。硬规则：叛徒是认识的人；求饶含具体开价；处置比死亡更诛心（让你活着看今日的我）。
- **18 知遇之恩**：公式=恩人弱小时小帮助+主角记情+恩人危机+强势相救+恩人感慨（当年那小子……）。硬规则：帮助小而具体（一碗饭/一句话）；危机与主角崛起直接相关；出手后有感慨。
- **19 万人臣服**：公式=惊天之举+第一人跪下+多米诺蔓延(一人→十人→百人千人)+齐声高喊(≤8字「拜见圣子」)+主角高处俯瞰。硬规则：第一跪作视觉锚点；由近及远；齐喊 ≤8 字；主角在高处。
- **20 天骄追随**：公式=天骄前期高傲+交手/共处+被实力品性折服+低头「我服了」+主角「看你的表现了」。硬规则：前期足够高傲；折服有具体事件；理由合理（想成为像你这样的人，非图好处）。

### 智谋型（穿插在硬实力之间保持新鲜感）

- **21 设局反杀**：公式=提前布置+反派入瓮+主角现身揭真相+反派「原来你是故意引我来？」+回敬（「你猜对了，但晚了」）+反杀执行。硬规则：提前埋线；规模匹配威胁等级；揭示有解释台词（枯草是我故意踩的）。
- **22 利用规则**：公式=前文明文规则+发现常人忽略细节(「规则没说不能……」)+对手常规出牌+利用漏洞出奇制胜+裁判无法反驳。硬规则：规则前文提及；漏洞合理不耍赖；成功后有官方确认。
- **23 借刀杀人**：公式=A 与 B 真实矛盾+信息差挑动(一句话/一件物品/匿名纸条)+两败俱伤或一方被灭+置身事外+渔翁之利。硬规则：矛盾真实；操作隐晦；不留把柄。
- **24 信息差碾压**：公式=独家情报(秘境入口/弱点/考题)+他人常规行事+利用信息差出奇制胜+事后才发现/懊悔。硬规则：来源合理（前世记忆/金手指/遗物）；第 2 章前铺垫；收益即时兑现。
- **25 扮猪吃虎**：公式=伪装弱小+因误解被欺凌(招仇恨)+欺凌到顶点(最低点)+展露真实实力(最高反差)+表情由讥笑到恐惧+一句「这下，够了吗？」。硬规则：藏拙有合理理由；被欺凌足够深（跪/当众辱/被踩）；展露后 ≥3 旁观者震惊。

### 命运型（天命/气运/身份）

- **26 天命认证**：公式=触发场景(圣物/秘境/天象)+异象显现(光柱/雷鸣/祥云)+圣物认主/天地传音+全场目光聚焦+有人喊「他是天命之人！」。硬规则：认证前有无人能触发的铺垫；异象比历史最高宏大；后有官方仪式（封圣子）。
- **27 血脉觉醒**：公式=触发(受伤/触碰特定物/灌顶)+身体变化(血脉沸腾/纹路浮现/气息突变)+能力展示+有人认出来历(敬畏)。硬规则：前期铺垫一句；能力有代价（寿命/特殊灵石）；来历分阶段揭示。
- **28 气运通天**：公式=不可控随机事件+最好结果(大奖/宝地/最好洞府)+嫉妒质疑不甘+淡然接受。硬规则：完全随机（非操控）；概率足够低（万分之一/千年一遇）；至少一个质疑者被现实打脸。
- **29 旧日真相**：公式=触发(遗物/古籍/被告知)+核心真相(2-3句)+震惊/沉默/追问+新问题抛出+下一步行动变化。硬规则：分三章释放（现象→线索→核心）；改变主角行动；即时外化反应（捏碎茶杯/拳攥出血）。
- **30 命运逆转**：公式=预言/占卜/毒誓(所有人都信他会死)+挣扎求生越挣扎越绝望+金手指/外力介入+逆转时刻（他还活着！他突破了！）+预言者色变（我的占卜从未出错……）。硬规则：逆转前 ≥200 字绝境；方式意料之外；预言者反应。

### 群体反应型（最省字数的爽感：环境共振）

- **31 万众瞩目**：公式=重大场合+不凡之举+目光由近及远 ≥3 节点(身边回头→远处转头→全场安静看向主角)+主角淡然。硬规则：目光传递 ≥3 节点；主角淡然非得意；被看后推进下一步行动（看完了，然后呢？）。
- **32 鸦雀无声**：公式=惊人之举+前后声音对比(前一秒吵闹后一秒死寂)+寂静持续(三息无人说话)+打破方式(茶杯落地/一声咳嗽/某人颤声)。硬规则：寂静前有吵闹铺垫；持续可感知；打破有具体声音。
- **33 倒吸凉气**：公式=出人意料表现+至少 2 人同时倒吸+扩散到更多人+有人喃喃「我没看错吧？」。硬规则：多人同时（数十人）；紧接具体人的质疑/确认（揉眼睛/低声问）。
- **34 谣言风暴**：公式=完成一件事+第一波传播者(杂役/店小二)+传播路径(酒楼→坊市→内门→长老)+版本越传越夸张+主角听到传闻的反应（摸摸鼻子，传成这样）。硬规则：传播有路径；版本比原始夸张（筑基传成凝元）；主角有内心活动。
- **35 官方认可**：公式=完成考核/贡献+官方宣布+授予象征物(令牌/称号/金匾)+宣读者官方感（兹有弟子陆沉……）+全场见证。硬规则：书面感表达；改变实际权利（A 进 B 地/领更多灵石）；后有对比反应（撇嘴/恭贺）。

### 爆发/突破型（肉眼可见地变强）

- **36 当场突破**：公式=绝境/极限状态+突破征兆(灵气暴动/瓶颈松动)+突破瞬间(能量爆发/异象)+即时验证(一掌反杀)+对手震惊绝望逃跑。硬规则：突破前有瓶颈感（卡三个月/灵气像堵塞的河流）；突破有代价（灵石耗空/极度虚弱）；立即验证（不能只数字变化）。
- **37 功力暴涨**：公式=触发事件(吞噬宝物/传承/丹药)+能量涌入身体反应(经脉胀痛/血管发热/骨骼作响)+连续突破 ≥2 小境界+对比（三天前炼气二重如今七重）。硬规则：暴涨有来源；过程有身体感受 ≥2 感官；外界认证（探测术震惊/威压逼退）。
- **38 反败为胜**：公式=绝对劣势(受伤/枯竭/被围)+故意露出破绽(关键)+对手全力出击以为胜券在握+破绽是陷阱+逆转一击精准+死前不可置信。硬规则：破绽故意露出且前文埋伏笔；一击精准（刺要害）；后有解释台词/闪回（他等的就是这一击）。
- **39 一路畅通**：公式=进入场景(秘境/战场/竞技)+连续挑战 3-5 个+碾压速胜+难度递增应对越来越轻松+尾声所有人眼神变了。硬规则：至少 1 个略有威胁对手被举重若轻化解；不超过 1.5 章（防平推流）；之后必有转折（真大敌/招来嫉妒）。
- **40 靠山俯首**（用户增补 2026-08-31，势力反水型）：公式=反派亮靠山（名号+层级具体）+主角不动声色（此前 1-3 章已埋"该靠山已被主角降服/收买/击败"的因果）+靠山当众表态（躬身行礼/撤走护卫/反绑其人/划清界限）+反派惊慌失措（三级递进：不信→环顾寻找→声音发颤行为失态，具体化到动作台词）+众人即时改口（换称呼/换站位）+主角轻收（"你的靠山没走，只是换了个站的地方"）。硬规则：靠山俯首必须有前文因果（被击败/欠恩/利益绑定），禁机械降神式突然跪；俯首必须当众（有围观见证者）；反派惊慌失措须具体化（衬3），禁抽象"他很害怕"；与衬式1 构成势能对偶（衬式1=靠山压主角，本点=靠山反压反派），与双7 NPD 失态同源；靠山降服≠开篇债结清（对04：更高层新债照立）。

## System 锁死段（可直接贴进提示词）

```text
【爽点模块 - 全局规则】
创作玄幻男频爽文时，每个爽点必须遵循对应公式和硬规则（39 点逐点公式见 satisfaction-catalog.md）。全局性硬规则：
1. 爽点间距：连续两个高烈度爽点之间至少间隔500字或一个场景过渡，避免爽感疲劳。
2. 爽点锚定：每个爽点必须有可感知的结果（见血/碎物/跪地/变色/惊呼），不能让读者猜主角赢了。
3. 爽点类型轮换：连续三章内至少使用3种不同类型的爽点，避免单一模式。
输出爽点段落时必须附带类型标注：【本章爽点：当众打脸（规则01）+身份碾压（规则03）】
```

一句话总纲：**八大类四十点（含用户增补 40 号），每点一个公式一把闸；间距五百字、结果可感知、三章三类轮换——弹药库按需取用，不许连发同一种。**
