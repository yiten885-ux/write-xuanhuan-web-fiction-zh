## 1. 总纲四则（衬1–衬4，硬门禁）

1. **衬1 主次落差**：主体（主角）与陪衬（反派/配角/环境）存在至少一种对立落差——身份、实力、认知、情绪；陪衬的存在只为突出主体，不可喧宾夺主。
2. **衬2 情绪势能**：顺序强制——先积累（压抑/低估/嚣张）→ 再释放（碾压/揭晓/打脸）→ 后渲染（震惊/悔恨/余波）；积累越足，释放越爽；渲染越到位，余韵越长。
3. **衬3 具体化、可视化**：用数字、时间、空间、物品、心理活动等细节制造反差；避免抽象形容（如"很强""很弱"），全部转化为可感知的对比。
4. **衬4 合理性与节奏**：主角的强有伏笔/金手指支撑；陪衬的狂有性格/逻辑依据；频率适中，维度轮换（实力、智力、身份、财富等），避免审美疲劳（由衬检7把关）。

## 2. 核心六式（衬式1–6）

### 衬式1 反派嚣张反衬主角深藏不露
```
[反派立威]：反派用具体言行（贬低+挑衅+赌约）展示狂妄，围观者起哄附和。
[主角示弱]：主角不辩解、不愤怒，用淡定或自嘲回应，让旁人更加轻视。
[关键爆发]：在某个触发点（比试/打赌/冲突），主角轻描淡写地展露实力，瞬间碾压反派。
[余波震惊]：全场死寂→旁人震惊反应（语言、动作、心理）→权威者惊呼揭示真实实力。
```
参数要求：反派狂言须具体（如"让你三招""碰到衣角算我输"）；主角示弱须真实（动作、语气、神态）；爆发须简洁（一个动作、一招制敌）；余波至少包含 2-3 种不同人物的反应。

### 衬式2 配角失败反衬主角轻松成功
```
[难题铺垫]：描述一个公认的极高难度目标（有具体门槛或历史记录）。
[群雄尝试]：多名强者/专家付出巨大代价（时间、人数、灵力、生命），失败或惨胜。
[主角登场]：众人不看好甚至阻止，主角无视。
[轻松解决]：主角用极低成本（一个动作、一句话）完成，效果轻松到诡异。
[旁人震撼]：尝试者的震惊、怀疑、敬畏等反应。
```
参数要求：配角失败的细节要具体（数字、过程、代价）；主角解决方式要极简且出人意料；反差至少体现在"代价对比"和"难度对比"上。

### 衬式3 绝境反衬主角从容
```
[绝境营造]：描绘必死之局（强敌/天灾/绝地），众人绝望、崩溃、放弃。
[主角反常]：主角在绝境中做与紧张氛围相反的事（喝茶、看书、弹琴），淡定自若。
[闲笔强化]：主角对闲事发表评论或做出悠闲动作，与众人绝望形成强烈对比。
[破局利落]：主角用极为优雅或简单的方式瞬间化解绝境（一口气、一个眼神）。
[神格确立]：幸存者从绝望到震撼，跪拜或称呼"仙人""神"，确立主角超凡地位。
```
参数要求：绝境压迫感要强（环境描写、人物反应）；主角淡定必须有具体生活化细节；破局方式要出人意料但合理（符合金手指设定）。

### 衬式4 世俗眼光反衬主角高瞻远瞩
```
[反常选择]：主角做出违背大众认知的选择（放弃热门珍宝，选废品/险路）。
[众人嘲笑]：众人用具体语言和态度嘲讽主角愚蠢、没见识。
[主角淡然]：主角不解释、微微一笑，保持神秘。
[真相揭示]：事后证明主角的选择极其正确（废品是至宝，险路是捷径），众人悔恨。
[后悔后续]：有人试图挽回（高价买回、道歉），主角拒绝或反击，强化打脸效果。
```
参数要求：反常选择必须有伏笔或主角特殊能力支撑；揭示时机不能太晚，需在读者失去耐心前点明；后悔后续要具体（出价、下跪、哀求）。
> 注意："微微一笑"属语言合同禁用词（语8），正文改写为具体动作（如"笑了笑"或神态动作）。

### 衬式5 情绪反衬（先抑后扬）
```
[深度压抑]：主角遭受严重打击（被废、退婚、背叛），情感浓烈且具体。
[情绪沉淀]：主角不立即反击，默默承受，让读者憋屈感积累。
[回归舞台]：设置一个高光场合（大典、婚礼、比试），主角华丽回归。
[瞬间释放]：主角以绝对实力/身份揭露，让昔日仇人惊恐、跪伏。
[清算行动]：主角用具体行动兑现报复，彻底碾压仇人，爽感释放。
```
参数要求：压抑阶段要足够惨烈但不过度（避免读者弃书）；回归时的气场描写要强（步伐、眼神、气势）；清算要彻底，不留余地。

### 衬式6 规则反衬主角打破规则
```
[规则建立]：明确一个公认的、不可逾越的规则（境界壁垒/物理常识/阵法限制）。
[主角挑战]：主角以低姿态或弱势状态面对规则，众人认为必败。
[规则破碎]：主角用简单粗暴的方式打破规则（一拳/一指），效果震撼。
[众人震惊]：旁观者无法置信、惊恐、甚至吓晕，强调规则被颠覆的冲击。
[新秩序暗示]：主角轻描淡写地质疑规则（"谁定的？"），确立超越规则的地位。
```
参数要求：规则必须简单易懂；打破规则后必须有合理解释（金手指、特殊体质、系统）；众人反应要夸张化以强化戏剧性。
> 层级约束：前三章只允许破"凡俗规则"（世俗常识/小镇纪录/凡铁极限）；修行界硬规则（境界壁垒/宗门法/本图规则）的打破仍受金手指隐藏层 L3（第30章）与对01/对02 授权约束，不因本式放宽。

## 3. 微观五式（衬微A–E）

- **衬微A 数量/程度对比式**：[陪衬付出]大量资源（人数、灵力、时间）仅微小效果 → [主角付出]极小资源（一根手指、三息）获得巨大效果。示例：三位老祖联手 → 妖兽退三步；主角一指 → 妖兽飞百丈。
- **衬微B 时间差对比式**：[陪衬耗时]三天三夜尝试失败 → [主角用时]三息完成。附加细节：陪衬的失败道具掉落（罗盘/武器），强化震惊。
- **衬微C 空间位置反转式**：[初始]反派居高临下，主角处于低位（被俯视/踩踏）→ [反转]主角一个动作（跺脚/抬手）改变空间关系，反派跌落低位，主角居高临下。
- **衬微D 物品状态反差式**：[物品原状]某物在配角手中/仓库里平凡无奇（锈剑、废铁）→ [主角使用]一接触便展现惊人威力（剑光照天、神器觉醒）。
- **衬微E 心理活动打脸式**：[配角心理]内心极度自信、轻视主角（"一只手捏死他"）→ [现实打脸]短时间内被主角击败，心理崩溃（"怎么可能"）。

## 4. 宏观三式（衬宏F–H）

- **衬宏F 章内反衬（短周期）**：[开端]反派挑衅、主角低调（约1/4篇幅）→ [升级]冲突加剧、旁人看衰（约1/4）→ [爆发]主角出手瞬间碾压（约1/2）→ [余波]众人震惊+悬念钩子（约1/4）。
- **衬宏G 跨章反衬（中周期）**：[铺垫期（数章）]主角受辱/隐忍，穿插小反衬维持兴趣 → [发酵期（数章）]旁人议论、敌人嚣张、环境压迫，抬高期待 → [爆发期（1-2章）]在标志性场景集中释放 → [余波期（数章）]写后续影响，强化成果。关键控制：信息释放节奏，不能让读者过早猜到主角实力。
- **衬宏H 全书级反衬（长周期）**：[第一卷]主角处于底层被轻视，埋下金手指 → [第二卷]逐步展现实力，打破小范围认知，但仍有更强轻视者 → [第三卷]大范围反衬爆发，登上巅峰，昔日轻视者仰望 → [第四卷]新维度展开（如仙界），再启新一轮反衬。

## 5. 情感层次五型对照

| 爽感类型 | 反衬设计公式 |
|---|---|
| 优越感爽 | 大众短视/愚蠢 → 主角智慧/远见 → 结果证明主角正确 → 众人悔恨。 |
| 复仇感爽 | 仇人当初嚣张 → 主角隐忍 → 主角归来辉煌 → 仇人凄惨后悔。 |
| 守护感爽 | 主角平时低调被忽视 → 危机时挺身而出 → 保护众人 → 赢得敬畏。 |
| 逆袭感爽 | 主角起点极低（废柴/凡人）→ 努力/金手指 → 成就巅峰 → 对比昔日悲惨。 |
| 打脸感爽 | 反派/路人极度嚣张 → 主角干脆利落打脸 → 全场震惊。 |

## 6. 与其他手法的组合公式

- 反衬+伏笔：先反衬（选废品）→ 后揭示（主角早知真相）→ 逻辑闭环。
- 反衬+悬念：反派出手 → 主角淡定设问（"知道我为什么没出手吗？"）→ 实力展露。
- 反衬+对比：配角之间先对比 → 主角再反衬所有配角，突出主角。
- 反衬+夸张：用极度夸张描写配角失败（口吐白沫）和主角轻松（打个哈欠结束战斗）。
- 反衬+反转：先反衬主角弱 → 主角胜 → 再反转主角故意输 → 引出更深布局。

## 7. 自检八项（衬检1–8，生成后逐项登记 QA 侧车）

1. 主次分明：主体是否为唯一焦点？
2. 落差足够：陪衬的弱/蠢/狂与主角的强/智/淡定是否都写到极致？
3. 铺垫合理：主角的强有伏笔吗？陪衬的狂有依据吗？
4. 情绪积累：释放前是否有足够期待/憋屈/好奇？
5. 爆发利落：是否突然、轻松、有视觉冲击？
6. 余波渲染：是否有旁观者反应、敌人后悔、后续影响？
7. 避免重复：与之前反衬维度是否不同？
8. 信息增量：是否推动剧情或揭示设定？

## 8. 门禁与口径

1. 衬检1–8 逐项生成后登记 QA 侧车；任一不通过只回滚该反衬场景并复检。
2. 衬式6 层级约束（见上文）不受本节放宽。
3. 与既有合同衔接：打脸四拍/留08 管节拍与递进，衬式管反衬方向与围观层次设计，两者并存；衬式3/衬式6 的破局必须金手指在场（对01/对02）；衬式1 的"主角示弱"不违反 C04 不解释（沉默+动作即示弱）；反衬段落受语8 禁用词与 5.21 留06（环境≤15%）约束。
4. 抽象对比词（"很强""很弱"）按语8 禁用词同等处理，出现即替换为可感知对比。
