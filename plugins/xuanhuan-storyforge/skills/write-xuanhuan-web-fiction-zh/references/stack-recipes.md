- **T091 拍卖套餐**：被请出或限资 → 他出价或亮物主权 → 全场嘲 → 拍品认主飞向他 → 仇人发现拍的是自家赃/灭门物 → 金主或刑堂进场。

- **T094 宗门清人**：清人台宣读 → 读到他的姓或他的谱名 → 袖里令或印自己亮 → 执法停顿 → 半揭或冲突 → 清人令的签发者被请出来。
- **T095 朝堂/宗门献俘**：被绑上台献俘 → 当众定罪 → 印/令翻面，献俘的人资格裂 → 堂上改口一档 → 真要的人从席后站起来。
- **T096 医诊**：当众判死、砸牌或下文书 → 他要过手把脉/看方 → 毒或病灶指向判官或在座仇人 → 危症对照（真病人好转或假死揭穿）→ 医馆/官府要收他同时也要灭口。

## NOSTACK 原则
- 一章最多 PRIMARY_T + 可选 SUB_T 两个套路；禁止超过两个。
- 只加载所选两个 ID 的条目；禁止一次吞 96 条。
- T001（救美）不得当主糖，不得与主线感情戏叠用。
- 假高潮少给一档（只赢人、不赢规则）；真高潮才改标的。
