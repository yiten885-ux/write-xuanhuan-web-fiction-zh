## 适用范围（什么时候读这份文档）

- 写、改、审玄幻爽文章节，凡涉及反转、打脸、掉马、压制-释放节奏时：先读「爽文反转」和 report 13 的公式 1-10；每场动笔前必须先填反转卡（report 13 公式 1）。
- 凡涉及虐、损失、退婚、背叛、亲情刀、死人刀、替嫁等加压剧情时：先读「爽文虐点」和 report 14 的公式 1-9；下刀前必须先开讨债票、填虐点卡（N01 / report 14 公式 2）。
- 凡想让打脸、装逼、震惊里嵌网络热梗，或让 AI 自动接梗时：先读「热梗运用」和 report 19 的模板集；写章前用户消息必须带【本周梗池】强制槽位，模型必须先出「本场用梗计划」再写正文（R19-36、R19-37/45）。
- 三份规则是同一套骨头的三段：虐负责压力积累（硬冲突的加压段存货），反转/打脸负责释放，金手指负责讨债手段，梗只允许出现在释放段（拍 4 余震或离场句）（R14-03、R19-04/05/21）。
- 密度底线速查：每章 1 次微反转 + 1 个第一档虐 + 当章最小兑（report 13 公式 10、report 14 公式 8）；每章最多 1 个明梗 + 2 个结构梗（R19-03/42）。
- 系统性红线速查：反转合同、虐点合同、热梗合同三份锁死段见「公式与结构模板」末尾，可直接贴 System Prompt。

## 硬规则总表（按主题分组；每条保留原始编号如 F01/N01，同义合并标注多来源，冲突并列保留）

### 一、反转·分类与配比（report 13）

**总公式（report 13 P1 标题级，覆核补录）**：反转爽感=错误信念的硬度×揭开速度×反差级数×当众程度。必须有观众，否则没有余震。

| 编号 | 规则（祈使句） |
|---|---|
| R13-01 | 必须先分清三种反转：①信息差反转（场上的人被骗，读者感受"我就等这下"，是主力，用于扮猪吃虎、退婚现场）；②加码反转（骗读者幅度，感受"比我想的还狠"，是每场打脸的第二刀）；③认知反转（骗读者事实，感受"原来不是那样"，少用，用于隐藏层、内鬼、更大棋盘）。 |
| R13-02 | 番茄爽文反转配比必须遵循：信息差 60%、加码 30%、认知 10%（认知反转一卷最多一次大的）。 |
| R13-03 | 认知反转必须少用——用多了读者不敢期待，追读会掉；读者需要"等打脸"的确定性。 |
| R13-04 + R13-20（F04） | 反转必须有观众、必须当众：反转没有观众，就只是情节变化、没有余震，不是打脸。（同义合并：R13-04 与 F04 两条合并） |

### 二、反转·四拍与时机（report 13）

| 编号 | 规则（祈使句） |
|---|---|
| R13-05 | 爽文反转必须走通用四拍：信息前置→压制→拉扯→反击（和硬冲突、打脸是同一套骨头）。前置=让读者先知道底牌一角，建立"等着吧"；压制=对手按错误信念作死，读者憋；拉扯=对手再加码、主角不解释，更憋更确定要炸；反击=短爆发，揭的是结果不是说明书。 |
| R13-06 | 信息前置是爽文反转的命门：必须让读者先知道一点底牌——读者不知道底牌，压制段就是纯受虐；读者知道一点，压制段就变成期待。前置只露齿（身份一句、面板一行灰、信物一个印），禁止把反转内容讲完。 |
| R13-07 | 揭开时机必须是压力最高、对手话最满、观众最齐的那一秒；最佳落点是对手那句羞辱说完、动作还没收回。禁止回房再揭，禁止章末用旁白揭。 |

### 三、反转·八种类型（report 13）

| 编号 | 规则（祈使句） |
|---|---|
| R13-08 | 一次只能用一种主反转，辅反转最多加码一刀。 |
| R13-09 | 身份反转（掉马）：场上以为是 X 其实是 Y，Y 必须比 X 高至少两级（X=废物/赘婿/杂役→Y=战神/供奉/真传私生子）。揭法只能靠别人来接、令牌、一声称呼，禁止靠自己报家门。必须共享底层动机：装废是为了躲因果/完成托付，不是为了挨骂，否则读者觉得主角犯贱。 |
| R13-10 | 实力反转：境界数字对不上（炼气打筑基），必须有可见对照：护体裂、一口血、旁人喊境界。 |
| R13-11 | 规则反转：必须让对方拿来压你的规矩当场砸到他自己脸上（"杂役不可还口"→点名册上他才是被除名的那个；"退婚需长老公证"→公证权在主角手里）。这是卷高潮最硬的一种，因为它打的是地图，不只是人。 |
| R13-12 | 因果反转（将计就计）：对手设的套必须是主角要的燃料（"他们要当众废你→你要的就是当众→金手指只在观众面前计价"；读者已知"装逼值看见证者境界"，对手把长老请来，等于自己把燃料送到嘴边）。 |
| R13-13 | 对象反转：骂的人、抢的人、退婚的人，打的必须不是他们以为的那个（当众羞辱杂役，回廊里放下茶杯的才是他要见的人；替婚女不是庶女，婚书上的印是皇女）。 |
| R13-14 | 立场反转：友变敌、敌变债，爽文里友变敌比洗白更有用，洗白容易圣母。硬规则：底层动机开局就要有一条；纯两肋插刀的兄弟后期背刺=人设崩，不是反转。 |
| R13-15 | 金手指隐藏层反转：旧用法失败→新动词亮灯。这是认知反转的合法配额，必须按隐藏层节点出，禁止随便加。 |
| R13-16 | 态度反转（反套路）：读者以为要打脸，主角必须不接、先走、先退婚、把场子留给对方自己崩（对方等他解释→他问"聘礼今晚送还是我去取"→离场；打脸发生在下一章，由对方的新对象/父母完成）。这一型用来打破"每章必对线"的疲劳，但一单元最多一次，否则读者会觉得主角不还手。 |

### 四、反转·写作硬规则 F01-F14（report 13）

| 编号 | 规则（祈使句） |
|---|---|
| F01（R13-17） | 方向不骗读者，幅度可以骗：必须承诺"他会翻"，可以让翻的方式、对象、代价出乎意料；禁止让主角突然惨死当主高潮（那是虐文）。 |
| F02（R13-18） | 读者必须先站在正确一边：信息差反转必须读者≥主角>场上；加码反转必须读者=主角<真相幅度；禁止长期读者<全场（那是悬疑，番茄爽文会掉完读）。 |
| F03（R13-19） | 揭的是结果，不是说明书：必须亮令牌、裂护体、改名册、一声"见过供奉"；禁止当场讲身世三分钟。 |
| F05（R13-21） | 必须短：核心翻转≤200字；余震必须给别人喊，禁止给主角说。 |
| F06（R13-22） | 伏笔至少 3 齿，且不与真相打架：齿=重复动作、灰色面板、看不懂的印、对某类人反常手软。误导只能"不完整"，禁止"写反"——写过"他真的是凡人、确无后台"，后面就不能变战神。 |
| F07（R13-23） | 人设不反转：杀伐不会因为反转变圣母；装废不会因为揭身份变话痨。反转改的是场上认知，禁止改主角性格。 |
| F08（R13-24） | 反转必须改局面：删掉这句揭晓剧情还能走=假反转；必须当场改名分、资源、阶层或解释权。 |
| F09（R13-25） | 反转后必须立刻欠新债：更高层看见、规则反噬、身份齿被登记；空窗一章，钩子断。 |
| F10（R13-26） | 类型轮换：禁止连续 3 章都是"其实我很强"；下一章必须换规则/对象/因果。 |
| F11（R13-27） | 认知大反转一卷一次：假死、梦境、全员卧底，全书各限一次；禁止用第二次——用第二次，读者开始不信死亡。 |
| F12（R13-28） | 时机：话最满的时候打。对手的"你也配"说完再打；提前揭=浪费压制；拖到回房揭=浪费观众。 |
| F13（R13-29） | 加码必须遵循 +1 级：你以为校董→其实城西商会会长（+1）；禁止一揭就是仙帝，后面没有层。 |
| F14（R13-30） | 反派必须因错误信念获益：他嚣张是因为信息差对他有利，禁止写成作者让他作死；反转才能打在"他算错了"上。 |

### 五、虐点·定性（report 14）

| 编号 | 规则（祈使句） |
|---|---|
| R14-01 | 爽文虐点=已落地的不可逆损失+明确欠债人+可执行的讨债票，三件缺一不可：缺损失落地=软虐加压不够；缺欠债人=虐命运虐作者、读者恨书；缺讨债票=白挨、虐文或弃书。 |
| R14-02 | 必须把刀抽出来砍到该还债的人身上：写完一场虐，必须能指出哪一章、砍谁、拿回什么；指不出来就是写成虐文了。 |
| R14-03 | 虐点不是独立剧情，是硬冲突的加压段存货（爽=压力积累×释放满足×反差程度；虐负责压力，反转打脸负责释放，金手指负责讨债手段）。 |

### 六、虐点·12 种三档清单（report 14）

| 编号 | 规则（祈使句） |
|---|---|
| R14-04 | 第一档（当场能兑，开局/每章都可用）：1.当众羞辱——面子被踩观众还在（退婚、点名、宴席骂废物），兑=同一批观众改口；2.剥夺——名额、丹药、婚书、房子、宗门籍，必须已经拿走不是威胁，兑=当众拿回来或拿走更贵的；3.规则不公——"杂役不可还口""庶女不入谱"，地图本身在打人，兑=规则反转套到对方头上；4.倒计时绝望——日落前滚、三日改嫁、开钟除名，兑=时限内反杀，最好提前当众完成。 |
| R14-05 | 第二档（能撑一个打脸单元 5-8 章）：5.退婚/替婚——归属+面子+资源一起掀，兑=后悔药分级、不复合；6.背叛——兄弟交情报、师兄抢机缘、未婚妻带路，硬条件：开局给过共享动机，否则像作者变脸，兑=清算不当场和解；7.努力作废——闭关成果被废丹、积分被改、功劳记在别人名下，兑=物证翻案+对方当众丢人；8.功为他人做嫁衣——主角挡灾/炼丹/破阵好处归天才，兑=下次让对方自己上当场翻车，或把契约锁回去。 |
| R14-06 | 第三档（一卷一把，慎用，兑得必须更狠）：9.亲情偏心——家族养嫡废庶、父母把主角当聘礼，男频禁止写成哭戏，兑=断供、除名、把资源从家里搬空，主角不回头跪；10.牺牲不被看见——挡刀没人信、背锅洗不白，兑=解释权易手，靠结果不能靠哭诉；11.关键人物重伤/死——师父、引路人、唯一善待他的人，这是最险的刀，兑=仇必须具名、必须在本卷内第一次见血、禁止"先变强十年再报仇"；12.身份当货物——替嫁、联姻、炉鼎、祭品，人被标价，兑=婚书/契约/祭名单改写、定价的人破产。 |
| R14-07 | 男频默认删掉的三种：13.误解虐（他不解释她误会，男频杀伐文里这是假冲突）、14.虐恋拉扯（爱而不得）、15.洗白虐（让读者心疼反派，男频会把打脸写软）。男频要用 13，只能虐场上误解、读者已知，读者跟主角一起憋，禁止跟主角一起傻。 |

### 七、虐点·写作硬规则 N01-N14（report 14）

| 编号 | 规则（祈使句） |
|---|---|
| N01（R14-08） | 必须先开讨债票，再下刀：写虐前必须能填欠债人、兑付章、拿回什么；填不出就不要虐。 |
| N02（R14-09） | 损失必须落地："小心我废了你"不是虐；丹砸了、籍除了、婚书撕了、人倒下了，才是虐。 |
| N03（R14-10） | 虐完当章至少兑一角：番茄=本章虐、本章最小翻盘（挡下致命、拿回信物、金手指亮齿）；禁止连续 2 章纯虐 0 兑。 |
| N04（R14-11） | 读者希望不能虐死：可以虐处境，禁止虐金手指报废、虐主角永久降智、虐到读者觉得"这书没盼头"；信息前置那颗齿必须留着。 |
| N05（R14-12） | 不虐主角智商：能躲不躲、能说死不解释还导致误伤无辜、明知是局还送人头——读者虐的是作者。 |
| N06（R14-13） | 不虐主角人设：杀伐被虐完变跪舔，装逼被虐完变哭包；虐的是局面，禁止改性格。 |
| N07（R14-14） | 欠债人必须具名、必须有脸：禁止虐天道、虐命运、虐"大环境"（读者无处出气）；刀必须砍在具体人/具体规则上。 |
| N08（R14-15） | 亲情刀在男频必须兑成断，不兑成跪：父母偏心→主角断供离开、把账算清；禁止哭回家族、禁止"他们是我爸妈"。 |
| N09（R14-16） | 死人刀必须本卷见血：师父死于第 8 章，仇人最晚第 30 章必须付出不可逆代价（废、死、夺权）；拖过一卷，刀就臭了。 |
| N10（R14-17） | 一把刀只砍一次完整形状：同一句废物、同一套退婚羞辱、同一个哥哥抢功，最多一个单元；下一刀必须升级标的。 |
| N11（R14-18） | 虐的观众必须比对手高：没有更高见证者，余震和上报都没有，这刀兑不干净。 |
| N12（R14-19） | 禁止用虐拖字数：内伤描写、夜哭、回忆童年，单段≤200字；情绪必须用动作：手、停顿、把东西放下。 |
| N13（R14-20） | 比例锁：章内加压≤60%，必须留 30% 给兑现；单元（5-8 章）虐:兑≈1:1，禁止 5:1；卷可以有一次第三档大刀，但必须配一次破规则级释放。【冲突并列保留：同报告锁死段写作"每卷第二档大刀<1必须配破规则级释放"（OCR 原文如此），档位表述与 N13 的"第三档"不一致，两条并列保留】 |
| N14（R14-21） | 刀口必须对准"他以为自己赢了"：最好的虐是对方得手的那一瞬（名额改了、婚书撕了、丹碎了）；读者恨的是那张脸，不是天气。 |

### 八、热梗·原则与密度（report 19）

| 编号 | 规则（祈使句） |
|---|---|
| R19-01 | 热梗必须拆成"态度结构"再嵌进打脸、装逼、震惊里；禁止让角色直接说原梗词。原词能出戏，结构能加分。 |
| R19-02 | 能进对话的梗必须三问全过才写进台词：①功能对得上（这一句在干嘛：嘲、装、震惊、认栽、真香、赶人；干不了活=装饰，删）②人设说得出口（遮住名字还是这个人吗；杀伐主角和系统、跟班禁止同一张嘴）③读者会不会出戏（宗门外门说「尊嘟假嘟」=穿帮；都市 intern 说可以［OCR 存疑：应为 intern/网络人士］）。 |
| R19-03 + R19-42（合同 3） | 每章最多 1 个明梗（读者能听出是梗）+ 最多 2 个结构梗（态度同构，原词不出现）；合同版重申：每章最多 1 句明梗、2 句结构梗，打脸爆发段（≤200字）禁止梗。（同义合并） |
| R19-04 + R19-05 + R19-21（M03） | 禁止在打脸爆发段堆梗/插梗：拍 3 爆发里禁止插梗（会把一招制敌冲成段子）；爆发≤200字里不准梗；梗只能放在拍 4 余震或离场句。（同义合并：R19-04、R19-05、R19-21/M03 三条合并） |
| R19-06 | 打脸余震里，梗的正确形态必须是第二层震惊台词，禁止用弹幕。 |

## 爽文反转（与悬疑反转的区别/三分类/四拍/八种类型/假反转对照；完整公式保留）

### 与悬疑反转的区别

- 悬疑骗的是"事实本身"，长期把读者放在信息最底层；爽文反转禁止长期读者<全场（那是悬疑，番茄爽文会掉完读）（F02）。
- 爽文必须方向不骗：承诺"他会翻"，只骗幅度和方式；禁止让主角突然惨死当主高潮（那是虐文）（F01）。
- 骗事实的认知反转必须限量：配比只占 10%、一卷最多一次大的，用多了读者不敢期待、追读会掉（R13-02、R13-03）。
- 爽文的信息前置是命门：读者知道一点底牌，压制段才从纯受虐变成期待（R13-06）。

### 三分类（R13-01/02/03）

| 类型 | 骗谁 | 读者感受 | 定位与用途 | 配比 |
|---|---|---|---|---|
| 信息差反转 | 场上的人被骗 | "我就等这下" | 主力，用于扮猪吃虎、退婚现场 | 60% |
| 加码反转 | 骗读者幅度 | "比我想的还狠" | 每场打脸的第二刀 | 30% |
| 认知反转 | 骗读者事实 | "原来不是那样" | 少用，用于隐藏层、内鬼、更大棋盘；一卷最多一次大的 | 10% |

### 四拍（R13-05/06/07）

- 必须走通用四拍：信息前置→压制→拉扯→反击（和硬冲突、打脸是同一套骨头）。
- 前置=让读者先知道底牌一角，建立"等着吧"；只露齿（身份一句、面板一行灰、信物一个印），禁止把反转内容讲完。
- 压制=对手按错误信念作死，读者憋。
- 拉扯=对手再加码、主角不解释，更憋更确定要炸。
- 反击=短爆发，揭的是结果不是说明书。
- 揭开时机必须是压力最高、对手话最满、观众最齐的那一秒；最佳落点是对手那句羞辱说完、动作还没收回；禁止回房再揭，禁止章末用旁白揭。

### 八种反转类型（R13-08~R13-16）

| 类型 | 用法 | 硬约束 |
|---|---|---|
| 身份反转（掉马） | 场上以为是 X 其实是 Y | Y 必须比 X 高至少两级（X=废物/赘婿/杂役→Y=战神/供奉/真传私生子）；揭法只能靠别人来接、令牌、一声称呼，禁止靠自己报家门；必须共享底层动机：装废是为了躲因果/完成托付，不是为了挨骂，否则读者觉得主角犯贱 |
| 实力反转 | 境界数字对不上（炼气打筑基） | 必须有可见对照：护体裂、一口血、旁人喊境界 |
| 规则反转 | 对方拿来压你的规矩当场砸到他脸上（"杂役不可还口"→点名册上他才是被除名的那个；"退婚需长老公证"→公证权在主角手里） | 卷高潮最硬的一种，打的是地图不只是人 |
| 因果反转（将计就计） | 对手设的套是主角要的燃料（"他们要当众废你→你要的就是当众→金手指只在观众面前计价"；读者已知"装逼值看见证者境界"，对手把长老请来=自己把燃料送到嘴边） | 打完点一句燃料入账，不要解说策略 |
| 对象反转 | 骂的人、抢的人、退婚的人，打的不是他们以为的那个（当众羞辱杂役，回廊里放下茶杯的才是他要见的人；替婚女不是庶女，婚书上的印是皇女） | — |
| 立场反转 | 友变敌、敌变债 | 爽文里友变敌比洗白更有用，洗白容易圣母；底层动机开局就要有一条；纯两肋插刀的兄弟后期背刺=人设崩，不是反转 |
| 金手指隐藏层反转 | 旧用法失败→新动词亮灯 | 认知反转的合法配额，必须按隐藏层节点出，禁止随便加 |
| 态度反转（反套路） | 读者以为要打脸，主角不接、先走、先退婚、把场子留给对方自己崩（对方等他解释→他问"聘礼今晚送还是我去取"→离场；打脸发生在下一章，由对方的新对象/父母完成） | 打破"每章必对线"的疲劳；一单元最多一次，否则读者会觉得主角不还手 |

- 一次只能用一种主反转，辅反转最多加码一刀（R13-08）。

## 爽文虐点（三要素定性/12种虐点三档/毒虐对照/虐是燃料不是产品）

### 三要素定性（R14-01/R14-02）

- 爽文虐点=已落地的不可逆损失+明确欠债人+可执行的讨债票，三件缺一不可：缺损失落地=软虐加压不够；缺欠债人=虐命运虐作者、读者恨书；缺讨债票=白挨、虐文或弃书。
- 必须把刀抽出来砍到该还债的人身上：写完一场虐，必须能指出哪一章、砍谁、拿回什么；指不出来就是写成虐文了。
- 下刀前必须先开讨债票：必须能填欠债人、兑付章、拿回什么；填不出就不要虐（N01）。

### 虐是燃料不是产品（R14-03 + N04）

- 虐点不是独立剧情，是硬冲突的加压段存货：爽=压力积累×释放满足×反差程度；虐负责压力，反转打脸负责释放，金手指负责讨债手段。
- 燃料不能烧光读者的盼头：可以虐处境，禁止虐金手指报废、虐主角永久降智、虐到读者觉得"这书没盼头"；信息前置那颗齿必须留着（N04）。
- 虐完必须当章兑一角（N03），比例锁章内加压≤60%、单元虐:兑≈1:1（N13）——燃料是拿来烧的，不是拿来存的。

## 热梗运用（态度结构拆解/外挂梗池/转写层/人设过滤器）

### 态度结构拆解

- 热梗=情绪压缩包：必须拆成"态度结构"再嵌进打脸、装逼、震惊里；禁止让角色直接说原梗词。原词能出戏，结构能加分（R19-01）。
- 能进对话的梗必须三问全过才写进台词（R19-02）：①功能对得上（这一句在干嘛：嘲、装、震惊、认栽、真香、赶人；干不了活=装饰，删）②人设说得出口（遮住名字还是这个人吗；杀伐主角和系统、跟班禁止同一张嘴）③读者会不会出戏（宗门外门说「尊嘟假嘟」=穿帮；都市 intern 说可以［OCR 存疑：应为 intern/网络人士］）。
- 功能清单必须先拆：嘲/装/震惊/认栽/真香/赶人/自嘲（R19-15）。
- 密度：每章最多 1 个明梗+最多 2 个结构梗（R19-03/42）；打脸爆发段禁止堆梗/插梗，梗只能放拍 4 余震或离场句（R19-04/05/21）；余震里梗的正确形态是第二层震惊台词，不是弹幕（R19-06）。
- 出口必须与打脸四拍对齐：拍 1 反派嘲讽←可接「你也配」结构；拍 4 余震←路人「这谁啊」结构；离场←主角一句短的，或系统一句（R19-14）。

### 外挂梗池（AI 自动接梗不靠模型记忆）

- AI 自动接梗必须外挂三件一套：梗池+转写层+人设过滤器；禁止指望模型"记得"（模型有截止时间，会把 2023 的梗当新的）；禁止用训练记忆里的「网络流行语」直接当新梗；只允许使用用户消息【本周梗池】和长青结构：你也配、这谁啊、真香、不解释离场、原句奉还、退（R19-29/40）。
- 梗池来源只盯中文区，禁止混 Reddit：微博热搜/抖音热榜评论区口头禅、B 站弹幕高频词、小红书/贴吧「XX梗」、搜「2026网络热梗/本周热梗」（R19-30）。
- 每条梗必须写成标准卡（id、原梗、功能、结构、明梗可用、玄幻转写、出口、位置、过期、禁用）；丢给模型的必须是卡，禁止给通稿（R19-31）。
- 长青结构梗（可写进 System，不依赖热点）：你也配、这谁啊、真香、不解释离场、退、原句奉还（R19-32）。
- 时事梗只进【本周梗池】，写完一章就作废，禁止沉淀进人物口头禅（R19-33）。
- 微调模型接梗不划算，梗衰变太快（R19-34）。
- 能联网的模型（元宝等）写章前必须先搜索"微博本周热梗、B 站弹幕热词、2026网络流行语"再填池：只保留能标注「功能+结构」的梗，丢掉新闻事件本身；每条输出一张梗卡，过期高的只保留结构；然后才写本章。不能联网的模型，每周贴 10 条卡进用户消息（R19-35/38）。
- 写章时用户消息每章必须带强制槽位：【本周梗池】贴 5-10 条卡、【本章允许出口】、【本章禁用原词（过期表）】、【本章最多明梗】1（R19-36）。
- 模型必须先输出「本场用梗计划」再写正文：明梗=哪条→谁说→哪一拍；结构梗 1/2=功能→转写句；不用的池内梗列出，防止硬塞（合同版：写正文前先输出【本场用梗计划】四行）；删掉梗打脸仍成立才保留（R19-37/45）。
- 禁止把热搜事件写进剧情（那是时事植入，不是玩梗）；热搜人物、惨案、政治，一律当违禁，只借句式（R19-39）。

### 转写层

- 禁止把热词直接贴上去；必须先拆功能，再按出口转写（R19-15）。
- 转写公式（R19-16）：明梗=原词（只给系统或都市）；结构梗=保留节奏和态度，替换名词为世界词；动作梗=不说话，用梗对应的动作（真香=对方来求；退退退=让位离场）。
- 世界观转写必须改用词、保留结构（R19-17）；过期风险高的梗只保留结构，禁止用原词（R19-18）。

### 人设过滤器（出口白名单）

- 出口白名单（R19-07~R19-12，合同版 R19-43 同此）：系统面板是唯一合法说「6」「哈人」的地方；穿越/重生者内心可用明梗但禁止说出口（OS 一行，台上仍用世界词）；跟班/路人震惊层只能用结构梗（这谁啊、不可能），必须转成「他是炼气？」「把名籍给我」；反派嘲讽必须落到身份+资源，禁止空骂；主角离场只能用结构梗（真香等着、不解释），必须动作化：把茶喝完、把扫帚靠墙；女主/长老基本不玩梗，一玩就崩身份。
- 平台差异（R19-13）：番茄都市/脑洞可以明梗；传统玄幻默认只走结构梗+系统明梗；起点老白少梗，梗会显得作者在刷存在感。
- 对话硬规则 M01-M10（M03 已并入「爆发段禁梗」条目）：M01 梗必须服务冲突，不服务作者秀——删掉这句，打脸还成立，才留下；M02 一章一张明梗嘴；M04 过期明梗禁用（yyds、绝绝子、尊嘟假嘟、栓Q、破防当口头禅、遥遥领先、绝了、家人们；出现则改写；唯一例外——除非讽刺过时的穿越者）；M05 反派嘲讽必须落到标的，禁止「废物」+乱码热词；M06 全员禁止同一语感——系统可以贱，长老必须板；M07 谐音梗（雨女无瓜、夺笋）进玄幻几乎必出戏，都市也要角色配得上土；M08 违禁、拿惨案玩、拿现实政治玩的梗一律禁止进正文；M09 同一结构全书必须限频——「你也配」当退婚原句可以反复奉还，「这谁啊」每章必须换说法；M10 明梗优先顺序：先系统面板，其次 OS，最后才是角色出声。
- 遮住名字仍能认出说话人：系统语感和人物语感禁止混同（R19-46）。

### report 13：反转十套公式

- **公式1 反转卡（每场必填，填不完不准写爆发段）**：主类型（信息差/加码/认知八选一细分）；场上错误信念（一句话）；读者已知多少（齿）；对手靠这个信念要抢的标的；观众（含一个更高层）；揭开物证（令牌/名册/数字/一声称呼）；揭开动作（≤200字）；局面改了什么（名分/资源/阶层/解释权）；新债；下一场禁止再用的类型。
- **公式2 信息差主循环（章级默认）**：前置（读者看到齿：面板灰行/来接的人在门外）→压制（对手当众按 X 羞辱）→拉扯（主角不解释，对手加码：倒计时、再夺一样东西）→反击（用物证把 X 打成 Y）→余震（近→远→权威）→新债（权威把这件事上报）。
- **公式3 加码公式**：读者预期的反转结果=N，实际揭开=N+1（高一级身份/多一个标的/多一个见证者）；禁止 N+5（一次揭完）。例：预期"他有内门后台"→加码"来接的人喊供奉，后台是宗门那尊不露面的"→再留齿"供奉看了一眼他手腕上的印，没出声"。
- **公式4 掉马三件套**：1.物证先于口；2.别人先开口（来接的人、系统、长老）；3.主角仍不解释，做无关的事（喝茶、扫地、收聘礼单）。自己报"其实我是战神"是最弱掉马。
- **公式5 规则反转**：对手引用规则 R 压主角→主角不辩 R 对不对→亮出 R 的适用条件/公证权/例外条款→R 当场套到对手头上→观众被迫按 R 改口。例：退婚需三长老画押。两长老在，第三押是主角昨晚刚拿到的供奉令。
- **公式6 将计就计**：对手的杀招=金手指的燃料→读者已知燃料公式→对手越把场面做大，反击越便宜→打完点一句燃料入账，不要解说策略。
- **公式7 关系反转（慎用）**：开局给一条共享动机（家族/任务/活命）→中期 3 齿（重复动作、反常护短、一句当时不像反话的话）→揭晓卡在"刚为他拼命"之后→揭晓后不准立刻和解，先变成债。友变敌：爽在被骗后的清算。敌变友：爽文里很弱，除非对方立刻献上硬资源，且主角不心软。
- **公式8 章末反转钩子**：反转可以打在章中爆发，也可以打在最后 100 字。章末只用半揭：全揭=本章释放下章写余震和债；半揭=物证亮了、称呼被打断（"见过——"门开了）。番茄更吃半揭当钩子，但本章必须已经有一次小兑现，不能整章只压不给。
- **公式9 三步埋线（认知反转专用，卷级）**：第一步齿：提前 8-20 章塞 3 处，读者不当真；第二步误导：用配角观点帮读者建错误第一印象（不写反事实）；第三步命题句：反转前一章末放一句可回看的话。例："这枚印，和退婚那天婚书上的灰烬是同一个。"揭晓靠关键事件强迫切换，不靠回忆杀讲课。番茄不要"提前50章"，免费读者记不住。
- **公式10 反转密度**：每章 1 次微反转（小打脸/小加码）；每 5-8 章 1 次单元反转（身份齿或规则）；每卷 1 次认知大反转（隐藏层或内棋盘）；禁止每章都"你不知道的是"。
- **衔接·和前面三套系统怎么接（report 13 P10，覆核补录）**：硬冲突提供「桌上那件不可让的东西」；退婚/替婚提供开局现成的错误信念（他配不上）；金手指隐藏层提供加码和认知反转的弹药；反转是把错误信念当众折断的那一刀。所以反转不是第三套剧情，是冲突的释放段写法。退婚场：场上信念=他配不上，反转=婚书/聘礼/供奉令把「配不上」折断；隐藏层：场上信念=金手指只会掉垃圾，反转=这回掉的是规则本身。

### report 14：虐点九套公式（含公式 7b）

- **公式1 虐点总公式**：虐=落地损失×当众×倒计时×欠债人清晰度；兑=同一观众+原句奉还或加一级剥夺+新债；虐完不兑，分母是 0。
- **公式2 虐点卡（下刀前填）**：这刀类型（1-12 选）；落地损失（已经发生）；欠债人（姓名/身份/他图什么）；观众（含更高层）；倒计时；主角态度动作（不解释、不跪）；当章最小兑（哪一角）；单元兑（第几章、拿回什么）；卷兑（如需）；下一刀禁止重复的形状。
- **公式3 先虐后爽四拍（章级）**：拍 1 得手（对方把标的拿走，虐落地）→拍 2 加码（再当众踩一脚/倒计时缩短）→拍 3 齿（金手指或身份露一角，读者有盼）→拍 4 兑一角（挡致命/改回一个数字/跟班裂开）；章末=新债（更高层看见或对方新婚期）。拍 3 不能省——没有齿的纯虐，免费读者第二轮就不跟了。
- **公式4 讨债票**：欠条=【谁】在【场合】拿走了【什么】，说了【原句】；兑付=在【同一或更高场合】用【物证/一招/规则】让他失去【原物或+1级】；奉还=把原句还回去，然后离场；禁止教育、原谅、把东西还他以德报怨。
- **公式5 虐点升级（防复读）**：同一仇链往上走，不要换沙包：跟班羞辱→执事剥夺→真传退婚→长老动规则→家族除名；损失：面子→名额→归属→本图资格→血脉/供奉；每一级的兑，必须让上一层的人看见自己算错。
- **公式6 死人刀（第三档）**：死者必须给过主角不可替代的一样东西（名额、功法齿、一句人话）；死因必须是具名仇人的选择，不是天灾；主角反应短、动作化（收遗物、把灯吹了、去排队），禁止哭章；第一次讨债本卷内必须见血或废；余债可以留到下图，但本卷不能 0 兑。
- **公式7 亲情刀（男频）**：偏心必须有账本（钱、丹、名额、婚约，写成数字）；主角不辩论谁亲；当章动作=把账本合上/把钥匙放下/把宗门籍自己划掉；兑=资源搬空或关系断干净；禁止年夜饭感化、临终和解当高潮。
- **公式7b 背叛刀**：开局一条共享动机（家族/活命/任务）；3 齿（反常的手、晚到的援、一句当时不像反话）；揭晓卡在"刚为他拼命"之后；兑=清算资源与解释权，不听理由；理由可以有，给读者看，不给主角改决定。
- **公式8 密度**：每章 1 个第一档虐（羞辱/剥夺）+当章最小兑；每 5-8 章 1 个第二档虐单元闭环；每卷最多 1 个第三档大刀且必须配破规则释放；禁止连续 2 章 0 兑现；禁止开局 10 章只虐不亮金手指。番茄读者忍虐的窗口很短，飞卢更短，起点可以多压几章但爆发必须更狠。
- **公式9 虐的写法（怎么写惨又不写成哭戏）**：只写物件和手续（婚书两半、名册一笔墨、丹粉在地上、灯灭）；羞辱台词≥3 句，具体到身份和资源；主角写手、走位、把东西放回桌上；内心 OS≤3 行；旁人反应 1-2 个，留一个更高层给余震；惨在手续里，不在形容词里。

### 锁死段（可贴 System Prompt）

**反转合同（report 13）：**
爽文反转默认信息差（读者已知≥主角>场上），加码为辅，认知大反转每卷≤1；方向不骗（逆境转顺境），只骗幅度和方式；每场先填反转卡（错误信念、读者已知齿、物证、≤200字揭开动作、局面改什么、新债）；揭开靠物证和别人开口，禁止主角演讲报身份；必须当众；必须改名分/资源/阶层/解释权之一；人设不随反转改变；连续 3 章禁止同一反转类型；伏笔至少 3 齿，只可"不完整"不可"写反"；假死/梦境/全员卧底全书各限 1 次。

**虐点合同（report 14）：**
爽文虐=落地损失+具名欠债人+讨债票，缺一不准下刀；本章虐必须本章最小兑，禁止连续 2 章纯虐；不虐主角智商、不虐人设、不虐金手指报废，读者希望必须留齿；亲情刀兑成断不兑成跪；死人刀本卷见血；背叛开局就要有共享动机；虐写物件和手续，不写哭和回忆；羞辱≥3 句，OS≤3 行；一把刀只砍一次完整形状，下一刀升级标的；每卷第二档大刀<1 必须配破规则级释放（原文如此；与 N13"第三档"表述冲突，并列保留）。

**热梗合同（report 19，System 段 7 条）：**
1. 禁止用训练记忆里的「网络流行语」直接当新梗。只允许使用用户消息【本周梗池】和长青结构：你也配、这谁啊、真香、不解释离场、原句奉还、退。
2. 先拆功能再进对话。原词默认不出口；玄幻只许系统面板出现原词。
3. 每章最多 1 句明梗、2 句结构梗。打脸爆发段（≤200字）禁止梗。
4. 出口白名单：系统可贱；路人只震惊；反派嘲讽必须落到身份+资源；主角最多一句离场或全用动作；长老/女主不玩梗。
5. 过期明梗禁用：yyds、绝绝子、尊嘟假嘟、栓Q、破防当口头禅、遥遥领先、绝了、家人们。出现则改写。
6. 写正文前先输出【本场用梗计划】四行，再写正文。删掉梗打脸仍成立才保留。
7. 遮住名字仍能认出说话人。系统语感和人物语感禁止混同。

## 禁忌与反例

### 假反转对照（report 13，全文见「爽文反转」节）

无前置→至少 3 齿且不写反；自己报身份→别人来接、物证先开口；揭开太长→砍到 200 字余震给观众；无观众→改到宴席点名台；不改局面→当场改名册/婚书/规则；人设跟着转→只转认知不转态度；幅度一次揭完→+1 级留齿；连续同型→轮换规则对象因果；假死二次→全书一次先铺解药条件；洗白无齿→开局就给共享动机否则别洗；虐向主高潮→方向必须逆境→顺境，失败只能当加压不当释放。

### 一段对照（report 13 原文）

- 软（假反转）="被骂废物他忍着，回房后作者写没人知道他是隐世家族少主，下一章出门把人打了"。
- 硬（信息差+加码）="议事堂里苏绾说完'炼气三层也配'，陆沉不接话把婚书叠好，门开了进来的人没看苏绾，把一枚青令放在石桌上只喊了一声供奉；护体裂的是她跟班；回廊里茶杯放下的人站起来——加码还没说完，那人看的不是令，是陆沉袖口一道灰印"。读者已知：他不简单；场上刚知：供奉；读者新知（齿）：印比供奉更大；局面改了：婚书还在桌上，解释权已经不在苏绾嘴里；新债：站起来的人会上报。

### 假虐/毒虐对照（report 14，全文见「爽文虐点」节）

软虐→先撕婚书先划名册；无债主→换成具体人的选择；白挨→当章最小兑；虐智商→隐忍必须有收益（燃料/不暴露）；虐人设→只虐局面；哭章→砍到物件手续；亲情跪→断、搬空；刀臭→本卷见血；复读→升级标的；虐读者希望→齿必须留下；女频刀硬塞男频→改成当众剥夺。

### 一段对照（report 14 原文）

- 软虐="未婚妻瞧不起他，他很受伤，夜里失眠，想起童年被骂废物，发誓要变强"。
- 硬虐（可兑）="婚书两半落在青石上；聘礼单被执事卷走；苏绾说'炼气三层也配写进苏家谱'，三日后另嫁内门第一人；名分当场没了。陆沉把两半对上、叠好、放回去，问聘礼今晚送还是他去取；跟班护体应声裂开——最小兑；回廊茶杯放下——讨债票已经开给更高层"。虐在：婚书、聘礼、三日、原句；兑在：裂开的护体；债在：放下的茶杯；没有失眠，没有童年。

### 一句话总结（各报告原文）

- report 13（OCR 原 PDF 第 12 页）：让全场信错，让读者先信对一点；在对方话最满、人最多的时候，用一件物证把错误信念折断，只加一级，立刻欠下一笔债。
- report 14（OCR 原 PDF 第 12 页）：先让对方把东西当众拿走，再给读者留一颗齿，当章兑一角，单元把原句和原物加一级讨回来。刀砍在人脸上，不砍在命运上，更不砍在主角的脑子上。
- report 19（规则文件原文）：梗先拆成态度，再穿进这个世界的词；原词能进系统就不能进长老的嘴。AI 不要回忆流行语，每周喂梗卡，强制先出用梗计划再写正文，过期词直接判废。
