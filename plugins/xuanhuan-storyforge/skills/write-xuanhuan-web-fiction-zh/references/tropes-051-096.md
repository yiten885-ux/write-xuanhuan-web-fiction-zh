# 爽文套路库·第二卷（T051-T096）
> 字段说明：本库每条套路按统一字段组织——HARD（硬规则）/ FORMULA（公式）/ VISIBLE（验收可视化）；对应套路系统字段 WHEN/HARD/FORMULA(PRESS→PAYOFF→HOOK→VISIBLE)/BAN/STACK，其中 BAN 与 STACK 由全局合同与配方文件管理。

## 第五批 关系（T051-T060）

### T051 退婚真香：原句奉还，不接
- HARD（硬规则）：必须对得上退婚原句。分级：跟班 → 本人私下 → 父母带利益 → 新对象翻脸。第三章不准跪完。不教育、不复合。
- FORMULA（公式）：对方带资源来求 → 他把原句还回去 → 只要被拿走的那份，不多要人情 → 走 → 对方更高层看见求失败。
- VISIBLE（验收）：关系未复合，资源可收，解释权仍在他。

### T052 倒贴只收情报或资源，不收人
- HARD（硬规则）：倒贴要有对方的目的（靠山、功法、逃命）。男主定价：情报、路引、证人。禁止收房。
- FORMULA（公式）：对方献身/求跟 → 他问三件事（谁主使、令在哪、下一刀谁来）→ 给最低保护或给一个过路权 → 钩：倒贴者被自己人灭口。
- VISIBLE（验收）：情报入账，人不入队也可。

### T053 联姻对象发现你是他们要灭的余孽
- HARD（硬规则）：联姻先当众推进，再对上灭门令。发现后对方阵营分裂：有人要杀、有人要用。男主不求「看在婚约份上」。
- FORMULA（公式）：联姻仪式或换帖 → 印对上灭门令 → 宴席变刑场 → 他用婚书/令卡住当场杀局 → 钩：联姻家主向上报余孽。
- VISIBLE（验收）：婚约成刀，不是甜，杀局升级。

### T054 上门被打的天才跪求收徒
- HARD（硬规则）：先打脸再跪。男主可收可拒，收了也是工具徒不是温情。禁止收徒后变成奶爸文。
- FORMULA（公式）：天才上门踩 → 被打裂 → 求师 → 他开条件（情报、名额、当证人）→ 钩：天才的旧师门来问罪。
- VISIBLE（验收）：强弱易位，师门债起来。

### T055 当年拒你的师父回来请你开坛
- HARD（硬规则）：必须能奉还「朽木不可雕」。开坛是资源（堂口、功法、保护），不是父子情。可拒。
- FORMULA（公式）：师父当众请 → 原句奉还 → 只收银或只借堂口打下一场 → 走 → 钩：师门内有人反对请他，要下毒。
- VISIBLE（验收）：面子真香完成，师徒名分不必定。

### T056 灭门分赃的发小是名单第二层
- HARD（硬规则）：开局给共享动机齿（发小得了你家的地或婚）。揭完必须兑，禁止「看在小时候」。
- FORMULA（公式）：发小以故人身份靠近 → 用你家的东西装逼或劝你认命 → 物证对上分赃名单 → 当众兑一笔（夺回地或废他）→ 钩：分赃名单下一行。
- VISIBLE（验收）：兄弟情死亡，名单前进。

### T057 余脉人质加压（护短不养成）
- HARD（硬规则）：幼弟/家仆是加压物和态度对照：对弱者短、对仇人绝。禁止养成日常。禁止为救人放过主仇。
- FORMULA（公式）：仇人绑余脉当众要挟 → 男主表面可让一寸手续 → 短手救人同时记原句 → 余脉安置后立刻反击 → 钩：仇人发现余脉是诱饵或还有下一脉。
- VISIBLE（验收）：人救出或未全救出都要让仇人出血，主线不改成保姆。

### T058 女神当众认错，你喝茶走
- HARD（硬规则）：认错必须当众，必须有原句对照。男主不原谅演讲。茶喝完是离场辅货。禁止认错后感情线起飞。
- FORMULA（公式）：她当众道歉/澄清 → 他喝完茶或把杯子放下 → 只要被夺走的名/物 → 走 → 钩：她的阵营因她认错内裂，或她被罚来杀他。
- VISIBLE（验收）：舆论改一寸，人不回收。

### T059 双修邀请当众提出，功法反客为主（资源货）
- HARD（硬规则）：邀请是羞辱或算计（吸他、绑他、当众污名）。反客是阵法/功法抽气机，不写色情。事后不收她。
- FORMULA（公式）：当众提出双修羞辱 → 他应下并动手 → 功法反客，对方气机被抽或秘密被照出来 → 离场 → 钩：双修宗要拿人。
- VISIBLE（验收）：污名反套，功法秘密成齿。

### T060 美人计：她来盗令，令认主锁她
- HARD（硬规则）：她必须有盗令任务和主使。锁住是令的规则，不是爱情。可留活口当证人。禁止感化。
- FORMULA（公式）：接近、盗令 → 令认主反锁或反噬暴露主使印 → 她被迫开口一个名字 → 钩：主使弃子灭口。
- VISIBLE（验收）：令还在，主使名字进债务账。

## 第六批 复仇（T061-T070）

### T061 开局灭门，当夜废现场刀
- HARD（硬规则）：灭门手续化（划谱、点火、收令）。现场刀具名。当章最小兑现：废或逃过现场刀之一。禁止三章纯哭。禁止第三章屠幕后。
- FORMULA（公式）：祠堂/城门划谱点火 → 独苗因具体原因没死成 → 金手指改「今夜必死」→ 现场刀之一废 → 钩：名单第一行还活着。
- VISIBLE（验收）：族灭已成事实，他活着且欠条成立。

### T062 名单流：残谱每兑一人亮一笔
- HARD（硬规则）：名单读者可知。每笔当众兑，升档，不要打卡游戏。一次只亮一层。
- FORMULA（公式）：仇人当众得意 → 对上残谱这一行 → 短兑（废、夺籍、夺地）→ 谱亮一字或一印 → 钩：上一层看见谱亮了。
- VISIBLE（验收）：进度条可见，幕后未亮完。

### T063 以律还律：连坐套回下令者
- HARD（硬规则）：先撞墙（律确实压过他）。不辩律对不对。亮适用条件或证据权。套回去改的是名籍香火，可比砍人更硬。仍可有杀，但不靠演讲。
- FORMULA（公式）：对方宣读连坐 → 他亮证据在对方府上或亮令的条件权 → 律套回去 → 下令者名籍裂一寸 → 钩：写这条律的人要收回解释权。
- VISIBLE（验收）：同一条律两边可见，解释权开始易手。

### T064 仇人拿你家婚书或令装逼被拆
- HARD（硬规则）：物必须是你家的。装逼场合要大。拆是认主或对印，不是吵架。
- FORMULA（公式）：宴上举你家令/婚书吹 → 对印或抽回 → 原句噎回去 → 更高层问这物怎么到他手。
- VISIBLE（验收）：物回或物反噬，分赃链暴露一环。

### T065 内应揭完本卷必须见血，不和解
- HARD（硬规则）：开局埋三齿（手、印不对、少一具）。揭完清算，禁止误会和解。见血指内应废或死或夺籍，不可逆。
- FORMULA（公式）：齿齐 → 当众对质物证 → 内应还想认兄弟 → 短兑不可逆 → 钩：内应上面还有给过他刀的人。
- VISIBLE（验收）：内应退出棋盘，上一层暴露。

### T066 坟前宴你坐主位
- HARD（硬规则）：仇人必须正在用你全家的祭礼装善或装胜。你坐主位是掉马加复仇，不是哭坟。
- FORMULA（公式）：仇人祭你全家、念假悼词 → 你入席坐主位或把祭文改一字 → 全场崩 → 最小见血或夺祭器 → 钩：真正的灭门令在祭器底下。
- VISIBLE（验收）：祭权易手，悼词原句可还。

### T067 同一块青石把族谱改回去
- HARD（硬规则）：地点对照：开局划谱的同一块石。改回去只改一笔或一个名，不要全族复活式改完。观众要有当年笑过的人。
- FORMULA（公式）：回到祠堂青石 → 仇人阻止 → 印/血/令改回一笔 → 当年观众改口 → 钩：族地契约跟着谱走，下一笔在矿上。
- VISIBLE（验收）：空间反差成立，谱未一次改完。

### T068 真香五级：跟班→本人→父母→新靠山→解释权易手
- HARD（硬规则）：一级一次，禁止一天五级。每级对方再丢真资源。男主反应锁死：原句+走。第五级是场子易手，不是复合。
- FORMULA（公式）：按级来求 → 还原句 → 收被拿走的那档资源 → 走 → 下一级在钩里出现。
- VISIBLE（验收）：级次记录在账上，不许跳级跪齐。

### T069 仇家用你家祠堂祭天，你收回香火
- HARD（硬规则）：香火/牌位/供奉位是标的。收回要当众改牌或改香。这是规则复仇的一种。
- FORMULA（公式）：仇家在你家祠堂祭他们的天 → 你亮家印，香火不认他们 → 牌位裂或改字 → 他们的气运/面子裂 → 钩：宗门供奉系统报警。
- VISIBLE（验收）：香火权易手一寸。

### T070 灭门夜原句「叛宗当诛」当众奉还
- HARD（硬规则）：原句必须在灭门夜出现过。奉还场合要同等或更高。奉还时同步执行律或刀，不要只嘴还。
- FORMULA（公式）：仇人再当众说同类话或正在用这条律 → 他复述灭门夜原句 → 律/刀落到说话人身上 → 观众听见同一句换了对象。
- VISIBLE（验收）：原句闭环，说话人不可逆受损。

## 第七批 规则（T071-T078）

### T071 名册除名反套到执事自己
- HARD（硬规则）：执事必须先动笔。反套要有权（令、印、更高公证）。名册转过来是物证，不靠口才。
- FORMULA（公式）：执事勾他的名 → 令或印压上 → 名册最后一行变成执事 → 堂上乱 → 钩：谁给过执事勾名的权。
- VISIBLE（验收）：他的名还在或勾废，执事的名裂。

### T072 退婚缺末押，律上未废
- HARD（硬规则）：退婚规则开场就要用冲突教给读者（需要契押）。高潮是令压空位烫印。假高潮只放下令，真高潮才烫成末押。
- FORMULA（公式）：撕婚书 → 点押发现缺一 → 令压空位 → 空位烫印 → 回廊人看印。
- VISIBLE（验收）：婚书在律上未废，定义权暂不在退婚者嘴里。

### T073 杂役禁言律，对方先开口违律
- HARD（硬规则）：禁言律先压过男主（他真的不能还口）。他不辩，让对方多说。违律的罚落到对方。
- FORMULA（公式）：宣布杂役不可还口 → 对方当众辱到具体规则禁区（辱宗、辱令、妄点名册）→ 执法被动用 → 对方受罚 → 他仍可不说话离场。
- VISIBLE（验收）：律打的是开口的人，男主没靠对骂赢。

### T074 大比只认击碎护体，不认境界
- HARD（硬规则）：规则要赛前当众宣读。仇人靠境界压人。男主按规则打碎护体。裁判必须改口。
- FORMULA（公式）：宣读规则 → 对方秀境界羞辱 → 一招护体碎 → 榜按规则改名 → 钩：有人要改规则重赛。
- VISIBLE（验收）：名次按规则成立，改规则的人成新债。

### T075 公证堂：文件大于嘴
- HARD（硬规则）：谁先定义「你是废物/婚书作废」用嘴。男主摊开文件、当场的人、谁有权签字。人输给文件。
- FORMULA（公式）：对方先定义 → 文件上桌（婚书、名册、令）→ 公证按文件改口 → 对方定义作废 → 钩：伪造文件或更高公证来抢权。
- VISIBLE（验收）：解释权改到文件，嘴失效。

### T076 连坐证据在下令者府上
- HARD（硬规则）：证据要可出示（账、血衣、密令）。搜出来要当众。下令者会灭证，所以要有倒计时。
- FORMULA（公式）：被安叛宗 → 证据指向下令者府 → 当众翻出或让公证去翻 → 连坐反咬 → 钩：写密令的印还在。
- VISIBLE（验收）：叛宗名落到下令者一寸，印未揭完。

### T077 赌约写进宗门律，输者脱籍
- HARD（硬规则）：必须真写进律或备案，否则是空约。执行要当场。脱籍是中爽，不要开局就用。
- FORMULA（公式）：对方逼着备案 → 比试 → 执法按律脱对方籍或脱对方弟子籍 → 对方后台说律是假的 → 钩：律堂要人。
- VISIBLE（验收）：籍变动可见。

### T078 供奉令压空位，空位自己烫印
- HARD（硬规则）：空位是规则可视化。令压上去自己烫，比人盖章更硬。烫完立刻新债，不要演讲身份。
- FORMULA（公式）：末押空着 → 令压上 → 空位烫印 → 手续完成一角 → 更高层盯印。
- VISIBLE（验收）：手续可视化完成，印的来历成下一问。

## 第八批 金手指（T079-T088）

### T079 当众被否定才触发
- HARD（硬规则）：私下无效。观众是燃料。触发当章改处境。禁止无观众开大。代价：被更高层看见。
- FORMULA（公式）：当众否定（废物、除名、退婚）→ 权限亮 → 短改当场手续或反噬嘲讽者 → 灰行代价 → 钩：有人记录这次异常。
- VISIBLE（验收）：没有观众就不亮；有观众必须改桌子。

### T080 旧法失败才亮新动词
- HARD（硬规则）：旧用法必须先不够用。新动词当章实战。新代价必须付。禁止讲座解锁。一次只亮一层。
- FORMULA（公式）：旧法打在新对手上失败 → 灰行亮不超过两个字 → 当章用新动词改手续 → 过热或被看见 → 钩：新对手没死，规则更大。
- VISIBLE（验收）：新层有失败前置，说明书为零。

### T081 越级必须有对照物碎
- HARD（硬规则）：先报双方数字。越一级，不越五级。碎的是护体、兵刃、榜文或旁人喊出的境界。
- FORMULA（公式）：公布数字 → 一招 → 对照物碎 → 有人喊「他是炼气？」→ 更高层看见数字对不上。
- VISIBLE（验收）：无对照则重写。

### T082 羞辱计价，反噬到嘲讽者护体
- HARD（硬规则）：计价要可感（字数、声量、境界差），不要公式课。反噬短。嘲讽越具体越好。
- FORMULA（公式）：羞辱落地 ≥ 三句 → 计价入账 → 反噬到护体/嗓子/令 → 原句噎住 → 钩：计价被更高境界的人看见会更贵。
- VISIBLE（验收）：嘲讽者可视受伤，男主付出代价（过热、暴露）。

### T083 别人闭关三月，你一炷香破境
- HARD（硬规则）：对照必须同场或同一倒计时墙上。破境要立刻实战，禁止回房享受。只破一档。
- FORMULA（公式）：墙上三月香 vs 他的一炷香 → 香尽他破 → 当场打刚才压他的人 → 闭关归来的人错过场子。
- VISIBLE（验收）：时间反差可见，实战完成。

### T084 失败也入账，灰行计数加一
- HARD（硬规则）：本场可以输人，但不能输成白挨。失败必须改一小手续或留下齿。计数不解释。
- FORMULA（公式）：硬打失败 → 灰行 +1 或亮齿 → 他抢走一件小物或留下印 → 逃或被带走 → 钩：计数到某数会变。
- VISIBLE（验收）：读者看见进度，角色可以不懂。

### T085 本图的门只认你家的印
- HARD（硬规则）：先让别人的令打不开。他的家印打开。打开后里面是本图规则或灭门物证，不是观光。
- FORMULA（公式）：众人验令失败 → 他按印 → 门开 → 里面物证/Boss齿 → 门外有人要抢印。
- VISIBLE（验收）：权限可视化，印成为本图钥匙。

### T086 签到 / 抽卡当众出金，全场当作弊
- HARD（硬规则）：先当众失败或出白。出金要引起执法。禁止系统语音播报很长。出的金当章能用。
- FORMULA（公式）：当众抽/签，被嘲 → 出金 → 执法要没收或验作弊 → 金当章挡一击或改名册 → 钩：平台/宗门要收他的号。
- VISIBLE（验收）：作弊疑云成新债，金入局。

### T087 读心：他们密谋你当众拆
- HARD（硬规则）：读心有代价（过热、鼻血、被高境界察觉）。只拆与桌上标的有关的密谋，不读闲情。当众拆一句就打住。
- FORMULA（公式）：他们耳语密谋害他 → 他点破关键一句 → 现场崩 → 付代价 → 钩：有人开始防读心或要杀他灭口。
- VISIBLE（验收）：密谋破产，能力暴露风险上升。

### T088 预知未来，按剧本反杀第一刀
- HARD（硬规则）：预知给的是第一刀，不是全本剧透。按预知改变手续，让第一刀落到空处或反噬。禁止全知。
- FORMULA（公式）：看见自己死法/灭门第一刀 → 他改变站位或物证位置 → 第一刀落空或砍到内应 → 未来图变化一寸（灰行改字）→ 钩：改命引起修史者注意。
- VISIBLE（验收）：只改第一刀，后面仍未知。

## 第九批 场面套餐（T089-T096）

套餐硬规则（八条都吃）：按顺序拍，不许打乱成流水账；每一拍都有物在桌上；假高潮少给一档（只赢人，不赢规则）；真高潮改标的；最后一拍是更高层进场；全程不超过一单元五到八章，番茄可压进三到五章。

### T089 家宴套餐：辱 → 退婚 → 天才登场 → 叠婚书 → 令放下 → 父母改口 → 回廊看印
- HARD（硬规则）：天才不是来聊天的，要带三日婚期或名额。父母改口不等于复合。回廊的人看的是印不是惨状。
- FORMULA（公式）：羞辱三句 → 撕婚书收聘礼 → 天才进门加压 → 男主叠两半婚书（态度）→ 令或物证放下（半揭）→ 父母真香一级（改口或失语）→ 回廊茶杯放下盯印（新债）。
- VISIBLE（验收）：（原文此批未设验收字段）

### T090 大比套餐：垫底 → 点名羞辱 → 一招 → 榜首易名 → 旧主来认 → 拒 → 新债
- HARD（硬规则）：榜必须可视化。旧主来认是真香，不是温情。拒完才能抬更高层。
- FORMULA（公式）：垫底席 → 点名陪练或当众宣读零分 → 一招护体裂 → 榜文改名 → 旧主/师父来认亲认徒 → 原句奉还并拒 → 内门或主办方要人。
- VISIBLE（验收）：（原文此批未设验收字段）

### T091 拍卖套餐：穷样 → 出价 → 嘲 → 真物认主 → 仇人拍到自家被盗物 → 破产或丢脸
- HARD（硬规则）：穷样要写实。认主当章。仇人破产是中爽，金主是钩。
- FORMULA（公式）：被请出或限资 → 他出价或亮物主权 → 全场嘲 → 拍品认主飞向他 → 仇人发现拍的是自家赃/灭门物 → 金主或刑堂进场。
- VISIBLE（验收）：（原文此批未设验收字段）

### T092 收徒套餐：拒你、收仇人 → 你考核第一 → 徒辱师 → 师父当众改口
- HARD（硬规则）：拒词必须可奉还。改口要有榜作为物证。男主不必拜。
- FORMULA（公式）：收徒台拒词落下 → 名额给仇人 → 考核榜你第一 → 仇人徒当众踩你连带踩师门脸 → 师父改口请你 → 你可拒，师门内斗起来。
- VISIBLE（验收）：（原文此批未设验收字段）

### T093 校场婚期：另嫁对象剑先到，红绳还在剑上
- HARD（硬规则）：红绳从退婚场长出来，不许另开无关魔教。剑必须出手，不能只站着。
- FORMULA（公式）：三日婚期缩短到今日 → 退婚者在场 → 天才的剑穗扫过门槛，红绳可见 → 打或挡 → 婚期手续和剑绑在一起 → 更高层要看这场婚能不能成。

### T094 宗门清人：余孽名单宣读，读到你那行令亮了
- HARD（硬规则）：名单是灭门/除名指纹。令亮是半揭，不要自己报供奉。签发者才是新债。
- FORMULA（公式）：清人台宣读 → 读到他的姓或他的谱名 → 袖里令或印自己亮 → 执法停顿 → 半揭或冲突 → 清人令的签发者被请出来。

### T095 朝堂或宗门献俘：献的是你，印是灭门令的反面
- HARD（硬规则）：献俘是最大当众。翻面必须改当场手续（罪名暂停、献俘者失礼）。幕后只露齿。
- FORMULA（公式）：被绑上台献俘 → 当众定罪 → 印/令翻面，献俘的人资格裂 → 堂上改口一档 → 真要的人从席后站起来。

### T096 医诊：判你必死，你把脉把判官的毒找出来
