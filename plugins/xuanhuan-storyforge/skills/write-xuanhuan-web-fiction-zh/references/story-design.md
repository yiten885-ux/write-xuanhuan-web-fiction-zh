# 故事设计通用参考

仅在规划全书、世界、力量、地图、秘境、高潮或命名时读取。这里提供检查维度，不提供固定题材配方。

## 1. 一句话承诺

用一句话回答：

> 一个怎样的人，在怎样的压迫下，凭什么独特行动，持续获得什么阅读满足？

承诺至少包含：

- 主角当前缺口；
- 可反复运行的行动循环；
- 世界施加的主要阻力；
- 每轮循环的可见回报。

## 2. 主线因果

每个阶段按以下链条设计：

> 目标 → 障碍 → 主角选择 → 代价 → 状态变化 → 新问题

检查：

- 没有主角行动，结果是否会不同；
- 反派和盟友是否有自己的行动理由；
- 回报是否真的落袋；
- 新危机是否由旧结果生长，而非凭空刷新。

## 3. 世界与力量

最小世界表：

| 项目 | 必答问题 |
|---|---|
| 力量来源 | 力量从何而来，能否被垄断或污染？ |
| 成长接口 | 修炼、资源、知识、契约或制度如何让人变强？ |
| 边界 | 什么情况下无效、失控或被克制？ |
| 代价 | 使用、突破、恢复分别支付什么？ |
| 社会后果 | 力量怎样改变身份、法律、经济与战争？ |
| 验证 | 读者如何通过场景看见差距和质变？ |

境界名称只是索引。每次升级至少改变解决问题的方法、行动权限或风险结构之一。

## 4. 金手指

建立五项：

1. 触发条件；
2. 可执行能力；
3. 使用代价；
4. 失败与禁区；
5. 成长或揭密路径。

金手指帮助主角选择，不替主角完成核心选择。奖励进入获得账：来源、控制权、状态、代价、首次使用、后续去向。

## 5. 地图与势力

新地图必须回答：

- 旧能力还能解决什么；
- 新规则让什么失效；
- 旧关系如何继续产生影响；
- 主角为何必须进入；
- 离开时世界和主角各改变了什么。

势力不是标签，要有资源、治理、内部利益、外部依赖和行动能力。

## 6. 秘境与副本

使用九格闭环：

> 入口 → 开放条件 → 空间结构 → 特殊规则 → 危险 → 奖励 → 原住者或对手 → 主线关联 → 离境余波

奖励必须解决旧问题并生成新责任。规则要在解法前以可观察方式出现，不能高潮时临时补充。

## 7. 高潮

通用六拍：

> 铺垫 → 压迫 → 选择 → 反转 → 状态落袋 → 余波

小、中、大高潮的区别不是爆炸规模，而是改变的状态层级：

- 小：局部资源、关系或名声；
- 中：阶段目标、主要对手或地图权限；
- 大：世界格局、核心身份或终局方向。

高潮之后留恢复段，让人物处理伤势、关系、战利品和新责任。

## 8. 长篇结构

每卷记录：

- 本卷承诺；
- 主角主动目标；
- 对手网络；
- 核心资源；
- 三个不可逆状态变化；
- 已关闭和未关闭的线；
- 下一卷接口。

滚动大纲优先细化近期，远期只锁因果节点。不要用固定章数冒充节奏质量。

## 9. 命名

名称由“来源或意象 + 功能或形态 + 层级信息”组成，但应服从世界语言。

检查：

- 同类名称结构一致；
- 高频名称短而易辨；
- 重要名称能暗示功能或历史；
- 不靠堆叠“太初、混沌、万古”等宏大词制造等级；
- 新专名第一次出现时立即承担动作。

## 10. 题材组合

组合题材前分别写清：

- 开局包装；
- 成长机制；
- 世界形态；
- 主要行动循环；
- 独有失败方式；
- 能否与主线共享资源和因果。

没有独立行动循环的标签只是装饰，应合并或删除。
