# 故事设计通用参考

仅在规划全书、世界、力量、地图、秘境、高潮或命名时读取。这里提供检查维度，不提供固定题材配方。

## 1. 一句话承诺

用一句话回答：

> 一个怎样的人，在怎样的压迫下，凭什么独特行动，持续获得什么阅读满足？

承诺至少包含：

- 主角当前缺口；
- 可反复运行的行动循环；
- 世界施加的主要阻力；
- 每轮循环的可见回报。

## 2. 主线因果

每个阶段按以下链条设计：

> 目标 → 障碍 → 主角选择 → 代价 → 状态变化 → 新问题

检查：

- 没有主角行动，结果是否会不同；
- 反派和盟友是否有自己的行动理由；
- 回报是否真的落袋；
- 新危机是否由旧结果生长，而非凭空刷新。

## 3. 世界与力量

最小世界表：

| 项目 | 必答问题 |
|---|---|
| 力量来源 | 力量从何而来，能否被垄断或污染？ |
| 成长接口 | 修炼、资源、知识、契约或制度如何让人变强？ |
| 边界 | 什么情况下无效、失控或被克制？ |
| 代价 | 使用、突破、恢复分别支付什么？ |
| 社会后果 | 力量怎样改变身份、法律、经济与战争？ |
| 验证 | 读者如何通过场景看见差距和质变？ |

境界名称只是索引。每次升级至少改变解决问题的方法、行动权限或风险结构之一。

## 4. 金手指

建立五项：

1. 触发条件；
2. 可执行能力；
3. 使用代价；
4. 失败与禁区；
5. 成长或揭密路径。

金手指帮助主角选择，不替主角完成核心选择。奖励进入获得账：来源、控制权、状态、代价、首次使用、后续去向。

## 5. 地图与势力

新地图必须回答：

- 旧能力还能解决什么；
- 新规则让什么失效；
- 旧关系如何继续产生影响；
- 主角为何必须进入；
- 离开时世界和主角各改变了什么。

势力不是标签，要有资源、治理、内部利益、外部依赖和行动能力。

## 6. 秘境与副本

使用九格闭环：

> 入口 → 开放条件 → 空间结构 → 特殊规则 → 危险 → 奖励 → 原住者或对手 → 主线关联 → 离境余波

奖励必须解决旧问题并生成新责任。规则要在解法前以可观察方式出现，不能高潮时临时补充。

## 7. 高潮

通用六拍：

> 铺垫 → 压迫 → 选择 → 反转 → 状态落袋 → 余波

小、中、大高潮的区别不是爆炸规模，而是改变的状态层级：

- 小：局部资源、关系或名声；
- 中：阶段目标、主要对手或地图权限；
- 大：世界格局、核心身份或终局方向。

高潮之后留恢复段，让人物处理伤势、关系、战利品和新责任。

### 7.1 平台爽点模式

平台名称在本 Skill 中只代表用户选择的编辑模式，不代表官方算法、当前推荐政策或市场保证。用户询问平台实时规则、签约要求或榜单表现时，必须另行核对官方当期资料并标明日期；未核对时只能说“按该平台常见阅读场景设计”。

开始正文前选择一种模式：

| 模式 | 核心承诺 | 爽点兑现 | “收”的重点 |
|---|---|---|---|
| 订阅成长向（常用于起点、QQ 阅读类需求） | 让读者持续期待主角能力、身份和地图上升 | 章节内仍给局部回报，阶段大回报可以长线积累 | 资源、资格、成长接口、地位和更大目标 |
| 免费滑读向（常用于番茄、七猫类需求） | 迅速制造可感知情绪变化并持续翻页 | 四拍尽量在本章或相邻章闭合，减少无回报压抑 | 当场反制、身份反差、实利和紧接的新危机 |
| 超快脑洞向（常用于飞卢类需求） | 让新奇设定和主角优势高速连续兑现 | 缩短“压、扬”，高频展示能力的新用途 | 新能力、新权限、新地图接口 |
| 情感关系向（常用于晋江类需求） | 让关系、身份、边界和情感认知持续改变 | 爽点可来自社交反制、关系选择和舆论逆转 | 信任、边界、身份、关系主动权 |
| 通用平衡 | 同时维持成长期待、即时回报与因果可信 | 每章有落袋回报，阶段高潮充分铺垫 | 状态变化与下一阶段目标 |

未指定平台时采用“通用平衡”。平台模式不能替换前三章合同、九项留存锁、01–10、反派最优解、正文隔离或逐章净字数锁。具体关系如下：

- 订阅成长向允许终极目标延迟兑现，但不能借“慢热”取消每章微爽与三章阶段胜利。
- 免费滑读向在现有前 300 字异常、约 800 字信息差截断之外，优先每约 300–500 个读者可见字符形成一次情绪、信息或控制权变化；不得为了频率制造无因果反转。
- 超快脑洞向可以压缩铺垫，不能省掉规则边界、代价与公平线索。
- 情感关系向的“打”不必是武力，仍必须由人物主动选择产生可见关系后果。
- “不虐主、不让配角抢戏、不长期憋屈”等只作为所选平台与项目的开篇偏好；不得升级为全 Skill 对悲剧、群像或复杂人物的永久禁令。

### 7.2 打脸四拍

所有明确以“打脸、身份反差、反踩、当众翻盘”为核心的场景，使用：

> **压 → 扬 → 打 → 收**

四拍按状态变化验收：

1. **压**：对手基于自身利益，凭真实资源、制度、武力、证据或关系先行动，并给主角造成可见损失、时限或控制权下降。只有嘲讽、没有行动目的和后果，不算“压”。
2. **扬**：主角采取一个会增加期待的主动动作，并留下事后可回看的底牌线索；不得站着挨骂、只在心里说“等着瞧”，也不得提前解释完整解法。
3. **打**：主角用已铺垫的能力、身份、证据、资源或关系改变控制权。若依靠设局或信息差，继续完整执行三层智斗锁；四拍不能替代反派拆解及其副作用。
4. **收**：让对手当场承担身体、利益、名誉、权限或关系后果，同时让主角获得可使用的资源、资格、身份、关系主动权或阶段目标。旁人震惊、反派后退和一句狠话不能单独冒充落袋收益。

执行后检查：

- 同一状态变化只登记一次爽点；不能把“震惊、失态、求饶”拆成三个收益重复计数。
- 旁观者按各自利益站队、沉默、退让、撇清或加价，禁止全场同声跪舔。
- “收”必须保住已落袋结果；章末新危机只能在更高层继续施压，不能原样撤销胜利。
- 免费滑读向可以把四拍压缩到数百字或一章；订阅成长向可以跨章拉长，但每章仍要有局部状态变化和回报。

内部公式只用于章卡：`有效打脸 = 具体压迫 × 可回看期待 × 主角逆转 × 落袋结算`。若任一项为零，不能把场景登记为完整打脸。

### 7.3 黄金三章的平台适配

通用骨架仍是：

> 第一章：困境与主角特质，核心能力或异常出现
> 第二章：小试能力、展示边界与代价，形成明确目标
> 第三章：首次完整反踩或阶段胜利，落袋回报并抛出新钩子

- 订阅成长向把第三章的胜利用作长期成长线的可信凭证，并打开更大的资源、境界或地图问题。
- 免费滑读向最迟在第三章完成一次小打脸；第一章已有条件时可更早兑现，但不得用身份口播替代主角行动。
- 无金手指作品把“核心能力”替换为独特技能、认知、身份、关系或选择方式，不为套公式强加系统。
- 章节长度继续服从当前用户要求或默认逐章净字数锁；“约一万字”“三章必须爽”等说法不能改变已生效的计数字段。

## 8. 长篇结构

每卷记录：

- 本卷承诺；
- 主角主动目标；
- 对手网络；
- 核心资源；
- 三个不可逆状态变化；
- 已关闭和未关闭的线；
- 下一卷接口。

滚动大纲优先细化近期，远期只锁因果节点。不要用固定章数冒充节奏质量。

## 9. 命名

名称由“来源或意象 + 功能或形态 + 层级信息”组成，但应服从世界语言。

检查：

- 同类名称结构一致；
- 高频名称短而易辨；
- 重要名称能暗示功能或历史；
- 不靠堆叠“太初、混沌、万古”等宏大词制造等级；
- 新专名第一次出现时立即承担动作。

## 10. 题材组合

组合题材前分别写清：

- 开局包装；
- 成长机制；
- 世界形态；
- 主要行动循环；
- 独有失败方式；
- 能否与主线共享资源和因果。

没有独立行动循环的标签只是装饰，应合并或删除。
