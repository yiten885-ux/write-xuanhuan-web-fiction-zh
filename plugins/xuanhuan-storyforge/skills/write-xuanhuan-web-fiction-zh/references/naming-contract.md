# 玄幻命名合同（丹药 · 功法 · 兵器法器）

> 来源：pasted_text_20260827-074009（report 33）。配套溯源：rules/rule-33.md。本文件属世界构建层，与 story-design.md（世界观/力量体系）配套；命名直接决定世界质感和读者第一印象——好名字让读者秒懂品阶、属性、功能，烂名字让人瞬间出戏。

## 适用范围

生成任何丹药、功法、兵器/法器名称时必读；生成后跑命名自检清单。

## 一、丹药命名

**核心公式**：丹药名 = [前缀(品阶/数量)] + [核心词(功效/原料/属性)] + [后缀(形态/品阶)]

| 位置 | 词库 |
|------|------|
| 前缀区 | 一~九、十、百、千、万；玄、紫、金、玉、龙、凤、麒麟、太乙、混元、无极 |
| 核心区 | 还魂、续命、筑基、破障、洗髓、淬体、凝元、化神、融灵、焚天、镇魂、归元、易筋、换骨、通脉、开窍、孕婴、合道 |
| 后缀区 | 丹、丸、散、膏、液、露、精、华、玉、灵、元、珠、珀、晶、髓 |

**品阶映射**（AI 自动匹配）：

| 品阶 | 命名结构 | 示例 |
|------|---------|------|
| 凡品（1-3阶） | 单字原料+单字功效+丹 | 凝气丹、止血散、养元丸 |
| 黄品（4-6阶） | 双字功效+丹 | 筑基丹、洗髓丹、破障膏 |
| 玄品（7-9阶） | 数词+双字功效+丹 | 三转还魂丹、九转洗髓丹、六合凝元露 |
| 地品（10-12阶） | 属性前缀+双字功效+后缀 | 九幽续命膏、紫府化神丹、赤阳融灵液 |
| 天品（13-15阶） | 稀有前缀+四字功效+后缀 | 九转太乙还魂丹、七彩凤凰涅槃露、无极混元归真丸 |
| 神品（16+阶） | 极数前缀+天地异象+终极功效 | 九转九死九生造化丹、混沌开天洗髓玉 |

映射规则：品阶≤3 → 名长≤4 字；4-6 阶 → 4-6 字；7-9 阶 → 前缀含数词（一转/三转/六合/九转）；≥10 阶 → 前缀含玄/紫/金/玉/龙/凤；≥13 阶 → 前缀含太乙/混元/无极/九幽/涅槃。

## 二、功法命名

**核心公式**：功法名 = [前缀(属性/品阶)] + [核心动作词/名词] + [后缀(类别/形态)]

**三种经典句式**：
1. 动词+名词：翻天印、劈山掌、碎星拳、断岳刀
2. 名词+名词：九幽玄功、太虚剑典、紫霄雷诀、混元真经
3. 动词+名词+名词：焚天诀、镇魂经、破虚剑、凝元功

| 位置 | 词库 |
|------|------|
| 前缀区 | 九幽、太虚、紫霄、混元、无极、玄天、赤阳、寒冰、太乙、归元、万象、苍冥、混沌、造化 |
| 核心区 | 翻、劈、碎、断、焚、镇、破、凝、化、引、聚、炼、融、吞、噬、裂、斩、灭、封 |
| 后缀区 | 印、掌、拳、刀、剑、诀、经、典、功、法、录、鉴、要、纲、谱、图、阵、符 |

**品阶映射**：凡阶无前缀（铁砂掌/奔雷拳）；黄阶双字属性+动作（赤火掌/寒冰诀/青木功）；玄阶三四字属性（九幽玄冰掌/紫霄雷霆诀/混元归真经）；地阶传说前缀+核心名词（太虚破天剑/无极镇魂印/苍冥裂空掌）；天阶极致前缀+四字组合（混沌开天造化功/万象归元镇魔典）。

## 三、兵器/法器命名

**核心公式**：兵器名 = [前缀(材质/品阶/属性)] + [核心名(本体/功能)] + [后缀(形态/类别)]

| 位置 | 词库 |
|------|------|
| 前缀区 | 玄铁、寒铁、赤铜、紫金、玄冰、赤炎、九幽、太虚、无极、七星、九环、断岳、裂天、镇海、焚山 |
| 核心区 | 龙吟、凤鸣、虎啸、镇魂、斩妖、诛魔、破虚、裂空、焚天、碎星、断江、崩山、锁魂、封脉 |
| 后缀区 | 剑、刀、枪、戟、斧、锤、鞭、锏、钩、叉、伞、镜、钟、鼎、塔、印、旗、幡、轮、环、尺、杖、棍 |

**类型风格表**：
剑=雅致飘逸（青霜剑、紫电剑、太阿剑、寒月秋水、九霄凤鸣）；刀=刚猛霸道（屠龙刀、破军刀、碎岳刀、裂天战刀）；枪戟=凌厉大气（破阵枪、霸王破阵枪、九幽穿云戟）；锤斧=沉重碾压（碎星锤、开山斧、九幽震岳锤、裂地轰天斧）；鼎塔印=厚重镇压（镇魔塔、封天鼎、翻天印、九幽镇魂印）；伞镜幡=玄奇防御（遮天伞、照妖镜、招魂幡、玄天遮日伞）；鞭锏尺=灵活审判（打神鞭、量天尺、九节龙骨鞭）。

**品阶映射**：凡兵单材质+形态（铁剑/铜刀）；黄阶材质+意象+形态（玄铁剑/赤铜锤）；玄阶属性+意象（寒月剑/紫电枪）；地阶功能前缀（斩妖剑/诛魔刀/破阵枪）；天阶四字复合（九霄凤鸣剑/七星龙渊刀/九幽镇魂印）；神阶传说（混沌开天斧/鸿蒙量天尺/太初镇世塔）。字数校验：凡兵≤4 字、黄阶 4-6、玄阶 4-8、地阶 6-10、天阶 8-12。

## 四、辅助规则

- **规则四十一 · 名字即线索**：名字必须与实际功能存在至少一个词的直接关联（九转还魂丹→还魂/续命；焚天诀→火系；斩妖剑→对妖加成）。禁止名字与功能无关（九转还魂丹实际加力量 = 命名欺诈）。生成后提取核心词对照功能，无重合语义强制改名或改功能。
- **规则四十二 · 品阶与字数暗示**：字数越短品阶越低、越长越高（铁剑<玄铁剑<九霄凤鸣剑）。映射：凡品 2-4 字、黄品 4-6、玄品 4-8、地品 6-10、天品 8-12、神品 10+。例外：极短名配极高品阶（翻天印、诛仙剑）制造反差压迫感，**每部小说最多 3 次**。

## 命名自检清单

```text
丹药类：
- [ ] 丹药名匹配品阶（字数/前缀特征）？
- [ ] 含数词+动词+名词结构或变形？
- [ ] 品阶与功效匹配（九转配还魂而非止血）？
功法类：
- [ ] 功法名匹配品阶（前缀特征）？
- [ ] 属三种句式之一？
- [ ] 属性前缀与动作核心自洽（寒冰配凝而非焚）？
兵器/法器类：
- [ ] 兵器名匹配品阶（字数/前缀特征）？
- [ ] 前缀与核心意象搭配（九幽配镇魂而非凤鸣）？
- [ ] 后缀与类型一致（剑不后缀印、鼎不后缀剑）？
```

## AI 执行步骤

丹药：定品阶 → 选 1-2 功效词 → ≥玄品加数词前缀 → ≥地品加属性前缀 → ≥天品加传说前缀 → 后缀统一丹/丸/散/膏/液/露/玉/髓。
功法：定品阶 → 选句式 → 抽属性前缀 → 抽核心动词 → 抽类别后缀 → 检查通顺与含义重复。
兵器：定品阶与类型 → 抽材质/属性/功能前缀 → 抽本体意象 → 后缀统一类型名 → 检查读音顺口与字数区间。
