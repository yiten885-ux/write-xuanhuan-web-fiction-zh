# 小人物剧情引擎（五类推动模式 · 触发 · 闭环）

> 来源：pasted_text_20260827-074557（report 35）。配套溯源：rules/rule-35.md。本文件与 reflection-mirror.md（小人物反射镜）互为表里：本文件管「小人物推剧情」，反射镜管「小人物映主角」。

## 适用范围

写任何含路人、杂役、外围弟子、店小二等小人物的章节时必读。核心：真正的好爽文，小人物的每一次出现都在推动主角——一句闲话、一个动作、一次背叛，像多米诺骨牌把主角推向新冲突或新机遇。

## 硬规则总表（小1-小5，R35 全量）

- **小1 五类剧情引擎**：①消息传送者（无意说漏/偷听/被审问→提供行动目标：「听说后山的禁地昨晚有光……」）；②冲突点燃者（嘴贱挑衅/偷东西/抢资源→拖入新对抗：「你就是那个废物？」然后拔刀）；③人性对照者（被折磨/被踩→唤醒共情/愤怒/觉悟：他跪在地上被世家公子的靴子碾过指骨，惨叫却被欢呼淹没）；④规则解锁者（递话/善意提醒/反面教材→规避风险：「你要是想活，千万别走正门那条路。」）；⑤命运映射者（同地同路不同结局→紧迫感/感恩/战斗欲：他死了，死在距终点三步处，主角亲眼目睹）。同一类型连续 3 章内出现 ≥2 次 → 强制轮换。
- **小2 硬触发 60% / 软触发 40%**：硬触发=小人物因自身欲望/利益/求生本能主动做事影响主角（嘴贱路人挑衅抢灵石→触发熔炉反击震碎其兵器）；软触发=主角主动找小人物问出/观察出关键事（花三块灵石从醉散修口中套出「今晚有人要在演武场截杀外门弟子」）。禁止「突然有人喊了一句」式凭空触发；无动机解释 → 事件前 150 字内插入动机描写。R = 硬触发动机(1-5) + 软触发主动系数(1-5)，R < 4.0 判硬塞。
- **小3 人性逻辑一致**：小人物行为必须匹配五类动机库——利益驱动（赏钱/出头机会）、恐惧驱动（不做就被杀）、无知驱动（不知主角多强）、欲望驱动（酒色财气上头）、身份绑架（我是某某的人）；禁止「为了坏而坏」或「无代价倒戈」；行为比动机更激烈（怕死却攻击而非逃跑）→ 调整行为强度或补动机。
- **小4 主线关联度**：事件必须链接主线下一步（读者读完知道主角去哪/找谁/防什么）；导致行动变化 = 1.0 合格，仅氛围填充 = 0.3 水字数。字数占比 8-15%：<8% 追加消息传送者事件，>15% 压缩；事件后行动无变化 → 改为与下一步直接相关。
- **小5 事件闭环**：关键小人物 3 章内收尾三选一——后续交代（店小二拿赏钱连夜离城）、悲剧收场（报信被杀尸体挂城门→主角愤怒升级）、反转变数（乞丐是长老道童，递话有意为之）；禁止说完话就消失。闭环率 C = 已收尾/总数 < 80% → 强制插入收尾。

## 量化公式汇总

| 公式 | 式 | 阈值 |
|---|---|---|
| 类型丰富度 | R = 本章类型数 | 同型 3 章内 <2 次 |
| 触发合理性 | R = 硬触发动机(1-5) + 软触发主动(1-5) | R ≥ 4.0 |
| 人性可信度 | H = 动机 ∈ 五类库 | 必须匹配 |
| 主线推进 | E = 事件字数占比 ∈ [8%,15%] 且行动变化 | 双满足 |
| 事件闭环 | C = 已收尾/关键总数 | C ≥ 80% |
| 事件价值 | V = E × C | V = 0 → 重写 |

## AI 调用示例

硬触发（利益驱动）：尖嘴弟子收「安顿费」→ 动机（榨三块灵石是今晚酒钱）→ 主角捕捉「外门例钱+打点」规则 → 计划改为找靠山 → 闭环（三个月后那人绕道走）。软触发（主角主动）：蹲三天等采药老人 → 两枚灵石放石块 → 暗道与认罪书情报 → 闭环（老人消失，传言是长老暗桩）。

## System 锁死段（可直接贴进提示词）

```text
【小人物推动剧情模块】
「小人物」作为剧情推动者必须遵守：
1. 类型轮换：从[消息传送者/冲突点燃者/人性对照者/规则解锁者/命运映射者]五类中选，连续3章内不得同一类型用2次以上。
2. 触发有因：硬触发（小人物主动）必须有动机（利益/恐惧/无知/欲望/身份）；软触发（主角主动）必须有主角为何找上他的解释。
3. 人性可信：小人物行为必须匹配底层生存逻辑，禁止「毫无理由地坏」或「无代价倒戈」。
4. 主线关联：小人物事件字数占本章8-15%，且事件后主角的下一步行动必须发生变化。
5. 事件闭环：关键小人物在事件结束后3章内必须有收尾（离开/死亡/转场/身份揭露）。
若任一指标不满足，标注【小人物事件无效】并强制修正。
小人物事件价值公式：V = 主线推进效率(E) × 事件闭环率(C)；E=事件后主角行动变化(1/0)，C=收尾交代是否存在(1/0)；V=0 判「NPC凑字数」，强制重写。
```
