# 爽文套路全局合同（所有套路共通）

> 来源：pasted_text 20260827-001753。所有套路条目（T001-T096）都必须满足本合同；违反任一 = 废章重写。

## 通用前置（每条都吃）
- 必须当众
- 损失先落地
- 爆发不超过两百字
- 收获能看见（名册、令、数字、护体碎）
- 只比场上预期高一档
- 主角不解释、不圣母、不复合
- 本章改完桌子，章末把更高层送进画面。

---

## 贴进模型的总约束（八条，放在九批前面）
- 你写任何一个上列套路时：
- 1. 先写场上抢走什么（婚书、名册、令、名额、族谱、药、座位）。
- 2. 羞辱落到身份和资源，至少三句具体的。
- 3. 主角用手续和物证，不演讲、不复合、不圣母。
- 4. 爆发不超过两百字，必须有对照物（护体裂、榜改字、印烫上、数字跳）。
- 5. 收获只比场上预期高一档，多出口的那一档只露齿。
- 6. 章末更高层看见桌上那件物，下一章第一句接这一帧。
- 7. 救美、双修、收徒、真香一律不得改成主线感情戏。
- 8. 灭门、除名、退婚必须写成画过押的手续，不许只写心情。

## 全局废章条件
- 撞 BAN 或套路条目内 S/F/V 判定 = 废章重写，禁止带病续写。（全局 S/F/V 语义原文未给出；2026-08-31 审查处置：补源前以各号套路的 HARD/BAN 字段为废章依据，不得引用未定义的全局词）
- 违反通用前置七条、总约束八条或套餐硬规则任一 = 废章。
- 爆发超过 200 字、无对照物（护体裂/榜改字/印烫上/数字跳）、收获不比预期高一档、章末更高层未进场 = 废章。

## 套餐硬规则（T089-T096 通用八条）
- 按顺序拍，不许打乱成流水账
- 每一拍都有物在桌上
- 假高潮少给一档（只赢人，不赢规则）
- 真高潮改标的
- 最后一拍是更高层进场
- 全程不超过一单元五到八章，番茄可压进三到五章。
