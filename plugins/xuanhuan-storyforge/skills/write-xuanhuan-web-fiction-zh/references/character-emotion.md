# 人物与情绪通用参考

仅在设计人物、关系、人物弧、反派、配角、爱情或情绪节奏时读取。

## 1. 人物四层

每个重要人物至少明确：

1. 可识别的行为或感官特征；
2. 在不同关系中的身份与利益；
3. 深层恐惧、渴望和自我解释；
4. 面对代价时不会轻易放弃的原则。

额外给一个与主线无关的生活习惯，让人物在剧情外也像在生活。习惯不是必须回收的伏笔。

## 2. 能动性

人物立住依靠：

> 可选道路 → 压力 → 主动选择 → 可见代价 → 后续坚持或修正

- 主角至少完成核心行动和道德选择。
- 配角有私人目标、拒绝权、失误和独立关系。
- 爱情对象不是升级奖励，宠物不是消耗品，导师不是答案机器。
- 牺牲可以使用，但牺牲者的选择、未竟生活和死亡后果必须成立。

## 3. 人物弧

用 3—5 个可见决策台阶，而不是突然顿悟：

- 初始策略；
- 第一次动摇；
- 旧策略造成代价；
- 在相似压力下做出新选择；
- 新选择被行动和后果确认。

弧光可以正向、负向或平直。转变不等于把人物改成另一个人；应保留可辨认的核心。

## 4. 反派

一个有效对手需要：

- 自洽目标与资源；
- 能主动改变局面的能力；
- 与主角目标相交但价值或手段冲突；
- 可观察的前科和当下行动；
- 行为后果与退场余波。

可理解的过去不自动抵消责任。反派失败应来自主角选择、既有规则和可验证代价，而非临时降智。

## 5. 群像与配角

为每条配角线填写：

- 私人目标；
- 与主角的交集；
- 独有能力与局限；
- 独立行动；
- 状态变化；
- 退出或继续参与的条件。

高光错峰只是可选手段，不设固定比例。死者的遗物、习惯或愿望可以影响生者，但不能抹掉生者自己的选择。

## 6. 爱情

爱情线必须同时更新至少两项：信任、边界、共同目标、风险承担、未来安排。

- 好感通过共同经历和具体照顾生长。
- 冲突来自真实利益、价值或外力，不靠拒绝沟通维持。
- 双方都要在分离期间行动和改变。
- 重逢不是占有权回收，而是重新确认选择。
- 终局给出可执行的共同生活，而不只是一句承诺。

## 7. 情绪设计

情绪点的有效结构：

> 建立在乎 → 施加变化 → 人物反应 → 行动或关系改变 → 恢复与余韵

不同情绪的常见功能：

- 笑：释放紧张、展示关系和认知差；
- 泪：确认珍惜与代价；
- 痛：暴露无力、不公或价值冲突；
- 共鸣：用具体生活压力连接读者经验；
- 共情：让读者理解人物为何作此选择；
- 爽：让期待通过主角行动获得可见结算。

不要求每个情绪都兑换战力，也不要求悲伤在固定章数内结束。若用户明确选择“泪后升级、快速复仇、哭后行动”等写法，可执行，但仍需符合人物与因果。

## 8. 喜剧与敏感材料

喜剧优先来自预期违背、身份错位、认知偏差、关系默契和行动后果。

题材本身不是自动禁区。涉及残疾、亡亲、灾难、贫困或受辱等材料时，检查：

- 笑点究竟指向谁；
- 被写者是否仍有主体性；
- 语气是否符合人物和作品；
- 笑后是否产生作者未预期的价值判断；
- 用户是否明确要求保留。

检查不是擅自禁写。若存在明显伤害风险，说明风险并给出不同强度写法。

## 9. 回忆、遗言与延迟真相

回忆可以在后期新揭遗言、功劳、秘密或隐情，并不自动视为作弊。必须建立：

1. 信息载体或知情者；
2. 信息为何此前未公开；
3. 发生时间和因果位置；
4. 与已知事实的兼容关系；
5. 新信息如何改变理解而不抹掉旧事件。

回忆杀应优先重组已知情绪；新增事实用于升维理解，不用于临时修补前文漏洞。

## 10. 场景验证

每个关键场景检查：

- 谁先行动；
- 每个人想得到什么；
- 谁付出什么；
- 哪个状态在场景后不可逆地变化；
- 下一场戏为何因此发生。

如果删掉某个角色，剧情仍完全一样，该角色尚未真正参与因果。
