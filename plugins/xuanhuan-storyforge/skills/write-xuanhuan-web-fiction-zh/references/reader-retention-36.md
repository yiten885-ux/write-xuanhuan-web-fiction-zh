## 2. 四层使用结构（每章固定执行）

生成前检查（灵魂三问 → 开篇100字设计 → 本章欲望 → 爽点/悬念规划）→ 生成中约束（每500字抓人点 → 情绪↔信息交替 → 环境功能性 → 对话压迫感）→ 生成后校验（36项清单，不达标局部重写）→ 滚动规则（每3章一个反转+三类场景、每章结尾目标感、主线谜团持续推进、收集进度条更新）。

**灵魂三问（每章生成前必答，答案写章卡）**：①这一章读者会不会爽到/揪心到/燃到？（至少一种，最好两种）②这一章结束，读者不点下一章，会不会难受？③这一章的信息和情绪，能不能支撑下一个500字让读者继续读下去？三问有一问不通过，本章不落稿。

## 3. 最终全维度检查清单（五优先级，逐章生成后核验）

**第一优先级：读者会不会留下来**
- [ ] 开篇前100字有"异常"+"主角异常信号"？
- [ ] 每500字至少一个抓人点（信息/情绪/动作/悬念/金句）？
- [ ] 第一章内完成至少一次"金手指爽感循环"？
- [ ] 第一章结尾有带情绪的强悬念？
- [ ] 前三章内出现至少一次"读者知道但主角不知道"？

**第二优先级：读者会不会追下去**
- [ ] 每3章一个小反转？
- [ ] 每章结尾有"具体的下一步目标"+阻力+时限？
- [ ] 主线谜团每章有新推进？
- [ ] 打脸分三层递进（破防→碾压→定性→余韵）？
- [ ] 收集/成长进度条有更新（数字、数量、等级）？

**第三优先级：读者会不会代入**
- [ ] 每章至少一个情绪支点？
- [ ] 每章至少一次"暖"的情绪（对弱者/同伴的保护）？
- [ ] 金手指代价与收益在同一章内兑换，读者觉得"值"？
- [ ] 主角对敌人狠、对同伴护、对弱者有原则的好？
- [ ] 配角有私心，不是工具人？

**第四优先级：读者会不会记得**
- [ ] 金手指有固定视觉意象（颜色、状态变化）？
- [ ] 核心资源数字化（钱、时间、数量、等级）？
- [ ] 每章对话中有至少一句"只有主角能说"的狠话？
- [ ] 每处环境描写至少有一个功能（压情绪/暗示危险/埋线索）？
- [ ] 每章切换至少三种情绪（冷→暖→狠/爽→疑）？

**第五优先级：读者会不会掏钱**
- [ ] 免费章节最后200字是"不忍心放下"型悬念？
- [ ] 至少一个"收集进度条"让读者想看到最终结果？
- [ ] 至少一个"别人也想要金手指"的暗示？
- [ ] 至少一个"还愿固碑"的持续驱动力？
- [ ] 主角有一个具体、可视、有难度的中期目标？

## 4. 全链路时间线（开书到付费的结构验收）

- **第一秒（点击决定）**：书名、简介、开篇100字——同时有"异常+主角特殊+危险逼近"。
- **第一分钟（是否继续读）**：500字内第一个抓人点；1000字内第一次"受迫+反抗"；3000字内第一次"金手指爽感循环"。
- **第一章结束（是否翻页）**：带情绪的强悬念——某人/某物处于危险中，且有明确时限。
- **前三章结束（是否加书架/追更）**：清晰的金手指规则+成长路径；一个让读者恨意的反派；一个让读者牵挂的人物关系；一个清晰的收集进度条；≥1个名场面；≥1次爽点、虐点、燃点；主线谜团向前推进至少三步。
- **前十章结束（是否付费/持续追更）**：≥1个反转改变故事走向；中期目标明确且激动人心；≥1次"读者优越感"时刻；角色情感债务开始产生利息；读者开始替主角算账（钱、时间、代价、收益心中有数）。

## 5. 优先级排序（多合同叠加时的取舍参考）

- 节奏篇：爽感循环 > 章末悬念 > 情绪支点 > 人物关系钩子 > 金手指规则/世界观 > 文风精简。
- 深层篇：每500字抓人点 > 打脸分层递进 > 章末目标感 > 代价收益对等 > 情绪曲线 > 主线谜团推进 > 对话压迫感 > 配角私心 > 环境功能性 > 金手指可视化。
- 全局：先按 [alignment-protocol-16.md](alignment-protocol-16.md) 的 P0–P5 处理开篇三章，再按本文件优先级处理留存层，最后执行语言合同与既有硬锁；任何一层不得以"文笔更好"为由挤占上一层。
