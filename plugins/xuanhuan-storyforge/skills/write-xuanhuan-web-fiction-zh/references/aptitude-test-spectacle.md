# 资质测试+全宗震荡+抢人大战（测试 · 失控 · 抢人 · 收益 · 续节奏）

> 来源：pasted_text_20260827-075503（report 37）。配套溯源：rules/rule-37.md。本文件是「主角资质测试引发全宗震荡+抢人大战」名场面的完整操作化；与 reversal-special.md（底牌反转）、minor-character-engine.md/reflection-mirror.md（高阶版小人物反射）、exam-contract.md（可作考核第一关反套路替代）联动。

## 适用范围

写资质测试、测灵根、测骨、碑前验天赋等「测试引发全宗震荡+高层抢人」剧情时必读。四重爽感：权威背书（历史被打破）、集体震惊（全场鸦雀无声→高层失控）、价值飙升（无人问津→疯抢）、地位跃升（底层登顶）。

## 硬规则总表（测1-测7，R37 全量）

- **测1 历史对比锚定**：测试前三层铺垫——宗门历史最高（前 300-500 字，30-50 字）、当代天骄基准（前 200-400 字，20-40 字）、历代平均线（前 100-300 字，15-30 字）；主角成绩必须 ≥ 历史最高 ×1.2，否则不算震惊全宗。
- **测2 感官烈度三叠加**：测试触发（1-3 秒物理接触，20-40 字）→ 异象爆发（3-10 秒，视觉/听觉/威压/触觉四维叠加，80-120 字）→ 结果呈现（定格，20-40 字）；禁止只写「石碑亮了」。
- **测3 高层五级失控**：执事/导师（掉笔/失声）→ 普通长老（霍然起身/茶杯粉碎）→ 核心长老/副宗主（灵识全开/灵力失控/传音）→ 宗主/掌教（站起/捏裂玉扳指/亲临）→ 太上长老（闭关被惊动/神念横跨千里/声音从天穹落下）；层级 ≥3，禁止跳过中间层；红线标志：至少一人「坐不住站了起来」或「说话被打断」。
- **测4 抢人三大件**：参抢人数 ≥3（最低）、≥5（标准含核心长老/副宗主）、≥7（顶级含宗主/太上，灵压对撞桌案碎裂宗主调停）；争执台词 ≥5 句；开价条件 ≥3 项；禁止 1-2 位长老「表示欣赏」了事。
- **测5 五重收益清单**：身份（封圣子/藏经阁权限/内门最高权限）、功法（地阶功法/镇宗心法）、资源（圣子洞府/供奉翻百倍/护身法器）、人脉（太上记名/亲传令牌/隐世高人示好）、信息（宗门秘史/父亲真相/秘境入口）、地位（轻视者跪认错/天骄示好）——至少 5 项立即兑现；禁止只有「你以后就是我徒弟了」。
- **测6 快节奏延续**：测试+抢人后 3 段内开启新前进指令——新任务下达（三日后随队万兽秘境，最优先）/新冲突引入（「我不服，要挑战他」）/新信息解锁（「你父亲曾是天命碑前另一道异象的主人」）/新场地解锁（圣子洞府深处藏着东西）；禁止「尘埃落定回房休息」。
- **测7 多宗派竞抢**（如适用）：参抢宗派 ≥3（顶级 ≥5 含超级宗门）；每宗 ≥1 次宣示 + ≥1 项条件；宗派间 ≥1 次直接争执（顶级：差点动手/调停/异象被打断）；主角必须选择且结果震惊全场（选最弱宗派/选超级宗门但附条件）；禁止「代表看了看就走」。

## 量化公式汇总

| 公式 | 式 | 阈值 |
|---|---|---|
| 震撼度 | S = 主角成绩 / 历史最高 | S ≥ 1.2 |
| 画面饱满 | P = 视觉 + 听觉 + 环境反馈 | 三维齐备 |
| 失控强度 | U = 层级数(1-5) × 烈度词数 | 层级 ≥ 3 |
| 争抢烈度 | B = 人数(≥3) + 台词(≥5) + 开价(≥3) | 三大件齐 |
| 收益价值 | V = 收益项数 | V ≥ 5 |
| 节奏延续 | C = 新事件距离 | ≤ 3 段 |
| 竞抢规格 | Q = 宗派(≥3) × 台词(≥3) × 筹码(≥3) | 三维齐 |

## 六步执行流程

Step1 三层对比锚定 → Step2 测试感官三叠加（触发/异象/定格）→ Step3 高层五级失控 → Step4 抢人大战三大件 → Step5 收益清单 ≥5 项 → Step6 三段内新事件。

## 完整示例（节选）

> 「此碑名为天命碑，三百年来最高纪录乃第九代老祖——七尺三寸，赤光通天。此后百年无人能破六尺。」
> 「当今内门第一人陆天都上月测出六尺九寸，紫气东来，掌教赞其百年一遇。」
> 「寻常弟子三尺合格，五尺称天才。你且上前。」
> 陆沉深吸一口气，手掌按上碑面。石碑轰然一颤，一道赤金色光柱冲天而起直刺云霄，将漫天云层撕裂出巨大漩涡。在场弟子耳中嗡鸣，脚下青石寸寸龟裂，空气中弥漫焦灼的雷霆气息。碑面一行金纹缓缓浮现：九尺九寸，万丈金光。
> 【执事】记录笔啪嗒掉在地上。【长老】三名长老霍然起身，茶杯砸得粉碎。【核心长老】后山凝元巅峰气息轰然冲开闭关石门：「谁？」【宗主】中年男人缓缓站起，捏了三十年的玉扳指咯嘣捏出裂纹。【太上长老】苍老声音从天穹落下如九天雷霆：「九尺九寸……这孩子，三百年了……总算让老夫等到一个了。」
> 「老夫乃武堂首席，此子归我！」「你教出的弟子最好的也就六尺三寸，别糟蹋好苗子！」「老夫愿拿出九转淬体经上卷！」……宗主一掌拍在桌案：「本座亲自收他，封圣子！谁敢跟本座抢？」
> 【圣子收益清单】①身份：封青云宗圣子，内门弟子行半礼；②功法：镇宗心法《青云诀》前三卷；③资源：圣子洞府灵气 50 倍，月供灵石 300 块；④人脉：宗主亲传令牌；⑤信息：宗主传音——「你父亲当年也曾在此碑前留下异象，只是被主家压了下去。」
> （紧接着下一段）宗主话音未落，殿外一个声音传来：「我不同意。」紫袍青年步入大殿，正是内门第一人陆天都：「圣子之位，要打过才知道谁配。」

## System 锁死段（可直接贴进提示词）

```text
【资质测试+全宗震荡+抢人大战模块】
创作「主角资质测试引发全宗震荡」剧情时必须遵守：
1. 三层对比锚定：测试前铺垫「宗门历史最高+当代天骄基准+平均合格线」，主角成绩≥历史最高×1.2。
2. 三叠感官烈度：测试过程包含视觉（光/色）+听觉（鸣/震）+环境反馈（裂/烫/颤）三叠加。
3. 五级失控反应：测试结果引发执事→长老→核心长老→宗主→太上长老逐级失控，层级≥3级。
4. 抢人三大件：参抢人数≥3、争执台词≥5句、开价条件≥3项，缺一不可。
5. 五重收益清单：抢人后兑现≥5项可量化收益（身份/功法/资源/人脉/信息/地位）。
6. 三秒快节奏延续：测试后3段内开启新任务/新冲突/新信息，禁止让主角停下来休息。
7. 多宗派竞抢（如适用）：参抢宗派≥3、每宗有具体开价和争执描写。
震撼度公式：S = 主角成绩 / 宗门历史最高纪录；S≤1.2 判「不够震撼」。
失控强度公式：U = 反应层级数(1-5) × 反应烈度词数；层级<3 判「震撼不足」。
```
