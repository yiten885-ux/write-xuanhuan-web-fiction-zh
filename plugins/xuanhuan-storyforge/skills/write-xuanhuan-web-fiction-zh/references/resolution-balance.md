# 智武结算配比（智商与武力合同 · 7:2:1 锁）

> 来源：pasted_text_20260827-062627（report 28）。配套溯源：rules/rule-28.md。本文件是番茄玄幻爽文的结算方式配比合同，与 SKILL §5.4（智斗三层锁）、§5.15（斗智模式与冷却）并列执行。

## 适用范围

写任何含冲突、打脸、结算的章节正文前必读。核心问题：模型最爱把「信息差碾压」写成「真智商碾压」（内心推演、对谈拆局、「其实我早算到了」），写多了像权谋，追读掉。

## 三分类对照表

| | 是什么 | 算不算智商戏 | 番茄爆款 |
|---|---|---|---|
| **信息差碾压** | 读者知道他不简单，场上当废物 | 不算。是反差燃料 | 每章都要有 |
| **武力 / 修为碾压** | 数字、护体、一招、越级对照 | 主糖 | **主结算** |
| **真智商碾压** | 多步布局、反间、三章才收网 | 才是智商戏 | **少、短、必须当场见血** |

## 硬规则总表（R28 全量）

- R28-01 本章爽点验收只认画面：护体碎、吐血、榜改名、令烫印、名册改字、丹成、兽改口、数字跳；只有嘴赢、对方「恍然大悟」=不算兑现。
- R28-02 结算配比锁 7:2:1：每 10 章 7~8 章武力/修为主糖，1~2 章信息差点破（一句拆穿+立刻动手或改手续），最多 1 章真布局。
- R28-03 每章内部篇幅：动手/验功/物证烫印 ≥50%；对话拆局 ≤15%（拆完 200 字内必须见结果）；内心推演 ≤3 句。
- R28-04 单元高潮必须武力或规则落地，禁止用「揭穿阴谋」当唯一高潮；揭穿只能当辅——揭完一招或揭完令烫上。
- R28-05 起点偏慢玄幻可放武力 60%/信息差 25%/布局 15%；权谋玄幻才反过来；番茄打脸按 7:2:1 锁。
- R28-06 先打后说，或只打不说；禁止先讲三章计再动手；允许一句话点破 → 两百字内动手/改手续。
- R28-07 点破不超过一句（≤20 字）点在物上，后面立刻烫、裂、抽令；禁止展开成破案课。
- R28-08 内心推演不超过三句；禁止树状图；要算，用手上的物去碰，碰出结果。
- R28-09 禁止事后解释：「其实我从第一章就……」删。
- R28-10 连续三章禁止「还在布局、本场不打」；十章最多一场真布局，当场必须废一个人或改一条手续。
- R28-11 真布局必须短网：同一场、同一桌、同一炷香内收网；网底必须是刀、律、印，不是对方认输道歉。
- R28-12 高潮章禁用纯智商：主货必须是打脸、越级、规则反套、掉马物证；规则反套也要烫印/改名册。
- R28-13 智商不能代替修为：炼气可靠信息差打过筑基的嘴，但不能靠嘴让筑基护体自己裂；护体裂仍要一招、一丹、一令、一反噬。
- R28-14 反派可以蠢，但不能蠢得没好处：对方上当是因为贪名额、贪婚、贪灭口。
- R28-15 越级仍要报数字：场上喊境界、碎对照物；不得用「他看破了」跳过打。
- R28-16 对话不讲计：对白只羞辱、只报价、只宣律、只喊境界；计在动作里。
- R28-17 金手指不是诸葛锦囊：系统给的是权限、反噬、灰行两字，不是「宿主请按甲乙丙方案」。
- R28-18 反派行动优先于主角心计：先写反派要抢的好处和下的手；主角反应挡、抽、烫、裂。

## 配额与排程（公式B）

每 10 章：第 1、2、4、5、7、8、10 章武力修为主结算；第 3、6 章信息差点破（一句）+立刻动手；第 9 章可真布局但章末必须废现场刀或改手续；下一轮换掉第 9 章位置，禁止连着布局。

黄金三章：第一、二章武力最小弹；第三章可以半揭（信息差）但必须一招或令上桌；禁止第三章靠揭穿身世当高潮。

每章正文前必填公式A章结算标签：主结算三选一（武力修为/信息差点破/真布局）；选后两者必须同时填写「两百字内的武力或手续结果」；近三章已出现过点破或布局，本章强制选武力修为。

## 点破句模具与打戏最低配置

点破句模具（公式C）：一句（≤20 字）点在物上 → 两百字内抽令/一招/烫印/改榜 → 观众改口喊的是数字或身份，不是「好深的心机」。对例：他放下令，「缺一押。」空位烫印。错例：他分析退婚律十五条，对方被说哭。

打戏最低配置（公式E）：报双方境界或公开身份 → 一招或一物 → 对照物碎 → 旁人改口 → 更高层看见。缺对照物碎，本章武力结算无效，重写打，不准改成「他识破了所以对方不敢动手」。

真布局短网（公式D）：同一场、同一桌、同一炷香内收网；网底必须是刀、律、印。合法例：宴上让对方先宣连坐 → 证据在对方袖里亮出 → 当场按同一条律废对方名籍（三拍一场，不算权谋长剧）。

## 篇幅闸门与自检

篇幅闸门（公式F）：推演/拆局/回忆算计合计超过本章 15% = 废段改成动手；单段对话拆局超 200 字 = 腰斩留一句点破；「计策、布局、棋、算到、早知、不过如此」等词超过 2 次 = 改动作句。

反派先行（公式G）：先写反派要抢的好处和下的手；主角反应挡、抽、烫、裂；不写主角设计让反派来抢——信息差还在（读者等打脸），但戏是武力。

自检三问（公式H，有一个答错就改）：①读者截图发群的是「裂了/榜变了/令烫了」，还是「他真聪明」？必须是前者。②删掉所有分析对话，打脸还成立吗？不成立=智商戏替了武力，补一招。③本章改成纯开打会更爽吗？会=分析是水，删。

## System 锁死段（可直接贴进提示词）

```text
智商与武力合同（番茄玄幻）：
主结算武力修为占七到八成。信息差点破占一到两成。真多步布局不超过一成。
本章写正文前必须声明主结算：武力修为 / 信息差点破 / 真布局。近三章已出现过点破或布局，则本章强制武力修为。
信息差点破只准一句（≤20字）点在物上，200字内必须动手或改手续（护体碎、令烫、榜改、名册改、数字跳）。
内心推演≤3句。禁止事后「其实我早算到」。禁止对话讲计、禁止系统给方案。
单元高潮和卷高潮禁止纯揭穿当主糖。揭穿只能当辅，主糖必须是打、越级、烫印、改籍。
炼气可以打过筑基的嘴，但不能靠嘴让护体自己裂。越级必须报数字、对照物碎。
出现计策/棋/算到超过两次，改成动作句。分析对白删掉后打脸不成立，则补一招，不准用更长的解释补。
验收只认画面：裂、烫、改字、吐血、兽改口、数字跳。对方恍然大悟不算兑现。
```

一句话总纲：**七成用打和修为把桌子改掉，两成用一句话把刀指对，一成才允许同一场内收一个短局；模型每想写「他算到了」，就改成护体裂或令烫上。**
