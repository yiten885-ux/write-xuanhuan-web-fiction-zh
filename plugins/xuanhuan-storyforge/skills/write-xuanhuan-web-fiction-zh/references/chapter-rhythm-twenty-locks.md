## 1. 共同口径与冲突仲裁

1. **触发项合取**：每章先判断二十项中哪些已触发。触发项必须全部满足；未触发项只能在 QA 侧车记录“未触发：具体原因”，不得提前登记 PASS。
2. **净字数窗口**：用户本轮明确启用的默认窗口是每章独立 **2000–3200 个净正文有效字符**。标题、标点、空白、Markdown、HTML、注释、代码、状态数据、规则文字、自检和其他章节不能补足。用户当前任务另定窗口时，以任务卡记录的新值为准。
3. **有效节拍**：只把会新增事实、升级冲突、迫使关键选择或改变环境规则的状态变化计为节拍。气氛句、重复解释、无后果争吵和换名词不计。
4. **事件必须有来源**：任何补节拍、反派痕迹、意外打断或章尾威胁都必须调用已播种的人物、期限、资源、世界规则或因果线；禁止为了达标临时插入无铺垫袭击、异象、救兵或机械降神。
5. **单一 POV 优先**：旁观者反应必须是当前 POV 能观察到的两份独立反应；反派暗线优先写可见痕迹、后果、密报或第三方反应。只有任务卡已登记视角切换点时才可换 POV。
6. **示例不变门禁**：用户提供的角色、宗门、器物、功法、桥段和示例动作只帮助理解，不进入触发路由、固定剧情、模板或测试。
7. **能力 3+1 不固定功能名**：三项基础功能必须是本故事中本质不同的用途，不强制采用任何示例功能；另加一项独特代价、限制或谜团，以免与设定稀缺性锁冲突。
8. **首次能力披露优先安全**：首次有效使用仍须当场说明可操作的效果、代价、边界、量化参照和恢复暗示。三章释谜只延迟来源、终极真相、全貌或最终用途，不能隐藏安全使用所需规则。
9. **标签只在内部**：配角功能、钩子类型、节拍类型、爽点等级和三幕结构只写内部账。正文必须用人物选择和可见后果证明，不得用旁白宣布“他是情报源”之类标签。
10. **数字是验收口径，不是市场保证**：通过只证明本文件要求的结构证据齐全；不得据此声称作品已爆、留存率已达标或平台一定推荐。

## 2. 规则一：节奏控制协议

### 强制结果

1. 章节以“钩子 → 冲突或核心事件 → 反转与代价 → 新钩子”形成闭环。
2. 开篇钩子不超过约 200 个读者可见字符；过渡场景单次不超过 800 个净正文有效字符；核心冲突或核心事件累计不少于 1200；反转与代价累计不少于 400；结尾新钩子不超过约 200。各部分可以交织，但证据必须可定位。
3. 目标每约 800 个净正文有效字符出现一次有效节拍，相邻有效节拍的间隔不得超过 900。连续 2000 个净正文有效字符没有战斗、对峙、环境规则异变或重大秘密揭露，判为节奏塌方。
4. 过渡场景接近 800 字仍未改变状态时，调用既有压力源插入有效事件，或压缩过渡；不能用随机异象凑数。

### 内部公式

`章节结构 = 开篇钩子（≤200）+ 过渡/铺垫（≤800）+ 核心冲突或事件（≥1200）+ 反转/代价（≥400）+ 结尾新钩子（≤200）`。

## 3. 规则二：主角能动性协议

1. 任意连续两个场景内，主角至少完成一次会改变地点、资源、关系、风险、任务路径或控制权的主动决策。
2. 场景结尾不得让主角停在默认顺从。主角可以拒绝、反问规则、索取代价、改变路线、留下标记、反向追踪或形成可执行计划。
3. “独立宣言”只指独立立场或反制动作，不要求口号或豪言；动作落地优先于台词。
4. 主角的新决策必须改变下一场景的初始状态，只有心理表态不计。

内部因果：`场景结局 = 主角动作 A + 环境反馈 B → 主角新决策 C`，且 C 不等于默认顺从。

## 4. 规则三：反派压迫感协议

1. 当作品存在活跃敌对线时，任意滚动 2–3 章至少一次让反派势力以直接登场、间接威胁或因果后果显现。
2. 直接登场要改变场景压力；间接威胁要提供可验证动向；因果显现要让主角从细节推断出反派行动。只提一次名字不计。
3. 单一 POV 任务禁止为了“暗线镜头”无过渡跳头。可改用悬赏、追踪痕迹、旧伤或能力响应、遭篡改的记录、第三方恐惧等当前 POV 可感知证据。
4. 每次显现都必须推进追捕距离、资源封锁、时间死限、身份暴露或主角策略中的至少一项。

## 5. 规则四：金手指差异化记忆点协议

1. 有核心外挂或特殊能力的作品，内部建立“3+1”：三项本质不同的基础用途，加一项反常规的代价、限制或未解谜团。
2. 每次高风险、失控或关键调用，正文须写出能力功效、至少两项具体负面感官或身体后果、可观察的显性代价，以及一个暂未解释的异常问题。
3. 成熟的低风险常规使用可以不机械重复疑问句，但仍要保留独特介质、结算方式或边界，禁止退化为“光芒亮起、力量涌入”。
4. 能力成长必须尊重设定稀缺性、量化边界、恢复路径和非线性代价；不得把三项基础功能固定成同类玄幻的通用组合。

内部公式：`金手指描写 = 功效动作 + 具体感官 + 显性代价 + 未解异常`。

## 6. 规则五：信息密度编码协议

1. 连续 500 个净正文有效字符不得只靠纯对话或纯旁白交代设定。
2. 新设定必须挂载在冲突、交易、危机、考核、训练、审讯、追踪、复盘或其他会改变选择的事件载体上。
3. 有效信息必须同时完成两件事：让读者看见世界规则；让主角据此调整路线、筹码、风险判断或关系。
4. “安全坐着听”不是自动违规；若谈判、审讯或复盘本身含利益冲突且改变状态，可以合格。无行动后果的说明段必须压缩、后置或事件化。

内部公式：`有效信息传递 = 事件载体 ∩ 新设定披露 ∩ 主角策略调整`。

## 7. 规则六：开篇钩子协议

1. 每章前 300 个读者可见正文字符内必须出现非稳态：危险、困惑、期待、紧张、规则异常或反常态中的至少一项。
2. 前三段至少包含当前异常、主角即时身体或行动反应、一个亟待回答的具体问题。问题可以由事实缺口表达，不强制出现问号或感叹号。
3. 禁止以纯天气、风景、晨起洗漱、独坐回忆或无目标日常作为前 300 字主体。
4. 第一章还须同时满足前 150 字共情顺序锁、前 300 字不可逆锚定和前 1000 字命运危机，不得互相替代。

内部公式：`开篇钩子 = 异常处境 + 即时反应 + 待回答问题`。

## 8. 规则七：章节结尾断崖钩子协议

1. 每章最后约 200 个读者可见字符必须进入未闭合状态：新危机、旧谜题新线索、风险性决定、关系翻转或后果失控之一。
2. 钩子至少允许读者形成两个合理的后续猜测方向；“追兵来了”但无信息变化、“力量增长了”、睡去、休息、明天再说或总结升华不合格。
3. 本锁与动作+信息双钩子累积：最后三句既要保持动作压力，又要新增会改写前文因果判断的信息。
4. 第三章和阶段卷末继续执行更严格的客观异常末句锁；不得以主角口号收尾。

内部公式：`结尾钩子 = 状态突变 + 必须等待下一步才能确认的后果`。

## 9. 规则八：情绪收益打脸反差节奏协议

1. 每章至少一个落袋小收益；任意滚动 2–3 章至少规划并兑现一个中收益；约每 10 章完成一个会改变格局的大收益。滚动周期未到期时只记规划，不得提前写 PASS。
2. 明确登记为打脸场景时，打脸前至少有 200 个读者可见字符的低估、限制、压迫或误解铺垫。
3. 场景遵循“外部低估 → 主角蓄力 → 临界触发 → 超预期兑现 → 环境反馈”。旁观反馈必须是当前 POV 可观察到的至少两份独立反应，不得跳到两个人的内心视角。
4. 旁观者震惊不能代替收益；资源、身份、惩罚、能力或控制权必须实际落袋。

## 10. 规则九：对话信息冲突双载协议

1. 主流快节奏模式下，单句对白目标不超过 30 个中文有效字符；超过时优先拆成动作、停顿与短句。审判、誓词、文书宣读、告白或用户指定声线可以在风格卡中登记例外。
2. 每组问答至少推进剧情信息，或暴露关系、动机、情绪与立场冲突；最好同时满足两项。
3. 连续三句对白没有新信息、立场变化或情绪交锋时，删去冗句或以动作和潜台词重构。
4. 寒暄只有在后续 200 个读者可见字符内揭示伪装、试探、交易或关系目的时才保留。

内部公式：`有效对话 = 说话人动机 + 对方反应 + 对话后状态改变`。

## 11. 规则十：宏观信息三章释放定律协议

1. 重大设定、能力来源、反派真实身份、身世核心线索或关键区域真相按三次释放：T1 现象/症状/传闻；隔 1–2 章后的 T2 部分验证、代价或限制；再隔 1–2 章后的 T3 核心真相、功能或选择条件。
2. 同一章不得把一个宏观谜题的现象、原理和最终后果全部解释完。
3. 每次释放都必须改变主角当前选择并产生一个新疑问；不得只增设定密度。
4. 首次能力使用所需的效果、当场代价、操作边界、量化参照和恢复暗示必须立即交代；三章释放不得以悬念之名延迟安全规则。

内部公式：`谜题释放节奏 = T1 钩子 → T2 验证/代价 → T3 答案/选择`。

## 12. 规则十一：打斗场景三幕式协议

1. 持续超过 500 个净正文有效字符的完整战斗或对抗必须有三幕：试探不超过约 200；压制/危机约 200–400；逆转/底牌不少于 200，且伴随真实代价或限制。
2. 连续三句不得都只是纯能量、光效或爆炸对轰；必须穿插位移、肢体接触、地形反馈、伤口或身体负荷。
3. 每场长战斗至少一次主动战术判断，如预判、佯攻、借力、卡视野、争位置、骗资源或利用规则。
4. “物理感约 4、法术感约 6”仅作内部构图诊断，不按指定动词机械判定；阵战、魂战、静止领域等仍须用空间关系与因果反馈建立可感知层次。

内部公式：`有效打斗 = 动作 + 环境反馈 + 身体状态 + 战术决策`。

## 13. 规则十二：配角功能标签变数协议

1. 每个反复登场的有名配角在内部人物账登记一个主要功能：情报、压力、资源、情感、喜剧反差或自定义功能；同时登记公共身份、私人欲望和当下恐惧。
2. 正文首次登场用标志性动作、口头习惯或选择证明其辨识度，不得用旁白直接贴功能标签。
3. 重要配角每累计三次有效出场，至少一次做出在自身利益逻辑下打破原标签预期的行为。
4. 反标签行为不能无因果倒戈；必须由独立利益、知情变化、风险或关系债务触发。

内部公式：`配角魅力 = 明确功能 + 可识别行为 + 有因果的反标签变数`。

## 14. 规则十三：战力边界锚定协议

1. 项目力量体系必须给出大境界鸿沟的可验证参照。若任务卡未另定，常用诊断参照为可比基础能量或压制强度约 10 倍，并通过威压、速度、防御等至少三项感官结果表现；该数值可由项目正史覆盖。
2. 主角跨一个大境界获胜，至少满足两项前置条件：对手受伤或资源不足；一次性消耗品；阵法、天象或地形外力；对手轻敌、信息差或有效偷袭。
3. 同时支付当前战斗内不可恢复、不可连续复制的真实消耗。重大跨阶胜利还须有长期或永久后果；恢复路径存在不等于当场可撤销。
4. 仅凭愤怒、临时顿悟或未铺垫血脉升级硬跨境界，判定战力崩溃。

内部公式：`越阶合理性 = 已有底牌 + 外部削弱 + 不可连续复制的代价`。

## 15. 规则十四：环境五感触发协议

1. 进入主要新地点、建筑或明显换时段后的前 200 个读者可见字符内，至少触发三种当前 POV 确实可用的感官。
2. 常规人物默认包括视觉、听觉，以及触觉/嗅觉/味觉中的至少一项；感官受限角色或特殊环境必须服从人物卡和世界规则，以其可用感知替代。
3. 连续超过 100 个读者可见字符的纯视觉陈列必须由动作、体感、声音、关系压力或信息变化打断。
4. 感官细节必须影响导航、警觉、判断、情绪或选择，不能成为无后果装饰。

内部公式：`场景沉浸 = 主体景象 + 环境音或替代感知 + 体感/气味/味觉反馈`。

## 16. 规则十五：心理行动外化协议

1. 标准和强约束风格下，单次连续心理独白不超过 50 个净正文有效字符；超过时拆成“短心理 → 动作 → 短心理 → 决断”。用户明确选择意识流或情感慢章时可在风格卡登记例外。
2. 心理内容目标不超过所在段落的 20%；推测必须被物件、动作、对话或环境反馈打断。
3. 情绪不直接总结，优先写触发、身体反应、冲动、克制或爆发，以及外部反馈。
4. 最终必须落到可执行决定；反复权衡但不改变行动的心理段落压缩或删除。

内部公式：`心理描写 = 外部触发 + 瞬时反应 + 外化动作 + 短决断`。

## 17. 规则十六：修炼升级三不写协议

1. 主流快节奏模式下，纯静坐运功不超过 300 个净正文有效字符；不得连续两章以修炼为唯一主线；突破不得无损。
2. 每次突破至少消耗资源、加剧旧伤、缩短时间窗口、损坏能力载体或支付其他可见损失。
3. 突破后立即用一个具象动作验证此前做不到的能力，如力量、速度、感知、控制精度或规则权限变化。
4. 修炼流或用户指定慢修模式可以覆盖“连续两章”和 300 字窗口，但具象验证、真实消耗和主线状态变化仍保留。

内部公式：`有效突破 = 瓶颈 + 身体冲击 + 具象验证 + 真实代价`。

## 18. 规则十七：支线三章回收挂起协议

1. 已激活并形成任务、承诺或行动成本的短期支线必须在三章内完成回收；长期支线在开启后的第三章末前给出阶段结论、暂缓原因和可追踪的新线索。
2. 活跃支线不得连续超过四章完全无进展、无后果、无挂起标记。沉睡伏笔不等于活跃支线，不为凑频率机械回忆。
3. 每次新任务、承诺或谜团进入行动层时，在故事圣经登记开启章、三章期限、回收或挂起状态和下一调用条件。
4. 支线回收必须改变资源、关系、知情、风险或主线入口，不能只用一句“完成了”结案。

内部公式：`支线管理 = 开启 + 三章内回收或阶段结论 + 长期挂起的新线索`。

## 19. 规则十八：悬念类型轮换协议

1. 在故事圣经记录每章主导信息悬念类型：身份、物品、事件、关系、后果五类之一。
2. 任意连续三章不得重复同一主导类型；连续两章不得使用相同表面装置，如“某人推门”“令牌震动”或“远处爆炸”。
3. 本锁轮换的是主导信息类型和表面装置，不取消每章必须具备的动作+信息双钩子。
4. 改写类型时必须保持既有因果和章后状态，不能只换一个新名词伪装轮换。

内部公式：`结尾悬念类型 = 本章主导类型，与前两章比对后选择未重复项`。

## 20. 规则十九：章间前情微召回协议

1. 除全书第一章外，每章前 150 个读者可见正文字符或前两段内，至少保留上一章结尾的一个因果余震：未完动作、伤势、物件状态、地点、关系压力、信息缺口或环境痕迹。
2. 微召回不要求词面复述，更不能复制上一章结尾；它必须同时推进本章新事件。
3. 时间跳跃或换地图章也要写清上一钩子的后果、过渡或为何暂时挂起，不能直接丢弃张力。
4. 内部按“约三成旧状态余震、七成新推进”检查节奏，不机械按字数切分。

内部公式：`章间衔接 = 上章余震 + 本章新事件`。

## 21. 规则二十：世界观名词首次出现即锚定协议

1. 单章首次出现且要求读者记住的关键地名、势力、功法、境界、种族或制度名不超过五个；普通人名、称谓、既知简称和无需记忆的背景名不计。
2. 每个关键新名词在同段或下一段完成至少一种锚定：与已知事物比较；展示得罪、使用或进入后的后果；给出稳定感官特征。
3. 锚定还须说明它与主角当前目标、风险或资源的关系。只写词典释义不合格。
4. 锚定只解释读者此刻必须知道的可见后果，不得提前泄露三章释放账中的终极原理。

内部公式：`名词可记性 = 新名词 + 可见锚定 + 与主角当前行动的关联`。

## 22. 二十项 QA 闭环

### 章前

1. 载入连续性状态、最近三章摘要和二十项滚动账。
2. 标记本章触发项、窗口到期项和任务卡覆盖值。
3. 在内部关键帧中预先放置有效节拍、主动决策、核心事件、回报、章尾信息类型与下一章微召回接口。

### 生成与修订

1. 先生成纯正文，不在正文中输出检查过程。
2. 对每个 FAIL 只回滚触发范围；修订必须调用既有因果，不得用随机事件补指标。
3. 修订后重新检查正文纯净、每章 2000–3200 净正文有效字符、标题、连续性和全部已触发语义锁。
