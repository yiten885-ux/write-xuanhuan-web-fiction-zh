# 反转专精模块（三段式 · 线索密度 · 收益兑现 · 情绪曲线）

> 来源：pasted_text_20260827-072658（report 31）。配套溯源：rules/rule-31.md。本文件是反转的专项执行层，与 reversal-anguish-meme.md（F 系列四拍：前置→压制→拉扯→反击）叠加执行：F 系列管宏观节奏，本模块管反转瞬间的微观结构与量化验收。

## 适用范围

写任何反转/掉马/揭底段落时必读。核心问题：反转要么同质化（只会底牌反转）、要么突然开挂（零线索）、要么反转完就没了（无收益兑现）、要么平淡如水（无情绪跳变）。

## 硬规则总表（转1-转5，R31 全量）

- **转1 类型轮换**：反转必须从四种类型选一——①底牌反转（隐藏实力/手段揭露）；②身份反转（真实身份出乎意料）；③资源反转（废物变宝藏）；④理解反转（因果判断被颠覆）。不得连续两章同型；禁止连续三章仅用底牌反转。
- **转2 三段式结构**：①铺垫（前 200-500 字建立默认预期：他人评价/自我怀疑/环境暗示）→②触发（50-100 字打破预期）→③揭示（100-300 字真相 + 「为什么之前没发现」的合理解释）。禁止直接说出答案而缺隐瞒闭环。
- **转3 线索前置密度**：关键线索在反转前至少 500 字埋入；显性线索 ≥1 处、隐性线索 ≥2 处（显:隐 = 1:2）；禁止零线索+事后补丁。密度 D = 显性×1 + 隐性×0.5，D < 2.0 判铺垫不足。
- **转4 收益即时兑现**：揭示后同一章内展示至少一项收益——局势逆转 / 地位资源跃升 / 情绪碾压三选一；禁止「待后续分解」「主角也懵了」收场。反转后 200 字内主角仍被动 = 收益悬空，强制插入即时效果（对手色变、众人惊呼、主角反制）。
- **转5 情绪曲线锚定**：反转前基线=被压制/被误解/被低估（≥3 句描写）；触发瞬间≥1 个情绪爆点词（「不可能」「他竟然是……」「原来如此」）；反转后≥2 个角色的震惊/恐惧/崇拜/懊悔反应。情绪强度 E = (压抑时长×1.2)+(震惊值×1.5)+(旁观者反应数×0.8)，E < 5.0 判平淡。

## 量化公式汇总

| 公式 | 式 | 阈值 |
|---|---|---|
| 反转效果 | R = 预期强度 P × 触发冲击 T × 揭示合理性 E | P 低=无效；E 弱=崩塌 |
| 线索密度 | D = 显性×1 + 隐性×0.5 | D ≥ 2.0 |
| 反转收益 | I = 前劣势 × 后优势差值 | 差值 ≥ 3 |
| 情绪强度 | E = 压抑×1.2 + 震惊×1.5 + 旁观×0.8 | E ≥ 5.0 |

## 合格 / 不合格对照

❌ 不合格（无铺垫、无结构、无收益）：
> 「够了。」陆沉突然抬起头，眼中血光一闪，「我已突破凝元境。」说罢一掌拍出，所有人倒飞出去。

✅ 合格（三段式+线索+收益+情绪曲线）：
> 【铺垫】陆英冷笑：「废柴就是废柴，三年前灵海碎裂，这辈子都别想翻身。」围观弟子窃窃私语。陆沉的脸贴着石板，没有人注意到，他左手的袖口里，有一丝极淡的红光一闪而没。
> 【触发】陆英抬脚踩向陆沉的头颅：「给我跪好了——」然而这一脚，踩空了。
> 【揭示】陆沉不知何时已经站起身，气息节节攀升至凝元境初期。「三年前灵海碎裂？」他声音平静，「那是我自己碎的。不碎，怎么骗得过你们主家派来的探子？」
> 【收益兑现】陆英笑容僵在脸上，瞳孔骤缩。围观弟子长剑咣当落地。陆沉拂去肩上泥土，朝陆英踏了一步——那一步，震得整个演武场的石板龟裂出蛛网般的纹路。
