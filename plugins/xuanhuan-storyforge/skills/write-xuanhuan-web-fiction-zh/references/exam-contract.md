# 入门考核合同（三关递进 · 黑幕 · 多重出口 · 收益清单）

> 来源：pasted_text_20260827-074317（report 34）。配套溯源：rules/rule-34.md。本文件与 SKILL EVENT-RULE-09（考核规则预埋锁）、tropes T092（收徒套餐）、naming-contract.md（世界构建层）配套；写入门/入宗/晋级考核剧情前必读。

## 适用范围

写入门考核、入宗试炼、晋级大比等「考核剧情」前必读。核心问题：AI 把考核写成流水账——内容平庸（测灵气打擂台）、过程只有主角在动、结果毫无悬念、对后续毫无推动。

## 硬规则总表（考1-考6，R34 全量）

- **考1 三关递进**：完整考核必须三关，每关维度不同——第一关·门槛关（资质硬指标，10-15%）、第二关·筛选关（实战/应变/心性，40-50%）、第三关·决胜关（对决/终极，35-45%）；淘汰率逐级递增 50-70% → 60-80% → 30-50%；禁止两关制或三关同质化。
- **考2 反套路差异化**：避开经典套路并按替换方向改写——测灵根→道心/气运/特殊体质；猎杀妖兽→特定目标/护送/解谜；擂台赛→混战/夺旗/守关；心魔幻境→问心石/因果镜/血誓台。新鲜度 N = 1 − 套路占比 < 0.5 时强制替换 ≥2 关；禁止连续两次考核同形式。
- **考3 作弊/黑幕**：至少一处不公正因素（考官偏袒/世家联手/买通关系/规则倾斜/暗杀干预）；禁止全程公平零波澜；黑幕揭露必须与主角反转/打脸在同一考核周期内完成。压迫感 P = 作弊 × 影响程度(1-5)，P=0 强制插入。
- **考4 破局差异化**：主角过三关不得全靠硬实力——武力破局 ≤1 关，非武力破局 ≥2 关（智谋/奇遇/人性/代价/规则五类，如「没说不能合作」）；否则判「主角变莽夫」强制改写。
- **考5 多重出口**：结果至少三种——甲等通过（卓越→内门/亲传）/乙等通过（常规→外门+任务）/丙等通过（争议→破格+附加条件）/被针对通过（黑幕压分→自证或闹翻另投）/未通过但有收获（关键物品/信息→另一条成长线）/主动弃权（发现阴谋→提前触发主线）；禁止一句话交代。
- **考6 后置收益清单**：考核结束 200 字内列出 ≥3 项可量化收益——身份/资源/信息/人脉/能力/悬念六类；禁止只有「成功入门」零收益；输出格式「1. 身份收益：…2. 资源收益：…3. 信息收益：…」。

## 量化公式汇总

| 公式 | 式 | 阈值 |
|---|---|---|
| 结构强度 | S = 关卡数(3) × 维度差异化 | 任两关维度重复→替换 |
| 新鲜度 | N = 1 − 套路占比 | N ≥ 0.5 |
| 压迫感 | P = 作弊(0/1) × 影响程度(1-5) | P ≥ 1 |
| 破局多样 | V = 武力(≤1) + 非武力(≥2) | 合格 |
| 出口丰富 | E = 结果选项数 | E ≥ 3 |
| 考核价值 | V = 收益项数 | V ≥ 3 |

## 反套路替换表（考2 配套）

| 经典套路（避免） | 替换方向（优先） |
|---|---|
| 测灵根（摸水晶球） | 测道心（幻境坚持）/气运（随机试炼场）/特殊体质（血滴石台） |
| 猎杀妖兽（杀怪数数量） | 特定目标（兽核/灵草）/护送任务/解谜任务 |
| 擂台赛（一对一） | 混战淘汰/夺旗战/守关战 |
| 心魔幻境（看幻象） | 问心石/因果镜/血誓台 |

## 多重出口表（考5 配套）

| 结果 | 触发条件 | 后续走向 |
|---|---|---|
| 甲等通过 | 三关卓越/惊人表现 | 直接内门/长老收亲传 |
| 乙等通过 | 中等偏上 | 外门+后续任务证明 |
| 丙等通过 | 某关极差但其他极亮 | 破格录取+附加条件（一年内突破否则逐出） |
| 被针对通过 | 黑幕压分但表现优异 | 后续自证清白/闹翻另投他门 |
| 未通过但有收获 | 未过但获关键物品/信息 | 带收获离开，另一条成长线 |
| 主动弃权 | 发现考核背后阴谋 | 提前触发主线（揭露宗门黑幕） |

## 后置收益清单（考6 配套，六类）

身份收益（内门令牌/藏经阁权限）；资源收益（凝气丹×3/黄阶功法）；信息收益（父亲陨落标记/长老与身世有关）；人脉收益（长老注意/天才结盟）；能力收益（突破瓶颈/新法术）；悬念收益（场地古碑纹路暗示秘密）。输出格式：「1. 身份收益：…2. 资源收益：…3. 信息收益：…」考核结束 200 字内呈现。

## AI 调用四步流程

Step1 定三关递进结构表（关卡/维度/内容/破局方式）。Step2 插入作弊/黑幕（例：黑衣人提前潜入猎场灭口，主角发现箭矢上的陆家标记）。Step3 设计多重出口表（≥3 种结果+触发+后续）。Step4 输出【考核收益清单】≥3 项。

### 调用示例

第一关「问心石」测试（反套路）——主角心志坚定问心石异光（奇遇破局）；第二关「迷雾猎场」猎妖——考核被内鬼渗透（黑幕），主角发现箭矢陆家标记、利用地形设伏反杀（智谋破局）；第三关多人混战夺旗（非一对一）——拉拢散修结盟、挑拨世家内讧（人性破局）。出口：甲等（被长老关注入内门）/乙等（遇袭成绩受损但考官发现端倪，入外门+长老暗查）/主动弃权（避追杀获关键线索走另一条线）。收益清单：外门令牌 + 箭矢陆家标记（父亲之死线索）+ 散修赵四结盟 + 问心石异动解锁熔炉新功能。

## System 锁死段（可直接贴进提示词）

```text
【入门考核模块】
创作入门/入宗考核剧情时必须遵守：
1. 三关递进：设计三个递进关卡（门槛关→筛选关→决胜关），每关考核维度不同。
2. 反套路：避免测灵根/猎杀妖兽/擂台赛经典三件套，至少替换两关为差异化内容。
3. 作弊/黑幕：考核中必须至少设置一处不公正因素（考官偏袒/世家联手/暗杀干预），作为主角外部压力。
4. 破局差异：主角的三关破局方式中，武力破局≤1关，非武力破局≥2关（智谋/奇遇/人性/代价/规则）。
5. 多重出口：考核结果提供≥3种可能出口（甲等/乙等/丙等/被针对/未通过有收获/主动弃权）。
6. 后置收益：考核结束后必须列出≥3项可量化收益（身份/资源/信息/人脉/能力/悬念）。
若任一指标不满足，标注【考核无效】并强制重写。
```
