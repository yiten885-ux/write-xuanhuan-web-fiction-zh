## 1. 核心目标

- **双标抑扬**：通过 NPD 角色的双标行为让主角受尽屈辱（抑），再以主角反击打脸 NPD（扬），制造读者情绪剧烈起伏。
- **民族情怀**：利用 NPD 旁白（台词/内心独白）贬损主角所属族群，激发读者民族自尊与悲愤，再通过反击与复兴让读者热泪盈眶。

## 2. NPD 双标抑扬十则（双1–双10）

### 双1 双标可视化
```
NPD 在同一或相邻场景中，对主角使用严苛标准，对自己或心腹使用宽松标准，形成具体事件对比。
→ 用对话和行动呈现两套标准，不公明显到让读者愤怒。
```
参数要求：对比要具体到事件（训斥主角 vs 包庇心腹）；双标内容可涉及规则、道德、资源分配；读者能立刻指出"这不公平"。示例：NPD 长老当众训斥主角"残害同门"，前一天其亲传弟子打伤主角却被说成"切磋难免失手"。

### 双2 道德绑架与情感操控
```
赋予 NPD 对主角的恩情或道德高位（救命、收养、师长），主角因道德包袱前期忍让。
→ 打脸时揭露 NPD 道德破产或主角斩断情感羁绊，实现精神解脱。
```
参数要求：NPD 的"恩情"要具体可信，让主角忍让有说服力；压抑阶段要写出主角的内心挣扎；打脸必须包含道德层面的反击，而非单纯实力碾压。示例：NPD 养父以"养你十年"为由索取主角宝物，主角隐忍，后发现养父害死自己亲生父母，彻底爆发。

### 双3 群体盲目放大不公
```
旁观者不分是非偏袒 NPD，指责主角，形成集体压力。
→ 打脸时真相揭露，群体震惊、羞愧、倒戈，放大爽感。
```
参数要求：群体偏见要具体（言论、眼神、行为）；可设计"群众反转"：从指责主角到声讨 NPD；群体醒悟是打脸的重要组成部分。示例：族人骂主角"恩将仇报"，主角拿出族长通敌证据后，族人集体沉默，转而愤怒声讨族长。

### 双4 羞辱层层加码
```
NPD 对主角的欺辱分阶段升级：言语贬低→行动打压→夺取资源→牵连亲友。
→ 主角反击按逆序清算：先解决眼前欺辱，再揭露旧冤，最后摧毁 NPD 核心利益。
```
参数要求：欺辱程度递增，触碰主角底线；反击节奏与欺辱对应，让读者感到"每一笔账都算了"；最终清算要彻底。示例：NPD 先贬低主角修为，再夺传承，后暗害主角妹妹；主角归来后先废其修为，再夺回传承，最后公布其谋害亲族证据。

### 双5 逻辑漏洞反杀
```
找出 NPD 双标中的自相矛盾点（如"强者为尊"却欺负弱者，"尊师重道"却自己不尊师）。
→ 主角用 NPD 的逻辑回敬，使其无法反驳。
→ 围观者意识到 NPD 虚伪，打脸效果加倍。
```
参数要求：矛盾点必须明显且与情节相关；主角的反击要简洁有力，用对方的规则说话；要有旁观者反应强化效果。示例：NPD 说"强者为尊，你弱就该被我踩"，主角击败他后踩其头说"现在我是强者，你该被我踩，对吗？"
> 兑现口径：点破限一句 ≤20 字，200 字内须以动作/物证/改手续兑现（R28-01 爽点验收只认画面），不单独当结算。

### 双6 虚假屈服与极限反转
```
主角被逼至绝境，所有人以为其无翻盘可能。
→ 主角做出认输/妥协姿态，NPD 更加嚣张。
→ 下一秒主角亮出底牌，局势瞬间逆转。
```
参数要求：绝境铺垫要充分，让读者也感到绝望；假意屈服的动作要明显（低头、下跪前奏等）；反转要突然，最好在 NPD 最得意时发生。示例：NPD 得意道"跪下求我，饶你一命"，主角缓缓低头，突然抬头："我只是在找你的破绽。"一剑封喉。

### 双7 NPD 失态暴露
```
打脸过程中，NPD 不是体面失败，而是暴露真实嘴脸：歇斯底里、推卸责任、出卖盟友、跪地求饶。
→ 其失态与之前的高高在上形成对比，衬托主角胜利。
```
参数要求：失态行为要符合 NPD 性格（外强中干、自恋受损）；可以加入狗咬狗情节（NPD 与心腹互相攀咬）；观众反应（鄙夷、解气）需描写。示例：NPD 被击败后指着心腹大喊"是他怂恿我的"，心腹反目"明明是你自己贪婪"，两人当众狗咬狗。

### 双8 主角精神独立
```
主角初期对 NPD 抱有幻想、依赖或敬畏。
→ 受辱过程中逐渐认清真面目，心理觉醒。
→ 打脸时明确表达："我不再受你控制，我不需要你的认可。"
```
参数要求：精神转变要有过程，不是突然；打脸时的台词要体现心理独立；精神胜利比实力胜利更重要。示例：主角看着狼狈的 NPD，平静道："我曾经那么渴望你的认可，现在我才明白，你根本不配。"转身离开。

### 双9 清算彻底性
```
击败 NPD 后，必须让其失去最在意的东西（面子、地位、控制权），并揭露所有罪行，瓦解其影响力。
→ 主角接管 NPD 资源或地位，防止反扑。
```
参数要求：清算要涉及社会层面（当众揭露、执法处置）；原有追随者划清界限；确保 NPD 无法再兴风作浪。示例：主角将证据交给执法堂，NPD 被废修为、逐出宗门，追随者纷纷倒戈，主角成为新长老。
> 适用口径：本则适用于 NPD 作为单元/卷 Boss 的结算章；若 NPD 为开篇具名压迫者，对04"赢一寸枷锁紧一圈"仍生效——清算其欺辱账，更高层新债照立。

### 双10 节奏张弛
```
在"抑"的大周期中，穿插小反抗、小温暖或幽默情节，维持读者追读动力。
→ 压抑程度控制在读者忍耐阈值内，每隔几章给一个小甜头。
```
参数要求：小反抗可以是局部胜利，小温暖可以是朋友支持、爱人陪伴；避免连续多章纯压抑；张弛交替，情绪曲线起伏。示例：主角被当众羞辱后，回到住处发现小师妹送来疗伤药并鼓励："师兄，我相信你。"主角心头一暖，重燃斗志。

## 3. 民族情怀八则（怀1–怀8，架空族群口径）

### 怀1 文化贬损
```
NPD 以"文明人"自居，用轻蔑、扭曲的语言评价具体民族文化符号（文字、典籍、节日、技艺）。
→ 主角/同胞受辱（愤怒、握拳、眼眶发红）。
→ 读者产生强烈屈辱与愤怒。
```
参数要求：贬损对象要具体（架空族群的文字、医道、传统节日、古代发明）；NPD 语气要"优雅地恶毒"，非泼妇骂街；受辱反应要真实。示例：NPD 贵族指着古籍嗤笑："这种用竹片刻的鬼画符，也配叫文字？我们帝国的字母才是文明的象征。"

### 怀2 血统优越论
```
NPD 宣扬血统/种族优越，美化侵略史（"我们带来了文明"），提及具体历史罪行（屠城/掠夺/奴役）。
→ 主角或长者含泪回忆祖先苦难。
→ 读者悲愤交加，民族仇恨被点燃。
```
参数要求：要暗合真实历史中的侵略与反抗，但用架空设定隐喻；NPD 的言论要体现"文明傲慢"，而非单纯残暴；要有亲历者或长者的情感反应。示例：NPD 将军庆功宴上举杯："三百年前，我的祖先用铁蹄踏平了你们的王城，那不是屠杀，是给你们带来了秩序。"在场老兵浑身发抖，泪水无声滑落。

### 怀3 历史篡改
```
NPD 歪曲、否认或贬低民族英雄、伟大成就，甚至颠倒黑白。
→ 主角沉默或同胞被蒙蔽。
→ 主角揭露真相（展示古籍、遗迹、传承，或重现英雄壮举）。
→ 同胞醒悟，民族自豪感爆发，读者热泪盈眶。
```
参数要求：NPD 的谎言要编得煞有介事，让部分人也信了；揭露方式要有冲击力（现场演示、遗迹开启）；真相揭露后要有群体反应（欢呼、落泪）。示例：NPD 学者宣称"龙渊剑圣是传说，你们没有剑道传承"，主角拔出祖传锈剑，一剑劈开苍穹："龙渊剑圣，正是家祖。今日，我替他再出一剑。"全场死寂后爆发出震天欢呼。

### 怀4 集体蔑视
```
NPD 否定整个民族（"你们就是一群奴隶，天生该被统治"）。
→ 群体出现分歧（有人麻木，有人愤怒）。
→ 主角站出来唤醒同胞（演讲、行动、牺牲）。
→ 群体觉醒，团结反抗，打脸 NPD。
→ 读者被集体力量感动，热血沸腾。
```
参数要求：群体麻木与觉醒要形成对比，觉醒过程有层次；主角的唤醒方式要有感染力（引用历史、展示象征物、带头冲锋）；觉醒场景要有规模感（从几个人到成百上千）。示例：NPD 总督对百姓喊"你们这些贱民，生来就是给我们当牛做马的"，百姓低头不敢言。主角高声道："我们的祖先曾建立过伟大的王朝，我们不是奴隶！"越来越多的人抬起头，握紧拳头。

### 怀5 民族符号升华
```
NPD 侮辱民族神圣符号（践踏旗帜、焚烧祖庙、污蔑图腾）。
→ 同胞愤怒但无力。
→ 主角挺身而出，用生命/实力守护符号。
→ 符号成为精神旗帜，众人汇聚，民族情感达到高潮。
```
参数要求：符号要贯穿全文，提前埋设，让读者有感情；守护场景要有仪式感（高举、展开、插上城头）；众人齐呼口号或名称，增强感染力。示例：NPD 士兵将金龙战旗踩在脚下："这种破布，也配当旗帜？"主角一拳打倒士兵，将战旗高高举起，身后族人眼眶湿润，齐声高呼："金龙不灭！"

### 怀6 NPD 内心独白暴露
```
NPD 表面傲慢贬低（"你们的文明不值一提"）。
→ NPD 内心独白透露恐惧、嫉妒或困惑（"为什么他们的传承如此强大？"）。
→ 读者看到 NPD 外强中干，民族自信心增强。
```
参数要求：内心独白要少而精，点到为止；恐惧内容要具体，对比双方差距；通过反差强化 NPD 的虚伪。示例：NPD 主教当众焚烧经卷："这些异端邪说，只配焚毁。"内心却恐惧："为什么这些经文里的力量，比我们神国的圣典还要纯粹？绝不能让更多人看到……"

### 怀7 民族精神胜利
```
NPD 在败局已定时仍嘴硬（"你们不过靠蛮力/运气"）。
→ 主角/旁白回应：这是民族传承的力量（"这是祖先的智慧/我们先辈用血换来的"）。
→ NPD 精神崩溃，承认失败。
→ 读者为民族精神热泪盈眶。
```
参数要求：回应要简洁有力，最好化用民族精神内核；众人齐声回应的场景能增强感染力；NPD 的崩溃要与其之前的傲慢形成对比。示例：NPD 统帅跪地嘶吼："不可能！我们帝国铁骑天下无敌，怎么会败给你们这些泥腿子！"主角淡淡道："你们有铁骑，我们有万年的骨气。你们可以杀死我们，但永远无法让我们跪下。"身后战士齐声怒吼，声震四野。

### 怀8 余波中的民族复兴
```
NPD 势力覆灭后，展示民族/群体的复兴景象（重建家园、文化复兴、后代传承）。
→ 用细节体现时间跨度和希望（孩子学习本族文字、祭祀大典、英雄纪念碑）。
→ 读者感到民族生生不息，情感升华。
```
参数要求：余波要有时间跨度（如战后十年）；复兴细节要具体（学堂、典籍、石碑）；情感基调从悲壮转为温暖、自豪。示例：战后十年，废墟上建起新学堂，孩子们诵读祖先留下的典籍，学堂中央石碑刻着牺牲者的名字。主角站在碑前轻声道："先辈们，你们看到了吗？我们没有忘记。"风吹旗帜，猎猎作响。

## 4. 总公式与情绪曲线

- **NPD 双标抑扬总公式**：
```
NPD双标欺辱（可视化+道德绑架+群体盲目+层层加码） → 主角忍让/觉醒（精神独立） → 反击打脸（逻辑反杀+极限反转+NPD失态） → 彻底清算 → 余波与张弛节奏
```
情绪曲线：愤怒 → 憋屈 → 小甜头 → 绝望 → 爆发 → 解气 → 释然。
- **NPD 旁白民族情怀总公式**：
```
NPD旁白贬损（文化/血统/历史/集体/符号） → 同胞受辱/觉醒 → 主角捍卫真相/精神 → 反击胜利（民族精神胜利） → 复兴升华
```
情绪曲线：屈辱 → 悲愤 → 觉醒 → 激动 → 热泪 → 自豪。

## 5. 门禁与口径

1. **架空化硬门禁**：族群、帝国、历史须为架空设定；不得指涉现实国家、现实民族或现实历史事件专名（衔接 C7 不写现实政治影射）。架空隐喻暗合真实历史的情感结构是允许且推荐的做法。源示例中的"五千年"等现实纪年表述，正文落地时须替换为架空表述（如"万年王朝传承"）。
2. **点破兑现**：双5 逻辑反杀若以台词点破，限一句 ≤20 字，且 200 字内须以动作/物证/改手续兑现（R28-01 爽点验收只认画面），不单独当结算。
3. **与对04 衔接**：双9 彻底清算适用于 NPD 作为单元/卷 Boss 的结算章；NPD 若为开篇具名压迫者，"赢一寸枷锁紧一圈"仍生效——清算欺辱账，更高层新债照立。
4. **并存关系**：双标欺辱是衬2"积累"段与虐点 N01–N14 的素材来源；怀6 = 留18 读者优越感的 NPD 场景特例；双10 = 留14 情绪曲线与留10 小温暖的落地；NPD 台词受语13 三人三嘴约束（羞辱落到身份+资源+时限，"优雅地恶毒"）；双6 极限反转须有铺垫（留25/转1–转5）。
5. **爽点锁不豁免**：NPD 压抑周期不豁免 5.21 留26/留存锁——每章仍须有落袋微爽点或小温暖（双10），压抑程度控制在读者忍耐阈值内，禁连续多章纯压抑。
