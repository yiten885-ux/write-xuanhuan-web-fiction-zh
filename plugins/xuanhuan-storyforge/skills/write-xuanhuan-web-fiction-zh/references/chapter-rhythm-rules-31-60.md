# 逐章节奏增量硬锁：规则三十一至六十

> 本文件必须与 [chapter-rhythm-twenty-locks.md](chapter-rhythm-twenty-locks.md) 和 [chapter-rhythm-rules-21-30.md](chapter-rhythm-rules-21-30.md) 完整合取执行。它只新增规则三十一至六十，不替换、不删减、不放宽前二十项和规则二十一至三十，也不替换 `SKILL.md` 的其他合同。

> 规则名、编号、阈值、证据坐标、PASS/FAIL 与滚动账只写独立 QA 侧车；状态事实写独立 state。最终读者正文只含章标题与小说正文，不得在小说正文中输出规则三十一至六十的名称、编号或自检报告。

## 1. 共同口径与冲突仲裁

1. **证据真源**：证据只能来自已接受正文、已验证 state 或用户明确确认的事实。计划中的证据不得登记为 PASS；未触发写“未触发：原因”，未到期写“尚未到期：章位”，因果上暂时无法落地写“阻塞：原因”。
2. **禁止伪证**：不得为通过门禁伪造证据位置、动作、节拍、物件状态或关系变化，也不得临时召来人物、制造感官损失、随机异动、袭击、救兵或世界规则。
3. **重算窗口**：字符距离、滚动三章、连续在场、物件活跃期和危机累计只按单一最终正文重算。旧章改动后，从最早受影响锚点重放状态与期限。
4. **即时锚定与延迟解释并存**：规则二十、二十一、二十二合取后取更严的单章关键新专名最多 4 个。规则三十二不延迟规则二十、二十一要求的首次同段锚定；锚定只给父类、可见后果、感官特征和当前行动关系，完整功能原理另按延迟窗处理。
5. **安全信息优先**：首次有效能力使用、眼前生存选择或正式竞赛仍立即给出本次操作所需的效果、代价、边界与胜负条件；来源、终极原理、全貌和非当场用途继续延迟。不得用悬念隐藏安全必需信息。
6. **限知与因果优先**：规则五十一禁止用规则三十六制造真实视角切换。关系见证、配角截断、反派压力和环境锚都必须处于当前 POV 的感知权限内；人物不在场时不得瞬移入场补指标。
7. **状态隔离**：规则五十五的台账只进入状态文件或 QA 侧车。正文只通过自然动作、物件后果和人物选择表现状态，不打印表格、字段、规则标签或执行报告。
8. **机械边界**：脚本只验证篇幅、标题、目标窗口和控制文字污染，不能证明术语是否真正首次出现、功能解释是否完整、POV 是否合法、动作是否个性化、峰谷是否有效或情绪是否成立。
9. **示例不固化**：用户提供的角色名、器物名、地点、感官映射、固定台词和桥段只用于理解，不进入通用路由、模板、测试或强制剧情。

## 2. 规则三十一至四十：术语、信息、泄压、线索与对话

### 规则三十一：滚动一千五百字新术语密度协议

1. 任意滚动 1500 个净正文有效字符内，新术语最多 2 个。每输出约 800 个有效字符做一次内部扫描，但 800 只是检查点，不把滚动窗口缩短。
2. 新术语指首次出现且要求读者记住的世界规则、制度、势力、功法、境界、地点或关键物品正式名。普通人名、称谓、旧简称、自然地貌和临时描述性代称不计。
3. 窗口可以跨段、跨场景和跨章；同一对象的别名只计一次，也不得把多个独立概念合称一个词规避统计。
4. 超限时优先保留与本章主选择直接相关的术语；其余用自然代称先展示动作与后果，等后续窗口有预算再给正式名。
5. 本锁与规则二十二合取，单章关键新专名仍不得超过 4 个。QA 记录正式名、首次字符偏移、段落锚与滚动窗口结果。

内部诊断：`滚动术语密度 = 任意 1500 个有效字符内首次关键术语数`。

### 规则三十二：功能解释五百至八百字延迟协议

1. 新设定先以动作或外部变化出现，再给当前 POV 的感官反馈；完整功能解释延迟到首次效果展示后的 500–800 个有效字符。
2. 首次锚定、可操作边界与安全限制不得延迟。首现同段、本句或下一句仍须完成父类、后果或感官锚定，并说明它为何影响当前目标。
3. “完整功能解释”指明确回答它是什么、如何工作、能解决什么、为何生效中的两个以上核心问题。重复命名、模糊惊叹或单一可见后果不算完整解释。
4. 若生死选择要求即时说明，只给本次使用必需的效果、代价、无效条件和停止条件；来源、机制全貌与未来用途仍留在延迟窗或 T1/T2/T3 账中。
5. 不得用无状态变化的打斗、环境或寒暄灌满 500 字。QA 分开记录首次正式名、即时锚定句、首次效果句、完整解释句和实测距离。

内部流程：`动作 → 感官后果 → 500–800 字有效推进 → 完整功能解释`。

### 规则三十三：概念父子链协议

1. 必须同时引入多个概念时，采用 `父概念 → 子概念 → 实例` 的单向链；子概念由父概念的使用、限制或副作用自然产生。
2. 父概念必须是读者已知事物、常识类别或已经锚定的旧概念，不能再用一个全新专名解释另一个全新专名。
3. 子概念的当场价值只承担父概念的一项差异、后果或操作接口；不得与父概念并列开启第二套无关世界观。
4. QA 记录父概念旧来源、子概念首现、可见差异和它改变的当前动作；词典式分类表不能替代正文因果。

### 规则三十四：双危机或三千字冲突后泄压协议

1. 自上次有效泄压起，连续 2 次危机升级并形成“进入危机—人物应对—局部结果”，或冲突累计达到 3000 个净正文有效字符，谁先到即触发。
2. 下一合法节拍必须进入一次低烈度泄压：允许坐下、进食、包扎、清点、整理物件、关系协作或由旧物触发的短日常回声；禁止新增外部敌人和需要记忆的新设定。
3. 泄压必须改变身体状态、关系边界、资源认知或下一判断，不能只是静态风景、闲聊或总结；未解威胁仍保留，不能把章尾安全区锁清零。
4. 物理照护须有真实伤势、触感或呼吸反馈；日常回声须由既有物件或习惯触发并短于当前主线推进，不得临时编造身世。
5. 整场正处于无法停顿的连续危机时记录因果阻塞，在第一个安全动作缝隙兑现；不得在刀下强行休息，也不得伪报 PASS。

### 规则三十五：代价关系角色可见协议

1. 改变能力、关系、风险承担或下一选择的重大代价，必须在同场或下一次有因果的相遇中被一个既有关系角色看见。
2. “看见”必须由关系角色可在当前 POV 中观察到的动作完成：触碰、试探、纠正动作、改变距离、接管物件、命令式边界或风险分担。旁白说“对方注意到了”不算。
3. 角色反应必须改变共同计划、信任、照护边界或资源分配；泛问“还好吗”但无后果不算见证。
4. 无关系角色在场、对方无感知权限或角色已经失去行动能力时，登记“待见证”并延后到下一合法相遇；禁止召人、跳头或让远处人物凭空知道。
5. QA 记录代价迹象、可感知者、见证动作、命令或边界、关系与策略状态变化。

### 规则三十六：牺牲型策略非战斗截断协议

1. 主角准备执行独自承担全部风险、不可逆损失或主动排除同伴的牺牲型策略时，由已建立且有独立利益的关系角色用非战斗行为截断节奏。
2. 截断可以是移动物件、破坏流程、提出事实问题、拒绝服从、公开共同债务或改变进入条件；不能靠更强战力代打，也不能无因果煽情。
3. 截断必须让主角获得新的理解角度、关系判断或风险分配方案，并改变牺牲的方式、代价或后果；不得切换 POV，也不得把“新角度”写成另一人物内心。
4. 场内没有合法关系角色时，本锁不要求凭空拦截；QA 写明未触发原因。若角色在场却基于人物卡选择不拦截，则必须写出其独立利益与后果，不能假 PASS。

### 规则三十七：普通线索N+3触碰协议

1. 普通线索首现章记为 N；仍活跃时，必须在 N+3 章结束前至少有一次因果触碰。
2. 触碰可以是重新审视、验证失败、改变携带方式、调整风险判断、影响路线或被另一事实重新解释；随机发热、机械摸一下或只提名字不算。
3. 规则三十七不替代重大伏笔的 N+1 / N+3 双提醒，也不替代未知物品的 N+3 边界和 N+5 阻断。
4. 已兑现、作废、转移出当前 POV 或有正文证据进入休眠的线索，先更新状态账再停止计时；不能事后改账掩盖失忆。
5. QA 记录线索 ID、首现锚、活跃状态、最迟触碰章、实际触碰动作和状态变化。

### 规则三十八：章尾四型轮换协议

1. 章尾另登记呈现方式轴：事件、认知、情感、感官四类；与旧规则十八的身份、物品、事件、关系、后果对象轴并行，不能互相替代。
2. 本章主型必须不同于前两章已经使用的呈现方式；即任意滚动三章内不重复同一主型。表面装置同样不得连续重复。
3. 认知钩须由新证据改写旧判断；情感钩须由可见台词或动作改变关系；感官钩须带来可复述的异常；事件钩须改变风险或控制权。心理总结不算钩子。
4. 第三章和阶段末继续满足客观异常末句、动作与信息双钩子、安全区禁令。因果上无法采用待轮换类型时记录阻塞并修订前置安排，不能只换名词。

### 规则三十九：对话L1/L2/L3单一主功能协议

1. 连续三句以上的对话单元，L1、L2、L3 中只能有一个主功能；允许自然次生效果，但 QA 不得双计或三计。
2. L1 目标不超过三轮交替或约 75 个有效字符；L2 不超过五轮或约 120 个有效字符；L3 不超过两轮或约 50 个有效字符。确有声线需要时在风格卡登记例外并证明状态变化。
3. 相邻两个 L1 单元之间必须插入会改变解读、位置、物件或权力感的动作或环境反馈；空泛“他点头”不算。
4. 旧规则九的“双载”解释为主功能之外可以产生潜台词和关系副作用，不要求一个对话单元平均承担多项任务。
5. QA 记录对话范围、主功能、轮数、有效字符、间隔动作和对话前后状态。

### 规则四十：亲密表达反套话协议

1. 重要关系的高浓度时刻，优先调用已建立的共享物件、称呼、习惯、身体协作、回避或具体照护，不直接用万能安慰套语替代人物选择。
2. “说反话”或“问事实不问感受”只是可选手段，不得固化为每次都使用的新模板；必须服从人物声线、知情和当前关系边界。
3. 合格表达要能回指旧关系事实，并改变信任、共同目标、边界或风险承担中的至少一项。泛化脸红、沉默、嘴硬或重复口号不算。
4. QA 只记录关系来源、表层话语、可见真实动作和关系状态变化；“亲密类型”标签不得进入正文。

## 3. 规则四十一至五十：感官、场景、冲突与人物线

### 规则四十一：长期感官损失异质代偿协议

1. 只有已进入正史并跨场景持续的感官损失触发。为受损角色登记一种仍真实可用、信息类型不同的感官或程序性方法作为异质代偿。
2. 异质代偿只提供低分辨率线索，不得恢复原感官精度、抹平代价或变成临时超能力。没有可用代偿时，限制必须真实阻断动作，并允许既有工具或同伴补位。
3. 在该损失实质影响的危机场景内，相邻代偿线索原则上不超过约 300 个有效字符；每次线索都要直接导向判断、移动、攻击、防御或撤退。
4. 规则四十三只使用当前 POV 仍可用的感官；规则四十一的代偿证据可与规则六十共用，但必须分别说明信息来源和动作后果。
5. QA 登记受损感官、开始章、持续状态、代偿渠道、可得信息、不可得信息和危机场景证据。

### 规则四十二：滚动三章代价清点协议

1. 任意滚动 3 章至少一次，以不超过 80 个净正文有效字符的世界内动作、短心理或关系对话清点仍在生效的累计代价与剩余资源。
2. 规则二十四继续每章提供当前绝对参照；本锁负责每三章聚合体温、次数、裂损、冷却、感官状态、债务或其他既有刻度，不重复打印 QA 统计。
3. 本窗口没有新损失时只陈述已确立状态，不得为满足清点凭空调用能力或扣减资源。非数值题材使用次数、裂纹、失感或明确边界。
4. 清点必须改变使用上限、下一选择或关系风险认知；纯列表但人物没有据此行动，只能算状态提示，不能算完整通过。

### 规则四十三：新场景环境三锚协议

1. 旧规则十四继续要求主要新场景前 200 字至少三种当前 POV 可用的感官；新增要求前 500 字内建立温度、声场、气味或触感三类环境锚中的至少两类。
2. 每个登记的锚在该场景后文至少一次影响导航、警觉、判断、情绪或动作。只为凑感官写一遍后永不使用，不合格。
3. 角色感官受限时只用其仍可获得的真实信号或已建立代偿；不能强迫失明者“看见”、失聪者“听见”或临时创造超感知。
4. QA 记录场景入口、前 200 字三感证据、前 500 字锚点、后续作用位置和出口状态。

### 规则四十四：场景中段物件过渡协议

1. 相邻连续场景用一个已存在的物件、人物、声音、伤势、消息或环境痕迹完成“旧场景出口 → 移动或时间变化 → 新场景入口”；该连接项统称中段过渡物。
2. 中段过渡物必须在两端均有正文证据并改变感知、方向、时间或动作，不能在转场时临时制造一个万能物件。
3. 明确时间跳跃、断章或合法 POV 切换也须以因果余震、未完动作、持续伤势、重复声响或消息传递承接，并同时满足时间锁、空间锁和章间微召回。
4. QA 记录旧场景出口锚、载体、移动或省略依据、新场景入口锚及状态是否连续。

### 规则四十五：重大冲突三波协议

1. 占一章约 40% 以上或决定本章控制权的重大冲突必须包含三波：试探波、变奏波、代价波。
2. 试探波验证当前已知规则并形成失败或有限结果；变奏波由对手反制、环境利用、配角自利动作或新变量改变策略；代价波支付本场不可撤销或不可连续复制的成本，取得有限胜利或明确失败。
3. 三波必须各有不同入口与出口状态；把同一招放大三次、连续对波或只升级特效不算三波。
4. 长战斗还须满足旧三幕与战术判断；智谋场景仍满足三层套娃。相同正文节拍可以合取举证，不需要重复制造场面。
5. QA 记录每波入口、动作、对手反馈、出口状态、控制权变化和代价。

### 规则四十六：规则博弈前三百字显化协议

1. 当胜负主要依赖正式规则、契约、考核、交易条件或因果结算时，在场景前 300 个净正文有效字符内，以动作、后果或短对话显化 1–2 条可操作规则。
2. 规则必须在第三波或破局点被遵守、转嫁、反向利用或支付代价后突破；只在开场念一遍但不影响结果不合格。
3. 本锁不允许静态规则表，也不放宽核心事件预埋锁。公开赛制可在现场建立；新世界底层限制仍须有先前正文证据，不能当前临补。
4. 可操作规则不等于完整世界观功能解释，因此不取消规则三十二的来源、原理和全貌延迟。

### 规则四十七：红黄绿线配比协议

1. 以完整滚动三章、一个副本或用户明确指定的更长窗口为验收单位，按每段或节拍的单一主用途统计有效字符，不重复计数。
2. 红线约 60% 以上，负责当前卷目标、核心障碍与控制权；黄线 20%–30%，负责人物关系、代价与弧光；绿线不超过 10%，只用碎片推进远期背景或暗线。必要转场可占未分配部分。
3. 黄线不是独立支线豁免。独立支线仍服从默认每章约不超过 20%；超过部分必须与红线同场推进，并按该段唯一主用途计数。
4. 绿线超过 10% 进入裁剪复核，超过 15% 直接 FAIL；窗口未完成只能写“尚未到期”，不得提前 PASS。
5. 比例是内部构图指标，不证明真实留存或商业结果。QA 记录窗口、分类依据、有效字符和后移内容。

### 规则四十八：红线新信息百字重估协议

1. 红线新信息出现后 100 个净正文有效字符内，当前 POV 必须完成一次局势重估，并改变假设、优先级或下一动作。
2. 连续纯心理仍服从不超过 50 字；其余重估用身体动作、物件清点、路线变化或短对白承载，不能停下写说明书。
3. 直接生命威胁下先执行本能动作，重估移到紧接的第一个合法短拍；QA 记录因果阻塞与实际距离，不能在攻击落下时强行分析。
4. 重估要把“未知”转成“已知但不完整”或把旧假设降级，不能重复刚揭露的信息。

### 规则四十九：配角连续三章自利决策协议

1. 有名配角在任意连续 3 章均有效在场时，最迟第三章做出一次基于独立利益的自利主动决策。
2. 决策必须改变资源、关系、风险、路线、信息或控制权；被动回应、替主角递工具、照令执行或旁白宣布“他有私心”不算。
3. 决策可以与旧规则十二的第三次出场反标签动作共用证据，但“超出主角预期”本身不是充分条件，必须能回指该配角欲望、恐惧或债务。
4. 角色因伤、囚禁、离场而确实不能决策时，连续在场窗口中断或登记阻塞，不能强行让其越权行动。

### 规则五十：反派三行动私人压力泄漏协议

1. 同章出现至少 3 个独立行动且都由同一反派完成、目标导向并改变状态时，必须有一次当前 POV 可见的私人压力泄漏。
2. 泄漏可表现为微小失误、资源核对、回避、习惯破裂、矛盾命令、身体紧绷或超出职责的迟疑；不得直接跳入其内心。
3. 私人压力不等于忏悔、洗白或降智，仍须符合其信息条件和独立利益，并影响后续选择或暴露可利用边界。
4. QA 逐一记录三个独立行动的入口与状态效果、压力迹象、可见权限以及它如何改变第三次或后续选择。

## 4. 规则五十一至六十：视角、动作、物件与章内节奏

### 规则五十一：紧密第三人称限知视角协议

1. 任务卡选择第三人称且用户未指定全知或多 POV 时，默认紧密第三人称限知：一个场景一个焦点，正文信息只能通过其五感、身体、记忆与有证据推断进入。
2. 他人情绪只能由表情、动作、呼吸、距离或话语推断；远处事件只能由声音、影子、震动、消息或后果进入；人物不能继承读者、旁白或另一视角的知识。
3. 第一人称、明确全知或多 POV 项目可以覆盖叙述形式，但事实、知情和场景边界仍不可覆盖。多 POV 只在登记过的场景边界切换。
4. 每章审查无感知来源的客观陈述和他人内心；发现即从最早越界句局部重写，不能在后文补“他猜的”掩盖。

### 规则五十二：不可直知信息迹象推断协议

1. 焦点人物无法直接获知的信息，只能以 `可见迹象 + 明示推断` 进入；推断必须保留与证据相称的不确定度。
2. 同段旁白不得立即替人物推断盖章。要直接展示真相，只能在合法场景边界切到有知情权的 POV，或等事实进入当前视角。
3. 无可见迹象的“直觉猜中”、为了钩子精准预感或把作者知识装成经验判断，均失败；超自然预感须先进入能力规则并承担边界。
4. QA 记录迹象来源、感知权限、推断句、置信状态和后续验证，不把推断写成正史事实。

### 规则五十三：角色动作签名协议

1. 核心角色内部登记 1–2 组动作签名。动作签名是“触发条件 + 惯用方法或节奏 + 愿付代价”的行为组合，不是独占某个常用动词。
2. 每个关键动作场景至少一次让参与核心角色的选择体现其签名；角色成长、伤势或伪装可以改变签名，但必须有状态转移证据。
3. 其他角色可以使用相同基础动词，不能靠禁词表制造辨识度。辨识度来自观察顺序、身体偏好、风险阈值、物件用法和动作节奏。
4. 动作签名与去重锁合取：有叙事功能的仪式可进风格白名单，但同一句式反复复制仍须改写。

### 规则五十四：动作观察判断执行协议

1. 改变风险、位置、资源或控制权的关键战术动作，必须让读者看见 `观察 → 判断 → 执行` 的因果链；三步可压在一句或一段内。
2. 判断必须由观察推出，不能用作者事后解释。若判断错误，也要写出当时合理证据和错误带来的状态变化。
3. 微动作、反射、防御本能和对白手势不强制三步。重大关系或生死刺激可用“刺激 → 本能动作 → 事后修正”替代，以保留情感先行。
4. 正文不得打印步骤标签；QA 记录关键动作观察 / 判断 / 执行及前后控制权。

### 规则五十五：物件跨章状态台账协议

1. 在独立 state 或 QA 中维护物件跨章状态台账：唯一 ID、正式名或代称、当前持有人、精确位置、数量或耐久、裂损或冷却、已知功能、未知部分、活跃状态、最后正文来源锚与摘录哈希。
2. 每章结束更新获得、转移、消耗、损坏、修复、冷却、隐藏、遗失和作废；下一章加载上一最终状态，不得凭记忆重建。
3. 已接受正文是事实真源。台账与正文冲突时从正文重建台账，不修改正文迁就旧表；改章后从最早转移事件重放。
4. 唯一物件同一时点最多一个有效持有人；共有、复制、分身或堆叠必须有已建立规则。毁坏、燃尽或消耗后不得无事件复现。

### 规则五十六：活跃物件三章触碰协议

1. 仍标为活跃物件的关键物件，在任意连续 3 章内至少触碰一次；触碰必须是使用、状态变化、关系影响、风险变化或决策改变。
2. 随机发热、摸口袋、只提名字或无后果清单不算。若物件不再需要，须在期限前用正文证据转为休眠、消耗、转移、遗失或作废。
3. 重大伏笔物件继续服从 N+1/N+3；未知物继续服从边界披露期限；同一有效动作可合取举证，但不能降低更严期限。
4. QA 记录活跃物件、上次有效触碰、三章到期、实际动作、状态变化和下一调用条件。

### 规则五十七：章内峰谷协议

1. 篇幅达到 1500 个有效字符的章节至少包含一组“高危峰段 → 低烈度谷段”；默认 2000–3200 字章节通常必触发。
2. 峰段最长不得超过 800 个净正文有效字符；达到上限前插入真实状态反馈、短关系协作、代价结算或环境用途变化。谷段至少 150 个净正文有效字符。
3. 旧节奏锁要求的核心冲突累计可以分布在多个峰段；本锁不减少核心冲突总量。不得连续三个峰段而没有有效谷段。
4. 谷段不能解除全部威胁、进入无风险安全区或靠静态风景灌水；它必须为下一峰或章尾钩子改变身体、关系、资源或判断。

### 规则五十八：缓场实体展开协议

1. 每个规则五十七的谷段至少包含身体状态或环境的二次展开中的一项。
2. 身体状态要有处置、失败、触感、呼吸、伤势边界或动作受限；环境二次展开要让旧细节获得新用途、后果、路线意义或关系意义。
3. 纯心理总结、静态设定梳理、重复同义环境描写或无目的寒暄不算实体展开。
4. 本锁可与泄压、代价清点、关系见证共用同一谷段，但每项都要有独立状态变化证据。

### 规则五十九：三轮对话动作穿插协议

1. 连续对白中每位说话者一次发言计一轮；每 3 轮对话后，在第 4 轮开始前必须插入当前 POV 可见的动作或环境反馈。
2. 插入项必须改变潜台词、空间、物件、节奏或权力感；“他说”“她点头”以及无后果神态不算。
3. 文书宣读、誓词、法令或用户锁定的单人长句可以在风格卡登记例外，但仍服从对白长度、信息负载和场景反馈规则。
4. QA 记录对白轮次、插入位置、动作或环境变化及下一轮对话为何被重新解读。

### 规则六十：纯动作三百字认知插针协议

1. 连续纯动作达到 300 个净正文有效字符前，插入至少一项有效感知、战术判断或关键对白，并让其改变后续动作。
2. 不强制新增人物或对白；单人追逐、潜行或无声战斗可以用空间判断、身体负荷、物件反馈或代偿感官完成。
3. 长期感官损失危机场景优先调用规则四十一的异质代偿；同一证据可以同时满足两锁，但心理片段仍服从不超过 50 字。
4. 插针不能变成说明书或重复动作摘要。QA 记录纯动作起点、插针字符偏移、信息类型和随后的动作变化。

## 5. 规则三十一至六十 QA 闭环

### 章前

1. 载入最近三章最终正文与 state，标记术语窗口、解释到期、危机累计、活跃线索、物件、感官损失、钩子双轴、人物连续在场和代价清点期限。
2. 登记本章 POV、场景锚、转场载体、重大冲突三波、规则博弈操作条件、红黄绿窗口、动作签名和峰谷计划。
3. 只把计划写成“待证”，不得提前登记 PASS。

### 生成与修订

1. 先生成纯正文；规则名、公式、计数表和检查过程只写独立 QA。
2. 从最早失败锚点局部回滚。需要前置证据时修订真正的前章并重放下游，不能在当前段补一句冒充历史铺垫。
3. 一个正文节拍可以同时满足多条规则，但 QA 要逐条说明因果和状态变化；不能把同一个无后果动作重复计数。
4. 修订后重算所有字符距离、滚动窗口、state 与最终正文哈希，再复检六十项全部已触发或已到期合同。
