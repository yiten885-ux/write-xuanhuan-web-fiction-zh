# 小说正文去模板化与人味审校

> 本文件约束小说语言，不判断作者身份。所谓“AI 味”只指表达过顺、过安全、过平均、过度解释或模板化的候选特征；任何扫描结果都不能证明文本由 AI 或人类创作。

## 1. 三层执行闭环

生成、续写、重写或审校正文时，依次执行：

1. **写前风格注入**：先确定叙述者、人物语域、句长倾向、感官来源、对白口语度和例外白名单。
2. **写中约束**：用动作、具体物件、感官和潜台词承载情绪与信息；允许停顿、打断、不完整句和人物犯错。
3. **写后检测与改写**：先标出候选，再逐处判断；只改有证据的问题句段，不改正史、因果、人物动机或已经落袋的结果。
4. **重新验收**：任何删改后都重新运行标题、正文纯净和逐章净字数门禁。改写前的通过状态不得沿用。

正文与控制层继续隔离。风格卡、候选词表、密度统计、改写理由和复检结果只进入章卡、故事圣经或独立 QA 侧车。

## 2. 写前风格卡

动笔前至少确定：

- 叙述距离：贴近人物感官，还是保留有限的外部观察；
- 人物声线：职业词、生活比喻、地域口语、常用短句和刻意不用的词；
- 句法节奏：短促、舒缓或混合，以及允许出现长句的场景；
- 感官来源：人物最先注意声音、气味、温度、触感还是形状，原因是什么；
- 对话习惯：停顿、打断、答非所问、回避、方言或脏话的尺度；
- 风格白名单：因人物、时代、题材或修辞目的需要保留的高频词和句式；
- 用户锁定的文风与不可改句段。

不得假扮某位在世作者，也不得仅靠替换同义词模仿参考文风。提取可描述的节奏、视角和语言特征，生成独立表达。

## 3. 写中硬约束

### 3.1 具体先于抽象

- 不直接宣布“他很愤怒、她感到悲伤、他十分紧张”。先写可见动作、生理反应、物件处理、对白潜台词或环境反馈。
- 抽象词可以出现，但必须由同场景中的具体证据托住；不得连续堆叠“命运、希望、灵魂、力量”等大词完成情绪。
- 背景和设定继续服从“当前代价进入”原则，不能借去模板化之名增加无关生活碎片。

### 3.2 对话像人物，不像说明书

- 允许停顿、打断、口语、废半句、答非所问和避重就轻；每种形式都应来自人物关系与当下目的。
- 禁止双方明知同一事实却为读者完整复述；规则说明必须嵌入训练、争执、交易、欺骗或风险决策。
- 对话之后优先接动作、停顿或他人反应，不用旁白立刻翻译潜台词。
- 不为凑“对话占比”制造无信息交换的问答。

### 3.3 句子和段落有呼吸

- 长短句交替；连续 3 句不得保持相同语法骨架、相近字数和同一种开头。
- 排比同一场景最多使用 1 组，每组不超过 3 个分句；刻意仪式、誓词或角色口癖可在风格卡中登记例外。
- 段首不连续依赖“然而、但是、于是、接着、随后、最终、终于”等连接词推进。
- 场景收束停在动作、对白、物件、画面或仍在发生的异常上；禁用作者总结替读者命名情绪。

### 3.4 比喻来自人物的生活

- 比喻优先取自人物职业、阶层、地理、食物、工具、宗教或修炼经验。
- 禁止无人物滤镜的万能比喻，如把悲伤固定写成潮水、愤怒固定写成火、心痛固定写成刀割。
- 如果删掉比喻后画面更清楚，删掉；如果比喻不能暴露人物认识世界的方式，重写。

### 3.5 心理活动服从行动

- 连续心理独白最多 3 句；之后必须回到动作、对白、感官或环境变化。
- 人物可以不理解自己的情绪，也可以做错、说漏、嘴硬或反应迟钝；不要让人物每次都先想清楚再行动。
- 生死或重要关系受威胁时，继续执行“先动身体，再动脑”的既有锁。

### 3.6 开头与结尾

- 开头从具体动作、异常物件或带目的的对白切入；感官细节必须附着在主角动作和威胁上，不得退回纯天气或空镜铺陈。
- 禁止用“这一天、故事开始、在一个……”作为无动作的通用起句。
- 结尾不得用“他终于明白、这就是人生、从此以后”一类总结替代已经要求的动作与信息双钩子。

## 4. 词语分层与白名单

不得把词表当作删词器。按三层处理：

### 4.1 高置信控制或说明文词

“综上所述、总而言之、值得注意的是、需要指出的是、因此可以看出”等出现在叙述层时，默认重写；人物对白、书信、官样文书或刻意喜剧可由风格白名单保留。

### 4.2 密度候选词

“仿佛、似乎、犹如、宛如、然而、但是、于是、接着、随后、最终、终于、不禁、不由得、忍不住、缓缓、静静、慢慢、渐渐、瞬间、刹那间、那一刻、某种、一种、一丝、阵阵”等只做频率预警。单次恰当使用不算失败；重复承担同一功能才重写。

### 4.3 抽象词候选

“美好、温暖、力量、希望、梦想、灵魂、生命、命运”等只有在缺少具体承载或成串升华时才判问题。角色名称、功法名、誓词和世界规则中的必要用法不自动删除。

使用 [zh-style-watchlist.json](zh-style-watchlist.json) 生成候选位置；`--allow` 记录项目白名单。候选命中不是错误，更不是作者身份判断。

## 5. 场景、描写、对话与情绪公式

### 场景

`进入场景 → 反常细节或动作 → 目标受阻 → 人物行动 → 意外后果 → 新决定或悬念`

最后一步不附作者总结。

### 描写

`具体物件 + 动态动词 + 一项感官 + 人物主观滤镜`

四项不要求每句齐全，但每个关键描写必须至少让物件、动作和人物认知发生联系。

### 对话

`带潜台词的台词 → 动作或停顿 → 对方不完全配合的回应`

下一句不由旁白解释双方“真正想说什么”。

### 情绪

`触发事件 → 生理反应 → 行为冲动 → 抑制或爆发 → 环境或关系反馈`

情绪的有效落点是人物接下来做了什么，不是形容词强度。

### 段落节奏

`一至两句较长描写 → 短动作 → 对话 → 半句心理 → 新动作或细节`

这是调节工具，不要求每段机械复刻；若连续两段骨架相同，必须换序或删减。

## 6. 默认密度目标

以下是正文默认目标，不是作者身份检测。用户锁定文风或特定场景确有需要时，可在风格卡中记录例外及理由：

- 每约 300 个读者可见正文字符至少 1 个具体感官细节；同一感官词机械重复不计。
- 每约 500 个读者可见正文字符至少 1 个改变动作、空间、物件状态或人物关系的具体动作；静态摆设不计推进。
- 平均有效句长目标不超过 25 个字符；允许高潮长句，但不得连续形成同构长句。
- “仿佛/似乎”合计每 1000 个净正文有效字符最多 1 次；“不是 A，而是 B”每 1000 字最多 1 次。
- 对话目标占读者可见正文约 30% 以上；环境描写目标不超过约 15%；抽象词候选密度目标低于约 5%。三项只能由语义审查确认，机械引号比例、词表比例不能冒充结论。
- 连续心理独白最多 3 句；连续同构句最多 2 句；排比每场最多 1 组且不超过 3 个分句。

数字用于发现异常密度，不能为达标强塞感官词、对白或动作。若加入内容不改变人物感知、选择、关系或场景状态，删除而不是计数。

## 7. 写后检测与定向改写

按以下顺序执行：

1. 扫描说明文元话语、模板连接词、模糊修饰、直接情绪标签、俗套比喻、同构句和章末总结候选。
2. 逐项判断是否属于人物对白、世界内文书、刻意口癖或必要修辞；有合理语境则加入白名单，不机械替换。
3. 对确认的问题句段执行最小改写：保留原意与事实，删除解释，补一个与当前人物相关的动作、物件、感官或潜台词。
4. 检查改写是否新增了原文没有的正史事实、能力、关系或线索；如有，撤回。
5. 检查章节结尾是否仍满足既有钩子和安全区禁令，爽点是否仍已落袋。
6. 对最终保存版本重新运行标题、正文纯净、逐章 2000–3200 净字数和语言候选审计。

推荐的严格候选命令：

```bash
python3 scripts/audit_chapter.py <正文文件> \
  --max-paragraph-sentence-average 25 \
  --forbid-outside-dialogue "综上所述,总而言之,值得注意的是,需要指出的是,因此可以看出" \
  --json-out <QA侧车>
```

对白或世界内文书需要保留时，用 `--allow` 添加精确白名单；白名单及理由必须保存在项目 QA，不得写入正文。

## 8. 机械审计边界

脚本可以稳定报告字面候选、重复段落、重复短语、长句、源文本段落平均句长和引号外禁词。它不能可靠证明：

- 引号内一定是人物对白；
- 对话是否自然、是否在解释剧情；
- 环境描写真实占比；
- 感官细节和动作是否有效；
- 心理活动是否属于内心独白；
- 比喻是否真正来自人物经验；
- 文本是否由 AI 或人类创作。

因此，机械报告只给候选；语义结论必须引用正文证据，并进入独立 QA 侧车。最终只能说“完成去模板化审校与哪些代理检查”，不能说“检测证明不是 AI 写的”。
