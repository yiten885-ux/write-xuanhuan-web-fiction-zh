# 小人物反射镜（认知失调 · 前后反差 · 代价感知）

> 来源：pasted_text_20260827-074815（report 36）。配套溯源：rules/rule-36.md。本文件与 minor-character-engine.md 互为表里：引擎管「小人物推剧情」，反射镜管「小人物映主角之强」。小人物眼里的震惊、敬畏、恐惧、后悔，比主角自夸有效十倍，且天然快——不铺陈、不解释、一个眼神一句闲话就爽到。

## 适用范围

写主角做出超预期表现后的「旁观者反应」段落时必读。核心问题：AI 只会写「路人震惊脸」（认知失调一种），且常无触发事件、只写一个人、小人物内心戏压过主角。

## 硬规则总表（反1-反5，R36 全量）

- **反1 三类型轮换**：①认知失调型（30-50 字：把他当软柿子的家伙，一指震碎了他跟了十年的护身玉）；②前后反差型（40-60 字：一刻钟前用鼻孔看人，此刻双手捧令牌脊背弯得比草低，「您……您请上座。」）；③代价感知型（50-80 字：护甲碎成七块，残留剑意嗡嗡作响，若那一剑偏了三寸……冷汗湿透里衣）。连续 3 章同型 ≥2 次 → 强制轮换。
- **反2 触发门槛三级**：一级（接酒杯/抖水珠→低反射：多看一眼/停顿一秒，占 50%）；二级（挡攻击/开禁制→中反射：面色微变/迟疑，占 35%）；三级（越阶反杀/破高阶阵法→高反射：失态/尖叫/瘫软，占 15%）。禁止无触发直接写「吓得发抖」；反射段前 30 字内必须有主角的可感官动作。反射强度 ≥ 触发等级+1 → 需补充原因。
- **反3 旁观者叠加**：核心反应者（1 人，最强情绪：执事张着嘴忘了合上）+ 环境共震者（≥2 人：随从面面相觑、登记簿掉地）+ 远距涟漪者（可选：二楼帘子掀开一角「下面怎么回事？」）。烈度 I = 核心×2 + 共震人数×0.8 + 涟漪×0.5 < 3.0 → 强制追加 ≥2 共震者。
- **反4 视角权重**：主角动作 ≥20 字（第一优先级）→ 小人物感知结果 30-50 字（第二）→ 小人物心理 ≤20 字（第三，禁止长内心戏）→ 共震者 10-30 字/人（第四）。小人物心理 > 主角动作 = 视角失衡，压缩心理扩写主角动作；反射场景 ≤300 字。
- **反5 后续涟漪**：反射后同一章或下一章内小人物必须有后续动作——传播者（杂役念叨「太强了」半个时辰传遍外门）、拉拢者（端灵果弓腰「师兄您尝尝」）、告密者（「您要小心后山那批人，今晚要设局」）、追随者（门口蹲三个杂役「师兄我们跟您干」）。有后续 D×2.0；无 → 强制插入 ≥50 字。

## 量化公式汇总

| 公式 | 式 | 阈值 |
|---|---|---|
| 反射丰富度 | R = 类型数 × 差异权重(0.3/1.0) | 3 章内同型 <2 次 |
| 可信度 | C = 触发等级(1/2/3) + 反射强度 | 强度 ≤ 等级+1 |
| 反射烈度 | I = 核心×2 + 共震×0.8 + 涟漪×0.5 | I ≥ 3.0 |
| 主角存在感 | P = 主角动作(≥20) + 小人物心理(≤20) | 心理 ≤ 动作 |
| 爽感持久度 | D = 反射(1) + 涟漪(0/1) | 有涟漪 ×2.0 |

## 完整示例（入门考核破阵）

> **【主角动作·第一优先级】** 陆沉抬手，中指在阵法枢纽上轻轻一叩。
> **【触发动作·二级】** 咔哒——困扰所有人半个时辰的九宫锁阵，像被捏碎的核桃壳一样寸寸龟裂。
> **【核心反应者】** 主持考核的执事弟子手中的记录笔停了。他盯着裂开的阵盘，像看着太阳从西边升起来。
> **【环境共震者×2】** 身后两名记录员手中的笔同时落地。围观弟子中有人倒吸一口凉气，下意识后退半步。
> **【小人物感知结果·第二优先级】** 执事弟子喉咙动了动，才发现自己忘了呼吸。这个昨天还在领外门杂役粗布衫的家伙……把内门专供的闭卷题，用手指头敲开了？
> **【小人物心理·第三优先级≤20字】** 他脑子里只剩一个念头：坏了，我刚才让他排最后了。
> **【远距涟漪】** 二楼廊柱后，一道青色衣角一闪而过。
> **【后续涟漪·下一章开篇】** 第二天清晨，陆沉门口的石阶上摆着三份早饭、两瓶灵液，一张纸条：「师兄，今晚外门弟子议事，有人要动你。看完即焚。——昨天给你递笔的那个。」

## 自检清单 54-58

```text
54. [反射类型] 三类型轮换？连续3章未重复超2次？(是/否)
55. [触发门槛] 反射段前有可被感官捕捉的触发动作？(是/否)
56. [旁观者叠加] 核心反应者+≥2环境共震者？(是/否)
57. [视角权重] 主角动作≥20字？小人物心理≤20字？(是/否)
58. [后续涟漪] 小人物有后续动作（传播/拉拢/告密/追随）？(是/否)
```

## System 锁死段（可直接贴进提示词）

```text
【小人物NPD反射模块】
通过小人物侧面反映主角厉害，必须遵守：
1. 反射三类型轮换：从[认知失调型/前后反差型/代价感知型]中选择，连续3章禁止同一类型出现≥2次。
2. 触发门槛：反射前必须有可被感官捕捉到的触发动作（一级/二级/三级），禁止无因恐惧。
3. 旁观者叠加：反射场景必须包含「核心反应者×1 + 环境共震者×2」，强化爽感烈度。
4. 视角权重：主角动作描写≥20字，小人物心理活动≤20字，禁止小人物内心戏压过主角存在感。
5. 后续涟漪：反射发生后，小人物必须在同一章或下一章内产生后续行为（传播/拉拢/告密/追随），让爽感二次放大。
反射烈度公式：I = 1(核心)×2 + 环境共震人数×0.8 + 远距涟漪(0/1)×0.5；I<3.0 判「反射太淡」。
爽感持久度公式：D = 反射段落(基准1) + 后续涟漪(0/1)；有后续动作 D×2.0。
```
