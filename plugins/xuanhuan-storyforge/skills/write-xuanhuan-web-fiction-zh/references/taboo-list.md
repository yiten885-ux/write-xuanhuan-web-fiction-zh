# 雷点清单（2026-08-31 审查补齐 A8）

> 番茄/起点男频高敏弃书点的默认禁用清单。定位：读者安全网——这些桥段不是不能写，而是有严格的豁免条件；默认遇到即改道。与 C7（不写违禁、不写现实政治影射）、C4（智商在线）配套。

## A 感情与伴侣类

1. 绿帽（伴侣被染指的实锤描写）——默认禁；误会梗须在 2 章内澄清且主角未受实际羞辱。
2. 女主/红颜被反派玷污——默认禁；"未遂 + 主角及时赶到"为上限，受害过程零细节。
3. 主角恋人无辜惨死且无复活/清算线——默认禁；死亡必须换来主线级觉醒与彻底清算（双9）。

## B 道德底线类

4. 主角圣母救仇人导致己方死亡——默认禁；主角可以有弱点，不能有致命愚蠢。
5. 主角屠杀无辜、烹食人肉等反人类细节——默认禁；反派做恶点到为止（C7 仇杀血腥点到为止）。
6. 主角跪求反派——默认禁（双6 假意屈服除外：须当场反转，且跪是计策不是真心）。

## C 弱势与宠物类

7. 无辜孩童受害过程细节——默认禁；可侧写（结果交代），禁过程渲染。
8. 萌宠/灵兽/忠诚坐骑死亡且不复活——默认禁；此类死亡必须 3 章内复活或等价补偿。

## D 主角自身类

9. 主角被夺舍成功且长期不夺回——默认禁；夺舍危机可作桥段，须 3 章内反夺。
10. 主角智商下线只为给反派递刀——默认禁（C07 降智制造冲突=假冲突）。
11. 至亲团灭且无清算线——默认禁；团灭必须开启双4 逆序清算单元。
12. 主角苦修成果被一句话废掉且无补偿——默认禁；废修为必须伴随更高获得或复仇线开启。

## E 处理规则

1. 触发 A–D 任一区的桥段：500 字内给出反转或实质代价；雷点画面不渲染细节，用侧写与结果交代。
2. 受害者不得用于纯猎奇；受害必须服务因果（结仇/立誓/觉醒）。
3. 每章生成后自检：本章是否触发 A–D 任一条？触发且未按豁免处理 = 该场景重写（QA 侧车登记）。
4. 雷点与爽点的边界：雷点用于"积压"（衬2 积累段、双4 层层加码），释放必须落在主角反击，不落在受害展示。
