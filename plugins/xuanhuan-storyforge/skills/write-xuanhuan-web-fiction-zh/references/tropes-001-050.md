# 爽文套路库·第一卷（T001-T050）

> 字段说明：本库每条套路按统一字段组织——HARD（硬规则）/ FORMULA（公式）/ VISIBLE（验收可视化）；对应套路系统字段 WHEN/HARD/FORMULA(PRESS→PAYOFF→HOOK→VISIBLE)/BAN/STACK，其中 BAN 与 STACK 由全局合同（global-contract.md）与配方（stack-recipes.md）管理。

## 第一批 开局（T001-T016）
### T001 英雄救美后美女青睐 / 双修
- HARD（硬规则）：救美只能当辅线，不能当主糖。先写清她被谁、为何、当场会丢什么。男主救人是因为场面里有仇、有证人、有令，不是因为好看。青睐可以出现，双修若出现只当功法/资源交换，不写色情过程，不让她分走复仇戏份。救完立刻有更高层看见或仇人记恨。禁止因她放过仇人、禁止三章内收女主、禁止用谈恋爱拖刀。
- FORMULA（公式）：有人当众要毁她（或毁她手里能证明男主的东西）→ 男主用已公开能力短手救人 → 她要报恩/双修/跟走 → 男主只要情报、证人、路，拒人情 → 仇人把账记在男主头上（章末钩）。
- VISIBLE（验收）：救完主线标的必须前进一寸，不是多一个女人。

### T002 退婚当众撕婚书，三日另嫁天才
- HARD（硬规则）：婚书、聘礼、三日期限三件必须上桌。羞辱不少于三句，落到身份和家族谱。男主不哭不辩，用手续说话。退婚者要有真实好处（另嫁天才、夺名额）。禁止第三章对方跪完复合。
- FORMULA（公式）：当众撕开婚书并收聘礼 → 宣布三日后另嫁谁 → 男主把两半叠好问今晚送还是他来取 → 最小兑现（跟班护体裂或改回一个数字）→ 香或铃按下，更高层看见婚书灰烬。
- VISIBLE（验收）：婚约在律上是否真废，必须留下缺口（缺押、未公证）。

### T003 赘婿入府，家宴当废物使唤
- HARD（硬规则）：家宴是刑场不是日常。必须当众被使唤、被比下去、被当众宣布「配不上」。男主留在这张桌是因为桌上有地契、令或名单，不是因为爱。禁止写三年忍辱专章。
- FORMULA（公式）：家宴座位/倒酒/点名羞辱 → 拿走一件属于他的面子或资源 → 他做一件反常日常动作（倒酒倒满、把筷子放正）→ 短兑现 → 上座或回廊有人看见。
- VISIBLE（验收）：他当晚必须拿回一寸（席位、一句话、一张契）。

### T004 废丹 / 废灵根，大比名额被夺
- HARD（硬规则）：废要有人动手、有见证、有名额易手。金手指必须当章改变「他会在大比前废死」。禁止回房慢慢养十章。
- FORMULA（公式）：当众废丹或当众验灵根失败 → 名额改到仇人名下 → 倒计时（大比何日）→ 当章最小反制（丹毒反噬到下药者，或灰行亮「未授权」）→ 钩：点名陪练或清场。
- VISIBLE（验收）：名额还在仇人手里，但男主死不了，且仇人身上留下把柄。

### T005 族谱除名，赶出祠堂
- HARD（硬规则）：族谱是指纹物，必须画押、当众划掉。划谱的人要拿走族产或名额。赶出不是结束，是通缉/余孽的开始。禁止哭族谱三章。
- FORMULA（公式）：祠堂当众划名 → 族产/婚约一并收走 → 男主把残页或印收进袖里 → 最小兑现（拦门的家丁废）→ 钩：新主人来收房。
- VISIBLE（验收）：残谱还在他手里，除名在族里生效，但印没交出去。

### T006 开局当祭品 / 炉鼎 / 炮灰送上祭坛
- HARD（硬规则）：祭坛上必须有观众和主祭。他没死成要有具体原因（血不认、阵反噬、系统卡住）。禁止写完献祭就瞬移变强。
- FORMULA（公式）：绑上祭坛，主祭宣读用他换什么 → 刀落下或阵起 → 反噬到主祭或阵心认他 → 他活，祭品身份变成「没献成的祸」→ 钩：灭口令。
- VISIBLE（验收）：主祭当场受伤或丢脸，男主被定义为必须再杀一次的人。

### T007 重生回灭门前夜或坟前被辱
- HARD（硬规则）：回忆不超过两百字。读者知道前世结局，开局写「第一刀仍要落下」或「坟前被吐口水」。今生改手段，不改圣母去救齐全家。前三章必须废掉名单上第一人（废即可，不必死）。
- FORMULA（公式）：前夜/坟前，仇人用原句羞辱 → 男主不告官、不硬刚全场 → 按名单拆最近的内应或现场刀 → 可视化（残谱亮第一笔）→ 钩：下令者听说余孽还活。
- VISIBLE（验收）：前世死法被改掉一角，不是全家复活。

### T008 穿越成该死的龙套 / 反派
- HARD（硬规则）：原剧情「他该死」必须当众启动（赐死、赐婚、去送死任务）。男主按原剧本走一步然后撕。禁止开场讲解全书世界观。
- FORMULA（公式）：穿越落地，原死法的手续开始（赐毒酒、点名出战）→ 他借手续反制 → 天命主角或原女主按剧本踩空 → 钩：剧本下一刀提前来。
- VISIBLE（验收）：原剧情第一死被改，仇人开始怀疑「戏不对」。

### T009 系统当众绑定失败，灰行其实未授权
- HARD（硬规则）：场上只看见失败，读者看见灰行两字。禁止系统念说明书。失败必须让他当章更惨（被嘲、被除名），同时灰行改变一寸处境。
- FORMULA（公式）：当众绑定，金光熄灭，全场笑 → 面板只亮「未授权」→ 他用失败后的最小权限挡下一击 → 钩：有人要拿「废物系统」去报功。
- VISIBLE（验收）：场上仍当他是废物，读者知道权限没死。

### T010 杂役三年，真传一脚踹翻丹炉
- HARD（硬规则）：三年压缩成当场损失，不写三年流水账。丹炉/功法残页被夺必须看见。扫地身份要有收益（能靠近刑堂、能听见令）。
- FORMULA（公式）：真传当众踹炉夺药 → 杂役把残页扫进筐或袖里 → 最小反制（炉火反噬真传袖口）→ 钩：执事点名他去赔药。
- VISIBLE（验收）：残页在他这，真传当众破相或丢脸。

### T011 替婚 / 换亲，洞房对象错位
- HARD（硬规则）：错位必须当众或有凭证（盖头、婚书姓名、过门令）。男主不是赚到美女，是被换上更危险的局（对方是仇家、炉鼎、刺客）。禁止写成艳遇开篇。
- FORMULA（公式）：盖头揭开 / 婚书对不上 → 当场羞辱或杀机 → 他按婚书姓名和令说话，不按感情 → 最小兑现（假洞房变成证人/人质）→ 钩：真正该成亲的天才明日上门问罪。
- VISIBLE（验收）：这桩婚在律上卡住，成为刀，不是甜。

### T012 拜师被拒：朽木不可雕
- HARD（硬规则）：拒要当众，要有被收的那个天才在场。男主不求第二遍。后文真香只能是师父来请，男主可拒。
- FORMULA（公式）：收徒台点名淘汰 → 名额给仇人 → 男主要回自己的投名状/拜帖 → 最小兑现（投名状上印发热，或考核暗线他分最高）→ 钩：明日外门大比强制上场。
- VISIBLE（验收）：拜帖还在他手里，拒词成为可奉还原句。

### T013 豪门弃子回归，机场或祠堂被拦
- HARD（硬规则）：拦的人要当众否认血脉。男主要有一件带不走的物证（玉、血条、旧令）。禁止回家先叙旧三章。都市就改机场、律师、股权。
- FORMULA（公式）：拦门「陆家没有你」→ 物证亮一角但不喊身份 → 对方要当众清人 → 短打脸（保镖/家丁倒下）→ 钩：遗嘱公证或族会倒计时。
- VISIBLE（验收）：血脉未公证，但拦门的人先丢脸。

### T014 都市兵王回乡，退婚现场打脸
- HARD（硬规则）：退婚现场必须有新对象和新靠山。兵王不报部队番号当高潮，要报也由别人的电话/证件喊出。打的是当场的脸，不是国际战争。
- FORMULA（公式）：酒楼退婚，新对象嘲穷 → 男主不解释，处理当场一个麻烦（闹事、假酒、绑架）→ 新靠山的人先跪或先走 → 钩：更大的靠山来电。
- VISIBLE（验收）：婚约未复合，现场秩序易手。

### T015 医馆被赶出，病人咽气栽赃
- HARD（硬规则）：死人和医案是指纹物。赶出要当众砸牌。男主当章用一次医术改栽赃方向（活人开口或尸斑对不上），不写医学论文。
- FORMULA（公式）：砸牌、当众宣布庸医 → 栽赃的死者/假死者 → 他留一枚针或一张方 → 假死或真凶露出一寸 → 钩：官府或师门要拿人。
- VISIBLE（验收）：牌匾砸了，但栽赃不成立，仇人必须再补一刀。

### T016 新婚夜被下药，醒来功法尽废
- HARD（硬规则）：谁下药、为了夺什么（功法、位置、新娘）必须清楚。醒来第一场就要当众验功失败。金手指当章让「废」不完全，或把药反记到下药者身上。禁止十年养伤。
- FORMULA（公式）：验功当众失败 → 位置/新娘被夺 → 他要回被夺的那件物的凭证 → 下药者当章破绽（自己经脉乱）→ 钩：三日后宗门复验。
- VISIBLE（验收）：功法公开已废，暗处留下可翻案的药引或灰行。

## 第二批 打脸（T017-T030）
### T017 比武陪练，一招裂护体
- HARD（硬规则）：先报双方境界。陪练是羞辱不是切磋。一招，对照物必须碎。禁止技能解说。
- FORMULA（公式）：点名陪练、报数字、嘲「打死无论」→ 一招 → 护体纹裂或吐血 → 观众改口喊境界 → 更高层看见。
- VISIBLE（验收）：数字对不上，名额或面子易手一寸。

### T018 宴会装逼，仇人拿你家的令吹
- HARD（硬规则）：令必须是你家的指纹物。仇人吹的内容要具体（矿、城、婚）。男主抽令，不抽自己的身世演讲。
- FORMULA（公式）：仇人举令吹 → 你认出印 → 短手把令抽回或令认主 → 全场安静 → 钩：这令本不该出现在这张桌。
- VISIBLE（验收）：令易手，仇人当众假。

### T019 考核垫底席突然唯一通关
- HARD（硬规则）：先坐垫底，先被宣读零分或除名。通关要有可见榜文变化。禁止考完才说「其实我一直会」。
- FORMULA（公式）：垫底点名羞辱 → 考核开始别人当他空气 → 唯一灯亮/唯一铃响 → 榜文改名 → 旧规则执行者脸色变。
- VISIBLE（验收）：名次可视化，下一场有人要复核作弊。

### T020 当众炼丹，废炉出本图最高品
- HARD（硬规则）：先宣布炉废、料废、人废。出丹要当场验色验香，不要回房开箱。通胀锁：只出本图能用的最高，不出仙丹。
- FORMULA（公式）：当众断料/砸炉 → 他坚持烧完这一炉 → 丹成，执事验 → 名额或赔礼改数字 → 钩：有人要收这炉为宗门秘。
- VISIBLE（验收）：丹在桌上，仇人刚才的「废」原句还在空气里。

### T021 赌约押名额 / 婚约 / 灵石，对方输到脱籍
- HARD（硬规则）：赌约必须写下来或有证人。赌注是硬标的。赢了立刻执行，不准「下次再算」。禁止赢到让对方灭门（那是复仇卷）。
- FORMULA（公式）：对方起哄立约 → 写下名额/婚书/灵石 → 短比试 → 当场收赌注 → 钩：对方后台说这约不算。
- VISIBLE（验收）：赌注进他手或进名册，后台出场。

### T022 街头清余孽，跟班反被废
- HARD（硬规则）：清余孽要出示令或名单。跟班是现场刀，不是下令者。打跟班只是小糖，章末必须让出示令的人看见。
- FORMULA（公式）：拦路宣读余孽 → 动手 → 跟班废 → 令掉在地上 → 更高的人来捡令。
- VISIBLE（验收）：活命权暂时留下，通缉令还在。

### T023 长老当众打脸自己弟子：收的是你
- HARD（硬规则）：长老改口必须有物证（血脉、成绩、旧令），不能无故眼瞎识珠。男主可以拒收。禁止立刻改口叫师父然后温情。
- FORMULA（公式）：弟子当众辱你 → 考核或令亮 → 长老改称呼 → 弟子崩 → 你不拜或只收资源。
- VISIBLE（验收）：解释权易手，师徒关系未强制绑定。

### T024 「三月内必亡」的人当众破境
- HARD（硬规则）：预言要当众、有记录、有倒计时。破境要在同一批观众前。预言者必须丢脸，不是悄悄突破。
- FORMULA（公式）：宣读死期 → 压迫到最后一日 → 当众破境对照物出现（光、纹、铃）→ 预言者的招牌裂 → 钩：预言背后的堂口要灭口。
- VISIBLE（验收）：死期作废，预言堂的权威裂一寸。

### T025 末席坐下，上座起身让
- HARD（硬规则）：让座的人必须比嘲讽者高。男主不抢座，是别人让。禁止自己报「我该坐主位」。
- FORMULA（公式）：被按到末席 → 嘲讽 → 更高身份的人进门只看他 → 上座让/或末席突然变成主宾签 → 嘲讽者站着。
- VISIBLE（验收）：座位易手，身份只露齿。

### T026 扔来的废铁是器胚，认主
- HARD（硬规则）：先当众当垃圾扔。认主要当场，器要能当章用一下（挡一击、亮一纹）。禁止鉴定会八百字。
- FORMULA（公式）：扔废铁羞辱 → 入手发热认主 → 挡下当场一击或印亮 → 扔的人要抢回去 → 钩：这铁是谁府上失的。
- VISIBLE（验收）：器在他手，来历变成债。

### T027 群嘲大会，最后一个开口的人闭嘴
- HARD（硬规则）：嘲讽要具体轮流，不少于三张嘴。男主不逐个对骂。一刀让全场同一句噎住。
- FORMULA（公式）：轮流嘲（身份、实力、女人、家族）→ 他只做手续动作 → 一刀对照物碎或令亮 → 全场同一句说不出来 → 主持人或长老要圆场，圆不了。
- VISIBLE（验收）：舆论场暂时易手，必有人上报。

### T028 直播或擂台弹幕辱，数据当场打脸
- HARD（硬规则）：弹幕/赔率/热度是可视化数字。先低到尘埃。打脸是数字跳和对手麦没声。禁止主角对着镜头演讲三观。
- FORMULA（公式）：辱骂上屏、赔率一边倒 → 他干活（打、医、鉴、做）→ 数字反转 → 对手直播事故 → 钩：平台或金主要封他。
- VISIBLE（验收）：数据能截图， ban 的新债上来。

### T029 鉴宝：他们当赝品，你标真价
- HARD（硬规则）：先被当众判假、被赶出。真假要用当场能验的一招（纹、年款、内里），不写论文。标价或留下，立刻有人要抢。
- FORMULA（公式）：判假砸席 → 他指出一处对照 → 全场改口 → 原主人尴尬 → 钩：这件是赃或是灭门物。
- VISIBLE（验收）：真假易口，物的来历变主线。

### T030 一道菜 / 一张方子，名医或名厨改口
- HARD（硬规则）：先被赶灶/赶诊。菜或方必须治当场的急症或揭当场的毒，不是秀才艺。改口的人要有牌坊可打。
- FORMULA（公式）：赶人 → 危症抬上来 → 他下一菜或一针 → 危症缓、毒源指向在座某人 → 名医改口或更惨。
- VISIBLE（验收）：活人/场面被改，栽赃或毒成新债。

## 第三批 身份（T031-T040）
### T031 扮猪吃虎：杂役身份，袖里供奉令
- HARD（硬规则）：装低必须有好处（不暴露、能靠近、积燃料）。读者先见齿，场上后见。自己报「其实我很强」最弱。
- FORMULA（公式）：场上按杂役羞辱 → 他做杂役该做的事 → 令或印被别人看见 → 半句「见过」被打断 → 更高层要带人走。
- VISIBLE（验收）：公开身份仍是杂役，物证已上桌一角。

### T032 马甲掉落：别人喊见过，自己不报
- HARD（硬规则）：物证先于口。只升一档（杂役到供奉，不到仙帝）。打断优于喊完。
- FORMULA（公式）：物证放下 → 来人开口喊到关键词 → 门/剑/铃打断 → 局面改一寸 → 钩：撞门的人比供奉更大或要灭口。
- VISIBLE（验收）：称呼没喊完，公证已受影响。

### T033 灭门遗孤，血对上灭门令的印
- HARD（硬规则）：对印要当众或在仇人桌上。对上之后不哭，不演讲家史。血契是债，不是眼泪。
- FORMULA（公式）：仇人出示灭门令装逼 → 血或家印对上 → 令发热/反噬 → 当场最小兑 → 钩：下令者要收回所有令。
- VISIBLE（验收）：他被定义为余孽且令不再听仇人的。

### T034 假少爷，真继承人被掉包
- HARD（硬规则）：假的那个必须正在用真的名、地、婚。三齿：血、旧物、证人。揭完要清算，禁止「都是一家人」。
- FORMULA（公式）：假少爷当众辱真的 → 旧物认主或血验 → 族老改口一档 → 假少爷后台出场。
- VISIBLE（验收）：名籍缺口出现，掉包人未死，后台看见。

### T035 扫地隐世，仇人拜的是他徒孙
- HARD（硬规则）：隐世不自己揭。徒孙当众欺师灭祖式踩扫地人。认师的可以是徒孙跪，隐世仍可不应。
- FORMULA（公式）：徒孙踩扫把 → 礼数或功法反噬到徒孙 → 有人认出步法/印 → 半揭师门 → 钩：这门本已灭。
- VISIBLE（验收）：扫地身份还在，师门债起来。

### T036 白日杂役，夜里刑堂
- HARD（硬规则）：双身份要有泄漏风险当代价。白日被辱时读者知道夜里他审过同类。禁止两章完全割裂像两本书。
- FORMULA（公式）：白日被当众辱 → 同一批人夜里进刑堂 → 他按白日原句问他们 → 放回白日时他们不敢认 → 钩：有人要对上这两张脸。
- VISIBLE（验收）：至少一个人发现重叠，追杀升级。

### T037 炮灰撕剧本，天命主角踩空
- HARD（硬规则）：天命主角要有剧本特权（气运、女主、任务）。男主撕的是第一场该死的戏。禁止开场把天命打死（主线没了）。
- FORMULA（公式）：剧本死法启动 → 他让死法落到别人或落到空处 → 天命主角的光环当众失灵一寸 → 系统或气运报警。
- VISIBLE（验收）：炮灰活，天命开始针对他。

### T038 敌族少主血脉（揭完必须清算，禁止和解）
- HARD（硬规则）：血脉是刀不是回家的票。敌族认亲是为了用他，他认血是为了拆敌。禁止认亲拥抱。
- FORMULA（公式）：血脉验出 → 敌族当众要收编 → 他用血脉开他们的门或令，反过来伤他们 → 灭门账对照 → 钩：敌族家主要灭自己这支血。
- VISIBLE（验收）：血脉已暴露，亲情未成立，猎杀开始。

### T039 战神归来，旧部当街跪，新贵还在骂逃兵
- HARD（硬规则）：骂逃兵要充分。旧部跪是掉马，不是男主点名。新贵的靠山必须紧接着出场。
- FORMULA（公式）：当众骂逃兵/懦夫 → 旧部看见疤或令跪 → 新贵脸裂 → 更大的军或宗出场要编制。
- VISIBLE（验收）：逃兵名未洗完，编制权成新标的。

### T040 被当双修炉鼎，其实是功法主
- HARD（硬规则）：炉鼎羞辱要当众。反转是功法认主或反客抽走对方修为/ copulation 写成「功法反噬抽走气机」，不写色情。禁止因此开后宫。
- FORMULA（公式）：当众按炉鼎绑 → 双修阵起 → 阵心认他为主，对方反被抽 → 观众改口 → 钩：要炉鼎的势力改要活擒功法主。
- VISIBLE（验收）：炉鼎名反套，人身威胁升级。

## 第四批 资源（T041-T050）
### T041 秘境血契独开，门外排队
- HARD（硬规则）：先写别人排队、验血失败。他的血契当章能进。进去立刻有争夺，不是观光。
- FORMULA（公式）：排队嘲他没资格 → 门认血开 → 独进或少进 → 里面第一件物与灭门/退婚有关 → 门外有人要砸门。
- VISIBLE（验收）：资格可视化，秘境里的物挂主线。

### T042 截宝的人把宝双手奉上
- HARD（硬规则）：先被截、先被搜。宝认主或反噬截的人，逼他双手送回。禁止男主苦苦哀求。
- FORMULA（公式）：拦路搜身夺宝 → 宝烫/认主/反噬 → 截者跪送回来 → 钩：截者背后的买主要原件。
- VISIBLE（验收）：宝在他手，买家成新债。

### T043 人人不要的残页是总纲
- HARD（硬规则）：先当众当垃圾。对上全文或对上他袖里另一页才亮。当章必须用出一招，禁止回房翻译十章。
- FORMULA（公式）：扔残页羞辱 → 他对上自己的缺页 → 当章用总纲改眼前一局 → 有人认出这是禁术目录。
- VISIBLE（验收）：残页升成指纹物，禁术债起来。

### T044 别人救命丹你当早饭
- HARD（硬规则）：反差要有对照（别人一粒千金，他吃了像嚼豆）。当章有人因缺丹要命或要买，他可以不给仇人。禁止无节制炫富发仙丹。
- FORMULA（公式）：有人哀求/拍卖救命丹 → 他从破碗里拿出同品吃掉或扔下 → 全场数字崩 → 有人要抢他的药囊。
- VISIBLE（验收）：财力/丹力反差成立，抢夺开始。

### T045 被占矿脉随残谱一亩亩亮回
- HARD（硬规则）：这是名单流的可视化，每兑一人亮一块，不要一次亮完。亮回要当众改地契或矿灯。
- FORMULA（公式）：仇人在矿上开宴 → 残谱发热对应这一亩 → 契印改字或矿脉不认仇人 → 最小冲突 → 钩：下一亩在谁名下。
- VISIBLE（验收）：进度条可见，未一次收全。

### T046 拍卖一口价，全场哑
- HARD（硬规则）：先穷样、先被请出去或被限价。一口价要有来源（令、欠条、真正的物主权），不是数字无限。
- FORMULA（公式）：被嘲买不起 → 他报一口或亮物主权 → 拍卖师改口 → 仇人拍到自己被盗的东西或拍破产 → 钩：拍卖行后台查他来历。
- VISIBLE（验收）：物或面子到手，金主出场。

### T047 他们抢的蛋隔空认你
- HARD（硬规则）：先抢、先争、先当他没资格碰。蛋/兽认主要当着抢的人。兽不讲萌，要能当章挡一击或曝光身份。
- FORMULA（公式）：拍卖或秘境抢蛋 → 蛋飞向他 → 抢的人攻击 → 幼体挡或反噬 → 钩：这蛋是某圣兽遗脉，宗门要收。
- VISIBLE（验收）：认主完成，争夺升级到宗门。

### T048 仇人洞府钥匙在你手里
- HARD（硬规则）：钥匙来源要交代（灭门遗物、搜身所得）。开门必须当众打脸或当众夺宝，禁止偷偷搬空十章。
- FORMULA（公式）：仇人夸洞府无人能进 → 他亮钥匙或血开 → 门开，里面有灭门物证 → 仇人要毁府 → 钩：洞府底层还有写律者的印。
- VISIBLE（验收）：门开了，物证出来了，幕后齿留下。

### T049 灵兽当众改口叫主人
- HARD（硬规则）：先是仇人的兽、先听仇人的。改口要当众，仇人面子裂。禁止灵兽讲相声。
- FORMULA（公式）：仇人放兽咬他 → 兽停、改口或改跪 → 仇人鞭兽无效 → 兽跟着他走或留下信物 → 钩：驯兽世家要问罪。
- VISIBLE（验收）：兽权易手，驯兽规则成债。

### T050 仇家聘礼原路退回还加码
- HARD（硬规则）：聘礼是退婚场的可视化。抽回是小糖，加码（令、地契）才升档。不加码就只是讨饭。
- FORMULA（公式）：聘礼单被收 → 他按单要回或抽回 → 额外多抢一寸（利息、名额、令）→ 对方父母改口或更怒 → 钩：加码的那件东西来历不正。
- VISIBLE（验收）：聘礼回，额外物成下一环指纹。
