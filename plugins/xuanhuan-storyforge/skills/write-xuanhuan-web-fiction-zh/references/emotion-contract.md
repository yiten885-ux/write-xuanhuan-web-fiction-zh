# 情绪合理性合同（锚定 · 烈度 · 生理优先 · 节奏 · 共鸣）

> 来源：pasted_text_20260827-073149（report 32）。配套溯源：rules/rule-32.md。本文件是情绪表达的标准与底线合同，作为**前置协议**在所有情节生成前优先执行；与 language-contract.md（语6 心理≤两成）、SKILL §5.6（情感先行）、reversal-special.md（转5 旁观者≥2，同源一致）叠加。

## 适用范围

写任何情绪触发场景（羞辱/退婚/背叛/杀亲/夺宝/嘲讽/反转/爆发）时必读。核心问题：AI 最容易在关键时刻写出「面瘫主角」——该怒不怒、该悲不悲，读者无法共情、爽感减半甚至弃书。爽文的核心是**情绪的极致释放**，不是压抑或淡漠。

## 硬规则总表（情1-情5，R32 全量）

- **情1 情绪锚定清单**：九种经典场景（当众羞辱退婚废黜 / 背叛绿帽 / 亲人恩人被杀 / 被踩脸踩尊严 / 所得被夺 / 被嘲讽废物 / 爱人受伤 / 长年积怨爆发 / 真相大白）必须触发标配情绪（至少三选一且含外化动作），不得弱化、合理化或跳过；禁止「面无表情/毫无波澜/淡然一笑/静静看着」（人设「天生无情」例外，且须前三章明确）。情绪词 <3 个或全为平静/淡然 = 情绪缺位，强制重写。
- **情2 烈度场景匹配**：高烈度（9-10 分）≥100 字+≥3 外化动作+≥2 感官；中烈度（5-8 分）≥50 字+≥2 动作+≥1 感官；低烈度（1-4 分）≥20 字+≥1 动作。|M|>3（严重度与烈度差）= 情绪错位，强制调整。红线：父亲被杀只写「握了握拳」、被退婚只写「他走了」= 违规。
- **情3 生理本能优先**：先生理本能（脸烧/手抖/牙咬/瞳孔缩/心跳漏拍/青筋暴起），再心理，最后语言/动作，顺序不可颠倒；禁止「他心想：我好愤怒」式开头。真实度 T = 生理 0.4 + 心理 0.2 + 外化 0.4；生理为 0 → T≤0.6 假情绪，强制插入。
- **情4 宣泄与克制节奏**：连续隐忍≤2 章；第 3 章必须有克制释放（冷笑放狠话/暗中动手脚/眼神威慑）；宣泄爆发必须有实际后果；黄金比例隐忍:宣泄 = 6:4；憋屈指数 F = 隐忍×1.5 − 宣泄×1 > 3.0 强制宣泄。
- **情5 旁观者共鸣放大器**：烈度≥8 分场景必须≥2 个旁观者反应（同情/嘲讽/震惊三型），用于验证合理性、放大共情、积累反转势能；A = 人数×0.6 + 强度权重 < 2.0 强制插入。

## 合格 / 不合格对照

❌ 被当众退婚（情绪缺位）：
> 「陆沉，你我婚约今日作罢。」柳如烟将婚书扔在地上。陆沉面无表情地看着她，转身离开了人群。

✅ 合格（锚定+生理优先+旁观+宣泄种子）：
> 柳如烟的声音在演武场上回荡，婚书像丢一张废纸般落在泥地。
> 陆沉浑身一僵，脸烧得发烫，耳根红透，双拳在袖中攥得指节发白，胸口闷得透不过气。
> 七年的陪伴，换来一地烂纸？他想冷笑，嘴角只抽动了一下，化作自嘲的弧度。
> 人群哗然，有人嗤笑「废柴果然配不上柳师姐」，几个女弟子偏过头不忍再看。
> 陆沉弯腰捡起婚书，缓缓折好，目光掠过柳如烟身后的锦衣男子，嗓音沙哑而平静：「这婚约，我接了。三年后，我会让你亲手拿回去。」

❌ 被戴绿帽（过度隐忍）：
> 陆沉推开房门，看到妻子与陌生男子同卧一榻。他沉默片刻，转身轻轻关上了门。

✅ 合格（生理优先+外化+低烈度宣泄+旁观）：
> 瞳孔骤缩，浑身的血冻住又烧成岩浆。太阳穴突突狂跳，牙关咬得咯咯作响，颈侧青筋暴起，眼前发黑。
> 手按剑柄，指节咯咯作响；房门被灵力撞上，轰然巨响，室温骤降。
> 他开口，声音沙哑得像铁片摩擦：「你们……活腻了。」
> 廊外丫鬟吓得瘫软，尖叫引来家丁，无人敢上前。

## AI 执行优先序（生成情绪触发场景前）

1. 场景命中锚定清单？→ 调用标配情绪模板。
2. 严重度对应烈度等级？→ 匹配表达强度。
3. 情绪表达以生理本能为开端？→ 否则强制插入。
4. 主角已隐忍多章？→ 是则强制宣泄。
5. 旁观者足够？→ 不足强制插入。

## System 锁死段（可直接贴进提示词）

```text
【情绪合理性模块】
主角情绪表达必须遵守：
1. 锚定强制：命中[退婚/背叛/杀亲/踩脸/夺宝/嘲讽/爱伤/积怨/真相]九类场景时，触发标配情绪（愤怒/羞辱/暴怒/悲痛/不甘），禁止面无表情或淡然。
2. 烈度匹配：高烈度（≥8分）≥100字+≥3动作+≥2感官；中烈度（5-7分）≥50字+≥2动作+≥1感官；低烈度（1-4分）≥20字+≥1动作。
3. 生理优先：先生理本能（脸烧/手抖/牙咬/瞳孔缩/心跳/青筋），再心理，最后语言/动作。
4. 隐忍上限：连续隐忍≤2章，第3章必须有释放（放狠话/小反击/暗中布局），禁止憋屈超3章。
5. 旁观者放大：高烈度场景插入≥2个旁观者反应（同情/嘲讽/震惊），作为情绪外部验证。
若任一指标不满足，标注【情绪失效】并强制改写。
```

一句话总纲：**命中九类场景就必须有标配情绪，烈度跟着事件走，先写身体再写脑子，憋屈不过三章，高烈度场面至少两个旁观者替读者惊呼。**
