# 系统流合同（2026-08-31 审查补齐 A1）

> 本文件是用户增补的内部合同，不是读者内容。适用于金手指类型为"系统任务/面板"的书籍（白名单 D4 类型 1）。与 v1/v2/v3、01–10、九项留存、5.20–5.24 并列累积；只能新增阈值与检查，不能替换或放宽既有任何锁。SKILL.md 侧蒸馏见 §5.25。

## 1. 面板硬格式

1. 面板单次呈现 ≤3 行；超过 3 行的信息拆成两次触发，禁止一次性大段面板。
2. 面板必须含至少一个数字（任务进度 x/y、倒计时、奖励清单），禁纯文字面板。
3. 面板只进叙述，不进角色对白（语14）；角色不得复述面板原文。
4. 面板触发必须有因（任务节点/击杀/抉择），禁无事件弹面板。

## 2. 任务四元组（缺一不发）

| 字段 | 要求 |
|---|---|
| 目标 | 可量化（击杀 x 只 / 取回 x 物 / 护送至 x 地），禁"变强""成长"式模糊目标 |
| 时限 | 明确（本章内/三日/抵达前）；无时限任务不得成为主任务 |
| 奖励 | 可验证（具体物品/数值/权限），禁"随机大礼" |
| 惩罚 | 可执行（扣属性/降评价/追杀）；失败必须真惩罚，禁"警告了事" |

## 3. 系统人格

1. 三选一：坑主（诱导接锅）/工具（冷漠结算）/贴心（护主但吝啬）——开书锁定，全书不得中途换人设。
2. 系统吐槽、情绪、私心只在面板与系统腔内呈现，禁入角色嘴（语14）。
3. 系统人格一致性逐章登记人设账（SKILL §7.4）。

## 4. 奖励边界

1. 系统奖励禁直接给境界、禁直接给越级战力；战力增长必须经主角修炼或代价兑换（对02 四拍拍 3）。
2. 大奖必带新麻烦（新债/被注视/任务升级），禁纯奖励无副作用。
3. 系统不得代主角做核心选择（C04 不解释；只给选项与信息，选与打由主角）。

## 5. 开篇与节奏

1. 系统流第 1 章必出面板（B2/R02 当章兑现），首任务必须与开篇死线绑定（留存锁1）。
2. 面板首秀之前不得出现第二次超凡展示（HOOK-EMO-01 顺序锁不变）。
3. 连续 3 章无任务推进 = 水章；任务链每 5 章一个小结点（对齐 E1 爽点日历：第 5、10 章中爽）。
4. 章末面板异动可作为升级型钩子（对齐 E6），但禁纯数字跳动无事件。

## 6. 自检（5 项，登记 QA 侧车）
