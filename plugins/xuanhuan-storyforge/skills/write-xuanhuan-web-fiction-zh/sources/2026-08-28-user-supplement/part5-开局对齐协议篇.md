# 给 Skill 补的不是「再写一遍爆款」，是一层**优先级更高的对齐协议**

这 16 条会同时出现，通常不是模型不懂爽点，而是你现有 skill 里 **文笔/物件/氛围/人设** 和 **开局兑现** 平级甚至更高。模型会优先满足「写得像、物件密、不解释、代价狠」，于是金手指变成觉醒、木牌抢走主线、打脸当场吐血。

**插入位置：** 全局铁律之后、文笔/去AI/意象层之前。  
**优先级：P0 卖点主权 > P1 金手指循环 > P2 仇与欲望 > P3 开篇节奏 > P4 配额与地图 > P5 气味文笔。**  
P5 与 P0 冲突时，P5 让路。没有这条，下面所有公式都会被「写得好」顶掉。

---

## 0. 写正文前必填：开书契约卡（缺一格禁止开写）

```
书名主语（读者以为这本书在玩什么）：______
金手指类型：租 / 得 / 系统 / 其他
循环四拍（获得/使用/代价/偿还或违约）：
  1.___ 2.___ 3.___ 4.___
开篇死线（数字+时限+失败后果）：______
开篇活仇人（第3章结束仍握有的资源）：______
主角此刻唯一在烧的欲望：______
护短网（命根/人情种子/会拖后腿的活人）：______ / ______ / ______
战力梯子一句土话：______
第10章前的新功能地：______
书名关键词（每章场面必须出现）：______
禁止抢戏的道具（可当线索，不可独立结开篇债）：______
```

**FAIL-IF：** 契约卡未填完整仍写第1章。

## 1. 十六条硬规则 + 一条公式（可直接粘贴）

每条格式固定：**MUST / NEVER / FAIL-IF / 公式**。模型只吃得动这种。

---

### R01 卖点主权 → 洞1「道具抢戏」

- **MUST：** 前三章主线每推进一步，书名承诺的金手指必须在场（用技、抢手、发热、还愿、反噬，任一）。
- **NEVER：** 用可被夺走的道具独立解决开篇主矛盾。
- **FAIL-IF：** 把金手指段落删掉，第3章结局不变。

**公式 F01 卖点主权测试**

```
书名主语 = 简介主语 = 前三章高潮主语
高潮场面里「真正干活的那个东西」必须能写进书名
```

操作：写完第3章，用一句话回答「这一局是谁赢的」。答案若是牌、契、官面、路人，重写，直到答案是骨头/租来的技/死人的愿。

---

### R02 循环演示 → 洞2「读者不会玩」

- **MUST：** 前三章内把金手指完整跑通一轮：获得 → 使用 → 代价出现 → 偿还或违约 → 可见强化或可见反噬。
- **NEVER：** 只开窍、只展示、只受伤，没有偿还拍。
- **FAIL-IF：** 读者看完三章答不出「下次碰到同类资源，我该怎么操作」。

**公式 F02 金手指四拍（开局必须演一遍）**

```
拍1 获得：资源进身，规则用场面亮出（骨字/口诀/代价可见）
拍2 使用：用它打赢「原先打不赢的一寸」
拍3 代价：血/冷却/反噬，但不得与拍2同镜
拍4 偿还或违约：还了→技增；不还→技抢身/规则收息
= 读者会玩
```

租赁类再加一条：**拍4 不出现，禁止写第4章。**

---

### R03 先满后亏 → 洞3「大爽被代价冲掉」

- **MUST：** 大爽（越级打脸、当众翻盘）先完成「落差落地 + 旁人反应链」，再切代价。
- **NEVER：** 吐血/反噬/虚弱与打脸同一拍。
- **FAIL-IF：** 打脸段落里，代价句出现在围观反应之前。

**公式 F03 先满后亏**

```
落差落地 → 旁人反应≥3句（认技/传话/敌方丢人）→ 余波（态度翻转）→ 再代价
```

反应链最低配置：1个懂行的、1个传话的、1个敌方自己的人先退。没有这三句，不准写嘴里的血。

---

### R04 活仇人 → 洞4「反派纸、开篇债结案」

- **MUST：** 第3章结束，开篇具名反派仍握有至少一项开篇资源（债/权/药/信息/人质/河道）。
- **NEVER：** 开篇死线在第3章被一次性结清（撕借据、灭门、反派逃出地图且不再能下手，都算结清）。
- **FAIL-IF：** 第4章起床，主角不再怕这个人。

**公式 F04 赢一寸，枷锁紧一圈**

```
主角得到：A（药/名/地契暂管）
反派失去：面子
反派仍握：B（更重的账/河道/更高的人）
B 必须在第3章当场面亮出，不得只在败退台词里补丁
```

---

### R05 黄金三段 → 洞5「冲突进场晚」

- **MUST：** 前300字内同时出现：主角动作、带数字的死线、金手指预热。
- **NEVER：** 先环境/气味/职业介绍，再用闪回交代冲突。
- **OVERRIDE：** 文笔层若写「氛围先行」，开篇300字内无效。气味可作第二句修饰，不可作第一段主体。

**公式 F05 黄金三段（2026）**

```
段1 动作+死线：谁在干什么 + 几日/几两/失败后果
段2 人设反差：贱身份 + 一口硬/一笔账（踢钱、拒棺、不接缓）
段3 金句或金手指预热：物件发热/残技/半句话，独立成段
```

禁开：天气、全景、身世履历、职业规矩说明书。

---

### R06 战力标尺 → 洞6「赢了不疼」

- **MUST：** 第一次越级胜之前，用一句角色土话给出：梯子、这一式的上限、只能赢哪一寸。
- **NEVER：** 用路人事后喊技能名来代替标尺。
- **FAIL-IF：** 读者排不出「上一层打谁、下一层打谁」。

**公式 F06 标尺句（一句话三项）**

```
梯子 + 本式上限 + 本场只取一寸
例：炼血五重开碑，过江龙全套断桅；他只有斜撩，第三行没刻完，所以削刀不取人头。
```

位置：出手前或刀碰刀的那一拍，不得到章末说明书。

---

### R07 对人沉默，对读者过账 → 洞7「不解释=读者不知情」

- **MUST：** 「不解释」只约束对白。每章必须给读者三通道之一：心里过账 / 旁人传话 / 物件记账。
- **NEVER：** 用事后揭秘连续超过两章作为智斗主手段。
- **FAIL-IF：** 章内主角布了局，读者在揭晓前没有任何可跟的账。

**公式 F07 不解释三通道（每章至少2条）**

```
过账：一文/一钉/三日/十八两（人设是算账就当场算）
传话：何婶/船老/账房把「他横/这刀眼熟/白家栽了」说出来
物件：小本、铜钱、刀自己走、碑文偏向
```

禁止用大段独白完成这三条。他仍可以不说话。

---

### R08 意象配额 → 洞8「象征分食情绪」

- **MUST：** 前三章只允许同时亮：1条明线死线 + 1套金手指规则 + 1个章末主扣。
- **NEVER：** 新意象>3个且未回收、未标记「锁进抽屉」。
- **FAIL-IF：** 章末钩子是灯花/数字异样/物件降温，而不是情节拐点。

**公式 F08 3章预算 1-1-1**

```
明线1：数字死线（债/药/三日）
规则1：金手指怎么玩
主扣1：下一章必须咬的情节（马蹄/卯时/验尸/第二资源）
其余锁抽屉：第4章后按需开
```

本章新意象若不开抽屉，写完即删。

---

### R09 护短必须有短 → 洞9

- **MUST：** 前三章亮出至少2个主角愿意付代价的活人；第3章至少把一条人情种子接住（记入短，不是谢过就散）。
- **NEVER：** 护短人设只有师父一个支点。
- **FAIL-IF：** 删掉师父，主角不再有能被捏的东西。

**公式 F09 护短三格**

```
命根（师父）+ 人情种子（何婶/账房/保正）+ 会拖后腿的活人（即将被抵矿/欠药钱/要收的尸）
第3章动作：把种子写成「以后是短」，写入他的账本或骨头反应
```

---

### R10 类型一句土话 → 洞10「修真还是权谋」

- **MUST：** 前三章用场面亮出力量梯子，并钉死开场地图在世界中的功能（下水道/回收处/账房底层）。
- **NEVER：** 只抛「练气修士」一词，不给梯子、不给这本书的战场。
- **FAIL-IF：** 读者无法判断自己在追低武修真、权谋、还是灵异。

**公式 F10 类型承诺（土话，不准说明书）**

```
力量怎么来 + 开场地图吃什么 + 主角走哪条歪路
例：炼血的开自己的碑，拓碑的开死人的碑。开自己的能活，开死人的葬得快。义庄是收执念的下水道。
```

由配角在冲突里说，不在章末讲史。

---

### R11 三镜对齐 → 洞11「书名简介正文三套镜头」

- **MUST：** 书名关键词、简介承诺的爽、前三章可截图场面，三者同一主语。
- **NEVER：** 简介写文学导语却不装已有弹药（残刀、当众按牌、七碑）。
- **FAIL-IF：** 用书名三词检索前三章，第3章场面里缺席任一核心词。

**公式 F11 三镜主语锁定**

```
书名：[身份地图] + [金手指动作]
简介三段：死线 / 规则（租不是得） / 本章能看到的爽 + 仍欠的债
正文：每章场面出现书名关键词，高潮主语=金手指
```

简介禁止只写气味。必须包含：数字死线、规则一句、已写出来的爽点画面。

---

### R12 租约四件 → 洞「觉醒不是租」

- **MUST：** 租赁/拓碑类金手指在前三章钉死四件：租约、租金、违约、退换（槽位）。
- **NEVER：** 一次性开窍却在简介自称「租」。
- **FAIL-IF：** 没有槽位规则（七碑）的可操作含义（满了怎样、能不能卸、下一道顶哪一道）。

**公式 F12 租约四件套**

```
租约：什么资源可拓（执念未消的遗骨）
租金：显性（血/七日）+ 隐性（愿进骨）
违约：愿空碑蚀 / 技抢身 / 夜半走别人的路
退换：七槽；满则下一道把最先一道连人带技葬掉
```

四件必须在场面里出现至少一次，允许骨字/醉话/小型还愿，禁止系统弹窗（除非书名就卖系统）。

---

### R13 资源给技，也必须给人 → 洞「过江龙是道具」

- **MUST：** 每一个被金手指吃掉的对象=人物卡，不是技能包。
- **NEVER：** 只给外号+技能名+器官特征。
- **FAIL-IF：** 读者叫不出这个死人要主角替他做什么。

**公式 F13 尸卡五格（每拓必填）**

```
名/外号 | 死法 | 一式技（残完整与残缺原因）| 一句没说完的愿 | 还愿会踩谁的局
```

愿必须具体到可执行（砍哪根桅、送谁回去、把牌按在谁的契上），禁止「江水声」「不甘」。

---

### R14 欲望单核 → 洞「此刻要什么」

- **MUST：** 同时只烧一个欲望。每章开头能用一句话回答「他此刻要什么」。
- **NEVER：** 开篇债结案后真空；也禁止三章换三个互不相关的欲望。
- **FAIL-IF：** 第3章赢完，第4章起床目标要靠作者说明书补。

**公式 F14 欲望四层，正文只烧一层**

```
眼前：药/三日/这口棺     ← 前三章明烧
骨头：第一笔还愿         ← 第1章进骨时挂上
地盘：这条街的短         ← 第3章接住
长线：七碑/师父是谁/锁   ← 锁抽屉
```

开篇债只许**升级**（十八两变成河上那一笔），不许结清。

---

### R15 十章换地 → 洞「缺地图」

- **MUST：** 第10章前，读者踏上新功能地，或新功能地的人踏进开场地图。
- **NEVER：** 前十章只在同一室内场景用物件变花样。
- **FAIL-IF：** 功能地（矿/码头/验尸场/乱葬滩）只在台词里存在。

**公式 F15 副本钟**

```
Ch1-3  开场副本：循环演示 + 活仇 + 死线升级
Ch4-6  同循环第二次（第二资源/第二尸）
Ch7-10 新功能地或外来高阶压力兑现（验尸吏必须下场，不只被提及）
Ch20   开场地图翻面
Ch30   第一笔还愿完成或失败（技完整或技反噬）
```

---

### R16 一章一动作，关键词在场面里 → 洞「章法/标签」

- **MUST：** 单章一个核心动作；书名关键词在**场面**中出现（不是回忆）；章末钩子是情节拐点。
- **NEVER：** 一章里灭火+打脸+讲史+数意象；章末用物件降温当钩子。
- **FAIL-IF：** 听书切片抽章末200字，听不出下一章要干什么。

**公式 F16 章职责（前三章锁死）**

```
第1章：死线进场 + 金手指获得 + 规则露头 + 微型还愿可发生 + 钩子=外来压力
第2章：金手指第一次赢「原先赢不了的人」+ 先满后亏 + 钩子=对峙预约/尸的愿未还
第3章：智斗可赢，但金手指必须在场；开篇债升级不结案；钩子=第二资源/高阶压力兑现日
```

章末钩子六选一（悬念/威胁/信息/反转/选择/情绪定格），**禁止第七种：文学意象**。

## 2. 前三章总公式（把 16 条收成一条流水线）

**F00 开局流水线**

```
300字：动作+数字死线+预热
第1章：尸卡五格 + 租约四件露头 + 微型还愿 + 卖点在场
第2章：标尺句 + 越级只取一寸 + 先满后亏 + 活仇人退但不死
第3章：三通道过账 + 护短接种子 + 类型土话已出现
      + 高潮主语=金手指 + 赢一寸枷锁紧一圈
      + 章末主扣=下一章必须咬的情节
通关测试：删金手指结局必变；读者能复述怎么玩；第4章起床仍怕一个具名的人
```

```
[ ] F04 开篇反派还握着哪项资源？写得出来才过
[ ] F05 前300字有数字死线吗？
[ ] F06 越级胜之前有标尺句吗？
[ ] F07 本章过账/传话/物件，满2条吗？
[ ] F08 是否超出 1-1-1 预算？
[ ] F09 除师父外还有短吗？第3章接住了吗？
[ ] F10 类型土话出现在冲突里了吗？

```

**硬门槛：** FAIL ≥ 1，禁止进入下一章。第3章必须 F01/F02/F04/F14 全过。

## 4. 现有 Skill 里要对齐的冲突规则（不改这条，新规则会被吃掉）

往你的 skill 里搜这些旧条，加上 **OVERRIDE**：

| 旧规则倾向 | 必须改成 |
|---|---|
| 氛围先行 / 物件密度 / 五感开场 | 仅 P5；开篇300字让路给 F05 |
| 人设「不解释」 | 加 R07：对人沉默，对读者必须过账 |
| 金手指第1章出现 | 改为「第1章内跑通四拍，不是露一面」 |
| 代价要狠 / 暗黑要抑 | 加 R03：先满后亏，代价后置一拍 |
| 每章留意象伏笔 | 加 R08 配额，超额锁抽屉 |
| 第3章给首个大爽/翻盘 | 加 R04：翻盘≠结案 |
| 智斗事后揭 | 最多连续1章，第2章必须让读者跟账 |
| 系统面板展示规则 | 租赁书禁止弹窗；用骨字/还愿反馈/土话 |

建议在 skill 顶部加一句总闸：

> **爆款对齐优先于文笔对齐。** 开篇三章若 F00 未通关，禁止扩写气味、象征、身世、世界观说明书。

---

## 5. 不要加进 Skill 的规则（会把这书写废）

- 不要加「必须系统面板 / 必须每章升级」。与「租」冲突。
- 不要加「前十章拓满七碑」。稀缺是卖点，第二次拓放在 Ch4–6。
- 不要加「主角开口解释局」。会毁掉不解释。
- 不要加「反派不许认栽」。许认栽面子，不许交账本。
- 不要加「禁止文学句」。金句白名单保留（护短句、过账句、反派账房句），禁止的是用意象当钩子。

## 6. 最小粘贴块（只加得动 6 条时）

若 skill 篇幅紧，只注入这 6 条，16 个洞能堵 80%：

1. **P0 总闸**（文笔让路）
