# 补充三：网文 skill 的“结构性规则”——从单章合格到全书架构

前两份规则解决了“单章怎么写”和“读者为什么不弃书”，但还有一个致命缺口：**AI 擅长写单章，却容易在连续多章中失去方向感和节奏递进**。以下补充聚焦于“全书骨架”和“跨章节的隐形推手”。

---

## 二十七、“爽点/虐点/燃点”三类场景必须按比例分配

**问题诊断**：前三章整体偏“虐”和“冷”，爽点只有一处（砍曹六），燃点几乎没有。读者被压了三章，却没有一次“燃起来”的时刻，会累。

**核心概念**：中文网文读者的情绪体验，本质上是在三类场景之间反复横跳：

- **爽点**：主角打脸、得宝、破局，读者看完舒坦
- **虐点**：主角吃亏、失去、被逼入绝境，读者看完揪心但更想看后续
- **燃点**：主角或同伴说出/做出让人热血上涌的事，读者看完想站起来

三类缺一不可。只有爽会腻，只有虐会跑，只有燃会空洞。

**创作规则（硬性）**

1. **每3章内必须出现三类场景各至少一次**，且顺序有讲究：  
   - 虐点在前（制造压抑）  
   - 爽点在中（释放一部分）  
   - 燃点在后或与爽点重叠（把情绪推到最高）  
   - 最后用悬念收尾（留下余味）

2. **燃点的定义要清楚**：不是打斗赢了叫燃，而是**一个人在最不该站出来的时刻站了出来**。比如：  
   - 沈拙明知打不过，还是挡在师父门前  
   - 耿老倌被捆在桥头，拼着断绳也要敲响那面锣  
   - 何婶在满街人噤声时，第一个喊出“沈小哥”  

3. **燃点场景必须给足“仪式感”**：动作慢一点，画面定格一点，让读者有时间起鸡皮疙瘩。

**写作公式**
```
[虐点：主角/同伴受伤、失去、被羞辱] → [短暂沉默/压抑] → [爽点：主角出手/反击/打脸] → [燃点：一个出乎意料的角色或主角自己做出象征性动作] → [悬念收尾]
```

**示例**：第二章如果加一个燃点，可以在火灭之后：
> 火灭了。薄皮棺烧塌了。  
> 沈拙蹲下来，把崩散的棺钉一枚一枚从雪里捡起来。  
> 三十六枚，他攥在手心，钉尖朝外，像攥着一把没开刃的刀。  
> 然后他站起来，看向曹六离开的方向：“这口棺材，我还会再打一口。打给你的。”

## 二十八、金手指的“成长曲线”必须和“敌人强度曲线”同步走，不能一直打平级

**问题诊断**：前三章里，主角拓了一碑就能砍退炼血五重，但白三爷是什么级别？河伯是什么级别？晏大人是什么级别？主角接下来打得过谁、打不过谁？读者心里没数。

**核心概念**：网文读者的爽感依赖于**清晰的战力阶梯**。他们需要知道：主角现在在第几层，上面还有几层，每层差多少。有了阶梯，每一次升级或越级才有意义。

**创作规则（硬性）**

1. **前五章内必须亮出战力的“三层楼”**：  
   - **地上层**：凡人/低阶修士（曹六：炼血五重，被主角一刀逼退）  
   - **台阶层**：中阶修士/权势者（白三爷：大约炼血九重或练气初境，主角目前不敢硬碰）  
   - **楼上层**：高阶存在（河伯、晏大人、师父的过去，只闻其名不见其人）  

2. **每次主角升级（拓碑），必须明确他“能打谁了”或“还打不过谁”**。升级不是抽象变强，而是**在阶梯上往上挪了半格或一格**，并且读者能看见那个“打不过的人”还在上面等着。

3. **禁止出现“主角突然打赢一个之前完全没铺垫过的强敌”**——除非这个强敌的“强”是吹出来的，实际水分大（网文常用但要有铺垫）。

**写作公式**
```
[主角当前层级] → [升级/拓碑] → [展示能力：打败一个略高/同级的对手] → [点出：还有谁打不过] → [给出“再升一级”的方向]
```

## 二十九、全书开篇要有“棋盘感”——三个以上势力在同一张桌子上博弈

**问题诊断**：前三章只有两个势力（白家和义庄），赵保正、邬先生、耿老倌都是“帮助主角的NPC”，没有形成真正的**多方博弈**。读者感觉这个镇子太小，故事容易写到头。

**核心概念**：爆款文的开篇世界观，至少要有**三方势力在互相盯着**，让读者觉得“这盘棋有意思，我想看他们怎么下”。两方对立太单薄，很容易变成“主角一直挨打然后反击”的单调循环。

**创作规则（硬性）**

1. **前五章内至少出现四个势力**，且各有各的算盘：  
   - **白家**：镇上的钱和势，背后可能是河伯或官府  
   - **义庄**：主角和师父，守着一堆死人秘密  
   - **县衙/晏大人**：官面势力，态度暧昧，可能查白家也可能查主角  
   - **河上的漕帮/河伯**：盘踞水路的暗势力，和白家有账要算，和过江龙的死有关  
   - **镇民/耿老倌/何婶**：底层百姓，有自己的小算盘，随时可能倒向任何一方  

2. **每个势力至少有一句台词或一个动作，让读者看出“他们不是铁板一块”**：赵保正怕呈文含糊连累自己、邬先生欠沈家恩情但不敢明帮、漕帮和白家面和心不和。

3. **主角必须至少成为两个势力拉拢或利用的对象**。只有一方打压、一方保护，格局太小。

**写作公式**
```
[场景中出现或提及势力A] → [A的私心通过台词/动作露出] → [主角察觉或未察觉] → [B势力出现或暗示，与A有利益冲突] → [主角站在中间，成为筹码或变数]
```

## 三十、“名场面”要在开篇就设计，不能靠后期灵感

**问题诊断**：前三章读完，读者能记住的画面是“火场、断刀、木牌”，但没有一个**让读者想截图、想转发、想讨论**的“名场面”。网文的口碑传播，靠的就是这些能被单独拎出来的瞬间。

**核心概念**：名场面不是“写得好的段落”，而是**“可以脱离上下文传播的画面+台词组合”**。它必须同时满足三个条件：画面感极强、情绪浓度极高、核心台词只有主角能说。

**创作规则（硬性）**

1. **每10章至少设计一个“名场面”**，前五章内至少有一个。名场面的结构：  
   - **前置压迫**：把主角逼到墙角  
   - **爆发动作**：一个出人意料的、极其果断的举动  
   - **核心台词**：一句短促、冷硬、只有主角能说出口的话  
   - **静场余韵**：周围人的反应，或一个定格画面  

2. **名场面的检验标准**：读者看完之后，会不会想**把这段单独复制出来发到评论区或书友群**？如果不会，就不是名场面。

3. **设计名场面时，台词比动作更重要**。动作可以忘记，台词会被人记住。

**写作公式**
```
[压迫到极致] → [主角做出一个所有人没料到的动作] → [一句只有他能说的台词] → [全场静默/围观者反应] → [定格画面结束]
```

**示例**：沈拙在白三爷撕了借据之后，如果补一个名场面：
> 白三爷撕了借据，转身就要走。  
> “三爷。”  
> 白三爷停步。  
> 沈拙从雪里捡起那两半纸，当着他的面，**一口一口吃下去**。  
> “十八两的债，不是你撕的。是我拿命咽下去的。”  
> 全场鸦雀无声。  
> 白三爷第一次没接话，转身走了。

## 三十一、主角的“欲望”要“具体到不能再具体”

**问题诊断**：前三章沈拙的目标是“保住义庄、救师父、还债”，但这些目标**太大、太远、太模糊**。读者需要的是“他在这一章的欲望是什么”，以及这个欲望和下一章怎么衔接。

**核心概念**：爆款文主角的欲望必须**小到读者能看见，又大到读者想看他继续追**。比如“今天不被打死”“今晚把药钱凑齐”“明天天亮之前搞清楚这算珠是谁的”——这些目标小而紧迫，读者容易投入。

**创作规则（硬性）**

1. **每章开头要有一个“本章欲望”**，章末要么实现、要么受阻、要么反转。这个欲望要和上一章结尾的悬念衔接。

2. **主角的“大欲望”（救师父、查真相、拓七碑）必须拆成无数个“小欲望”**，每个小欲望都有明确的时间限定和阻力。

3. **禁止主角“走一步看一步”**。哪怕他表面不动，心里必须有盘算：“我必须在天亮前做到X，否则Y。”

**写作公式**
```
[本章开头：主角明确“我要做什么”] → [过程中遇到阻力] → [调整策略或硬扛] → [章末：结果+新问题] → [下一章开头接上]
```

## 三十二、网文的“世界观”要用“规则”代替“设定”——读者要的不是“这个世界有什么”，而是“这个世界怎么玩”

**问题诊断**：原文设定了“守夜人”“义庄”“七碑”“拓碑”，但**没有形成一套读者能理解和参与的“规则系统”**。读者不知道“守夜人的规矩有哪些”“拓碑的禁忌是什么”“义庄的账怎么算”。

**核心概念**：网文读者喜欢**规则感**，因为规则让世界可信，让主角的每一个胜利都有依据、每一个代价都有意义。规则不能只是设定说明，必须转化为**可预期的因果**。

**创作规则（硬性）**

1. **前五章内必须建立至少三条“世界规则”**，每条都有“因→果”关系：  
   - 规则一：守夜人给亡人合眼，亡人会给守夜人一个“念”——所以沈拙能拓碑（因），但必须还愿（果）。  
   - 规则二：义庄的冰窖能保尸身七日不腐——所以尸体到义庄（因），七日内必须入殓（果），过期会出问题。  
   - 规则三：青河镇的账，白家记一份，河伯记一份——所以白三爷撕了借据（因），河上的账没消（果）。  

2. **每条规则都要有“例外”或“代价”**，让读者觉得这个世界不是死板的。比如：冰窖能保七日，但“执念太深的人，第三天就会自己出来”。

3. **禁止用大段说明文交代规则**。规则要通过**违规者的下场**、**主角踩线后的反应**、**角色的台词**带出。

**写作公式**
```
[角色触犯或利用规则] → [规则生效：代价/效果立刻出现] → [主角认知到规则的具体边界] → [读者同时理解规则]
```

## 三十三、金手指的“租”属性要“具象化为债务”，制造道德压力

**问题诊断**：设定里写“力量是租的”，但前三章读者只看到“租”的代价（血、温骨、碑满人葬），没看到**“租”带来的道德亏欠感**——主角欠了死者的，必须还，不还就出问题。这个设定太重要，不能只当背景。

**核心概念**：金手指最妙的地方是“力量有债主”，债主是死人。这制造了**双重压力**：外部敌人+内部债务。读者会替主角焦虑：“他用了这力量，欠了谁的？怎么还？不还会怎样？”这个焦虑是追更的核心驱动力之一。

**创作规则（硬性）**

1. **主角每次使用拓来的能力后，必须有“欠债”的意识**：一个闪回、一句内心独白、一个身体反应，让读者知道“这笔债没清”。

2. **前五章内至少出现一次“债主要账”的暗示**：  
   - 使用刀法后，沈拙看见水面倒影里，一个模糊的人影多站了一瞬  
   - 梦里有个声音说“你用了我的刀，要还”  
   - 碑文变色/发烫的频率和债务未清有关  

3. **“还愿”要和主线剧情绑定**：过江龙的愿是什么？查他的死因？送他的遗物回家？这成为主角必须做的一件事，不仅是道德压力，还是**解锁更完整能力的钥匙**。

**写作公式**
```
[使用能力] → [短暂“债主”提示：画面/声音/身体异样] → [主角意识到“这笔债赖不掉”] → [催生一个明确的“还愿目标”] → [成为后续剧情驱动]
```

## 三十四、“白三爷”这个反派要“活”，不能只当账房

**问题诊断**：白三爷在前三章里是一个“体面的恶人”，算账清楚、不动声色，但**读者对他的恨意不够具体**。他压迫的是“沈拙的债务”，不是“沈拙在乎的某个人某件事”。恨意不具体，后续打脸就不够爽。

**核心概念**：网文读者恨一个反派，不是因为他坏，而是因为**他伤害了主角在乎的人或事，而且态度轻蔑**。反派的“可恨值”取决于他当着主角的面做了什么，以及他那副“你能拿我怎样”的表情。

**创作规则（硬性）**

1. **前三章内，白三爷必须当着主角的面做一件“越界”的事**：不是要债，而是**直接伤害主角在乎的人/物**，比如：
   - 用脚碾碎沈拙给师父熬药用的炭  
   - 把老癞头那口薄皮棺的棺钉一枚一枚拔出来，扔进火里  
   - 当众说“你师父那种人，死了连义庄的门都配不上”  

2. **反派必须有一次“给了希望又踩灭”的动作**：白三爷撕借据时，先让沈拙以为他真放手了，然后说“义庄的契，我等你师父死了再收”——让沈拙和读者同时从松一口气跌入更深的恨意。

3. **反派的“可恨值”要和主角的“克制”形成对比**。主角越忍，读者的恨越积越多，最后的爆发就越爽。

**写作公式**
```
[反派表面友好/公事公办] → [突然做出伤害主角在乎之物的动作] → [轻描淡写/期待主角的反应] → [主角忍下/记下] → [读者恨意+1]
```

## 三十五、章节之间的“钩子链”——每个悬念不能孤立，要像锁链一环扣一环

**问题诊断**：前三章的悬念分别是“木牌是什么”“尸身是谁”“算珠为什么动”，但**它们各自独立，没有形成一条“钩子链”**。读者觉得每个谜团都只是“后面会讲”，而不是“这一个谜团直接连着下一个，必须看下一章”。

**核心概念**：网文追更的核心是**“钩子链”**：这一章的答案，同时是下一章的问题。悬念不能“并列铺开”，必须“环环咬合”。

**创作规则（硬性）**

1. **每章结尾抛出的问题，下一章必须部分回答**，但回答的同时抛出一个更大的问题。  
   - 第一章结尾：木牌是什么？  
   - 第二章开头：师父看出是漕引（回答）→ 但它为什么会在过江龙手里？（新问题）  
   - 第二章结尾：白三爷撕了借据，但说“河上会替我讨回来”（新问题）  
   - 第三章：验尸吏姓晏，长命锁烫了（旧线索激活）→ 晏大人和锁有什么关系？（新问题）  

2. **每章至少“回扣”一次前文出现的道具/台词/人物**，让读者觉得“这本书有设计，作者没忘”。

3. **钩子链的画法**：  
   ```
   [问题A出现] → [答案A₁+新问题B] → [答案B₁+新问题C] → [答案C₁+新问题D]
   ```
   每一环都要咬住上一环，不能跳开另起。

**写作公式**
```
[上一章悬念/问题] → [本章开头给出部分答案] → [答案引出新的问题] → [本章结尾：新问题+紧迫感] → [下一章开头接住]
```

## 三十六、关于“晏大人”这个角色的开篇处理——要“先声夺人”不要“只闻其名”

**问题诊断**：前三章提了两次“验尸吏晏大人”，但只闻其名不见其人，而且这个名字本身对读者没有意义。要让它有重量，必须**提前用侧面描写把他的“影响”砸进剧情里**。

**核心概念**：网文里重要角色登场前，需要**“预亮相”**——通过他人的反应、环境的改变、某件物件的异动，让读者在见到他之前就感到压力或期待。

**创作规则（硬性）**

1. **角色未出场前，至少用三个“侧面信号”铺垫他的存在**：  
   - 赵保正提到“晏大人最烦呈文含糊”——此人在官场极严  
   - 耿老倌听到“姓晏”时，手里的铜锣差点掉地上——此人让老江湖都怕  
   - 沈拙领口的长命锁在听到“晏”时发烫——此人与主角有旧事  

2. **当角色真正出场时，必须让之前的铺垫“兑现”**：他的出现立刻改变现场气氛，或者做了一件只有他能做到的事（一眼看穿尸体异样、认出了木牌的真正材质等）。

3. **角色出场时机不能太晚**：如果前五章都在提他的名字，第五章结束时他至少应该“露脸”或“留下一个动作”。

**写作公式**
```
[角色被提及] → [在场角色反应：变脸/停顿/动作异常] → [环境或物件异动] → [主角察觉但不明说] → [角色出场时兑现所有铺垫]
```

## 最终补充：三份规则合并后的完整检查优先级（从读者点击到付费的全链路）

**第一秒（点击决定）**  
书名、简介、开篇100字——必须同时有“异常+主角特殊+危险逼近”。

**第一分钟（是否继续读）**  
500字内出现第一个抓人点；1000字内完成第一次“受迫+反抗”；3000字内完成第一次“金手指爽感循环”。

**第一章结束（是否翻页）**  
必须有带情绪的强悬念：某人/某物处于危险中，且有明确时限。

**前三章结束（是否加书架/追更）**  
- 一个清晰的金手指规则+成长路径  
- 一个让读者恨意的反派  
- 一个让读者牵挂的人物关系  
- 一个清晰的“收集进度条”  
- 至少一个名场面  
- 至少一次爽点、一次虐点、一次燃点  
- 主线谜团向前推进了至少三步  

**前十章结束（是否付费/持续追更）**  
- 至少一个反转改变了故事的走向  
- 主角的“中期目标”明确且激动人心  
- 至少一个“读者优越感”时刻让读者觉得“我看懂作者埋的线了”  
- 角色之间的情感债务开始产生利息（友情升温、仇恨加深、债主催账）  
- 读者开始“替主角算账”——钱、时间、代价、收益，全都心中有数

## 最终整合给 skill 的“灵魂三问”

每章生成前，先问自己：  
1. **这一章读者会不会爽到/揪心到/燃到？（至少一种，最好两种）**  
2. **这一章结束，读者不点下一章，会不会难受？**  
3. **这一章的信息和情绪，能不能支撑下一个500字让读者继续读下去？**

三问有一问不通过，这一章就不该生成。这不是文学判断，是网文存活判断。
