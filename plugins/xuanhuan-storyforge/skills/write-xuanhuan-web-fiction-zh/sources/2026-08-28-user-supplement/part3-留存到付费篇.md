# 补充二：爆款网文 skill 的“隐性规则”——从留存到付费

前两份规则解决了“怎么写”，但还没有解决**“为什么读者要留下来，以及为什么愿意付费”**。以下补充聚焦于免费章节必须完成的两个核心任务：**钩住读者**和**建立信任**。

---

## 十七、开篇前100字——用“动作+反差”抢人，禁止用“世界观/氛围”起步

**问题诊断**：原文第一句“沈拙把第三枚棺钉咬在嘴里，腾出手，替死人合眼”——画面感有了，但**冲击力不足**。读者三秒内没遇到“异常”，就可能划走。

**核心概念**：网文开篇前100字是“抢人”的战场。读者在信息流里滑动，看到你的书名和简介点进来，正文的第一屏决定了他留不留。**第一屏必须同时完成两件事：制造异常感 + 让读者知道主角不是普通人。**

**创作规则（硬性）**

1. **前100字内必须出现一个“异常”**：  
   - 一个不可能的动作（“他徒手把棺材钉按进棺板里”）  
   - 一句反常识的话（“老癞头说，今晚会死三个人，已经死了一个”）  
   - 一个不合时宜的场景（“送葬队伍从白家后门出来，抬的是空棺”）  
   - 一个与身份不匹配的能力（“沈拙没练过刀，但刚才那一刀，劈开的是骨头”）  

2. **前100字必须让读者感知到“主角身体里有东西”**，哪怕只是一个暗示：骨头发烫、掌心发麻、耳鸣、闻到尸体以外的味道。

3. **禁止前100字只写环境、天气、背景介绍、人物外貌。**

**写作公式**
```
[主角正在做一件不可能/极不寻常的事] + [身体异常信号：发烫/发麻/骨响] + [一句话点出与常人的不同] + [外界干扰/危险逼近，打断当前状态]
```

**改写示例**：
> 沈拙把第三枚棺钉按进棺板时，发现它自己往里钻了半寸。  
> 他松开手，钉子停住。掌心一条烫痕，像是被什么从里往外推。  
> 里屋，老癞头咳了一声：“又爬了？”  
> “爬了一道。”沈拙盯着棺材，“还会更烫。”

## 十八、“读者优越感”——让读者比主角先知道一部分真相

**问题诊断**：原文几乎所有信息都和主角同步，读者没有“上帝视角”带来的优越感，就没有“我看穿了但主角不知道”的追更动力。

**核心概念**：网文读者爱追更的一个重要心理机制是**“比主角多知道一点”**。当读者看到主角即将踩进一个坑，或者即将遇见一个他认不出的人，读者的期待感会成倍放大。

**创作规则（硬性）**

1. **每3章至少出现一次“读者知道但主角不知道”的信息**，形式可以是：  
   - 白三爷深夜见了一个人，说的某句话被读者看到（但主角在场外）  
   - 配角在一场戏里做出一个意味深长的表情/动作，主角没注意，但读者看到了  
   - 一件物件的真实来历通过其他角色或细节透露给读者，主角还被蒙在鼓里  

2. **禁止所有信息都通过主角视角呈现**。可以穿插“摄像机离开主角”的短镜头，但**每章最多一次，每次不超过200字**，且必须有信息价值。

3. **“读者优越感”不能变成“读者全知”**。只比主角多一步，不能多十步。多一步，读者会替主角着急；多十步，读者会觉得主角蠢。

**写作公式**
```
[主角离开/分神的瞬间] → [短镜头切到对手/配角] → [一句台词/一个动作暴露真相] → [切回主角视角] → [主角毫不知情，继续行动]
```

**示例**：第三章白三爷退场后，可以加一段：
> 白三爷进了内堂，反手合上门。  
> 屏风后头，一只枯瘦的手伸出来，接住他脱下的外袍。  
> “三爷，那孩子身上的东西，不是木牌。”  
> “我知道。”白三爷盯着镜子里自己的眼睛，“是他师父的手太长了。”  
> “那还留着？”  
> “留。留着他自己来找我。”

## 十九、“资源稀缺”必须“可视”——读者要能替主角算账

**问题诊断**：原文有十八两借据、九节风涨价、温骨七日这些经济线索，但**没有形成清晰的“账本感”**。读者不会主动替主角算账，所以“穷”“缺时间”“缺资源”的压迫感打了折扣。

**核心概念**：网文读者喜欢“替主角算账”。当读者能算出主角的危机、算出路、算出买卖是否划算时，他们的参与感会极强。要给他们提供**可量化的数字**。

**创作规则（硬性）**

1. **核心资源必须数字化**：  
   - 钱：具体到文和两（“十八两”“浆水一文”“九节风三包一百二十文”）  
   - 时间：具体到更次和天数（“三日”“卯时三刻”“温骨七日”“验尸吏后天到”）  
   - 代价：具体到数量（“一口血”“一碗血”“七碑”“还剩六道”）  
   - 战力：具体到等级和数量（“炼血五重”“一刀断刀”“十三年刀龄”）  

2. **每章至少出现一次“数字化的资源变化”**：花了一笔钱、少了一天、多了一道碑、打死了一个人。

3. **关键资源的“性价比”要借角色之口点出**，让读者觉得“这笔账主角算得过来”，或者“这笔账主角算不过来，所以他必须冒险”——两种都能催生期待。

**写作公式**
```
[资源条目] + [具体数字] + [变化方向（增/减）] + [主角心中盘算一句话] + [读者可感知的紧迫感/划算感]
```

## 二十、“降级打击”与“越级挑战”要交替出现，不能只打平级

**问题诊断**：前三章所有冲突对象都是曹六（炼血五重）和白三爷（更强），主角一直处于“弱者反抗”的位置。读者虽然同情，但**缺少“主角也有绝对优势时刻”的平衡感**。

**核心概念**：爆款文的爽感来源之一是**“降维打击”**——主角在某一个维度上碾压对手，这个维度可以是信息、技能、胆量、后台，不一定是战力。哪怕主角整体弱，也要在某些时刻让读者觉得“这局稳了”。

**创作规则（硬性）**

1. **每5章内至少有一个“降维打击”场景**：主角用某个对手完全不具备的优势解决问题，让读者产生“他活该”的痛快感。  
   - 沈拙不懂修炼，但他懂死人、懂守夜人的规矩、懂义庄的每一个角落  
   - 曹六炼血五重，但沈拙在义庄里埋了十几年的机关（如果设定有）  
   - 白三爷会算账，但沈拙比他更懂“死人的账”

2. **降维打击的场景要点**：  
   - 对手自信满满进入主角的“主场”  
   - 主角用对手完全没预料到的方式解决战斗（机关、规矩、死人留下的东西）  
   - 对手败退时留下“你怎么会”的错愕，主角不解释  

3. **禁止主角始终只靠新获得的金手指打人**，要偶尔用“守夜人的本行”或“人情算计”赢得一场。

**写作公式**
```
[对手进入主角主场] → [对手暴露依赖某种优势（武力/权势/信息）] → [主角不接这个维度，换一个对手不懂的维度] → [对手错愕] → [主角不说话/只留一句让对手发毛的话]
```

## 二十一、金手指的“稀缺性”要靠“别人没有/别人想要”来强化

**问题诊断**：拓碑的能力目前只有主角有，但文中没有展示**别人多么想要这个能力**。一个没有人觊觎的金手指，稀缺性立不住。

**核心概念**：金手指的稀缺性不是自己说出来，而是**由别人的反应证明**。当读者看到别人为这个东西撕破脸、杀头、倾家荡产，他们就会觉得主角捡到了宝。

**创作规则（硬性）**

1. **前五章内至少出现一个“别人也想要这个能力”的暗示**：  
   - 白三爷为什么对一个守夜学徒如此关注？仅仅因为义庄的地？  
   - 师父为什么不让活人碰长命锁？  
   - 晏大人验尸，验的是死因，还是“尸体上有没有被拓过碑”？  

2. **“别人想要”最好是“知道这东西存在但不知道怎么用”，或者“知道怎么用但没有资格用”**——这样主角的独特性更强。

3. **每有一个新角色出场，都要问：他对拓碑的事知道多少？他的贪欲是什么？** 这个问题的答案决定了这个角色和主角的关系走向。

**写作公式**
```
[新角色出现/旧角色动机揭示] → [他对金手指的态度：知道/不知道/想要/恐惧] → [用一个细节或台词点出] → [主角察觉或未察觉]
```

## 二十二、“七碑为限”要转化为“收集清单”，给读者一个可预见的“进度条”

**问题诊断**：设定里写“七碑为限，碑满人葬”，但前三章只拓了一道，读者对“还剩六道”没有具体期待——因为不知道每一道碑对应什么、从哪来、难不难。

**核心概念**：爆款文的“收集流”之所以抓人，是因为**读者有明确的进度期待**。每获得一样东西，读者都能感觉到“离目标更近了”，同时“离代价也更近了”。这个双重张力是追更核心。

**创作规则（硬性）**

1. **前三章内必须给出“收集清单”的雏形**：七道碑分别可能来自哪些人/什么地方/什么领域。不必全亮，但至少亮出两三个候选：  
   - 第一道：过江龙（刀法）——已拓  
   - 第二道：义庄后山埋着的那个灭门案死者的遗骨（控风/其他）  
   - 第三道：河伯庙里被铁链锁着的那尊“河神像”底下的骸骨  
   - 第四道：白家祖祠里供着的一具无碑尸……  

2. **每获得一道碑，必须在章节末尾更新“收集进度”**：  
   - “碑一：过江龙·断江十三手（半式未刻全）——还差还愿”  
   - “碑二：未知——等待触发”  
   让读者觉得自己在跟着主角一起“集卡”。

3. **“还愿”要成为每道碑的“售后任务”**：拓完碑不是结束，要替死者还愿才能“固碑”。这个设定太重要了，前五章必须让读者知道——因为它是**金手指的持续驱动**，逼着主角去查每一个死者的故事。

**写作公式**
```
[获得一道碑] → [碑文/技能不完全（触发还愿任务）] → [主角发现还愿所需的条件/对象] → [新目标出现：完成还愿] → [碑才算真正归自己]
```

## 二十三、女性读者/泛读者向的“情感安全网”——主角对弱者的态度要“有原则的好”

**问题诊断**：沈拙这个角色冷硬护短，但如果他连对普通镇民都冷，读者会觉得他“太独”，缺少“人情味”带来的安全感。网文爆款主角普遍“对敌人狠，对自己人护”，两者越极端越出圈。

**核心概念**：读者追网文，本质上是**把自己代入主角的“保护范围”**。主角对“自己人”越好，读者越有安全感。冷硬型主角必须有一个**柔软的锚点**，通常是老人、孩子、弱者或小动物。

**创作规则（硬性）**

1. **前五章内主角至少对三种“弱者”展现出保护欲**：  
   - 对师父（病中老人）：掖被角、熬药、把最后一口参汤让出去  
   - 对何婶（市井妇人）：喝光浆水、碗底压钱、在何婶被白家为难时站出去  
   - 对耿老倌（残疾老人）：主动替他挡曹六的刀、把绳子解了  

2. **这些“保护动作”必须是具体的、可被读者记住的**，不是一句“他对街坊都很好”带过。

3. **主角的保护不能是“圣母式”的**，要有代价、有选择。比如：何婶的锅盔他自己没吃，饿着肚子去济生堂；替耿老倌挡刀，让他自己的伤口裂了。

**写作公式**
```
[弱者受欺压] → [主角出手，方式不华丽但有效] → [弱者用最朴实的语言表达感激] → [主角心里一句话：这是我该做的/这债我记着]
```

## 二十四、章节内“信息量”与“情绪量”要交替出现，不能一坨情绪一坨设定

**问题诊断**：原文整体偏“情绪流”，设定信息散在其中，有些段落情绪浓但信息量低，有些段落信息多但情绪断了。

**核心概念**：网文章节的最优结构是**“情绪—信息—情绪—信息”交替**，保证读者在情绪中记住信息，在信息中消化情绪。单方面过多都会导致读者流失。

**创作规则（硬性）**

1. **每300字内至少完成一次“情绪↔信息”的交替**：  
   - 情绪段（有人说话/冲突/回忆）  
   - 信息段（新线索/新设定/新人物身份）  
   - 情绪段（反应/决断/行动）  
   - 信息段（结果/规则/时间）  

2. **禁止连续500字以上只有情绪没有新信息，或只有信息没有情绪。**

3. **信息段要“接着情绪段的需求给”**：读者在情绪段里产生的疑问，在信息段里得到回答。不答的，留到下一章。

**写作公式**
```
[情绪场景] → [角色间张力/冲突] → [产生问题：这是什么？他是谁？为什么？] → [信息段：回答问题或给出新线索] → [情绪承接：主角对这个信息的反应/行动]
```

## 二十五、“追读惯性”的最后一块拼图——每3章必须有一个“大反转”

**问题诊断**：前三章整体是“压迫→反抗→小胜”的直线，缺少“原来是……”的认知反转。没有反转，读者就少了“这本书不套路”的惊艳感。

**核心概念**：网文读者在免费期的弃书率最高的地方，往往是在他们觉得“我能猜到后面了”的时候。反转不需要多，但**每3到5章必须有一个小反转**，让读者觉得“这本书有意思，不能按套路猜”。

**创作规则（硬性）**

1. **反转的类型**：  
   - **身份反转**：一个看起来是敌人的角色突然帮了主角（邬先生压银子是个好例子，但可以更狠一点）  
   - **信息反转**：主角以为A，结果真相是B（木牌不是缉私牌，是漕引，就是一次成功的小反转）  
   - **立场反转**：一直帮主角的人，突然在关键时刻沉默或退让（赵保正可以有这个苗头）  
   - **能力反转**：主角以为自己拓的是刀法，结果这刀法里有一样别的东西（比如一套刀法里藏着一句漕帮暗语）  

2. **反转的时机要精准**：要么在章节结尾抛出让读者“啊？”的点，要么在章节开头用反转解释上一章的悬念。

3. **反转必须有铺垫**，让读者回头想觉得合理，不能硬转。

**写作公式**
```
[铺垫：前文一个细节/一句台词/一个动作被读者忽略] → [反转点：真相揭开，主角或读者恍然] → [反推：之前那些细节的意义被激活] → [主角调整策略/进入下一阶段]
```

**示例**：第四章如果安排反转，可以这样：
> 沈拙一直以为师父只是青河镇的赤脚正骨匠。  
> 直到他看到师父从床底抽出一个油布包，打开，里面是七枚一模一样的棺钉。  
> 每一枚钉子上，都刻着一个他小臂上那种发白的字。  
> “你拓了一道碑，”老癞头说，“就该知道，我不是第一个。”

## 二十六、“付费转化”思维——免费章节的最后200字决定读者是否点“下一章”

**问题诊断**：这份规则目前都聚焦在“留人”，但网文的终极目标是**让读者翻到最后一页后，心甘情愿地点“下一章”甚至“付费”**。免费章节的结尾必须制造“不点下一章就难受”的焦灼感。

**核心概念**：付费转化的核心心理不是“好奇”，而是**“不忍心放下”**。读者想知道结果，但这种想知道必须带情绪（担忧、愤怒、揪心），而不是纯智力好奇。

**创作规则（硬性）**

1. **每章结尾的悬念必须带“情绪”**，不能只是“发生了什么？”而必须是“他怎么办？”“她会不会死？”“这账怎么算？”  
   - 弱结尾：“那扇门开了。”  
   - 强结尾：“那扇门开了，师父就站在门口，手里提着他三天前说‘卖了’的那口薄皮棺。”

2. **章节结尾的三种最有效的情绪钩子**：  
   - **担忧钩**：主角/重要的人陷入危险，下一章生死未卜  
   - **愤怒钩**：对手做出让人牙痒的事，主角还没反击，但读者已经想替他打  
   - **温暖钩**：在读者最冷的时候给一个微弱的希望，让人不忍心放手  

3. **禁止用“他睡了”“天亮了”“雾散了”等无情绪波动的句子作为章末。**

**写作公式**
```
[本章最后一个情节] → [出现新变量/危险/反转] → [主角或关系人面临即时选择/威胁] → [抛出带情绪的悬念] → [章节结束，不给结果]
```

## 最终全维度检查清单（合并前两份，按检查顺序排列）

**第一优先级：读者会不会留下来**
- [ ] 开篇前100字有“异常”+“主角异常信号”？
- [ ] 每500字至少一个抓人点（信息/情绪/动作/悬念/金句）？
- [ ] 第一章内完成至少一次“金手指爽感循环”？
- [ ] 第一章结尾有带情绪的强悬念？
- [ ] 前三章内出现至少一次“读者知道但主角不知道”？

**第二优先级：读者会不会追下去**
- [ ] 每3章一个小反转？
- [ ] 每章结尾有“具体的下一步目标”+阻力+时限？
- [ ] 主线谜团每章有新推进？
- [ ] 打脸分三层递进（破防→碾压→定性→余韵）？
- [ ] 收集/成长进度条有更新（数字、数量、等级）？

**第三优先级：读者会不会代入**
- [ ] 每章至少一个情绪支点？
- [ ] 每章至少一次“暖”的情绪（对弱者/同伴的保护）？
- [ ] 金手指代价与收益在同一章内兑换，读者觉得“值”？
- [ ] 主角对敌人狠、对同伴护、对弱者有原则的好？
- [ ] 配角有私心，不是工具人？

**第四优先级：读者会不会记得**
- [ ] 金手指有固定视觉意象（颜色、状态变化）？
- [ ] 核心资源数字化（钱、时间、数量、等级）？
- [ ] 每章对话中有至少一句“只有主角能说”的狠话？
- [ ] 每处环境描写至少有一个功能（压情绪/暗示危险/埋线索）？
- [ ] 每章切换至少三种情绪（冷→暖→狠/爽→疑）？

**第五优先级：读者会不会掏钱**
- [ ] 免费章节最后200字是“不忍心放下”型悬念？
- [ ] 至少一个“收集进度条”让读者想看到最终结果？
- [ ] 至少一个“别人也想要金手指”的暗示，让读者替主角捏把汗？
- [ ] 至少一个“还愿固碑”的持续驱动力，保证长线任务？
- [ ] 主角有一个具体、可视、有难度的中期目标？

## 给 skill 的最终整合说明

把三份规则合并进 skill 时，建议按以下结构组织：

```
【生成前检查】开篇100字钩子设计 → 本章核心爽点循环规划 → 本章悬念设计
【生成中约束】每500字抓人点 → 情绪↔信息交替 → 环境功能性 → 对话压迫感
【生成后校验】18项检查清单 → 不达标记为“不合格”并自动改写
【滚动规则】每3章一个反转 → 每章结尾目标感 → 主线谜团持续推进 → 收集进度条更新
```

**最核心的一条**：你前三章文笔已经到位，缺的是**对“读者当下感受”的精准把控**。这套 skill 的本质不是教 AI 写“更好的文学”，而是教它写**“让读者在这一秒不想放下手机”的网文**。
