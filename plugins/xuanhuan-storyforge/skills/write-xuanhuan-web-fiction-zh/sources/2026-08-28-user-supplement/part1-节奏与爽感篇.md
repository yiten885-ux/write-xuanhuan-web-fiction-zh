以下规则与公式可直接嵌入你的小说创作 skill 中，作为生成时的“硬约束”和“检查清单”。目的是强制 AI 模型在每一章生成时，优先满足网文读者的爽感、情绪、悬念需求，而非只堆砌氛围和设定。

---

## 一、金手指爽感循环——前三章强制触发

**问题诊断**：只写代价不写收益，只写被动防御不写主动碾压，战果不放大。

**创作规则（硬性）**  
1. 第1—3章内，必须完成**至少一次完整的“爽感循环”**，否则判定章节不合格。  
2. 爽感循环的五个环节缺一不可：  
   - **触发**（遭遇危机/对手/绝境）  
   - **代价**（主角付出明确成本：一口血、温骨、疼痛等，一句话带过即可）  
   - **获得/使用**（立刻使用金手指能力，不能拖）  
   - **战果放大**（具体写出效果：一刀断门闩、一刀断刀、对手退五步、虎口崩裂等，并给围观者反应镜头）  
   - **认知升级**（主角内心一句“这力量比我想的还强”或“这刀法我从未练过，骨头却认识”，让读者和主角同步爽到）  
3. 禁止出现“金手指生效后立刻切场景”或“只写主角吐血不写对手吃亏”的写法。

**写作公式（可直接给 AI）**  
```
[危机出现] → [主角付出代价（一句话）] → [金手指发动（动作+效果特写）] → [对手受伤/败退+数值或细节] → [围观群众震惊台词] → [主角内心独白确认力量] 
```
**示例要求**：每章至少一个“爽点镜头”，且镜头必须完整，不能只写开头不写结果。

## 二、主角情绪钩子——每章至少一个“情绪支点”

**问题诊断**：主角全程冷脸，没有内心波动，读者无法共情。

**创作规则（硬性）**  
1. 每章至少出现**一个主角的情绪支点**，形式可以是：  
   - 一句带情绪的内心独白（愤怒、心疼、冷笑、狠话）  
   - 一个身体反应（握拳、咬出血、眼眶发红但没掉泪、手抖后强稳）  
   - 一个决定性的动作（把铜钱踢出栅栏、把地契贴身收好、给师父掖被角）  
2. 禁止主角全程面无表情、只做客观动作。  
3. 情绪支点必须与当前情节强相关，不能为情绪而情绪。

**写作公式**  
```
[外部压力/事件] → [主角身体反应] → [主角内心一句台词/价值判断] → [后续行动]  
```
**示例要求**：在生成正文时，检查是否出现“沈拙咬住后槽牙”“他把那枚铜钱踢出去”“他在心里说：这账我记下了”等可感知的情绪标记。

## 三、钩子式人物关系——重要人物出场绑定羁绊

**问题诊断**：人物只是功能化出现，读者不关心他们死活。

**创作规则（硬性）**  
1. 每个重要人物（师父、女主、对手、伙伴）出场时，必须**用一句话交代与主角的情感债权/债务关系**，让读者立刻知道“这个人对主角意味着什么”。  
2. 禁止人物出场只做功能性对话（比如只通报消息、只交代背景）。  
3. 人物关系要有一个**可牵挂的具体目标**：  
   - 师父：随时可能断药，主角要凑药钱  
   - 耿老倌：曾经救过主角，主角欠他一条命  
   - 白三爷：害死主角父亲/毁掉师父的仇人  
   - 女主/伙伴：与主角有未完成的约定  
4. 该目标必须在前五章内被提及或暗示，让读者产生“这个人千万不能出事”的担忧。

**写作公式**  
```
[人物出场] → [一句话揭示关系/羁绊] → [当前互动中加入一个可牵挂的细节] → [主角内心反应] 
```
**示例**：耿老倌出场时，不只是说“河滩上捞了尸”，而是“耿老倌跛着脚进来，沈拙看见他裤腿上的泥，想起三年前就是他把自己从乱葬滩背回来，这条腿就是那时候断的。”

## 四、第一幕钩子——每章结尾必须有强悬念

**问题诊断**：章节结尾平淡，读者没有“我必须看下一章”的冲动。

**创作规则（硬性）**  
1. 每章结尾必须留下**一个具体、紧迫、可感知的悬念**，不能只是环境描写或抒情收尾。  
2. 悬念类型可以是：  
   - 时间倒计时（三天后、卯时三刻、天亮前）  
   - 新危险逼近（马蹄声停在门口、白三爷说“河上会替我讨回来”）  
   - 谜团加深（算珠自己转了半圈、木牌发烫、碑文偏移）  
   - 人物命运未知（师父突然咳血、同伴被抓走）  
3. 下一章开头必须**接住上一章悬念**，不能跳开。  
4. 禁止用“他睡下了”或“夜深了”这种无钩子收尾。

**写作公式**  
```
[当前问题解决/暂缓] → [新危险或新谜团出现] → [给出一个让读者忍不住追问的问题] → [有时限或代价] → [章节结束] 
```
**示例**：第三章结尾不是“他回屋睡了”，而是“那枚算珠在案上自己转了半圈，沈拙的小臂碑文像被什么拽着往左偏。他猛地回头，门外的雾气里，似乎站着一个人影。”

## 五、网文读者要的“东西”——框架性信息必须前移

**问题诊断**：金手指规则、修炼体系、升级路径给得太少，读者没有成长预期。

**创作规则（硬性）**  
1. 前三章内，必须交代清楚以下至少三项：  
   - **金手指规则**：七碑为限、碑满人葬、拓碑承技、承执念、还愿固碑、一碗血加七日温骨（可简略但要有）  
   - **升级路径**：主角短期目标（保住义庄、救师父）→中期目标（拓七碑、解河伯之局）→长期目标（查出父亲死因/超脱七碑限制）  
   - **力量天花板/世界观框架**：修士等级、白三爷是什么级别、义庄在这盘棋里的位置  
2. 禁止只展示局部不交代全局，让读者完全摸不着头脑。  
3. 交代方式要自然，通过对话、内心独白或师父的只言片语带出，不能大段说明文。

**写作公式**  
```
[触发事件] → [主角/他人主动提及金手指规则或世界观] → [主角确定一个可量化的短期目标] → [给出长期愿景暗示] 
```

## 六、风格硬约束——砍环境、对话刀、少回忆

**问题诊断**：环境描写过多、对话绵软、插叙打断节奏。

**创作规则（硬性）**  
1. **环境描写占比**：每章环境描写总字数不超过该章总字数的15%。只保留“承载情绪或功能”的环境细节（比如雪夜火光、冰窖寒气、灯花爆响），删除纯氛围铺陈。  
2. **对话要求**：  
   - 每段对话不超过三句，短句为主。  
   - 对话必须有“刀”：反问、威胁、回击、信息差。  
   - 禁止大段解释性对话，禁止人物说“你应该知道……”之类的废话。  
   - 对话中至少有一句让读者想截图的狠话或金句。  
3. **回忆与背景穿插**：  
   - 回忆只能由当前情节直接触发，且用一句话带过，不展开完整场景。  
   - 禁止在关键动作或对话中插入大段回忆。  
   - 如需交代背景，拆碎分散到多个章节的对话或动作中。

**写作公式（对话）**  
```
[对方挑衅/提问] → [主角短句回答+反击/反问] → [对方反应或沉默] → [主角补一刀或转身离开] 
```
**写作公式（环境）**  
```
[一个功能性环境细节] + [人物动作] + [情绪/氛围收束]  
```
**示例**：“雪粒子从檐口漏下来，落在契书上。沈拙把木牌按在契书正中，雪水洇湿了‘十八两’三个字。”

## 附：每章生成后自动检查清单（可直接写入 skill 校验层）

- [ ] 本章是否完成了至少一次金手指爽感循环？（是/否）  
- [ ] 主角是否出现了至少一个情绪支点？（是/否）  
- [ ] 是否出现了让读者牵挂的人物羁绊或目标？（是/否）  
- [ ] 章节结尾是否有强悬念，且下一章开头能接住？（是/否）  
- [ ] 是否交代了金手指规则/升级目标/世界观框架中的至少一项？（是/否）  
- [ ] 环境描写占比是否低于15%？（是/否）  
- [ ] 对话是否短、刀、有回击？（是/否）  
- [ ] 是否有大段回忆或背景插叙打断主线？（是/否，若有则删改）  

**优先级排序（按网文读者留存逻辑）**：  
爽感循环 > 章节末尾悬念 > 情绪支点 > 人物关系钩子 > 金手指规则/世界观 > 文风精简。

将以上规则和公式写入你的 skill 后，AI 生成正文时会自动按照“先给爽点、再给悬念、最后补设定”的顺序组织内容，从而弥补原有模型在网文节奏上的缺口。
