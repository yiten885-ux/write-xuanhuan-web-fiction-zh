## 缺的硬规则（按爆款因果，不是按条数）

番茄爆款链路是：

**书名拦住点击 → 三章完成觉醒+打脸+钩 → 每章供爽 → 换图不掉速 → 追读撑算法 → 8 万验证 / 30 万在读**

当前 skill 从「三章打脸」开始写，前面和后面两截是空的。

### P0　产品入口（缺了，书根本进不了池）

这些在 `rule-07` 里有原文，**`SKILL.md` 没有 FAIL-IF**。

| 缺的硬锁 | 最小验收 | 现状 |
|---|---|---|
| **书名三件套** | 身份处境 + 金手指 + 结果预告；禁文艺/意境/纯世界观名 | 对 11 只查「正文有没有书名关键词」，不生成、不验收书名 |
| **简介三段** | 困境 → 金手指 → 爽点预告；禁史诗开场白 | 无 |
| **读者画像一口锁定** | 平台（番茄/起点/飞卢）+ 性别频 + 年龄带 + **这本书替读者报哪口气** | 无。没有代偿，12 货就是盲发 |
| **熟套路 + 一个新拧法** | 主套路必须是读者认识的；金手指「做什么/怎么做/代价」至少一项是新拧，不能只换皮 | 5.18.7 稀缺性有雏形，但「未检索就不声称」= 生成时等于没查。缺 **新拧法一句锁** |
| **标签/分类/封面文案对齐** | 三镜从书名扩到标签。卖退婚就不能写成权谋封面 | 无 |

爆款第一刀常常砍书名，不砍第三章智斗深度。

### P1　人设魅力（缺了，追读第二周死）

`character-emotion.md` 是文学人设（弧光、爱情、主体性）。爆款要的是 **可转述的态度**。

| 缺的硬锁 | 最小验收 |
|---|---|
| **态度四选一** | 杀伐 / 苟 / 装 / 嘴炮，全书锁死至少一样，且每 3 章有一次态度兑现（R07-11、R07-17） |
| **一句话可转述** | 「废柴觉醒杀伐果断」「反派重生专坑气运之子」——读者能转述才有传播 |
| **道德底线矩阵** | 开书钉死：什么人可杀、什么场面不跪、收不收女主、护短边界到哪。圣母/变态都是人设崩，不是文笔问题 |
| **人设不崩** | 禁杀伐突然圣母、装逼变成真烦人、嘴炮变演讲三观。这是 30 万停住的经典死法，§7 长篇防崩只有软建议 |
| **有趣配额** | 每章 ≥1 句只有这张嘴能说的话（留 12 有苗头）。现语言合同禁感叹、禁比喻、心理 ≤2 成，会把嘴炮人格写没 |

没有态度锁，模型会写成「正确、隐忍、代价沉重的合格主角」——审计全过，读者觉得闷。

### P2　金手指是商品，不是暗黑设定

结构（四拍、隐藏层、边界）有了。商品性没有。

| 缺的硬锁 | 为什么是硬的 |
|---|---|
| **当章能用** | 禁「攒 50 章才变强」。对 02 要求四拍，没写成「当章改变处境」 |
| **读者看见数字在涨** | 任务进度、装逼值、杀敌掉宝、境界对照。现在强调不可逆抽象损耗，数字涨感被压下去 |
| **金手指服务人设，不替代人设** | 外挂给刀，翻盘必须是态度落地。现在智斗三层 + 外挂副作用，主角容易变成解题器 |
| **通胀死亡** | 无敌来太早 / 杂役章发仙帝。S06 有「只 +1 级」，缺 **全书天花板时间表**：第几章能打谁、第几章绝不能无敌 |
| **限制用来吊下一章** | 冷却、槽位、隐藏功能。不是每章叠加更恐怖的记忆缺失 |

### P3　中后期保命（§7 太软，这是 10 万→30 万的主因）

`story-design.md` 和 §7 是检查维度，不是硬锁。`rule-07` 的死法表没有 FAIL-IF。

| 缺的硬锁 | 阈值建议 |
|---|---|
| **升级必须换地图** | 同一张图反复打同级反派 = 10 万在读停住（R07-16） |
| **换图不掉速** | 新图第 1 章必须用冲突教新规则，禁止观光/重讲设定专章（R10 在参考里，不在 §5 总锁） |
| **开局骗量检测** | 前 10 章货级若高于后 10 章，强制判定通胀/空窗，回滚后段而不是再加钩子 |
| **阶段门** | 8 万=验证考卷；30 章附近必须大爽或换图；50 章必须改一条本图规则。现只有「10 章小副本」 |
| **配角功能锁** | 有名配角必须是：踩踏石 / 见证者 / 资源包 / 下图 Boss 预告 之一。禁功能漂移成话痨 |
| **后宫配额** | 默认非必须；感情线不得抢主爽链；真香保持后悔药，不收当女主（R07-19 未升格） |
| **旧债回收表** | 具名仇账本卷见血或废；禁「先变强十年」。复仇货有这条，全书债务账没有滚动审计 |

### P4　付费与算法（留 26 只卡了末 200 字情绪）

| 缺的硬锁 | 说明 |
|---|---|
| **付费卡点章位** | 番茄常见免费 8–12 章。卡点必须是中爽半揭或更高层进场，禁微爽/纯意象 |
| **有效推进** | 每章必须改桌子（标的/名分/数字/权限至少一项）。现用微爽点冒充推进 |
| **日更/注水** | 运营层可以不写进正文 skill，但要有「连续 2 章 0 兑现=废章」的跨章硬闸（节奏参考里有，生成闭环没强制跑） |
| **追读句** | 不是「有钩」，是读者能复述「下一章他必须去干一件具体的事」。留 09 有目标，缺复述验收 |

### P5　执行层漏洞（规则在，生成时打不中）

这是最大的系统漏洞。

1. **`SKILL.md` 约 10 万字符。** 模型先吞完全文，再按需读 5–10 份参考。场面锁、留存锁、对齐锁、衬、NPD 叠在同一章。结果是：填卡 > 写正文，写出来的是合格审计件。
2. **`rule-07` 未升格。** 26 份报告里最像「爆款说明书」的一份，只活在 `rules/`，不进 §5 合取合同。
3. **审计盲区是设计出来的。** `audit_chapter.py` 明确不查爽点语义、通胀、人设、换图、稀缺性。机械 PASS 会被当成「这章能发」。
4. **T072、T078 在套路索引里跳号**，96 库不完整，还不是主伤。

## 现有硬锁里会杀死爆款的「反规则」

缺规则是一层；**错规则更伤**。下面这些现在是默认强制，和番茄爽文目标相反。

| 现有锁 | 它会写成什么 | 爆款实际要什么 |
|---|---|---|
| **SYS-COST-03** 每次使用都种不可逆抽象损耗 | 暗黑恐怖金手指，读者越用越怕 | 数字在涨、冷却在走、隐藏功能在吊 |
| **5.20C 代价恐惧每章递增** | 外挂变成诅咒 | 代价分级，大代价绑大爽，日常小用不能越用越恶心 |
| **5.20 痛感峰值：读者不希望他做、但必须做** | 悲剧选择 | 爽文选择应是读者正想看他做的（反击、不接、原句奉还） |
| **PLOT-MIND-02 每次对峙三层智斗** | 起点老白权谋 | 番茄默认打脸/装逼/掉马；7:2:1 说武力为主，这条又强迫每场套娃 |
| **END-HOOK-05 默认客观异变**（死物复苏/金手指失控） | 悬疑气质 | 债的嘴巴应是「更高层看见」，不是每三章闹鬼 |
| **意外型翻盘 ≥60%** | 主角被动撞大运 | S11 要「方向猜对、幅度猜小」。意外过高 = 外挂代打 |
| **HOOK-EMO-01 超凡动作晚于第 3 段** vs **对 02 第 1 章跑通四拍** vs **R07-04 当章觉醒** | 模型左右为难，开篇要么金手指出晚，要么四拍假跑 | 前 300 字冲突 + 第 1 章最小弹，这才是番茄 |
| **R07-14 打脸装逼每章都要** vs **S07 连续 3 章禁同型** | 未调和 | 需要「微打脸可每章，主货必须轮换」 |
| **语言合同过死** | 合格公文网文 | 爆款要一张可识别的嘴。金句白名单应对抗禁用词，而不是一起被砍 |
| **原则 4：不承诺爆款** | 诚实，但变成不写市场合同的借口 | 不承诺市场结果，必须承诺产品结构：书名/简介/拧法/阶段门 |

对 03「先满后亏」和 5.1「代价当场转化」已经在打，口径表写了适用域，生成时仍容易两头都写，节奏黏。
